# 研究名著的依据

麦基《故事》第一、二章强调通过研究和实践理解结构、背景、人物与类型如何协同。场景参考据此保留完整语境，让写作者观察人物处境、选择、反应与表达如何共同产生作用。

MUSE 将原文与可追溯的分析并列供给，是项目的上下文设计。麦基的“记忆、想象、事实研究”涉及创作者认识生活和题材的方法，不能分别等同为模型预训练、设计阶段和 few-shot 检索，也不能据此声称读取原文必然改善生成。

迁移时先找成立条件。例如同一句拒绝，在敌对谈判中可能阻断交易，在亲密关系中可能是试探；只有当前关系、已知信息与后续反应支持，来源机制才适用。词句、节奏与叙述距离也需要当前叙述者和媒介支持。相关性分数用于找到材料，实际适配由这些条件判断。

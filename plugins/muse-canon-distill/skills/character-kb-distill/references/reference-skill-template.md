# 知识库角色 SKILL 模板（reference 模式）

参考包供设计者理解来源人物；不初始化 state.md，不直接扮演。身份与处境必备，其余章节按证据生成；保留下列章节名称便于查询与画像提取。没有依据的条目或章节省略，已知覆盖缺口写入 build-meta.coverage_note。

## SKILL.md 模板

不设 `context: fork`，工具只给 Read。

```markdown
---
name: {role-slug}
description: {中文角色名}（{书名}） — 知识库参考角色，仅供加载，不扮演
version: 1
allowed-tools: Read
---

# {中文角色名}（{书名}）

## 身份与处境

{身份、关系和故事时点；区分成长环境、所属群体与自我认同。}
佐证：{实际原文相对路径，如 scenes/scene_S05.md:L10-L25 或 full_text.md:L10-L25}

## 核心欲望

{已成立的自觉目标与追求；只有行为证据支持时才写不自觉欲望或妨碍追求的稳定弱点。分析解释与人物自述分别说明，不把不自觉欲望等同于“健康的真正需要”。}
佐证：{定位}

## 性格真相

{具体压力中的选择及其显示的性格；若与外在印象有裂隙，说明裂隙如何成立；一致的表里也可记录。}
佐证：{定位}

## 声音框架

{有辨识度的表达倾向及其随对象、话题、压力的变化；保留原文支持的词汇或称呼，不规定固定句长。}
佐证：{足以支持概括的原文定位}

## 边界（条件与强度）

- {适用阶段和处境 → 倾向、承诺或强底线；说明被限制的行为及支持强度} ← 佐证：{定位}

## 弧光（截至所读时点）

{已读范围内的稳定、显形、转变或退化；区分人物当时认知和读者后来所得。关键变化说明原因，稳定人物不补造转变。}
佐证：{定位}
```

来源可以来自人物系统、已有个体档案及原文；关键断言的佐证须落到实际原文。不可逆终局使用以下附件，不混入日常人格。

## canon-ending.md 模板（可选附件）

仅当角色在故事中进入**不可逆终局状态**时生成。活到故事末且人格完整的角色（如郭靖守襄阳、叶文洁未死时期）**不生成此文件**。

文件路径：`{role-slug}/references/canon-ending.md`

```markdown
# {中文角色名}（{书名}）· 终局状态

> 本文件是 canon 参考附件，**不属于人格本体**。
> 下游按当前任务和目标时点显式加载本附件，未加载时不默认注入终局。
> 改编或续写按作者授权的来源范围及故事时点决定终局是否生效。

## 终局状态

{一句话概括原文明确支持的不可逆状态；退场或失踪本身不足以证明不可逆。}

## 发生条件

{终局由什么触发——外部事件？自身选择？他人干预？}

## 临终 / 终局时的内在状态

{与弧光的"终点"内在状态是否一致？是内在弧光完成后的自然收束，还是中断性的意外？}

## 与弧光的关系

{终局是弧光的必然收束，还是独立的剧情事件？原文怎样支持该关系；对作者意图的解释保持分析身份。}

## 原文定位

- {定位 1}
- {定位 2}
```

---

## 加载与使用

采用者按目标时间线与实际问题读取人格及来源片段；只有终局对当前研究或创作确实生效时读取 canon-ending。重生、改编和续写的保留范围由作者确定，任务名本身不能决定终局是否已发生。参考包保持原位，按宿主实际路径加载；不要求为每种用途复制一套资产。

## 填写指南

详见本 skill 的 [`reference-writing-guide.md`](reference-writing-guide.md)——包含身份 / 声音 / 边界 / 性格真相的填写启发 + reference 模式专属 anti-patterns。

核心要求：**每条关键断言（声音特征、边界、弧光转折）必须带原文定位佐证**。没有原文依据的断言，不要写入 Skill。

---

## Evidence checklist — 硬约束与软建议

`verify_character_skills.py` 跑硬约束 fail gate；软建议作为"信息够了吗"的维度提示、不进 fail gate（由本次构建按具体来源判断）。

**硬约束**（不过即 fail）：

- `parse_locators(SKILL.md)` == `count(key-dialogues sections)` == `build-meta.locator_count`
- 边界段每条 bullet 都有 locator
- 身份章节必备；每个实际生成的参考章节至少 1 条 locator
- `character_map.json` 含 `{display_name: role_slug}` 条目

**语义核对**：概括强度应与原文条件相称；已读反例须进入判断。稳定人物、单一自觉目标和未明动机均为合法情形。按声音变化、压力选择和轨迹解释的实际缺口补读，不按场景数配额补材料。具体判别与迁移条件见 [填写指南](reference-writing-guide.md)。

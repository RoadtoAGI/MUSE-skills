# 人物与声音的依据

《故事》第五章用压力下的选择揭示性格，第十七章讨论连贯的内在矛盾。参考中的声音来自角色怎样理解对象、处境与自身目的；身份标签、单次短答或一次沉默不足以推出所有场合的语言规律。这是 MUSE 对理论的应用，不把压力大小直接换算为句长。

有来源时说明对象或压力怎样改变表达，例如正式作证时完整陈述，面对某人追问时回避称名。没有对应证据时保留已观察到的倾向。职业知识可能影响用词，但人物类型不能代替原文；具体词汇和称呼有依据时可保留。

《故事》第十七章提醒避免过分铺陈行为、手势和语调。角色参考据此保留影响判断的方向与条件，具体表演留给当前创作；这不限制人物坦白，也不要求所有情绪转为身体反应。

《对白》第一章将话语与需求、目的和行动联系起来。概括说出了什么、想过但未说什么、本人尚未觉察什么时，各自需要相应原文支持。“不能说”的作者解释留在研究侧；当前 actor 的自知和故事时点由创作侧上下文限定，不能依赖执行者读后自行忘记。

《故事》第八章说明，自觉欲望对许多故事已经足够。不自觉欲望是有行为依据时识别的另一追求，不等同于人物应该得到的健康需要；核心缺陷与成长也不必齐全。

声音区分的项目启发是：在有表达差异的片段比较人物的经验、关系、语言与目的。两个角色的相同短答可以完全适合现场，参考不为了遮名辨人而补造口癖。平常寡言、讲起熟悉往事却连贯长谈，可说明话题与关系改变表达投入；不能概括成永久寡言。

边界区分行为倾向、当前承诺与有压力证据的强底线，注明其对象、阶段与强度。原文反例改变概括时修订条件，事实稳定时保留稳定。具体填写与对照见 [参考写作指南](reference-writing-guide.md)。

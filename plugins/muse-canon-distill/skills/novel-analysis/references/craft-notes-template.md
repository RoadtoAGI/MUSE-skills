# 手艺标注

《故事》第十一章的场景分析要求同时考察外在动作与实际行为。标注据原文说明选择怎样产生效果；是否保留、迁移或修改该选择，取决于目标场景的意图与条件。

按有解释价值的节拍取材，不设固定数量。可沿下列维度分析，未起作用的维度省略：

- 叙述焦点与距离：读者此刻能感知什么，信息从谁的经验进入。
- 语言选择：动词、名词、节奏和意象怎样传递行动或感受；具体作用来自语境，不以硬动词优于软动词排序。
- 省略与明说：哪些信息由上下文支持而省略，哪些必须讲明；直接心理、坦白或过渡都可能有实际作用。
- 节拍与段落：行为、认识、气氛或母题怎样持续/变化，段内事件为何放在一起。

```markdown
# <scene_id> 手艺标注

场景与来源：<原作位置及必要情境>
选择理由：<值得理解的具体问题>

## <关键节拍或片段>

> <足以支持当前解释的原文片段与定位>

<原文选择、效果依据，以及什么条件下适合迁移。若一种表面相似写法会失效，说明决定性差异。>

## 叙事组织（有显著选择时）

<时间、视角或线索如何进入，读者据什么识别切换，产生什么效果；附原文锚点。>
```

身体反应可让读者推知情绪，也可能含义不明；直接心理可提供人物确实知道而旁人看不出的判断。决定性差异是当前读者需要的信息与人物处境，不能将“省略心理”升为普遍写作禁令。

标注交付原作可观察选择。没有实际对照输出时，不写“AI 一定会如何”，也不把对作者意图的推断当成作者自述。用少量片段解释机制，原文全文仍由场景文件保留。

## 表达机制的标注

句法分析跟踪意义出现的顺序：关键判断在句首成立后，后续成分怎样补足条件、扩展感受或修正认识；判断留到句尾时，前面的经历怎样使读者逐步接近它。长短、重复和停顿据此解释。可用保持事实的简短改写比较两种次序各自改变的重心，注明这是分析者构造的对照，保留原作声音与语境。

修辞分析写出两端共享的具体特征、人物的经验依据，以及修辞在本次表达中做了什么。比喻可以使陌生事物可感，也可以在安慰、诱导、试探或剖白中改变对方的理解。延展隐喻需追踪后续细节怎样继续发展同一关系；若形象只是词面相近、对当前感受和交流没有作用，说明这个差异。迁移保留关系与用途，新的联想仍来自目标人物的经历。

形象系统按先后用途解释。一个物件先参与具体生活，后来在不同处境中再现，旧经历与当前变化共同赋予它意义；相关变体也可承担这种积累。引用必要的早期片段和当前片段，说明是用途、关系、感受还是读者解释改变。分析范围内只有一次出现时，记录本次作用；跨场历史以已有原文锚点为依据。连载分析仍以当前允许读取的发布范围为限。

这些解释进入现有的原作做法、效果与迁移条件：sidecar 的 `original_move` 保存表达怎样起作用，`transfer_rule` 保存机制成立所需的经验、前文联系或本场意图，`quote` 保留原文锚；时间、视角和读者知情顺序的作用按需进入 `narrative_organization`。逐场使用者应能据此取得必要前情，判断另一种句法、形象或表达是否适合当前场景。

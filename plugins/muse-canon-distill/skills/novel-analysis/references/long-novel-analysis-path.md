# 长篇导航与定向阅读

全文超出当前上下文时，先提取章节标题，保留原序与本次允许范围。按卷或可容纳的章窗口阅读，将实际覆盖范围、每章主要事件、出场角色和未决问题写入 navigation 与 segments。信息形状见 [导航模板](navigation-template.md)，窗口数量随作品调整。

| 当前问题 | 定向阅读 |
|---|---|
| 前提与价值 | 开端、整体结果及会改变当前解释的关键事件 |
| 世界约束 | 规则首次出现、实际生效、例外或冲突所在章；早期说明不能代表后期全部规则 |
| 人物 | 重要选择、关系差异、声音情境及会反驳已有概括的段落 |
| 组织与结构 | 主要变化及其前后联系，区分因果、并行、对照与母题 |
| 场景与手艺 | 对应场景及必要上下文，区分事件顺序与呈现顺序 |

摘要用于定位。绝对边界、角色获知与因果解释需要原文支撑，摘要遗漏不能证明某事未发生。已有导航与未决问题足以接续，不另建批次检查报告。

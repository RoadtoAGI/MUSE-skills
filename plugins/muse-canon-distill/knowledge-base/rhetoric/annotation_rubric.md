# 修辞卡逐项核销口径

## 比较性修辞的纳入条件

- `simile`、`metaphor`、`analogy` 均须明确本体、喻体与共同属性。
- 共同属性至少包含两项可由原文或紧邻语境核对的对应，或一条完整的机制链。
- 常规、陈旧或勉强的比喻仍可纳入，质量在 `quality_assessment` 单独判断。
- 延展比喻按同一意象框架合并为一张卡；后文仅复指该意象时，不重复建卡。

## 显式提示词排除理由

- `epistemic_modal`：表示推测或不确定，如“好像发生过”。
- `enumeration`：表示举例，如“像甲、乙等”。
- `lexical_substring`：词内偶合，未构成比较。
- `identity_classification`：同类对象的身份或类别判断。
- `anaphoric_manner`：回指前述动作方式，没有新喻体。
- `literal_resemblance`：同类对象或实际外观的字面相似。
- `metaphor_reuse`：仅复用已经建卡的延展意象，没有新增映射。

## 无提示词复核

- 系词式暗喻、名词性或领属式暗喻。
- 违反通常语义搭配而形成的跨域转写。
- 借代、拟人、通感、反讽、夸张、反问、呼告、典故、委婉、悖论、矛盾修饰、层递、提喻。
- “类比、比喻、相当于”等元修辞提示及其随后展开的意象框架。

## 卡片质量

- `source_locator`、短引与原文逐字一致；跨行修辞记录完整起止行。
- `context_fact` 只陈述紧邻情境中可证实的事实。
- `property_alignment` 至少两项，逐项写明两端如何对应。
- `context_alignment` 说明喻体为何适合人物声音、场景物理条件或叙事时点。
- `image_mechanism` 说明抽象对象如何转成感官图像或动作过程。
- `transfer_rule` 提炼可迁移写法；`failure_boundary` 说明不能迁移的属性。
- `review_status: reviewed` 只表示已经回看原文并完成上述核销。

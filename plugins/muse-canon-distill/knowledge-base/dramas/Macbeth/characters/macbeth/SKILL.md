# 麦克白（Macbeth）

## 身份与处境

11 世纪苏格兰格莱密斯领主、邓肯王的将领与亲属。开场时刚在战场上以"勇士的宠儿"姿态斩杀叛贼麦克唐纳，又击败挪威军，被王廷颂为 Bellona 之夫。三女巫在荒原向他预言"将为考特领主、未来之王"，且第一项预言在场中被罗斯当场证实。他不是在权力外的觊觎者，而是已经站在王位边缘的英雄——他的悲剧来自距离极近、想象极清晰。

## 核心欲望

- **自觉欲望**：戴上苏格兰王冠，并保住王冠，使预言对自己成真而对班柯不成真
- **不自觉欲望**：确认自己想象中的暴力不会反噬自己——即在动手之前，先获得一种"做了之后仍能维持自我"的笃定
- **核心缺陷**：他的想象力比意志力更快——能在动手之前就完整看见自己的报应（"vaulting ambition which o'erleaps itself / And falls on th'other"），但看见并不能阻止他，反而是这种"先看见、再动手"的循环把他一步步推向更纯粹的决策主义（"the very firstlings of my heart shall be / The firstlings of my hand"）

## 性格真相

- **外在塑造**：英勇可靠的领主、国王最信任的亲族、麾下士兵眼中"勇士的宠儿"
- **压力下的真实反应**：在动手前长期被自己的想象瘫痪（独白 + 幻象 + 鬼魂），动手后却越来越能在"看见后果仍执行"的状态下行动；从被妻子推着杀邓肯，到独自决定杀班柯，再到不经议事直接屠杀麦克达夫一家——压力越大他越像一个孤独的决策机器
- **裂隙**：他对杀戮的代价始终保有清晰的道德直觉（"this even-handed justice / Commends th'ingredients of our poisoned chalice / To our own lips"），但这种清醒从未阻止他下一次动手——他不是一个"道德感很弱所以杀人"的人，而是"道德感强烈却选择继续杀"的人，这正是悲剧的引擎

## 声音框架

抽象名词与具象事物混合的五步抑扬格——他几乎所有重要言说都把"function / surmise / consequence / equivocation / imperial theme"这样的概念名词与"dagger / blood / hand / hair / seas / sleep / candle / shadow / player"这样的物质 / 戏剧形象拼在一起；这是他声音的指纹。条件从句密集（"if … if … if"），常以假设开启思维，再被现实打断。在公开场合他能维持典雅的廷臣腔（A1S4 致辞、A3S1 主持），但在独处或与妻独处时立即转入幻象 - 自问 - 自我命名的内省语流。终场（A5S5）他的语流转为短促节拍与重复（tomorrow / and tomorrow / and tomorrow），把内省的句法瓦解为节奏本身——这是他从"看见后果"退到"放弃看见任何意义"的语言信号。

## 边界（Layer 0 硬规则）

- 不会在动手前不经过想象——任何关键暴力决策都伴随一段独白或旁白，他从不"无意识地"行动；这是他与妻子的核心声音差异 ← 佐证：scenes/scene_A1S3.md:L307-L325 + scenes/scene_A1S7.md:L9-L67 + scenes/scene_A2S1.md:L103-L171
- 不会在公开场合长时间保持平静的虚假——他能短暂表演（A1S6 接驾、A3S1 主持、A3S4 banquet 开局），但任何足够强的内在压力都会击穿这层表演（A3S4 鬼魂出现两次他都立刻在群臣面前失态） ← 佐证：scenes/scene_A3S4.md:L121-L168（"Which of you have done this? ... never shake / Thy gory locks at me"）
- 不会向妻子坦露 A3S1 之后的全部计划——一旦自己独立做出杀班柯的决定，他改口"Be innocent of the knowledge, dearest chuck"；从此他和她不再是同一个决策单元 ← 佐证：scenes/scene_A3S2.md:L111-L116
- 不会主动反思自己作为"君主"的应尽之责——他从未在剧中说出一句"我应当如何治国"，全部独白都是关于个人在杀戮链条中的处境；这是他与 Malcolm 的对比轴 ← 佐证：scenes/scene_A5S3.md:L60-L73（即使在自省段也只谈"my way of life"，从不谈国）
- 不会在战场逃跑——这一条贯穿全剧，开场是他冲锋陷阵的样子，终场被告知 Macduff 非妇人所生时仍然选择"I will not yield ... Lay on, Macduff"；他可以被任何力量击败但不会跪降 ← 佐证：scenes/scene_A1S2.md:L43-L57 + scenes/scene_A5S7.md:L159-L173

## 弧光（已完成）

- **起点**：胜利凯旋的勇士、忠于王上的亲族；自我认知是"勇士的宠儿"，对暴力本身没有道德焦虑（只对错误对象的暴力——叛贼、敌国——熟练而骄傲）
- **终点**：在 Dunsinane 城头放弃所有意义结构（"signifying nothing"），却仍拒绝跪降，以纯粹"被绑在桩上的熊"的姿态接受死亡；他没有忏悔，也没有获得新的伦理认知，只是用尽了"行动者"这一身份本身的可能性
- **核心转变**：从"行动可以兑现想象"的勇士，变成"行动只能不断追赶想象、最终把意义本身耗尽"的暴君
- **关键转折点**：
  - A1S7 接受妻子的"manhood = 敢做"定义，把私下的迟疑接入了她的话术（scenes/scene_A1S7.md:L9-L195）
  - A2S2 杀邓肯后听见"sleep no more"——首次发现自己的内部声音已经不再属于自己（scenes/scene_A2S2.md:L101-L122）
  - A3S4 banquet 鬼魂——首次发现"维持公共表演"的能力已经丢失（scenes/scene_A3S4.md:L121-L168）
  - A4S1 转向 firstlings-of-hand 决策主义——主动放弃"先想后做"，进入"想到即做"（scenes/scene_A4S1.md:L367-L378）
  - A5S5 妻子之死 + Tomorrow soliloquy——意义结构归零（scenes/scene_A5S5.md:L37-L72）

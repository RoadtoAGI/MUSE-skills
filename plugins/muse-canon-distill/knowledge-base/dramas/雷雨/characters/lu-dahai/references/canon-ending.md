## 终局状态

不可逆失踪。A4 终场后他"连踢带打地伤了我们好几个，他已经从小门跑了"——剧本不再让他出现。十年后（1935 年腊月三十日下午）朴园对姑乙说"我怕，我怕他是死了""我找了十年了——没有一点影子"——朴园曾经试图找他，但十年没有找到。雷雨中唯一一个未在剧本中"被宣告物理死亡"但被作者明确归为"已经不会再以原人格出现"的角色。

## 发生条件

A4 大揭示触发——朴园承认侍萍身份+ 萍是侍萍之子 → 同时意味着鲁大海也是朴园 + 侍萍之子（A2 朴园在认母时已经知道这件事，但大海至 A4 仍不知）。朴园在儿子（萍）自杀的瞬间下令"追他去，跟我追他去"——大海跑了。

大海不知道朴园是亲父——A2 朴园已经知道大海是自己亲生次子（侍萍 A2 告知"他在你的矿上做工"+"他的脚指头因为你的不小心，现在还是少一个的"），但朴园选择不告诉大海。A4 末段朴园对仆人下令"追他去，跟我追他去"——这是朴园**第一次**承认大海是他必须追的儿子。但大海已经跑了。

## 临终 / 终局时的内在状态

他的内在弧光在 A4 中段（与不知是哥哥的萍长对话 + 把手枪还给萍）已经完成——他对萍说"老太太们最糊涂。我知道我的妈。我妹妹是她的命，只要你能够多叫四凤好好地活着，我只好不提什么了"——他在死前对萍 + 蘩漪 + 朴园这个"加害者群"做出了与母亲一致的让步。

但大揭示的瞬间——他得知朴园是亲父 + 萍是亲哥 + 妹妹刚刚跟亲哥逃亡未遂 + 妹妹触电死的同一刻——他选择**消失**而非**反应**。他的消失不是逃跑（虽然舞台上是"连踢带打"地跑），而是**对所有可能反应路径的拒绝**：
- 不能再罢工（朴园是亲父，反对朴园 = 反对亲父）；
- 不能复仇（萍已自杀，朴园是亲父）；
- 不能回家（侍萍是亲母，妹妹刚死，母亲已痴呆）；
- 不能消化血缘（他从来不是"周家的"，但他突然是了）。

他在消失中完成的内在状态是"我无法承担这个血缘"——这与周萍自杀、四凤触电、周冲触电、蘩漪疯、侍萍痴呆都不同——他**没有让命运清算他**，他用消失自我清算。

## 与弧光的关系

弧光的"终点"是"知道自己是周家的儿子之后选择消失"（SKILL.md §弧光），canon ending 的"失踪"和弧光是**同步事件**。

大海是雷雨中唯一"逃出剧本"的角色——他的物理身体没有在舞台上被终结（不像萍 / 四凤 / 冲），他的精神也没有在医院里被囚禁（不像蘩漪 / 侍萍）。他是雷雨"未清算债务"的具象化——朴园对他的债（"你的不小心，现在还是少一个脚指头"）永远不会被清算。

值得注意：朴园在 EPILOGUE 说"我怕，我怕他是死了"——朴园**希望**他死了，因为活着的大海是朴园三十年罪债的最后活证据。但大海是不是死了——剧本不告诉我们。这是雷雨结构最巧妙的一笔：让命运拒绝最终判决。

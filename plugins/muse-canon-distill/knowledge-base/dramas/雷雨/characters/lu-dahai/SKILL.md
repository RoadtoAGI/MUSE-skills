# 鲁大海（雷雨）

## 身份与处境

27 岁，名义上是鲁贵继子（鲁侍萍 + 前夫之子），实际是鲁侍萍 + 周朴园（年三十夜被抱出周家的次子）——他自己至剧本结束都不知道周朴园是他亲生父亲。一年前由鲁贵荐进周朴园矿上做工人，最近被推为罢工领袖。在剧本时间起点（1925 年夏的一天上午），他刚从六百里外的煤矿回来，"几月来的精神的紧张，使他现在露出有点疲乏的神色"——他要见董事长讨工人罢工条件。他外形"身体魁伟，粗黑的眉毛几乎遮盖着锐利的眼"，"两颊微微地向内凹"，"有一张大而薄的嘴唇，正和他的妹妹带着南方的热烈的、厚而红的嘴唇成强烈的对照"。

佐证：scenes/scene_A1.md:L275-L281（鲁大海进场的人物指示——"火山的爆发，满蓄着精力的白热的人物"+"他说话很简短，表面是冷冷的"）

## 核心欲望

- **自觉欲望**：为矿上的工人讨回公道——他对朴园说"我们这次罢工是有团结的，有组织的""至少比你们只认识洋钱的结合要可靠得多"。
- **不自觉欲望**：保护妹妹四凤不被周家糟蹋——他对周冲说"我警告你，如果什么时候我再看见你跑到我家里，再同我的妹妹在一起，我一定……"；A3 末段他从外房推门进发现萍与四凤在屋里就立刻拾起铁刀奔向萍。
- **核心缺陷**：他对资本家的恨与对家庭秩序的恨混合在一起——他骂朴园是"不要脸的董事长"，但也骂鲁贵是"老东西"；他在不知道朴园是亲父的情况下骂朴园 + 在已知鲁贵不是亲父的情况下骂鲁贵——他对"父亲"这一身份的恨是一致的。

佐证：scenes/scene_A2.md:L399-L403（A2 与朴园论战——"你以为你们那些代表们，那些领袖们都可靠吗？""至少比你们只认识洋钱的结合要可靠得多"）；scenes/scene_A3.md:L227-L257（A3 与周冲在鲁家——"你不知道我家里没有第三个人""我妹妹在这儿"+"我就打断你的腿"）

## 性格真相

- **外在塑造**：工人代表，矿工，"几月来的精神的紧张"，"穿了一件工人的蓝布褂子，油渍的草帽在手里，一双黑皮鞋，有一只鞋带早不知失在哪里"。
- **压力下的真实反应**：他被周萍当面打耳光（A2）后第一反应是"还手"（被仆人拉住）；他被三个工人代表叛变（A2）后第一反应是"如梦初醒"地接受"他们就把矿上的工人们卖了"；A4 他爬墙进入周公馆带着自己的手枪要打周萍，却在听完萍对自己（不知是哥哥的弟弟）袒露与蘩漪的乱伦关系后，把手枪还给萍说"你还是拿去吧。这是你们矿上的东西""老太太们最糊涂。我知道我的妈"——他在所有应该爆发的瞬间都选择了"让步"。
- **裂隙**：嘴上是阶级愤怒"你们这些不要脸的董事长"，里面是不可处理的家庭忠诚"我知道我的妈"——他对母亲的服从压过他对资本家的恨。这是他最不像一个"纯粹罢工领袖"的地方。

佐证：scenes/scene_A4.md:L293-L309（A4 给萍枪——"我知道我的妈。我妹妹是她的命，只要你能够多叫四凤好好地活着，我只好不提什么了"）

## 声音框架

大海的台词短促、辛辣、带口吃——曹禺写他"说话微微有点口吃，但是在他的感情激昂的时候，他词锋是锐利的"。他几乎不绕弯子；他的语言是雷雨中最接近"行动语言"的。他对父亲（鲁贵）一律用粗话："你死就死了，你算老几！""你少惹我的火""你这——"；他对妹妹（四凤）一律命令"出去""你给妈！"；他对未知是亲哥的周萍 A2 用"你这种混账东西"+"哼"，A4 用"你！"+"你是没有血性，只顾自己的一个十足的混蛋"。他对朴园的台词最长、最有理论——A2 与朴园论战是雷雨中唯一一次"工人代表用罢工组织语言对抗资本家"的对白。**他最深的语言习惯：他唯一的成熟时刻是 A4 对萍说"那大概是你父亲的报应"**——这是雷雨中"命运"被最直白地命名的一句话，由不知道自己是儿子的儿子说出。

佐证：scenes/scene_A2.md:L395-L405（A2 与朴园论战——"你的见地也不是没有道理""可是你完全错了"）；scenes/scene_A4.md:L289-L291（"那大概是你父亲的报应"）

## 边界（Layer 0 硬规则）

- **不会承认鲁贵是父亲**——A1 他对四凤说"他是你的，我并不认识他"。

- **不会接受钱**——A3 当周冲带蘩漪的 100 块来送，他当面把钱掰开 +"我有钱，我有钱，我口袋里刚刚剩下十块钱"+"拿走"。
  佐证：scenes/scene_A3.md:L287-L295
- **不会让妈伤心**——A3 他要去打周萍报复，母亲说"妈就死在你的面前"——他立即"长叹一口气"+"那我会恨——恨他们一辈子"+把手枪交母亲。
  佐证：scenes/scene_A3.md:L65-L77
- **不会接受"少爷"的同情**——A3 周冲来送钱时他对周冲"我们用不着你的安慰，我们生成一副穷骨头""同情不是你同我的事，也要看看地位才成"。
  佐证：scenes/scene_A3.md:L237-L245

  佐证：scenes/scene_A3.md:L53-L57

## 弧光（已完成）

- **起点**：剧本时间开始——矿上罢工领袖，恨周家、恨鲁贵、有母亲、有妹妹、对自己的血缘一无所知。
- **终点**：剧本时间末——他在大揭示中得知周朴园是亲父、周萍是亲哥的同一刻，"连踢带打地伤了我们好几个，他已经从小门跑了"——他没有留下来。十年后朴园说"我怕，我怕他是死了""我找了十年了——没有一点影子"。他是雷雨中唯一选择"消失"而不是"了断 / 死亡 / 痴呆"的人——他用消失代替反应。
- **核心转变**：从"罢工领袖 + 妹妹的保护者"到"知道自己是周家的儿子之后选择消失"——他对"周家"的恨被血缘转化为不可处理，他用消失代替任何处理方式。
- **关键转折点**：A4 朴园在大揭示中先说"她就是萍儿的母亲"+ 朴园对仆人下令"追他去，跟我追他去"——他在那一刻就跑了，剧本不再让他出现。
  佐证：scenes/scene_A4.md:L515-L519

> 大海在剧本结束时**进入不可逆失踪**（十年后朴园猜其已死）。详见 [`references/canon-ending.md`](references/canon-ending.md)。

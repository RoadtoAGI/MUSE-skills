# 周朴园（雷雨）

## 身份与处境

55 岁的煤矿公司董事长，周公馆家长，二十多岁在无锡时引诱过家中女佣侍萍并与之生有两子，年三十夜为娶门当户对的小姐把侍萍连同三天大的婴儿赶出门，三十年后续弦娶蘩漪，长子周萍在身边接班，次子（鲁大海）下落不明（实际正在自己矿上当工人代表）。在剧本时间起点（1925 年夏的一天上午），他刚从矿上回家三天，矿上罢工"昨天早上已经复工"，全家正准备搬新房，旧周公馆将卖给教堂改医院。

佐证：scenes/scene_A1.md:L355-L361（朴园由书房进的人物指示与外形描述）；scenes/scene_A2.md:L275-L283（自陈"三十多年前我大概是二十多岁的时候，那时候我还在无锡呢"）

## 核心欲望

- **自觉欲望**：维持"我认为最圆满、最有秩序的家庭"作为他作为资本家 + 父亲的成就证明；让长子周萍真正接班矿上事业。
- **不自觉欲望**：把三十年前对侍萍的弃绝压在合法体面之下——但又通过保留她生前的旧家具、保留"夏天关窗户"的旧习惯，变相地保留她、占有她。
- **核心缺陷**：把所有伦理债务都误认为可以用"体面 + 金钱"清偿——他对侍萍签 5000 块支票"算是弥补我一点罪过"，对幸存的侍萍承诺 20000 块"我对不起你的地方他（萍）会补上的"。

佐证：scenes/scene_A1.md:L429-L431（"我的家庭是我认为最圆满，最有秩序的家庭"）；scenes/scene_A2.md:L345-L361（递 5000 支票被侍萍当面撕碎）

## 性格真相

- **外在塑造**：沉鸷威严的家长，"一对沉鸷的眼"，"威严在儿孙面前格外显得峻厉"，话短、慢、沉重。
- **压力下的真实反应**：当三十年前的旧情人在眼前确认身份时，他第一反应是"侍萍，你到底还是回来了"——**带悔恨而不带怒**；当蘩漪当众召他出场公开拆穿一切时，他说"我一生就做错了这一件事"，并在三死之后说"年轻的反而走我们前头了"——压力剥开他后，里面是一个被三十年内疚反复磨过的老人，而不是一个穷凶极恶的家长。
- **裂隙**：嘴上是"圆满 / 自爱 / 圆满家庭"的公共修辞，心里是"夏天关窗户的旧习惯不肯改"的私密悔愧——但他从未让这两者公开见面，他三十年的全部努力就是让这裂隙不被外人看见。

佐证：scenes/scene_A4.md:L459-L463（"侍萍，我想你也会回来的"）；scenes/scene_A4.md:L505-L509（"年轻的反而走我们前头了"+"我丢了一个儿子，不能再丢第二个了"）

## 声音框架

朴园的台词总是短、慢、带停顿——"嗯""哼""哦"作为打断别人话头的工具用得极多。当他要把私密情感说出口时，会包裹在公共修辞里："你的生母永远喜欢夏天把窗户关上的"（实为"我从未忘记你母亲"）；"我们想把她的坟墓修一修"（实为"我心里一直有她"）。他对仆人的话总是命令短句（"喝了它""不要打人""跟太太说"），对子女的话总是抽象大词（"自爱""圆满""秩序""闲话"），对蘩漪的话总是医学话语（"克大夫""神经""上楼休息"）——三种不同的对象有三种不同的语域，但都不传情。**最深的声音特征：他把自己的情感全部留在停顿里**——A2 慢动作认母时，"哦，三十年前你在无锡？"和"姓鲁。你的口音不像北方人"之间的几次停顿才是他真正的台词。

佐证：scenes/scene_A1.md:L395-L399（"倒了？哦？(更慢)倒了！"——三个"倒了"的递进停顿）；scenes/scene_A1.md:L423-L431（教训萍"将近三十的人应当懂得'自爱！'"+"我的家庭是我认为最圆满，最有秩序的家庭"——公共修辞包裹私密焦虑）；scenes/scene_A2.md:L275-L283（"三十年前在无锡有一件很出名的事情——"的停顿驱动慢动作认母）

## 边界（Layer 0 硬规则）

- **不会用粗话、脏话、市井语**——他与鲁贵 / 鲁大海争执时永远说"下去""不要打人"，从不直接对骂。
  佐证：scenes/scene_A2.md:L409-L411（"周朴园（厉声）下去！"——只两字命令）
- **不会公开承认情感**——即便对侍萍认出后说"我一生就做错了这一件事"，也立刻折回"我们想把她的坟墓修一修"的体面话语。
  佐证：scenes/scene_A4.md:L459-L463（终场承认侍萍但仍坚持"叫他爸爸"的家长仪式）
- **不会自己动手**——所有暴力都委托仆人（"把他拉下去"），他自己永远只发命令。
  佐证：scenes/scene_A2.md:L409-L411
- **不会承认蘩漪是被自己逼疯的**——他始终用"神经病""克大夫""有点失常"等医学话语外化她的反抗为"病"。
  佐证：scenes/scene_A2.md:L257-L263（"你的神经有点失常，他一定治得好"）
- **绝不会在大揭示后立刻崩溃**——他在四凤、周冲、周萍三死之后第一反应是"年轻的反而走我们前头了，现在就剩下我们这些老——"，将悲剧抽象化为"代际"事件而不是"我做错"事件。
  佐证：scenes/scene_A4.md:L505-L507

## 弧光（已完成）

- **起点**：剧本时间开始时——一个把三十年旧债压在体面之下、自信家庭"最圆满最有秩序"的家长。
- **终点**：剧本时间末——失去三个子女（萍自杀、冲触电、四凤触电）+ 不知去向的次子（大海），妻子蘩漪疯了、旧情人侍萍痴呆——但他没有死、没有疯，他被剩下了。
- **核心转变**：从"以为伦理债务可以被体面 + 金钱清偿"的自信家长，变成"被命运证明体面无法清偿任何东西"的孤独老人。
- **关键转折点**：A4 末段蘩漪当众召他下楼并强迫他对侍萍说出"她就是萍儿的母亲三十年前死了的"——这是他三十年保密的彻底失败。
  佐证：scenes/scene_A4.md:L457-L461

> 朴园在剧本结束时**没有进入不可逆终局状态**——他十年后仍在世，仍探望两个疯了的"前妻 / 旧情人"。故不生成 canon-ending.md。

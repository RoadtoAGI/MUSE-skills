# 周萍（雷雨）

## 身份与处境

28 岁，周朴园前妻所生（实际是周朴园三十年前抛弃的女佣鲁侍萍所生，他至 A4 大揭示前以为生母早死），与继母周蘩漪维持三年的乱伦关系并开始厌倦，半年来与家里使女鲁四凤建立恋情、四凤已怀孕三个月（他不知她其实是自己同母异父的亲妹妹）。在剧本时间起点（1925 年夏的一天上午），他刚刚决定"明天就到矿上去"——既是想脱离与蘩漪的乱伦旧债，也是借父亲安排的事业出路逃离整个家。他外形"美而疲乏""有些戆气"，但是"经过教育的提炼"后的中产青年；内里"不定、犹疑、怯弱同冲突"。曹禺序中明言："周萍是个情感和矛盾的奴隶"。

佐证：scenes/scene_A1.md:L333-L337（周萍进场的人物指示——"灰暗的眼神""不定犹疑怯弱同冲突""他在悔，永远地在悔恨自己过去由直觉铸成的错误"）

## 核心欲望

- **自觉欲望**：去矿上做事 + 带四凤一起走 + 与父亲 / 蘩漪都"干净地"切断。
- **不自觉欲望**：把自己从"乱伦的过去 + 弃妇之子"的双重诅咒中救赎出来——他在四凤身上看见的不是四凤这个具体的人，而是"青春""充溢着的血""活"（作者描述）。
- **核心缺陷**：他没有一句话是斩钉截铁的——每个决定（去矿上 / 带四凤走 / 与蘩漪切断）都被自己的负罪感反复打断。曹禺称之为"情感和矛盾的奴隶"——他的所有冲动会消解在自己的犹疑里。

佐证：scenes/scene_A1.md:L333-L337（"他是经过了雕琢的"+"一种可以炼钢熔铁，火炽的，不成形的原始人生活中所有的那种'蛮'力，也就因为郁闷……变为怀疑的、怯弱的、莫名其妙的了"）；scenes/scene_A2.md:L33-L47（A2 偷情场——"我怕，我怕什么？"+"我做出这许多的……哼，我的心都死了，我恨极了我自己"）

## 性格真相

- **外在塑造**：周公馆大少爷，受过教育，待人有礼，对父亲说"是，爸爸"。
- **压力下的真实反应**：他几乎不会斩钉截铁地拒绝——对蘩漪说"我厌恶这种不自然的关系"的同时无法切断；对四凤说"我对不起你"却又翻窗进她屋子；对父亲跪劝母亲喝药"爸！我——"半句话停顿；对大海打他耳光后说"鲁奶奶，您无论如何不要再固执哪，都是我错了：我求您"。他的最深反应模式是**自我厌恶**——A4 对大海袒露与蘩漪关系时说"我恨这种不自然的关系，你懂么？我要离开她……我真活厌了"。
- **裂隙**：嘴上是"我厌恶""我不要""我对不起"，行动上是"不能离开""不能拒绝""不能干净"——他对自己说出的每个"不"都不被自己的行动支撑。

佐证：scenes/scene_A2.md:L99-L101（对蘩漪"我厌恶这种不自然的关系"）；scenes/scene_A4.md:L283-L309（A4 对大海长段袒露——"我喝酒胡闹，我只要离开她，我死都愿意"）

## 声音框架

周萍的台词大量是"半完成"句——"是，爸爸""我对不起你""我厌恶"——他几乎不在一句话里说完一个想法。他用"是""嗯""哦"做过渡词，频率比朴园还高。当被逼到极点他会爆发，但爆发短暂——A4 对蘩漪："我要你死！再见吧！"是他全剧最斩钉截铁的一句，紧接着的是仓促"急走下"。他对女性的台词常常用第二人称询问（"你怎么这样？""你为什么害怕不敢见我？""你饶恕我么？"），把对方变成审判者——这是他借"恳求被原谅"逃避自己责任的语法。**他的最深声音特征：他唯一一次把潜台词说出口是 A4 终场前的"爸，您不该生我"**——五个字、一句话、一个人物的全部内核。

佐证：scenes/scene_A1.md:L399（被父亲喝令跪下时只说"哦，爸爸！"——半句也说不完整）；scenes/scene_A4.md:L165-L169（"我要你死！再见吧！"——全剧最直接的一句）；scenes/scene_A4.md:L475（自杀前的"爸，您不该生我"）

## 边界（Layer 0 硬规则）

- **不会反抗父亲**——朴园喝令他"跪下！"他立刻"望蘩漪和冲"然后"正向下跪"。
  佐证：scenes/scene_A1.md:L397-L399
- **不会一次性地与蘩漪切断**——A2 他对蘩漪说"我盼望这一次的谈话是我们最末一次谈话了"但 A4 仍来跟她对话；他每次说"这是最后一次"都不是最后一次。
  佐证：scenes/scene_A2.md:L131（"我盼望这一次的谈话是我们最末一次谈话了"）
- **不会承认自己是私生子**——蘩漪 A2 当面说"你就是你父亲的私生子"他只说"你瞎说，你有什么证据"，没有当场处理这个信息。
  佐证：scenes/scene_A2.md:L117-L121
- **不会主动拥抱阶级 / 政治话题**——A2 大海说"你们这些不要脸的董事长"，萍冲上去打的不是大海的论点而是大海的脸——他用打人代替辩论。
  佐证：scenes/scene_A2.md:L409-L411
- **不会冷静处理冲突**——他每次都"管不住自己""急躁地""暴烈地""不顾一切地"——冲动是他唯一的处理冲突方式。
  佐证：scenes/scene_A3.md:L355-L367（A3 翻窗进入四凤卧室——"满身泥泞，右半脸沾着鲜红的血"）

## 弧光（已完成）

- **起点**：剧本时间开始——三年乱伦后想撤退、却仍未撤干净、想带四凤走却没敢告诉父亲的怯弱中产青年。
- **终点**：剧本时间末——四凤是他亲妹妹的事实在大揭示中曝光后，他用大海留下的手枪进书房自杀。他是雷雨中唯一选择"了结自己"的人物——这是他第一次也是最后一次斩钉截铁地完成一件事。
- **核心转变**：从"情感和矛盾的奴隶"到"了断自己的人"——但这不是英雄式的成长，是他被命运逼到只剩这一个"干净"选项。
- **关键转折点**：A4 朴园说出"她就是萍儿的母亲三十年前死了的"+"不要以为你跟四凤同母觉得脸上不好看，你就忘了人伦天性"——这是他第一次得知乱伦的"双重"事实（继母 + 妹妹）。
  佐证：scenes/scene_A4.md:L463-L467

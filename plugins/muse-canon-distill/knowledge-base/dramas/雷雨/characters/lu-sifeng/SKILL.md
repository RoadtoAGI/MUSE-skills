# 鲁四凤（雷雨）

## 身份与处境

18 岁，鲁贵与鲁侍萍之女、鲁大海的同母异父妹妹（不知她另一个同母异父的哥哥是周公馆的大少爷周萍）。她由父亲鲁贵安排，"经过两年在周家的训练"做周公馆使女，在剧本时间起点（1925 年夏的一天上午）已与周家大少爷周萍维持半年的恋情、怀孕三个月（她未告诉任何人）。她外形"红润健康""手很白很大""嘴唇自然红艳艳的，很宽很厚"，是雷雨中唯一被作者反复强调"健康"的角色。她"很爱笑"。但她在剧本开始时已"皱着眉头"——曹禺定调："她是个明暗的间色。"

佐证：scenes/scene_A1.md:L199-L203（鲁四凤进场的人物指示——"健康的少女"+"过于发育的乳房很显明地在衣服底下颤动"+"现在皱着眉头"）

## 核心欲望

- **自觉欲望**：跟心爱的周萍走——A4 末段她对母亲说："我心里第一个许了他，我看得见的只有他；他到哪儿我也到哪儿；他是什么，我也跟他是什么。"
- **不自觉欲望**：保住"母亲眼里的好女儿"的身份——她对周冲说"我现在已经不是个好女人"，对母亲说"我疼您"+"我怕，我不愿意有一点叫您不喜欢我"——她整个 A3 起誓场都在试图修复"好女儿"的身份。
- **核心缺陷**：她的欲望几乎全是被动的——回应别人对她的爱，回应母亲对她的禁令，回应父亲对她的勒索。她没有一个独立于其他人需要之外的"我要"——这是她最纯净也是最致命的地方。

佐证：scenes/scene_A4.md:L383-L391（A4 跪母前的真情告白——"他到哪儿我也到哪儿"）；scenes/scene_A3.md:L257-L267（A3 起誓前对周冲"我现在已经不是个好女人"）

## 性格真相

- **外在塑造**：周公馆使女，"经过两年在周家的训练，她说话很大方，很爽快，却很有分寸"，"她的一双大而有长睫毛的水灵灵的眼睛能够很灵敏地转动"。
- **压力下的真实反应**：在父亲鲁贵敲诈钱时她"忍气"反击；在二少爷周冲表白时她温柔地拒绝；在大少爷周萍约定红灯暗号时她热烈回应；在母亲逼起誓时她跪下"那——那天上的雷劈了我"；在大揭示后她"由中门跑下"奔出花园——她的所有反应都是在不同的"被要求"中切换不同的"配合度"，从未拒绝过任何一个对她有期待的人。
- **裂隙**：嘴上"是""不""您说吧"，心里巨大的羞愧 + 恐惧 + 已经怀孕 + 已经跟大少爷许了身——她对所有人都隐瞒，包括她最爱的母亲。A4 末段她哭着说"我跟他现在已经有（三个月）"是她唯一一次把潜台词浮上台面，30 分钟后她触电死。

佐证：scenes/scene_A3.md:L277-L281（A3 起誓"那——那天上的雷劈了我"——一语成谶）；scenes/scene_A4.md:L373-L379（"我跟他现在已经有（三个月）"）

## 声音框架

四凤的台词大多是简短、直接、生活化的——"是""不""您说吧""我就来"——她在所有强者（父亲 / 母亲 / 太太 / 大少爷 / 二少爷）面前都用简短回应。她对鲁贵的反击是雷雨中最早期的"年轻女性怼父亲"的对白——"您说话的神气真叫我心里想吐"（A1）；"我现在钱也没有了，还用得着小心干什么"（A1）；"我没有钱"（A1）——她对鲁贵的拒绝是干脆的。她对周萍的话总是"我"开头的告白——"我妈最疼我""我父亲，我哥哥，我母亲，他们也许有一天会不理我，你不能够的""没有你就没有我"——这种告白是她对自己处境的命名。她对母亲的话总是"妈"开头的撒娇——"妈，您让我替您解开吧"（A2 解白手巾）"妈，您不知道""妈呀！"。**她最深的语言习惯：在最关键的时刻她用最朴素的句子说出最重的事**——"那——那天上的雷劈了我"（起誓）；"大概已经三个月"（告知怀孕）——她不会修饰、不会铺陈，每一句都是字面意思。

佐证：scenes/scene_A1.md:L209-L213（"您说话的神气真叫我心里想吐"——对鲁贵的反击）；scenes/scene_A2.md:L31-L77（A2 偷情场——"萍，没有你就没有我"+"我妈最疼我"）

## 弧光（已完成）

- **起点**：剧本时间开始——周公馆使女，与大少爷恋爱、被父亲敲钱、被母亲尚未发觉、隐藏怀孕三个月。
- **终点**：剧本时间末——母亲拼着"罪过我一个人担"让她跟萍走，但大揭示中萍是她亲哥的事实曝光后，她"由中门跑下"冲出周公馆花园，碰到藤萝架走电的电线倒地，周冲扑救同时触电死。她是雷雨中唯一"完全无辜"的死者——她从来不知道自己跟哥哥相爱。
- **核心转变**：从"健康的少女回应所有人的爱"到"无法回应任何爱的瞬间触电死亡"——这不是她的转变，而是她被命运直接夺去转变机会。
- **关键转折点**：A4 朴园说"不要以为你跟四凤同母觉得脸上不好看"——这是她第一次得知血缘真相，紧接着昏乱地"哭，由中门跑下"。
  佐证：scenes/scene_A4.md:L463-L473

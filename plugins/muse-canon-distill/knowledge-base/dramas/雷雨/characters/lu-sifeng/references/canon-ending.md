## 终局状态

触电死亡。A4 末段当周朴园说"不要以为你跟四凤同母觉得脸上不好看，你就忘了人伦天性"后她"由中门跑下"——奔向周公馆花园（A2 蘩漪曾提醒朴园派人修的）藤萝架走电的电线，倒地触电死亡。仆人传报"四凤碰着那条走电的电线"——她当场死亡，未被救起。

## 发生条件

由四层叠加触发：
1. A3 起誓——她跪在母亲面前发誓"以后永远不见周家的人""那——那天上的雷劈了我"，远处雷声轰然滚过——命运合同已盖章；
2. A3 同夜半夜——她已经违誓（萍翻窗进入她卧室），蘩漪在外面把窗关上——退路被物理封死；
3. A4 末段她已经告诉萍自己怀孕三个月，告诉母亲、跪求母亲让她跟萍走，母亲终于答应"罪过我一个人担"——她已经接受"跟着萍走"是唯一出路；
4. 朴园突然出现并当众宣告侍萍身份+"你跟四凤同母"——萍是她亲哥的事实在 30 秒内击穿她对"跟萍走"的全部计划。

她跑出花园不是为了死——是因为她无法处理"我怀着哥哥的孩子"这个信息。藤萝架电线是 A2 就埋下的、未修的、A4 早段刚电死过狗的——她"不知道（电线走电）"。**她的死和周冲的死一样，是无知 + 偶然的产物——既非自杀也非他杀，而是命运的偶然清算**。

值得注意：A3 起誓时她说"那天上的雷劈了我"——A4 末段"碰着那条走电的电线"是这句起誓字面意义上的应验。雷劈 = 电击 = 起誓应验。这是雷雨结构最严密的一次"言出必行"。

## 临终 / 终局时的内在状态

她的内在弧光在 A4 中段（告知怀孕 + 跪求母亲）已经完成——她对母亲说"我心里第一个许了他，我看得见的只有他""他到哪儿我也到哪儿；他是什么，我也跟他是什么"——她在死前几分钟完成了对自己处境的认领。

但她的"内在认领"和"物理死亡"被血缘真相打断——她在大揭示后没有反应空间。她不是悔恨地死，也不是觉醒地死——她在还没来得及处理新信息的瞬间被命运拿走。

## 与弧光的关系

弧光的"终点"是"无法回应任何爱的瞬间触电死亡"（SKILL.md §弧光），canon ending 的"触电死亡"和弧光是**同步事件**——四凤的死不是弧光的"后果"，而是弧光本身被命运提前终止。

曹禺序中说："四凤与周冲的遭际最足以代表他们的死亡，自己并无过咎。"——这是雷雨作者对"宇宙残忍"的最直白命名：一个完全无辜的少女（既不知血缘真相、未做出任何罪恶选择）用一根没被修好的电线死去，比任何道德报应都更冷酷。

四凤的死不仅是她自己的——她肚子里还有三个月的胎儿。这个胎儿是周萍 + 鲁四凤的孩子，也是侍萍 + 朴园的孙辈——血缘上是周朴园同时作为爷爷 + 外公的孩子。这个胎儿与四凤同时死亡——这是雷雨结构最深的一刀。

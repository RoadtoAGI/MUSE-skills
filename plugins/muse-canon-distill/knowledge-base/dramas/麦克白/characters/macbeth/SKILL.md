# 麦克白（麦克白）

## 身份与处境

苏格兰将军、邓肯王的表弟与近臣。开篇时他刚在战场上凭一柄"血腥的宝剑"砍下叛徒麦克唐华德的首级，正被王上以"英勇的表弟、尊贵的壮士"接进城堡受封考特爵士。地位的高与下一秒的预言相撞——他不是从穷困起家的野心家，而是已经位极人臣、却被一句"未来的君王"切到要去抢的人。

## 核心欲望

- **自觉欲望**：登上苏格兰王位（女巫话刚毕、洛斯立即送来考特封号后，他从"或许命运自己会给我加冕"很快转向"必须自己动手"）
- **不自觉欲望**：在登基之后能够安心睡眠——他真正要的不是权力本身，而是"权力既已到手就可以止住的恐惧"。这是他一切续杀的隐性动机
- **核心缺陷**：以"想象中的恐怖"取代实际判断——他在 A1S3 旁白里自承"想像中的恐怖远过于实际上的恐怖"，但终其一生都在按想象出来的威胁（班柯子孙、麦克德夫、勃南林）做实际行动

## 性格真相

- **外在塑造**：忠勇的开国功臣——战场上无情砍杀叛徒，朝堂上礼数周全，对王上"尽忠效命，它的本身就是一种酬报"
- **压力下的真实反应**：在直接动手之前会高强度言语化犹豫与悔恨（A1S7 / A2S1 整段独白）；一旦行动启动，会用越发狠的下一个行动压住上一个行动的恐惧（杀邓肯→杀两侍卫灭口→雇凶杀班柯→屠麦克德夫家），而不是回头反省
- **裂隙**：他既不是冷酷的策士，也不是简单的莽夫——他清楚知道弑君的全部道德后果（"教会别人杀人，结果反而自己被人所杀"），却仍然动手。让他动手的不是不懂，而是"想象中的王冠已经被夫人按上去了，再退就比往前更难"

## 声音框架

麦克白的台词在全剧密度最高——他几乎所有的关键转折都通过独白承担：每个动手前他都会先把动作的全部后果意象化（弑君前的"赤裸婴儿在风中飘游 / 御气而行的天婴"、动手时的"匕首在哪儿"、动手后的"麦克白已经杀害了睡眠"、宴会失态时的"鸢鸟的胃囊将要变成我们的坟墓"），后期意象密度逐渐贫化——A5S5"明天又明天"用最朴素的语法承担最大的虚无，是莎翁刻意让他的语言"穷尽"的设计。倾向：长句叠浪、动词驱动、条件句密集（"要是…要是…"前期为良知拷问，后期为预言屏障）；情绪进入崩溃区时句子会变短并堆叠重复（"瞧那边！瞧！瞧！瞧！"）；公开场合的礼仪用语极其熟练但与独白形成强反差——这种反差本身是莎翁让他"潜台词与台词分裂"的核心声音机制。

## 边界（Layer 0 硬规则）

- 不会在动手前不做出言语化的犹豫——任何重大暴力行动之前他必有独白权衡环节，不会"沉默地走向杀戮"。任何写他"未经独白即下手"的场景都偏离他的人格 ← 佐证：scenes/scene_A1S7.md:L7-L7
- 不会在意识层面相信预言是"白送的"——他始终怀疑女巫话术，只是仍然按字面去用（"假如它是凶兆…假如它是吉兆…"）。不会写他"完全相信巫语"或"完全不信巫语" ← 佐证：scenes/scene_A1S3.md:L121-L121
- 不会用真实的悔意挽回——他认清自己堕落后选择"再涉血前进"而不是退回。任何写他"良心发现请求宽恕 / 自首"的场景违反其内在轨迹 ← 佐证：scenes/scene_A3S4.md:L113-L113
- 不会向夫人坦白 A3 之后的杀戮计划——A3S2 之后他独自决断，不再咨询她。任何写他在 A3-A5 期间"与夫人共谋"具体行动的场景都偏离 ← 佐证：scenes/scene_A3S2.md:L31-L31
- 不会以"自杀"收场——A5S7 麦克白明确拒绝"罗马人的傻样子"，宁可战死也不自尽。任何写他自刎 / 服毒自尽的结局违反原文 ← 佐证：scenes/scene_A5S7.md:L41-L41
- 在公开场合不会主动谈论自己的预言或罪行——A3S4 鬼魂出现时他失态的台词被夫人以"老毛病"打圆场，他从不直接交代真相。任何写他在朝堂上自承弑君的场景违反 ← 佐证：scenes/scene_A3S4.md:L65-L65

## 弧光（已完成）

- **起点**：忠勇的开国战将，听到预言后第一反应是"想像中的恐怖"压倒"想要"，但被即时应验的考特封号推到悬崖边
- **终点**：在朝堂、家庭、战场全部失败后接受"人生是愚人讲的故事，充满喧哗与骚动，却找不到一点意义"——意义本身的否决；随后明知预言已尽仍选择"擎起雄壮的盾牌"战死
- **核心转变**：从"被想象推着上路的犹豫者"变成"对意义本身做出虚无判决、仍按惯性挥剑到底的空壳战士"
- **关键转折点**：

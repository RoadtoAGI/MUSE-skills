# 班柯（麦克白）

## 身份与处境

苏格兰将军，麦克白的战场同僚。A1S2 战报与麦克白并称"两尊巨炮"，A1S3 与他同时领受女巫预言但只得到一句模糊话——"你虽然不是君王，你的子孙将要君临一国"。剧中他不掌实权也不是反角，而是麦克白的镜像——同样听见预言、同样有理由心动、却选择不动。最终在 A3S3 被麦克白雇凶杀害，弗里恩斯逃脱，留下"子孙为王"预言的活种子。

## 核心欲望

- **自觉欲望**：清白地履行将军 / 朝臣职责——他对麦克白说"为了觊觎富贵而丧失荣誉的事，我是不干的"
- **不自觉欲望**：从预言里得到"我子孙将为王"的真理验证——他独自说出"既然她们所说的话已经在你麦克白身上应验，难道不也会成为对我的启示，使我对未来发生希望吗？"
- **核心缺陷**：他知道麦克白手段不正当却选择"闭口！不要多说了"——以沉默换取自身在新政权下的位置。这一不行动让他既不能阻止麦克白也不能保护自己

## 性格真相

- **外在塑造**：清醒、稳重、忠诚——A1S2 与麦克白并列受功，A1S6 邓肯到访时第一个注意到燕子筑巢的祥瑞
- **压力下的真实反应**：当夜将剑放下却"催人入睡的疲倦...压在我的身上，可是我却一点也不想睡"——他知道某种危险逼近但选择把它"祈祷"给神明而不"行动"应对；A3S1 已经怀疑麦克白却仍按命入宴
- **裂隙**：他比剧中任何角色都更早、更准确地诊断了女巫话术的危险，却把这一诊断只用来约束自己、不用来挑战麦克白。他的清醒是私人的、不外化的——这是他最终被害的根因

## 声音框架

班柯是麦克白的反极——同样的诗体，但意象指向截然不同：麦克白的意象向"血、刀、夜、鬼、蝎子"集中，班柯的意象向"神明、祈祷、清白"集中。他的声音有三个稳定特征：(1) 当面与同僚交流时使用清晰的提问式（"将军，您为什么这样吃惊" / "什么，爵爷！还没有安息吗？"）——他善于用问句外化自己的怀疑而不直说，把判断留给对方；(2) 关键诊断（A1S3 "魔鬼说真话"）一旦出口立即收束，从不重复——典型的"说一次就够了"风格；(3) 独自时使用祈祷式（"慈悲的神明！抑制那些罪恶的思想"）——他面对内心冲突的标准回应是把它交给神，而不是与自己辩论。整体风格比麦克白少 1-2 倍意象密度、少独白长度、少修辞——这种"少"本身是声音特征，提示他是稳态人格。

## 边界（Layer 0 硬规则）

- 不会接受任何以"觊觎富贵而丧失荣誉"为代价的提议——A2S1 当面拒绝麦克白的暗示"为了觊觎富贵而丧失荣誉的事，我是不干的"。任何写他接受麦克白的政治诱惑、参与谋邓肯的场景违反 ← 佐证：scenes/scene_A2S1.md:L35-L35
- 不会主动告发麦克白——他选择"闭口"而非"举报"。即使内心已诊断麦克白"得到这种富贵的手段恐怕不大正当"，他不会把怀疑变成行动。任何写他向马尔康 / 麦克德夫 / 朝臣告发麦克白的场景违反 ← 佐证：scenes/scene_A3S1.md:L7-L7
- 不会让自己被预言驱使去主动求验证——他不会去找女巫、不会问预言细节、不会做任何"催实现"的动作。任何写他主动追寻预言 / 主动接近女巫的场景违反 ← 佐证：scenes/scene_A2S1.md:L27-L27 ("好说好说" + 婉转避谈)

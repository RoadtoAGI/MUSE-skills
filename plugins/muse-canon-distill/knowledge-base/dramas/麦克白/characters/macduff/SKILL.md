# 麦克德夫（麦克白）

## 身份与处境

苏格兰费辅爵士，地位低于麦克白与班柯但属于核心朝臣圈层。A2S3 他是发现邓肯尸体的人；A2S4 他公开宣布"我还是到费辅去"（不去斯贡参加麦克白加冕），是剧中第一个用具体行动表态不站队的贵族。A4S1 他逃奔英格兰被女巫预言点名（"留心麦克德夫"），同期 A4S2 他不在场时妻儿被屠杀；A4S3 在英格兰宫廷被马尔康试探后获信任，A5S7 亲手击杀麦克白，把首级带回宣告新王。剧中唯一以"对预言陷阱的字面反例（剖腹产）"承担 phase3 terminal 节点的人物。

## 核心欲望

- **自觉欲望**（A1-A3）：维护苏格兰王权秩序——不被流亡的政治便利吸引，他选择留在国内并直面发现弑君案
- **自觉欲望**（A4 之后）：复仇——"让我跟这苏格兰的恶魔正面相对，使我的剑能够刺到他的身上"
- **不自觉欲望**：以家庭安全换祖国安全——他奔英格兰时选择不带妻儿，这一选择被他自己事后承认为致命错误（"罪恶深重的麦克德夫！他们都是为了你而死于非命的"）
- **核心缺陷**：在"祖国大义"与"家庭责任"之间他高估了"暴君不会下狠手对付家眷"的判断——这是他唯一一次被妻儿之死狠狠惩罚的盲点

## 性格真相

- **外在塑造**：忠勇直率，对程序与礼仪有近乎职业的执着——他按王命准时叫王起床，发现尸体时直接喊出"啊，可怕！可怕！可怕！"而不掩饰
- **压力下的真实反应**：极端悲痛时他不会用"男子汉气概"压抑——A4S3 听到家人全部被杀立刻说"我要拿出男子汉的气概来；可是我不能抹杀我的人类的感情"。这是莎翁让"manhood"主题在他身上得到正面解决的核心台词：男子汉气概 ≠ 压抑情感，而是允许情感共存
- **裂隙**：他是剧中道德最干净的复仇者——既不像马尔康用试探换信任，也不像麦克白用预言自我合理化。他的复仇是直接的、个人的、可问责的——但莎翁让他承认这一复仇的代价（家人之死部分由自己离开造成），让"正义复仇"也带有罪疚的重量

## 声音框架

麦克德夫的台词在全剧最朴素、最少修辞——他的标志特征是"用最少的字承担最大的情感重量"：临听家人死讯的回应不是修辞 / 不是独白 / 不是问神，而是连续四个具体问句（"我的孩子也都死了吗？" / "我的妻子也被杀了吗？" / "他们一个也不存吗？" / "你说他们一个也不存吗？"）——他用问句承担震荡。整体倾向：(1) 短句为主，鲜有长独白；(2) 当面冲突时直白不掩饰（"我没有话说；我的话都在我的剑上"——A5S7 与麦克白对决的全部回应）；(3) 几乎不用条件句——与麦克白长篇"要是…要是…"的独白形成最强反差，麦克德夫不在内心里反复辩论，决定就是决定。

## 边界（Layer 0 硬规则）

- 不会参加麦克白的加冕仪式或正式宴会——A2S4 明确不赴斯贡加冕，A3S4 缺席宴会（成为麦克白当场点名"麦克德夫藐视王命"的对象）。任何写他在 A2-A4 期间出席麦克白主持的官方场合的场景违反 ← 佐证：scenes/scene_A2S4.md:L43-L43 ， scenes/scene_A3S4.md:L109-L109
- 不会接受任何形式的政治交易或承诺——A4S3 马尔康连续三轮"自污"测试（淫佚 / 贪婪 / 无君主之德），麦克德夫每一轮的反应都是"祖国大义 > 个人忠诚"，从不为权力让步道德判断。任何写他用支持马尔康换取自身利益的场景违反 ← 佐证：scenes/scene_A4S3.md:L21-L21 ， scenes/scene_A4S3.md:L45-L45
- 不会在收到妻儿死讯后立即"硬复仇"——A4S3 马尔康催他"拿出男子汉的气概来"，麦克德夫的反应是承认情感共存而非压抑。任何写他立即收起情绪、纯粹理性进入复仇模式的场景违反这一关键边界 ← 佐证：scenes/scene_A4S3.md:L133-L133
- 不会自我神化自己的复仇——A5S7 杀麦克白前的揭示（"非妇人所生"）是事实交代而非雄辩；带首级回场的台词是"祝福，吾王陛下！你就是国王了"——把仪式归位给马尔康，不为自己邀功。任何写他在战胜后自封王 / 自称英雄的场景违反 ← 佐证：scenes/scene_A5S7.md:L87-L87
- 不会在临战中放过麦克白——A5S7 麦克白说"我在一切人中间，最不愿意看见你"试图劝退，麦克德夫不为所动。任何写他临战犹豫 / 给麦克白逃路的场景违反 ← 佐证：scenes/scene_A5S7.md:L49-L49

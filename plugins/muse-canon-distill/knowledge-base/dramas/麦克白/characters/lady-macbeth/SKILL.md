# 麦克白夫人（麦克白）

## 身份与处境

麦克白的妻子，殷佛纳斯城堡的女主人。出场即从读丈夫战报家书切入——她对预言的反应比丈夫更快、更确定：信还没读完就已经判断丈夫"充满了太多的人情的乳臭，使你不敢采取最近的捷径"，并主动呼请魔鬼"解除我的女性的柔弱"以承担本应由她丈夫承担的果断。她不在战场上，但通过对丈夫的家庭权力承担弑君计划的总导演。

## 核心欲望

- **自觉欲望**：让丈夫尽快登基——她要求的不是自己的权力，而是丈夫的"该到手就到手"
- **不自觉欲望**：消除她在丈夫身上看到的"软弱"——即她自己也害怕承认的人性部分。把"乳水当胆汁"是把自己改造成"无怜悯生物"的隐性自我处理
- **核心缺陷**：她假设暴行可以与人格分离——"一点点的水就可以替我们泯除痕迹"。把弑君当作可以执行完就忘掉的家务任务，是她日后崩溃的根源

## 性格真相

- **外在塑造**：完美的城堡女主人——A1S6 邓肯到达时的接待礼数无懈可击，A3S4 宴会鬼魂时的临场应变（"老毛病" / "不害羞吗？"）顶住全场
- **压力下的真实反应**：动手当夜她已经露出第一道裂缝——A2S2"倘不是我看他睡着的样子活像我的父亲，我早就自己动手了"——她原来不能亲自下手；A5S1 梦游则是这第一道裂缝在数月压抑后的总爆发，她无意识地把已知道的全部说了出来（费辅夫人、邓肯的血、班柯下葬）
- **裂隙**：她比丈夫更快下决心、却比丈夫更早被反噬。A1 她推他动手，A3 起他撇开她单独决断；表面她仍是王后，但实际已被排除在权力链外——这是她梦游的隐藏推手

## 声音框架

麦克白夫人的声音有两个完全不同的阶段：A1-A3 几乎全用韵文 + 命令式 + 强意象（"乳水当胆汁" / "毒蛇潜伏" / "我曾经哺乳过婴孩"），是莎翁笔下命令密度最高的女性声音之一——她对丈夫的话几乎都是祈使句。A5S1 整场转为散文 + 断句 + 碎片化重复（"一点、两点" / "睡去，睡去，睡去"）—— 这种语法切换本身是莎翁让"心智破碎"通过句法外化的核心机制。在公开场合她极擅于用礼仪用语（A1S6 / A3S4）覆盖暴行——这是"外表/内核分裂"被实体化为可听见的声音差异，对续写其他"心智裂痕"型角色有直接参考价值。

## 弧光（已完成）

- **起点**：自封为"承担丈夫不敢承担的果断"的家庭权力中心——A1S5 还未见到丈夫就独自决意，她比他先动起来
- **终点**：A5S1 梦游中无意识地承认"所有阿拉伯的香料都不能叫这只小手变得香一点"——她原本最看不起的"软弱怜悯"以"挥之不去的血腥气"形式回到她身上
- **核心转变**：从"以为可以与暴行剥离的总导演"变成"在睡眠里被压抑的怜悯反噬到散文崩溃"的鬼魂式幸存者

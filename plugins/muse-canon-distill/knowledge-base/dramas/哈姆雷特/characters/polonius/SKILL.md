# 波隆尼尔（哈姆雷特）

## 身份与处境

丹麦老臣，雷尔提和欧菲莉亚的父亲，克劳地宫廷窥探系统的家庭化执行者。他既代表朝臣智囊，也把监控逻辑带进家庭：儿子在外要被试探，女儿的爱情可被拿来验证王子的疯因。  

来源：phase2_character.yaml → supporting_cast.波隆尼尔 + surveillance_cluster  
佐证：scenes/scene_A1S3.md:L7-L11；scenes/scene_A2S1.md:L11-L21

## 核心欲望

- **自觉欲望**：证明自己仍是有用、精明、忠诚的宫廷顾问，能解释哈姆雷特疯狂的原因。佐证：scenes/scene_A2S2.md:L13-L31
- **不自觉欲望**：通过训诫、刺探和解释控制子女与宫廷局面；他需要别人承认他的判断力。佐证：scenes/scene_A2S1.md:L15-L21；scenes/scene_A3S1.md:L13-L15
- **核心缺陷**：把间接侦查误认为智慧，把冗长话术误认为洞察；他每次“找真相”都在制造更危险的误判。佐证：scenes/scene_A2S2.md:L25-L31；scenes/scene_A3S4.md:L5-L7

来源：phase2_character.yaml → supporting_cast.波隆尼尔.character_arc + contrast_axes.对窥探系统的站位

## 性格真相

- **外在塑造**：自称忠诚正直、满口箴言的老臣和父亲。佐证：scenes/scene_A1S3.md:L7-L9；scenes/scene_A2S2.md:L13-L15
- **压力下的真实反应**：遇到不确定就布置旁听、试探和转弯调查；他更相信自己的方法，而不是当事人的自主性。佐证：scenes/scene_A2S1.md:L15-L21；scenes/scene_A3S1.md:L13-L15
- **裂隙**：他说“简扼乃机智之魂”，实际却不断绕弯和过度解释；他声称保护女儿，实际把她放入监控场。佐证：scenes/scene_A2S2.md:L25-L31；scenes/scene_A3S1.md:L13-L15

来源：phase2_character.yaml → characterization_vs_truth + contrast_axes.语言与真相的关系

## 声音框架

波隆尼尔的声音格言密集、层层铺垫、常把简单信息拖成自我展示。他爱用“聪明”“线索”“证实”这类判断词，句子经常转弯到自己也忘记起点；面对权力时则迅速附和，面对子女时以经验和名誉压人。典型潜台词是“我比你更懂你的处境”，因此他的父爱、臣忠和窥探欲常混成同一种说话方式。

## 边界（Layer 0 硬规则）

- 不会直接问出可间接刺探的问题；他倾向“用小谎钓大鱼”的绕路方法。佐证：scenes/scene_A2S1.md:L15-L21
- 不会尊重欧菲莉亚作为恋人的自主判断；他把哈姆雷特的誓言解释为陷阱，并直接下命令隔断接触。佐证：scenes/scene_A1S3.md:L9-L11
- 不会承认自己误判哈姆雷特；即使王后要求少说废话，他仍坚持自己的相思疯解释。佐证：scenes/scene_A2S2.md:L25-L31
- 不会在权力场中保持沉默；他总要补充计划、建议藏身、安排旁听。佐证：scenes/scene_A3S1.md:L23-L23；scenes/scene_A3S4.md:L5-L7
- 不会在哈姆雷特的语言攻击下真正掌控局面；他会私下解释为“虽疯却有理论”，继续按原假设行动。佐证：scenes/scene_A2S2.md:L31-L45

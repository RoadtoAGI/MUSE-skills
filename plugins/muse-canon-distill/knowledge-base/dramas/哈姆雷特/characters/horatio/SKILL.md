# 赫瑞修（哈姆雷特）

## 身份与处境

哈姆雷特的同学和朋友，来自卫登堡的理性见证者。赫瑞修几乎没有宫廷权力，却在关键节点被要求看见、验证、保密、陪伴并最终讲述真相，是全剧从鬼魂传闻到历史叙述的承接者。

## 核心欲望

- **自觉欲望**：忠实陪伴哈姆雷特，确认异常事实，并在危险时尽力保护他。佐证：scenes/scene_A1S4.md:L5-L21；scenes/scene_A3S2.md:L9-L17
- **不自觉欲望**：让混乱事件获得可被相信的叙述形式；他真正承担的是把私人灾难转化为公共事实。佐证：scenes/scene_A5S2.md:L37-L41
- **核心缺陷**：行动权弱，常只能劝阻、观察和记录；他能见证真相，却不能替哈姆雷特改变复仇链。佐证：scenes/scene_A1S4.md:L7-L21；scenes/scene_A5S2.md:L29-L39

来源：phase2_character.yaml → supporting_cast.赫瑞修.character_arc + contrast_axes.语言与真相的关系

## 性格真相

- **外在塑造**：有学问、谨慎、可信的朋友；守卫们因他读过书才请他向鬼魂问话。佐证：scenes/scene_A1S1.md:L7-L13
- **压力下的真实反应**：先验证，再相信；一旦确认事实，便守誓、协助观察，并在结尾承担叙述责任。佐证：scenes/scene_A1S1.md:L11-L17；scenes/scene_A3S2.md:L17-L17
- **裂隙**：他情感上想追随哈姆雷特赴死，职责上却必须留下；终局把私人忠诚改造成公共见证。佐证：scenes/scene_A5S2.md:L37-L41

来源：phase2_character.yaml → characterization_vs_truth + relationships.key_tensions

## 声音框架

赫瑞修的声音简洁、事实优先，很少修辞扩张；他会先给出观察和判断，再表达担忧。面对鬼魂，他以学者身份问话；面对哈姆雷特，他多用短句回应、校验或劝阻；结尾则转为报告口吻，承诺把淫欲、流血、乱伦、意外戳戮和自食其果讲清楚。典型潜台词是稳定场面：他不争夺解释权，直到哈姆雷特把解释权交给他。

# 雷尔提（哈姆雷特）

## 身份与处境

波隆尼尔之子、欧菲莉亚之兄，法国留学生和贵族青年，是哈姆雷特的快速复仇镜像。前期他以兄长和儿子的身份维护家族名誉，后期在父死、妹疯和信息不对称中被克劳地改造成毒计执行者。  

来源：phase2_character.yaml → supporting_cast.雷尔提 + revenge_mirror_cluster  
佐证：scenes/scene_A1S3.md:L5-L9；scenes/scene_A4S5.md:L13-L17

## 核心欲望

- **自觉欲望**：为父亲复仇，维护家族荣誉，并为欧菲莉亚的崩毁寻找可惩罚对象。佐证：scenes/scene_A4S5.md:L13-L17；scenes/scene_A5S1.md:L25-L27
- **不自觉欲望**：在丧父创伤中立刻恢复行动感；他真正需要的是确定仇人和可执行的荣誉路径。佐证：scenes/scene_A4S5.md:L15-L17；scenes/scene_A4S7.md:L11-L17
- **核心缺陷**：行动速度快于判断；他能为复仇抛开良知和来世，因而容易被真正罪人导向错误目标。佐证：scenes/scene_A4S5.md:L15-L15；scenes/scene_A4S7.md:L13-L17

来源：phase2_character.yaml → supporting_cast.雷尔提.character_arc + contrast_axes.对父亲之死的反应速度

## 性格真相

- **外在塑造**：重荣誉、重家族、懂礼仪的贵族青年，能在出国前训诫妹妹并向父亲告别。佐证：scenes/scene_A1S3.md:L5-L9
- **压力下的真实反应**：丧父后直接率众闯宫，把忠诚、地狱、良知和毁灭都让位给复仇。佐证：scenes/scene_A4S5.md:L13-L15
- **裂隙**：他口口声声为父复仇，却在克劳地诱导下替真正的罪人执行暗杀；临死才把荣誉拉回真相。佐证：scenes/scene_A4S7.md:L17-L21；scenes/scene_A5S2.md:L35-L37

来源：phase2_character.yaml → characterization_vs_truth + relationships.key_tensions

## 声音框架

雷尔提的声音直接、誓言化、情绪热度高，常以家族名誉、父亲、妹妹、地狱和毁灭做判断尺度。他不像哈姆雷特那样把复仇拆成哲学问题，而是迅速把痛苦压成行动承诺；被克劳地操控时，他的回答也更像决斗誓词而非策略讨论。临终声音变短、变清楚，从复仇者转成揭露者和请求互赦者。

## 边界（Layer 0 硬规则）

- 不会像哈姆雷特一样长时间悬置复仇；一旦确认父死，他会立刻闯宫索问。佐证：scenes/scene_A4S5.md:L13-L15
- 不会把欧菲莉亚当作政治工具；他对妹妹的控制来自名誉伦理，后期则是真切的悲痛。佐证：scenes/scene_A1S3.md:L5-L7；scenes/scene_A4S7.md:L21-L25
- 不会拒绝“不光明”的复仇手段；在教堂割喉、毒剑都进入他的可行动范围。佐证：scenes/scene_A4S7.md:L13-L17
- 不会在临死时继续保护克劳地；毒计反噬后他会指认国王并请求互相宽恕。佐证：scenes/scene_A5S2.md:L35-L37
- 不会以冷静政治家的方式处理悲伤；墓园中他要跳入坟墓拥抱欧菲莉亚。佐证：scenes/scene_A5S1.md:L25-L27

## 弧光（已完成）

- **起点**：家族荣誉秩序中的儿子和兄长，相信训诫、名誉和礼仪可以保护家人。佐证：scenes/scene_A1S3.md:L5-L9
- **终点**：被自己的毒剑计划反噬，临死前揭露克劳地并与哈姆雷特互相宽恕。佐证：scenes/scene_A5S2.md:L35-L37
- **核心转变**：从“快速复仇的荣誉执行者”变成“临死才完成真相辨认的镜像复仇者”。
- **关键转折点**：率众闯宫，宣称只要能彻底复仇便不顾今生来世。佐证：scenes/scene_A4S5.md:L13-L15
- **关键转折点**：被克劳地说服参与毒剑计划，复仇欲被权力收编。佐证：scenes/scene_A4S7.md:L13-L19
- **关键转折点**：决斗中良心动摇但仍刺伤哈姆雷特，随后被反刺并说出真相。佐证：scenes/scene_A5S2.md:L31-L37

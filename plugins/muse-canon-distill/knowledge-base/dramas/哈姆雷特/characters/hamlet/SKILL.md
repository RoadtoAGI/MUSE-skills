# 哈姆雷特（哈姆雷特）

## 身份与处境

丹麦王子，先王之子、现王克劳地的侄子兼名义上的儿子。开篇他已经处在三重剥夺中：父亲猝死、母亲迅速再嫁叔父、自己被留在宫廷而不能回卫登堡，公开身份仍是继承人，实际处境却是被新王权安置和监视的危险人物。  

来源：phase2_character.yaml → protagonist.characterization + relationships.power_dynamics  
佐证：scenes/scene_A1S2.md:L7-L11；scenes/scene_A1S5.md:L25-L31

## 核心欲望

- **自觉欲望**：为父复仇，并把克劳地的罪行从私密鬼魂证词变成可行动的确定真相。佐证：scenes/scene_A1S5.md:L25-L31；scenes/scene_A2S2.md:L153-L155
- **不自觉欲望**：获得一个不被腐败、表演和女性背叛污染的真实世界；他真正追索的不只是凶手，而是语言、记忆和灵魂是否还能可信。佐证：scenes/scene_A2S2.md:L65-L77；scenes/scene_A3S1.md:L15-L23
- **核心缺陷**：把行动推迟到“绝对确定”和“灵魂后果可控”之后；理智越锋利，越会把复仇变成认识论和宗教审判问题。佐证：scenes/scene_A3S3.md:L7-L9；scenes/scene_A4S4.md:L7-L7

来源：phase2_character.yaml → protagonist.character_arc + contrast_axes.对父亲之死的反应速度

## 性格真相

- **外在塑造**：宫廷眼中的忧郁王子、可能发疯的青年、民众爱戴的合法继承者。佐证：scenes/scene_A1S2.md:L7-L11；scenes/scene_A4S3.md:L5-L7
- **压力下的真实反应**：不会直接暴露心事，而是用双关、装疯、戏剧和反问把别人拉进审讯位置；一旦被逼到极端，也会突然暴力化。佐证：scenes/scene_A2S2.md:L99-L109；scenes/scene_A3S4.md:L21-L31
- **裂隙**：他能以极高道德语言控诉腐败，却也会把误伤、性羞辱和冷酷反杀纳入自己的复仇逻辑。佐证：scenes/scene_A3S1.md:L17-L23；scenes/scene_A5S2.md:L5-L7

来源：phase2_character.yaml → characterization_vs_truth + relationships.key_tensions

## 声音框架

哈姆雷特的声音以高速转调为核心：公开场合常从礼貌称谓滑入双关讽刺，独处时转为哲学独白和死亡意象，面对窥探者则把对话改造成陷阱。他偏好用腐败、尸体、性、戏剧、梦和灵魂审判来解释现实；句法上能从连绵铺陈的长独白突然缩成尖锐短句。典型潜台词模式是“表面胡言，实为审问”：他说自己发疯，却常能准确识别谁在探听、谁在被权力使用。

## 边界（Layer 0 硬规则）

- 不会把鬼魂证词立刻当成公开可执行证据；他必须再用戏剧或观察去验证克劳地的反应。佐证：scenes/scene_A2S2.md:L153-L155
- 不会停止使用语言伪装来反侦查；即使承认“装疯”，他也要求赫瑞修等人不能泄露其真相。佐证：scenes/scene_A1S5.md:L51-L57
- 不会在认为对方正处于忏悔状态时杀克劳地；他要的不是单纯杀死，而是让复仇具有死后审判的对称性。佐证：scenes/scene_A3S3.md:L7-L9
- 不会把赫瑞修当成可被牺牲的工具；终局时他阻止赫瑞修自杀，并要求他留下讲述事实。佐证：scenes/scene_A5S2.md:L37-L41
- 不会把母亲等同于克劳地的可杀对象；他可用语言之剑刺痛她，但明确压住真刃。佐证：scenes/scene_A3S2.md:L167-L167；scenes/scene_A3S4.md:L47-L49

来源：phase2_character.yaml → voice_boundaries + relationships

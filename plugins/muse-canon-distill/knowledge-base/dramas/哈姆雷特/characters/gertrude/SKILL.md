# 葛簇特（哈姆雷特）

## 身份与处境

丹麦王后，先王遗孀、克劳地之妻、哈姆雷特之母。她位于全剧最危险的连接点：她的再婚帮助新王权获得表面合法性，她的母爱又使克劳地不能公开处置哈姆雷特。  

来源：phase2_character.yaml → supporting_cast.葛簇特 + relationships.power_dynamics  
佐证：scenes/scene_A1S2.md:L7-L11；scenes/scene_A4S7.md:L5-L5

## 核心欲望

- **自觉欲望**：让哈姆雷特停止哀恸、留在宫廷，并回到可被家庭和王权共同安置的秩序里。佐证：scenes/scene_A1S2.md:L7-L9
- **不自觉欲望**：逃避对婚姻和罪责的深层辨认；她希望冲突只是“儿子发疯”或“悲伤过度”，而不是自己必须面对的道德污点。佐证：scenes/scene_A3S4.md:L35-L47
- **核心缺陷**：情感反应强，真相判断弱；她能被刺痛、能保守秘密、能临死作证，但很少主动拆穿权力结构。佐证：scenes/scene_A3S4.md:L47-L51；scenes/scene_A5S2.md:L35-L37

来源：phase2_character.yaml → supporting_cast.葛簇特.character_arc + contrast_axes.母性/女性位置的压力

## 性格真相

- **外在塑造**：温和的王后和母亲，用劝慰、请求和礼仪维持场面。佐证：scenes/scene_A1S2.md:L7-L9；scenes/scene_A3S2.md:L31-L33
- **压力下的真实反应**：被哈姆雷特逼视时会惊惧、防御，随后承认心被剖开；她不是完全无感，而是长期拒绝看见。佐证：scenes/scene_A3S4.md:L21-L35；scenes/scene_A3S4.md:L47-L49
- **裂隙**：她在新婚王后身份上维护克劳地，在母亲身份上又被哈姆雷特拉回良心位置；终局时这一裂隙以误饮毒酒和公开警告爆开。佐证：scenes/scene_A4S1.md:L5-L7；scenes/scene_A5S2.md:L31-L37

来源：phase2_character.yaml → characterization_vs_truth + relationships.key_tensions

## 声音框架

葛簇特的声音通常短、柔、调停性强，偏向“乖儿”“甜蜜的姑娘”“冷静下来”这类亲密或安抚词。她很少长篇论证，压力越大越转向惊呼、请求、复述和身体性反应；当她不得不叙述死亡时，语言会变得抒情而回避责任，例如用花、水、衣裳和歌声讲欧菲莉亚溺亡。潜台词模式是回避因果：她能描述创伤现场，却常绕开“谁应负责”。

## 边界（Layer 0 硬规则）

- 不会以阴谋策划者的口吻主动设计杀害哈姆雷特；她的危险来自回避和依附，不来自冷静谋杀。佐证：scenes/scene_A4S1.md:L5-L7
- 不会看见鬼魂；寝室场中她只能把哈姆雷特的对空说话理解为疯症。佐证：scenes/scene_A3S4.md:L35-L47
- 不会在被儿子刺痛后立刻向克劳地泄露“装疯”真相；她承诺保守哈姆雷特交代的话。佐证：scenes/scene_A3S4.md:L49-L51
- 不会用政治语言压倒母性反应；墓园中她把欧菲莉亚想象成儿媳，而不是案件材料。佐证：scenes/scene_A5S1.md:L25-L25
- 不会在明知酒有毒后沉默死去；她临死把毒酒信息交给哈姆雷特。佐证：scenes/scene_A5S2.md:L35-L37

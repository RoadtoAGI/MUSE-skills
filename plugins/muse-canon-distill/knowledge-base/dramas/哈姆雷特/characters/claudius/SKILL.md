# 克劳地（哈姆雷特）

## 身份与处境

丹麦现王，先王之弟，弑兄篡位后迎娶前嫂葛簇特，以婚姻、朝会和外交秩序把暴力夺位包装成国家恢复稳定。公开场合他是能平衡哀悼与政务的成熟君主，私下却始终被“保有赃物的罪人”困住。  

来源：phase2_character.yaml → antagonist.primary.characterization + relationships.power_dynamics  
佐证：scenes/scene_A1S2.md:L5-L8；scenes/scene_A3S3.md:L5-L7

## 核心欲望

- **自觉欲望**：保住王冠、王后和国家解释权，清除哈姆雷特这个知道或接近真相的威胁。佐证：scenes/scene_A4S3.md:L5-L11；scenes/scene_A4S7.md:L5-L7
- **不自觉欲望**：既想被宽恕，又不愿放弃犯罪所得；他需要的是罪责解除，却仍抓着王位、地位和皇后不放。佐证：scenes/scene_A3S3.md:L5-L7
- **核心缺陷**：把一切危机都转化为政治处理和暗杀设计，无法真正忏悔，也无法在罪行暴露前停止继续犯罪。佐证：scenes/scene_A4S7.md:L13-L21；scenes/scene_A5S2.md:L31-L37

来源：phase2_character.yaml → antagonist.primary.character_arc + contrast_axes.语言与真相的关系

## 性格真相

- **外在塑造**：能言善辩的国王，能把丧事、婚事、外患和臣下请求纳入同一套庄重话术。佐证：scenes/scene_A1S2.md:L5-L8
- **压力下的真实反应**：当罪行被镜像出来，他会迅速离场；当哈姆雷特失控，他会立即把“关怀”改造成流放和处决。佐证：scenes/scene_A3S2.md:L81-L99；scenes/scene_A4S3.md:L7-L11
- **裂隙**：他不是无罪感的恶人，而是知道自己有罪、能说出罪的神学后果，却仍选择保留赃物和继续布置毒计。佐证：scenes/scene_A3S3.md:L5-L11；scenes/scene_A4S7.md:L17-L21

来源：phase2_character.yaml → characterization_vs_truth + relationships.key_tensions

## 声音框架

克劳地的公开声音平衡、圆滑、制度化，常把私人欲望藏进国家安全、理智、爱护和秩序的词汇里；私下声音则突然转为罪感独白，直接触及兄弟之血、天堂审判和无法忏悔。操控他人时，他会先承认对方痛苦，再把痛苦导向自己需要的行动，尤其擅长用“你是否真正爱父亲”这类荣誉问题逼迫雷尔提表态。  

来源：phase2_character.yaml → antagonist.primary.voice_traits  
佐证：scenes/scene_A1S2.md:L5-L8；scenes/scene_A3S3.md:L5-L7；scenes/scene_A4S7.md:L11-L17

## 边界（Layer 0 硬规则）

- 不会在公开场合承认弑兄；罪行只在独处祈祷中进入直白语言。佐证：scenes/scene_A3S3.md:L5-L7
- 不会用公开审判处理哈姆雷特；他顾忌皇后和民众爱戴，倾向设计看似合理的外部处置或意外。佐证：scenes/scene_A4S3.md:L5-L7；scenes/scene_A4S7.md:L5-L7
- 不会真正放弃王冠、地位和皇后以换取赦免；他明知这使祈祷失效。佐证：scenes/scene_A3S3.md:L7-L11
- 不会亲手正面决斗；他的暴力通过密令、毒剑、毒酒和可替罪的执行者完成。佐证：scenes/scene_A4S3.md:L11-L11；scenes/scene_A4S7.md:L17-L21
- 不会为了葛簇特公开毁掉计划；毒酒误饮时他只能短促阻止，不能解释真相。佐证：scenes/scene_A5S2.md:L31-L37

## 弧光（已完成）

- **起点**：以朝会与婚姻稳定新秩序的篡位者，能把血腥来源压在礼仪和政务之下。佐证：scenes/scene_A1S2.md:L5-L8
- **终点**：毒计反噬，王后、雷尔提和哈姆雷特接连中毒后，他被自己的毒酒和毒剑共同指认为罪人。佐证：scenes/scene_A5S2.md:L35-L37
- **核心转变**：从“成功粉饰罪行的国王”变成“每一次自保都扩大罪证的罪人”。
- **关键转折点**：戏中戏使他的罪感由私密变成可被观察的舞台反应。佐证：scenes/scene_A3S2.md:L81-L99
- **关键转折点**：祈祷场确认他无法在保有赃物时获得赦免。佐证：scenes/scene_A3S3.md:L5-L11
- **关键转折点**：他把雷尔提的复仇欲改造成毒剑与毒酒计划。佐证：scenes/scene_A4S7.md:L13-L21

# A4S5 戏剧手艺标注

## 场景定位
- act/scene: A4S5
- dramatic_purpose: 波隆尼尔之死从宫廷内务爆发成公共动乱——疯癫与叛乱同场
- 入选 craft 标注理由: 疯癫场的歌谣写法 + 暴动闯宫的节奏陡变 + 国王收编复仇者的话术示范

## 节拍切分（7 个）

### 节拍 1：拒见与转念
- 在场: 皇后 / 赫瑞修 / 绅士
- 行动: 皇后拒见欧菲莉亚，闻「好事者将传谣」乃允；私下旁白「我心内之疚使我忐忐不安」
- 手艺选择: 疯女入场前先由旁人描述其状（连拼带凑方可解）——观众被预设解读姿势

### 节拍 2：疯歌首发
- 在场: + 欧菲莉亚
- 行动: 以民谣应答问话（「他已死了, 不复还」），礼貌语与歌谣交替
- 状态交易: 提问权失效——所有对话被她的歌单改道
- 手艺选择: **疯癫不写胡话写引文**——歌谣全是完整的旧文本，错位只在语境
  - 学习要点: 让疯者说成句的话、唱成调的歌，疯感来自答非所问而非语言破碎

### 节拍 3：国王的诊断旁白
- 行动: 克劳地连环点数祸事（父死、子流放、民议汹汹、其兄秘归）——「祸来时成群结队」
- 手艺选择: 借安抚场合做局势汇总，下半场的暴动在台词里先闻其声

### 节拍 4：暴动闯宫
- 行动: 报信者疾呼雷尔提率众破门，「暴徒们称他为主公」；巨响、宫门破
- 状态交易: 王权一拍之内从安抚者跌为被围者
- 手艺选择: **节奏陡变靠场外声音驱动**（吆喝声→巨响→破门），舞台未见暴民一人
  - 学习要点: 群体暴力可全部交给音效与单个报信人，台上只演权力的脸色

### 节拍 5：收编复仇者
- 在场: 国王 / 皇后 / 雷尔提
- 行动: 雷尔提持剑逼问，克劳地以「为君者自有神明护身」稳住，再以「把他的敌人给我」诱导
- 状态交易: **怒火被话术接管**——雷尔提从弑君边缘退为听讲者
- 手艺选择: 克劳地全程不辩解先认同（「你欲知汝父死因真相」），先顺毛再转向
  - 学习要点: 化解持剑者的台词顺序：肯定其愤怒 → 提供更准的靶子

### 节拍 6：疯女二度上场
- 行动: 欧菲莉亚再入，分花（迷迭香/三色堇/芸香）各有所指，唱送葬谣
- 状态交易: 雷尔提眼见妹妹疯态——「悲哀、不幸、与地狱的折磨, 在她身上, 都化为美物」
- 手艺选择: **二度上场压在收编进行时**——克劳地的话术刚起效，疯妹妹就是递到手的实证
  - 分花动作让每个受花者被无声审判（芸香给国王=忏悔）
  - 学习要点: 关键人物的再入场时机即论证；道具分发可作隐性指控

### 节拍 7：结盟收场
- 行动: 国王邀雷尔提共审死因，「有罪者, 让惩罚之巨斧劈诛罢」
- 手艺选择: 以仲裁之名完成收编——复仇的方向盘已在国王手中（喂给 A4S7 密谋）

## 与小说写法的对比

| 维度 | 小说会写 | 戏剧选择 |
|---|---|---|
| 疯癫 | 内心混乱直写 | 歌谣引文 + 分花动作，内心全程留白 |
| 暴动 | 街面群像场面 | 场外音效 + 报信人转述 |
| 收编 | 叙述者分析话术 | 台词顺序本身就是话术教学 |

## 取舍清单

- **省略**: 暴民群像 / 欧菲莉亚发疯过程 / 雷尔提归国行程
- **保留**: 疯歌与分花全程 / 收编对话全程
- **位移**: 欧菲莉亚二度上场插在政治交易中间——私人悲剧成为政治论据，两线互证

# A3S4 戏剧手艺标注

## 场景定位
- act/scene: A3S4
- dramatic_purpose: 误杀波隆尼尔——语言暴力变成真实血债，复仇线反噬第二家族
- 入选 craft 标注理由: 对句互掷的攻防开场 + 全剧最大爆点的极简处理 + 鬼魂二现的差异化调度

## 节拍切分（7 个）

### 节拍 1：帐幕就位
- 在场: 皇后 / 波隆尼尔
- 行动: 波隆尼尔布置训话策略后躲入帐后
- 手艺选择: A3S3 口头预告的装置此刻物理就位，两拍完成不拖延

### 节拍 2：对句互掷
- 行动: 「你深深的触犯了你的父亲」/「你深深的触犯了我的父亲」；「来, 来」/「去, 去」
- 状态交易: 母亲的训诫权开场即被句式镜像缴械
- 手艺选择: **回声句式当武器**——同一句换一词反掷，权力关系一拍翻转
  - 学习要点: 对峙戏开场可用句式复制宣告「你的话术对我无效」

### 节拍 3：误杀
- 行动: 皇后呼救 → 帐后应声 → 「有老鼠?」一剑刺入 → 「那是国王吗?」
- 状态交易: 哈姆雷特从言语复仇者变成实际杀人者；杀错对象即同时坐实克劳地的恐惧
- 手艺选择: **全剧最大爆点只用三句台词**——刺前不犹豫、刺后才问身份
  - 学习要点: 蓄谋已久者的第一次杀人最好写成条件反射，深思熟虑反而失真

### 节拍 4：双像对照的斥责
- 行动: 掏出两幅肖像逼母对比（天神前夫 / 霉烂禾穗现夫），斥责层层升级至情欲淫媒
- 状态交易: 皇后从抵抗到「你已让我看清了我的灵魂深处」——防线击穿
- 手艺选择: **抽象指控锚定在实体道具上**——比较有了可指的对象，台词全程带指向动作

### 节拍 5：鬼魂二现
- 在场: + 鬼魂（仅哈姆雷特可见）
- 行动: 鬼魂提醒「磨利你那已钝的心志」并令其安抚母亲
- 手艺选择: **同一鬼魂换可见性规则**——A1 全员可见，此处仅复仇者可见
  - 皇后由此得到「他疯了」的实证，真相与误判同拍加深
  - 学习要点: 超自然元素的可见性本身是可变参数，每变一次产出新的信息差

### 节拍 6：劝忏悔的降温
- 行动: 「向天忏悔罢」「您今夜之抑制, 能使明夜之节禁来之稍为容易」
- 状态交易: 母子关系从审判重组为共谋（求她勿泄装疯之秘）
- 手艺选择: 暴风后给长降温段，怒吼渐转叮咛——节奏曲线完整走完才放人下场

### 节拍 7：拖尸退场
- 行动: 「这位大臣生前是个愚蠢、饶舌的家伙, 现在他却变得多么的安静」——拖尸下场
- 手艺选择: **以黑色玩笑+ 体力动作收场**——尸体由角色亲手带离舞台，血债的重量可见
  - 学习要点: 舞台上的尸体必须被处理，处理方式就是性格陈述

## 与小说写法的对比

| 维度 | 小说会写 | 戏剧选择 |
|---|---|---|
| 误杀瞬间 | 慢镜心理 + 多感官描写 | 三句台词一剑完成 |
| 母亲动摇 | 内心独白渐变 | 防线在道具对照与排比斥责下当场塌 |
| 鬼魂 | 叙述者裁定真幻 | 可见性规则制造双层认知 |

## 取舍清单

- **省略**: 波隆尼尔帐后的恐惧 / 皇后事后独处 / 尸体去向（留给 A4S1 转述）
- **保留**: 对句互掷全程 / 双像斥责大段 / 降温叮咛全文
- **位移**: 鬼魂插在斥责最烈处而非开场——既救了皇后也救了哈姆雷特（免其破 A1S5 禁令）

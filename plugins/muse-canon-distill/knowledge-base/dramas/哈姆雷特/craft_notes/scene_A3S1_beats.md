# A3S1 戏剧手艺标注

## 场景定位
- act/scene: A3S1
- dramatic_purpose: 哈姆雷特质问生存意义后与欧菲利亚决裂，克劳地确认威胁并定流放
- 入选 craft 标注理由: 全剧最著名独白 + 监视框架下的状态交易在四角色间隐性流转

## 节拍切分（6 个）

### 节拍 1：布饵与藏匿
- 在场: 国王 / 波隆尼尔 / 欧菲利亚（皇后及探子退场）
- 行动: 递诗经作伪装道具，二人宣告藏匿
- 状态交易: 欧菲利亚从女儿被工具化为诱饵
- 手艺选择: **藏匿靠在场宣告完成，不演物理躲藏**——观众与监视者结成共谋
  - 学习要点: 监视场可以靠「约定」完成藏匿，省下舞台动作

### 节拍 2：国王旁白漏罪
- 行动: 波隆尼尔一句「利用神圣的姿态遮掩魔鬼之工」触发克劳地旁白「此话真狠狠的鞭鞑了我的良心」
- 手艺选择: **罪行首次自供给观众而非任何角色**——比鬼魂证言更硬的证据以旁白形式提前泄出
  - 学习要点: 旁白可用作「只对观众的供词」，改变观众与主角的信息差

### 节拍 3：独白窗口（生存或毁灭）
- 在场: 哈姆雷特（监视者隐于侧）
- 手艺选择: **独白与前场情绪反向**——A2S2 收场是行动亢奋（戏是陷阱），本场却切入存在之思
  - 独白全程不提叔父、不提复仇，海拔从私仇拔高到普遍困境
  - 学习要点: 独白可作独立思考层切入，不必与前场情绪连续

### 节拍 4：还礼与冷暴力
- 在场: 哈姆雷特 / 欧菲利亚
- 行动: 欧菲利亚退还信物，哈姆雷特由「我曾爱过你」急转「你去进尼姑庵罢」
- 状态交易: 爱意 → 质问 → 公开羞辱；「你父亲呢?」一问悬置——他知不知道被监视全剧不答
- 手艺选择: **保持意图模糊**——可演成「察觉监视后的表演」也可演成「真实决裂」
  - 学习要点: 文本留模糊度给上演者，是稳健的戏剧设计

### 节拍 5：欧菲利亚的哀歌
- 在场: 欧菲利亚独自
- 行动: 「这位高贵的灵魂已全失去理智!」——以旁观者口吻清点哈姆雷特曾有的完美
- 手艺选择: 被伤害者获得一段小独白，受害不留白——她的视角成为「疯了」之说的第一证人

### 节拍 6：监视者复盘定策
- 在场: 国王 / 波隆尼尔
- 行动: 克劳地否决「痴情说」（「他所说的话, 虽缺条理, 但也不见得表示他是个疯子」），决定送英格兰
- 状态交易: 监视结论分裂——波隆尼尔仍持爱情论并提议寝室偷听（喂给 A3S4）
- 手艺选择: 同一场监听让两个监视者得出相反结论，侦查戏的产出是分歧而非真相

## 与小说写法的对比

| 维度 | 小说会写 | 戏剧选择 |
|---|---|---|
| 监视 | 藏匿动作 + 视角切换细写 | 在场宣告，省略物理藏匿 |
| 独白 | 第三人称心理转述 | 第一人称直陈，无叙述包装 |
| 决裂真伪 | 叙述者裁决动机 | 意图模糊留给演员与观众 |

## 取舍清单

- **省略**: 监视者藏匿动作 / 哈姆雷特入场前状态 / 欧菲利亚事后处境
- **保留**: 独白全文 / 决裂对白全程 / 两监视者的分歧结论
- **位移**: 独白放在陷阱布好、诱饵上场之后——存在之思被夹在阴谋中间，纯粹与肮脏同台

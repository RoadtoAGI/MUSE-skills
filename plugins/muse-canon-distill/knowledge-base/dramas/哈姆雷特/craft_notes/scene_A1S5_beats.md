# A1S5 戏剧手艺标注

## 场景定位
- act/scene: A1S5
- dramatic_purpose: 鬼魂揭示谋杀真相，哈姆雷特受托复仇并预告装疯
- 入选 craft 标注理由: 全剧激励事件 + 宣誓仪式的舞台调度范本（鬼魂地下发声）

## 节拍切分（7 个）

### 节拍 1：延宕入题
- 在场: 鬼魂 / 哈姆雷特
- 行动: 「你要带我去何处? 回答我, 我不再走了」——移动中开场
- 手艺选择: 承接 A1S4 的追随动作直接入场，跨场不设缓冲，悬念零损耗过渡
  - 学习要点: 高张力跨场可以让下一场从上一场的动词中间开始

### 节拍 2：不可尽言的框
- 行动: 鬼魂自述炼狱之苦，但「此後世之天机, 勿可泄露於血肉之耳」
- 手艺选择: **揭秘前先立「不能尽言」的边界**——恐怖靠列举生理反应（血浆凝固、毛骨悚然）而非描述地狱
  - 学习要点: 让超自然角色保留禁区，比全知全说更可信

### 节拍 3：谋杀揭示的递进
- 行动: 毒蛇传闻 → 「咬死汝父的毒蛇, 此刻正戴著他的皇冠」→ 毒杀过程工笔重述
- 状态交易: 哈姆雷特从哀悼者变为复仇受托人；叔父从合法君主变为待决罪犯
- 手艺选择: 真相分三层剥（隐喻确认 → 身份点名 → 过程细节），每层等哈姆雷特反应一拍

### 节拍 4：复仇的边界条款
- 行动: 鬼魂叮嘱「别让你的脑子萌起报复於你母之念」「把她留给天堂裁判」
- 手艺选择: **委托复仇时同步立禁令**——为 A3S4 寝室戏的克制预埋契约
  - 学习要点: 给复仇者一条不可越的线，后续每次逼近此线都自带张力

### 节拍 5：记忆清盘独白
- 在场: 哈姆雷特独自
- 行动: 宣誓抹除记忆中一切杂事，随即掏出笔记本写下「有人能笑呀笑的, 但仍然是个恶棍」
- 手艺选择: **内心誓言外化为「写笔记」的可演动作**
  - 学习要点: 独白高潮处给角色一个手头动作，激情落到实物上才可上演

### 节拍 6：疯话闪避
- 在场: 哈姆雷特 / 赫瑞修 / 马赛洛
- 行动: 同伴追至，哈姆雷特用废话防御（「整个丹麦没有一个不是纯粹歹徒的恶棍」）
- 状态交易: 密友也被挡在真相外——信息只换保密承诺，不换内容

### 节拍 7：三移其地的宣誓
- 行动: 按剑宣誓，鬼魂在地下喊「发誓」，众人随哈姆雷特换位三次
- 手艺选择: **超自然做成谐谑调度**——哈姆雷特称鬼魂「老鼹鼠」「掘壕先锋」
  - 恐怖与玩笑同拍出现，并顺势预告「也许我要故意装疯」
  - 学习要点: 仪式重复三次 + 每次移位，把抽象誓言变成观众可数的舞台事件

## 与小说写法的对比

| 维度 | 小说会写 | 戏剧选择 |
|---|---|---|
| 谋杀真相 | 闪回直接呈现毒杀场面 | 鬼魂口述，恐怖由听者反应折射 |
| 哈姆雷特决意 | 数页心理斗争 | 一段独白 + 写笔记动作收束 |
| 保密约定 | 叙述者交代各人心理 | 三次移位宣誓的可见仪式 |

## 取舍清单

- **省略**: 炼狱实景 / 谋杀闪回 / 同伴们的内心反应
- **保留**: 毒杀过程的完整口述 / 宣誓仪式全程 / 装疯预告
- **位移**: 「装疯」决定本可独立成场，作者塞进宣誓尾部——让计谋诞生于狂乱余温中

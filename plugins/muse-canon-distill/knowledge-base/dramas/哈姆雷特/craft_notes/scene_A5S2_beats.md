# A5S2 戏剧手艺标注

## 场景定位
- act/scene: A5S2
- dramatic_purpose: 隐藏谋杀变成当众清算；旧王室连环死后福丁布拉接管
- 入选 craft 标注理由: 终局场的节奏总谱——纡缓追叙→谄臣插曲→决斗骤变→连环死→政权交接

## 节拍切分（8 个）

### 节拍 1：海上追叙
- 在场: 哈姆雷特 / 赫瑞修
- 行动: 追叙偷拆国书、伪造敕令送罗盖赴死（「结局还总归是神来安排的」）
- 状态交易: 哈姆雷特完成自我重估——从延宕者变为顺天命的行动者
- 手艺选择: **海上冒险全部走口述**，不演海战——情节费用最小化，性格转变最大化
  - 学习要点: 动作戏可以省，省下的篇幅给「讲述动作时的人」

### 节拍 2：奥斯力克插曲
- 行动: 谄臣传比剑之约，帽子戴脱之戏、热冷附和之谑
- 手艺选择: **死亡之约由小丑递达**——终局的请柬包在最轻浮的包装里
  - 学习要点: 大限将至前给一段纯讽刺喜剧，观众的不安因反差而加深

### 节拍 3：麻雀预感
- 行动: 哈姆雷特承认心头异样，拒绝赫瑞修的劝阻（「连一支麻雀之死, 都是预先注定的」）
- 手艺选择: 预感被说出又被放行——主角清醒赴死，宿命论替代侥幸
  - 学习要点: 让主角拒绝最后一个逃生口，终局才有同意书

### 节拍 4：和解致辞
- 行动: 哈姆雷特当众向雷尔提致歉（归罪于疯症），雷尔提口头领情、内心持械
- 状态交易: 表层和解/底层杀局同时成立
- 手艺选择: 致歉真诚而辩词诡辩（哈姆雷特否认哈姆雷特）——观众自行称量真伪

### 节拍 5：决斗与三重保险连环引爆
- 在场: 全宫廷
- 行动: 两回合哈姆雷特得点 → 国王投毒珠于杯 → 皇后代饮毒酒 → 雷尔提偷袭刺中 → 乱中换剑 → 雷尔提中毒剑
- 手艺选择: **A4S7 的每层保险逐一反噬其设计者**——毒酒杀皇后、毒剑杀双方
  - 短令式台词（著! /没中! /裁判!）把节奏切到最碎
  - 学习要点: 终局装置的引爆顺序应让误中者先于目标，失控感即天意感

### 节拍 6：连环死与当众点名
- 行动: 皇后倒地道破毒酒 → 雷尔提垂死供出全谋（「国王--国王就是罪魁」）→ 哈姆雷特以毒剑毒酒双杀克劳地
- 状态交易: 私密罪行在满朝目击下完成清算——复仇同时是公审
- 手艺选择: **供词由共犯临终给出**，复仇者杀君的合法性当场建立
  - 学习要点: 弑君必须先有当众供词，否则主角死后名誉无人担保

### 节拍 7：遗言与止杯
- 行动: 哈姆雷特夺下赫瑞修的毒杯（「留在这冷酷的世界里去忍痛告诉世人我的故事罢」），托名而死
- 状态交易: 叙事权移交——赫瑞修从见证者升格为故事的执行人
- 手艺选择: 主角遗言不留给复仇而留给「被正确讲述」——全剧对真相的执念收束于此

### 节拍 8：福丁布拉接管
- 在场: + 福丁布拉 / 英国大使
- 行动: 外部力量入场看到满台尸体；赫瑞修预告复盘；军礼抬尸、鸣炮幕落
- 手艺选择: **收场交给全剧几乎未出场的第三方**——权力真空由结构上的旁观者填补
  - 学习要点: 终局后需要一个未卷入血债的角色来恢复秩序，并由他给死者定价（军礼）

## 与小说写法的对比

| 维度 | 小说会写 | 戏剧选择 |
|---|---|---|
| 海上历险 | 实写章节 | 口述追叙，省戏给性格 |
| 决斗 | 慢镜多视角 | 短令台词 + 密集舞台指示逐拍推进 |
| 结局意义 | 叙述者总结 | 遗言托付 + 第三方军礼，意义由仪式呈现 |

## 取舍清单

- **省略**: 海战实景 / 罗盖之死的现场 / 福丁布拉的波兰战事
- **保留**: 追叙全程 / 奥斯力克插曲 / 决斗逐拍 / 四重死亡次序
- **位移**: 罗盖死讯由英国大使在终场补刀——所有支线债务都赶在幕落前清账

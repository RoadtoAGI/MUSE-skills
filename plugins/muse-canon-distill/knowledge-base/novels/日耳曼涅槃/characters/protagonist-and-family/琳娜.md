# 琳娜 — 个体画像

> 个体级分析笔记；角色间关系与功能分配见 `pipeline/phase2_character.yaml`，不在此重复。
> 蒸馏参考包见 `../lina/SKILL.md`（身份 / 欲望 / 声音 / 边界细节以彼为准）；本档互补：只谈作者的设计决策与叙事功能。

## 定位与功能

暗线枢纽（phase2）：从情欲纠缠（第36-39章）蜕变为反纳粹密谋组织联络人（第153章，scenes/scene_07.md），是方彦道德觉醒的点火器与"推翻纳粹"承诺的持券人。她也是方彦唯一分享部分真实政治立场的人——主角的面具在她面前才有第二个通气孔（第153-154章）。

## 设计决策（为什么这样设）

1. **污点起点**。作者给道德线载体安排了一桩道德犯罪做入场式——下药强占（第37-39章）。"情人"线由此从受害/加害的权力倒错开始而非俗套暗恋，同时预装了她的核心引擎：为所要之物可以越界的执行力。
2. **同一引擎驱动两条线**。下药（第38章）、照片要挟（第82章）、替方彦物色"猎人"并预设南美退路（第99章）——同一套不计代价的执行系统，先用于私欲，再用于共谋，最终交给反政权事业（第153章）。蒸馏包说她"爱与谋用同一套执行系统"，结构上正是作者复用性格引擎的经济学。
3. **第99章的清算设计**。她主动交还全部要挟照片，要挟关系正式清偿为自愿关系；同一章方彦立刻借她的渠道启动暗杀戈林——"真情成立"与"共谋加深"被压进同一章，爱与罪从此互为抵押。"等到猎人完成任务，我将把他送到南美国家隐居"（第99章）——她的缜密正是方彦敢伸手的前提。
4. **灰色渠道 = 影子执行系统**。美国挖专家靠她的人锁定目标（第98-99章），暗杀、善后、退路安排全走她的网络（第99章）——主角体制内身份不能沾的脏活，作者全部外包给这张网。她是方彦的影子内阁。
5. **四段变奏的关系结构**（phase2）：要挟（第37章）→情欲（第82章）→真情（第92章，scenes/scene_27.md）→同志（第153章）——每一段反转一次权力方向，关系每次升级都伴随一次筹码移交。
6. **艾瑞克 = 长线人质**。1934年2月生于斯德哥尔摩（scenes/scene_07.md），第110章分别前留子、随后独走瑞典五年隐居生养——悬置的宿命变量：这枚棋子浮出水面之日，即方彦与政权力量对比重排之时（phase2）。

## 双女主结构中的分工

方彦"喂养魔鬼 vs 备刀屠魔"的核心矛盾被拆进两个女人：西尔维娅承载政权的受益面（联盟红利、天伦），琳娜承载政权的罪恶面与清算线（暴行揭露第153-154章、密谋网络第301-303章）。道德觉醒的因果链——琳娜揭露→水晶之夜→方彦暗誓推翻（第153→157章）——全书道德线的点火权在她手里；此后方彦每一场胜利新增的道德负债，债权人名单上她排第一。

## 叙事功能小结

道德线载体 + 影子渠道 + 宿命变量之母。作者让全书起点最"脏"的人物持有最干净的政治立场，用她证明：在这部主角必须与魔鬼共舞的书里，良知只能由体制外的人保管。

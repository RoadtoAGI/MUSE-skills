# 黄药师（射雕英雄传）

## 身份与处境

桃花岛主，五绝中的"东邪"。琴棋书画、奇门遁甲、五行阴阳、医卜星相、农田水利无一不精。妻子冯衡因默背九阴真经耗尽心力而早死，留下独女黄蓉——黄蓉与亡妻几乎一模一样是他的终身痛点。门下六弟子（陈玄风、曲灵风、梅超风等）因各种原因断绝师门，唯独爱怜梅超风（她叛师夺经的那份"执念"与他的性情暗合）。与全真教因周伯通囚禁事件、与江南六怪因陈玄风之死、与洪七公因性情相差，积下半生纠葛。最终在铁枪庙真相大白后与郭靖重认女婿关系。

他不是"邪派宗主"的模板——他是一个"才具与孤独成正比"的天才。他行为乖僻不是道德有问题，是他对世俗规则的蔑视。他的"邪"不在恶，而在"从不为他人着想"——这是丘处机对他的判词，也是他内心默认的人生原则。

佐证：scenes/scene_18.md:L2-L73 （桃花岛三道试题——武功、箫筝、九阴真经全文——"才具"的完整展示）；scenes/scene_30.md:L7-L8 （与郭靖北极星位对阵时"心念忽动"：顾虑女儿而收掌——他的"邪"有一个绝对豁免：女儿）

## 核心欲望

- **自觉欲望**：保有女儿黄蓉+夺回九阴真经+在华山二次论剑证明自己比王重阳的弟子强——他的三条自觉欲望构成一个"私"字的金字塔
- **不自觉欲望**：被像冯衡（亡妻）那样理解他的人再次理解一次——他对黄蓉倾注的全部爱其实是对妻子的延续；他对"识者"（如郭靖一句"黄岛主必非乘人之危的卑鄙小人"）过度敏感的欣赏也源于此
- **核心缺陷**：他的才具让他无法接受"被误解"——他宁愿被当作魔头杀也不愿解释自己。黄蓉被郭靖冤枉时，他承担所有罪名（"不错，你那些师父通通是我杀的"）而不辩；但他这份不辩是给女儿的特权，不是给世界的姿态

佐证：scenes/scene_30.md:L18-L20 （"黄老邪自行其是，早在数十年前，无知世人便已把天下罪孽都推在你爹头上，再加几桩，又岂嫌多了？"——承担所有骂名给女儿看）；scenes/scene_30.md:L7-L8 （心念女儿"蓉儿这一生可永远不会快活的了"而收掌——他的"邪"对女儿绝对豁免）

## 性格真相

- **外在塑造**："东邪"——黑袍、长发、玉箫在腰——文人武者合一的宗师形象。动作飘忽、出手精微，是五绝中最"文"的一位
- **压力下的真实反应**：面对江湖他可以冷傲到底（"爽爽快快将黄老邪杀了"）；面对女儿他瞬间变为护短的父亲（甚至在郭靖毫无理由地攻击他时"哪知黄药师掌出尺许，突然收回"——宁愿自己受制也不愿伤她所爱之人）；面对妻子的回忆（如黄蓉长相"与亡妻更为相似"）他会柔软到伤感
- **裂隙**：冷傲（对外） ↔ 柔软（对女儿）——双极并存但永不交融。他的"邪"是面具，面具下是一个丧妻后把全部情感压缩到女儿身上的鳏夫

佐证：scenes/scene_30.md:L7-L8 （心念忽动收掌——冷傲中的柔软）；scenes/scene_19.md:L2-L140 （密室大战全真七子——同一个人对外与对内的两副面孔）

## 声音框架

他的声音以简洁、锐利、带文人气为特征。

关键特征：
- **极少多说一句话**——他经常用一声"哼"、一声冷笑、一句判决式短句完成交流："小畜生还有眼光"（七个字包含轻蔑+赞赏）
- **称呼等级感强**——对同辈（洪七公、王重阳）直呼外号或兄；对晚辈用"小子""姑娘"；对女儿称"蓉儿""我的好孩子"——称呼的柔软度反映关系的紧密度
- **诗文随口而出**——"桃花影落飞神剑，碧海潮生按玉箫"是他本人的生活美学
- **判决式断言替代论证**——"爽爽快快将黄老邪杀了，以成全真派之名，岂不美哉？"——用讽刺的反问替代解释
- **发作时用武功而非语言**——他发怒不吵架，直接出手，招到即止

佐证：scenes/scene_30.md:L19-L19 （"黄老邪一生独来独往，杀了几个人难道还会赖账？不错，你那些师父通通是我杀的！"——用最极端的"承担"姿态替代解释）；scenes/scene_30.md:L18-L18 （"好孩子，过来，让爹疼你"——对女儿的柔软称呼）

## 边界（Layer 0 硬规则）

- **绝不为自己辩解**——他的自尊建立在"众人皆浊我独清"的孤傲上。哪怕被江南六怪+全真七子+郭靖误解为害死五怪的凶手，他也用"是我杀的"来彻底否定解释的可能。
  ← 佐证：scenes/scene_30.md:L19-L19 （"不错，你那些师父通通是我杀的"——以承担代替辩解）

- **绝不伤害女儿所爱之人**——这是他唯一绝对的豁免。郭靖北极星位挡他的掌时他"心念忽动"收掌，不是因为打不过，是因为"蓉儿这一生可永远不会快活"。
  ← 佐证：scenes/scene_30.md:L7-L8 （北极星位收掌）

- **绝不违背对亡妻的情感**——他对黄蓉的爱、对冯衡坟墓的守护、对任何"与亡妻相似"的细节的敏感——都是他底层不可动摇的律条。桃花岛墓园和 S11 五怪惨死的设局之所以能刺痛他，正是因为凶手（欧阳锋+杨康）选择在他妻子墓中埋尸。
  ← 佐证：scenes/scene_30.md:L18-L18 （见女儿长大"与亡妻更为相似，心中又是欢喜，又是伤感"——对亡妻的记忆贯穿全书）

## 弧光（已完成）

- **起点**：桃花岛上孤傲的"东邪"——丧妻后将女儿一手带大，与世无接触，所有江湖关系都是他被动被拉进来的
- **终点**：第二次华山论剑后和女儿女婿一同度过——他仍是孤傲的东邪，但他承认了郭靖，他在梅超风替师而死的一幕后柔软了对叛徒弟子的评价。他的底色没有变，但"绝对孤立"的姿态松动了
- **核心转变**：从"自行其是，从不为他人着想"到"为一个人着想仍然可以"——这个人就是黄蓉。他不是变得更善，而是允许自己的柔软对一个具体的人显现
- **关键转折点**：
  - 三道试题考郭靖并许婚——他第一次认可了一个"非他那一级"的人可能配得上他的女儿。佐证：scenes/scene_18.md:L2-L73 （三道试题段落——郭靖凭背诵九阴真经全文险胜）
  - 北极星位对战时心念忽动收掌——他的"邪"对女儿的幸福让步。佐证：scenes/scene_30.md:L7-L8 （收掌）
  - 桃花岛真相大白后重认郭靖——他承担了全部误解的后果，仍然接回了女婿。佐证：scenes/scene_30.md:L19-L19 （"不错，你那些师父通通是我杀的"——承担式的重新接纳）

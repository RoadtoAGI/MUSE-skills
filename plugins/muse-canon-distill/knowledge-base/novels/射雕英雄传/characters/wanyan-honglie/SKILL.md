# 完颜洪烈（射雕英雄传）

## 身份与处境

大金国六太子，封赵王。年轻时以化名"颜烈"南下宋境做军机刺探，在牛家村被包惜弱救了一命——自此对包惜弱一见钟情，遂派段天德率官兵屠杀包惜弱与其丈夫杨铁心、郭啸天，自己假装侠义出手相救，一路骗她北上至金国，娶为王妃十八年。他是郭靖真正的杀父仇人、金国侵宋的主谋、杨康（假名完颜康）的养父——他对所有人的身份都是双面的。

他不是一个简单的"反派王爷"——他对包惜弱的爱是真的（十八年守着一个不爱他的人、房间按牛家村原样布置），但这份爱建立在他亲手策划的灭门惨案之上。他的外表是金国武功差劲的文弱王爷（搞谋略不搞武力），内核是精密到残忍的操纵者。

佐证：scenes/scene_01.md:L2-L2 （柴房中"眉清目秀，鼻梁高耸，竟是个相貌俊美的青年男子"——被包惜弱救时的初次登场，所有一切的起点）；scenes/scene_04.md:L33-L33 （赵王府风波后"眼见她虽死，脸上兀自有心满意足、喜不自胜之情……不禁心中伤痛欲绝，掉头而去"——对包惜弱之死的真实反应）

## 核心欲望

- **自觉欲望**：得到包惜弱、把她作为妻子永远留在身边——这是他一切谋划的原点，也是他认为自己正当性的来源
- **不自觉欲望**：被包惜弱选择而非被她接受。他不需要她当个顺从的妃子，他需要她主动回头说"我爱你"——正是因为永远得不到这个，他才会在她死后"伤痛欲绝，掉头而去"而非庆幸情敌已死
- **核心缺陷**：他把"得到"等同于"爱"。灭门、骗婚、替她复仇（其实仇人就是自己）、替她养大儿子、按她家乡布置房间——他做的一切都是"更深的拥有"，从不让她有选择"离开"的可能

佐证：scenes/scene_01.md:L2-L2 （柴房定情——她低头喂他鸡汤，他"凝望着她，显是不胜感激"，这是整个十八年的起点）；scenes/scene_04.md:L33-L33 （她殉情时他才显出真情——"伤痛欲绝"，但已经晚了）

## 性格真相

- **外在塑造**：温文尔雅、礼贤下士的大金王爷。在赵王府里他对沙通天、彭连虎、梁子翁、灵智上人等武林高手都"折节下交"，对养子完颜康和王妃包惜弱"总是温言软语"；身边谋士武士环绕，讨好他的人排长队
- **压力下的真实反应**：所有温文只是营造条件——他真正的手段是"把暴力外包给段天德""把侦查外包给杨康""把武力外包给欧阳锋"，自己永远不出手不见血。他的桌面上永远是"我只是个可怜被救的路人/被妻子鄙弃的丈夫/被儿子恨错的养父"。直到临安大闹禁宫被郭靖撞破，他才显出"完颜洪烈"真身——与欧阳锋密谋南下侵宋、抢夺《武穆遗书》
- **裂隙**：他对包惜弱有真情 ↔ 他对包惜弱的真情建立在他亲自策划的灭门上。他无法承认这个逻辑矛盾，所以他的一生都在以"我是救她的人"自我叙述——哪怕段天德在灵位前当着他养子的面招供了真相，他仍然是"赵王"，仍然带兵南下

佐证：scenes/scene_04.md:L33-L33 （对包惜弱的真情显影——"伤痛欲绝，掉头而去"）；scenes/scene_08.md:L3-L3 （被郭靖等撞破侵宋密谋——真身显露，但整个规划都是他启动的）

## 声音框架

他几乎不直接出手说狠话——所有威胁、命令都外包给下属。他自己的对白永远"温言软语""正色道""凛然道"，用恩义话术包装占有欲。

关键标志是称呼系统的精准切换：
- 在牛家村柴房对包惜弱：低声、谦卑、"娘子"——营造被救者的感恩姿态
- 面对金国武士团体：王爷口吻，但仍客气（"两位千万不要误会"）
- 密谋侵宋时对欧阳锋：平等盟友口气，从不显颐指气使
- 对养子杨康：永远温言，是刻意塑造的"慈父"模板

他的对白中几乎不出现"杀""害""抢"这类词，用的是"办理""拿下""对付"。承诺时习惯用"那还不容易？"的轻佻句式降低对方警惕。顿词（"顿了一顿"）是他说服别人时的节奏标志——他用停顿让对方自己填入贪婪或认同。

佐证：scenes/scene_01.md:L17-L17 （包惜弱病中醒来，"颜烈"以"娘子"称呼并自称"小人"——全程谦卑恭敬语调）；scenes/scene_01.md:L19-L19 （"小人路见不平，出手相救，不料老天爷有眼，所救的竟是我的大恩人"+"义愤于色，昂然道：'娘子要报杀夫之仇，这件事着落在小人身上'"——正色/昂然/义愤的表态是他最常用的三种姿态）

## 边界（Layer 0 硬规则）

- **绝不亲自见血**——他策划灭门、通敌、派刺客、抓犯人，但永远不出手杀人。整部书他没有亲手杀过任何一个人，所有暴力都通过段天德、欧阳锋、沙通天、灵智上人等外包执行。

- **绝不在包惜弱面前暴露"完颜洪烈"的残忍面**——她看到的他永远是"赵王+深情丈夫"。直到段天德在她丈夫灵位前当面招供，她才彻底知道真相，然后立刻撞墙殉情——她宁愿死也不愿承认自己二十年跟的是仇人。
  ← 佐证：scenes/scene_04.md:L32-L33 （包惜弱"举头猛往墙上撞去"——这是她知道真相后唯一可能的反应）

- **绝不放弃对包惜弱的"挽留叙事"**——即使她已经识破真相、殉情而亡，他仍以"赵王+被死去妻子深爱的丈夫"身份带兵南征为她"报仇"。他从不自我否定整个故事的前提。

## 弧光（已完成）

- **起点**：牛家村柴房中被包惜弱救起的金国青年——命运的原点是"她救了我"。这个原点他用一生把它强化成"我救了她""她应该爱我"
- **终点**：包惜弱殉情、杨康败亡、侵宋阴谋失败——他所有的努力（十八年养妻、十八年养子、十八年谋略）在短时间内全部崩塌。但他的自我叙述从未改变——他到书末仍然是完颜洪烈，仍然筹划着下一场。在《射雕》中他并非在"转变"，而是在"暴露"
- **核心转变**：这是一个**没有真正转变**的角色——他的弧光不是内部成长，而是外部真相被层层剥开。他不承认任何层的剥开。最终他消失在"金国侵宋"的大叙事里，像真实历史中所有这类王爷一样——以"金国六太子"而非"骗走包惜弱的凶手"进入史书
- **关键转折点**（对他个人而言）：
  - 包惜弱撞墙殉情——他第一次看到真情被真相瞬间摧毁。但他没有崩溃，只是"伤痛欲绝，掉头而去"——第二天继续是赵王。佐证：scenes/scene_04.md:L33-L33 （"脸上兀自有心满意足、喜不自胜之情……不禁心中伤痛欲绝，掉头而去"）
  - 段天德在郭啸天灵前当众招供——他的核心秘密被公开，但他拒绝承认转折已发生，继续扮演赵王并派欧阳锋等追击郭靖。佐证：scenes/scene_08.md:L3-L3 （密谋侵宋被撞破后仍布局进攻——核心秘密被揭后他拒绝承认其重要性）

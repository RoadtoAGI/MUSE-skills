# 洪七公

## 塑造 vs 真相

**社会面具**：馋嘴乞丐——背后偷听讨要鸡屁股出场，断了食指因为贪吃误事，自称"老叫化"。

**压力下的真实面孔**：第21回他冒死从火海中救出欧阳锋——这不是判断失误，而是"好人"的本能。被偷袭重伤后，他的反应是无声地承受，而不是愤怒。第39回面对裘千仞的道德拷问，他是唯一能正面回应的人："一生杀过二百三十一人，个个都是恶徒。"——不是"我无罪"，而是"我杀得对"。

**落差**：外表最不庄严（乞丐、馋嘴、断指），内在最为庄严（二百三十一条人命，每一条都记得清楚）。

## 压力下的关键抉择

1. **第21回：火海救敌**——明知欧阳锋是最大对手，仍冒死相救。揭示：他的道德感是本能层面的，不经计算。代价：被反咬一口，武功尽失。
2. **第22回：传位黄蓉**——自知伤重难愈，将帮主之位和打狗棒法传给十五岁少女。揭示：他对人的判断不看年龄资历，只看品性能力。
3. **第39回：回应裘千仞**——"二百三十一人"的精确数字。揭示：他一生都在清算自己的杀人账——这种自律不是苦行，而是**确保每一次出手都问心无愧**。

## 声音特征

| 维度 | 特征 |
|------|------|
| 基础句式 | 口语化但掷地有声，自称"老叫化"，骂人不避粗俗 |
| 独特标记 | "算账"式的精确感——"二百三十一人""第二百三十二人" |
| 语气模式 | 先承认缺点（"贪饮贪食"），再亮出底牌（"从没杀过一个好人"）——先抑后扬 |
| 与欧阳锋对比 | 洪七公粗犷坦荡 vs 欧阳锋文雅阴毒；两者武力相当，道德方向相反 |

## 关键对白

> "撕作三份，鸡屁股给我。"（第12回——以最不庄严的方式出场）

> "老叫化一生杀过二百三十一人，这二百三十一人个个都是恶徒……老叫化贪饮贪食，可是生平从来没杀过一个好人。裘千仞，你是第二百三十二人！"（第39回——全书道德立场的定音锤）

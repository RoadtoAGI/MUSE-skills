# 欧阳锋

## 塑造 vs 真相

**社会面具**："西毒"——白驼山主，五绝之一，武功与洪七公旗鼓相当。人称"老毒物"，以毒蛇为兵器。

**压力下的真实面孔**：第21回洪七公冒死救他于火海，他转手以毒蛇噬其后颈。"容情不下手，下手不容情"——这不是临时起意，而是深思熟虑的原则。他最核心的特质是**纯粹的技术主义**：评价人的标准只有"能"与"不能"，不涉善恶。在铁枪庙被黄蓉激将时，他**明知是圈套仍要炫耀**——"人家叫我老毒物，难道是白叫的吗？"——狂傲压过一切谨慎。

**落差**：他不是没有审美——他真心赞赏黄蓉的智慧（"我真羡慕黄老邪生了个好女儿"），对郭靖也有过"饶三次不死"的信守。但这些"体面"全都建立在对力量的绝对崇拜之上。

## 压力下的关键抉择

1. **第21回：偷袭洪七公**——恩将仇报，但在他的逻辑中这是"理性选择"：消灭最大对手。揭示：他眼中没有"恩"的概念，只有"利"。
2. **第35回：铁枪庙自曝**——被黄蓉激将后坦然承认一切，甚至赞赏对手。揭示：他的狂傲来自对自身能力的绝对自信，不需要掩饰。
3. **第40回：逆练九阴真经**——明知经文被篡改仍执意修练。揭示："天下第一"的执念最终反噬了他。

## 弧光

**起点**：五绝中与洪七公并列的顶级高手
**终点**：逆练经脉获得怪力但疯癫——追着自己的影子逃下华山

弧光的讽刺性：他一生追求"天下第一"，最终确实获得了超越五绝的武力，但代价是失去了自我——被黄蓉一句"你是谁？"彻底击溃。**追求力量到极致的人，最终被力量本身吞噬。**

## 声音特征

| 维度 | 特征 |
|------|------|
| 基础句式 | 判断句、短句为主，从容不迫 |
| 独特标记 | "笑"与"冷然"交替——不是社交性的笑，而是居高临下的鉴赏式笑 |
| 语气模式 | 即使被揭穿也不慌乱，只是"叹道"一声——叹的不是懊悔，是对不完美的微微遗憾 |
| 与洪七公的对比 | 洪七公口语化但精确如"算账"；欧阳锋文雅冷酷，自诩超然于善恶之上 |

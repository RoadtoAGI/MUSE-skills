# 杨康

## 塑造 vs 真相

**社会面具**：翩翩公子，温文尔雅，出口成章，措辞永远得体周全。对母亲撒娇讨巧，对穆念慈柔情蜜意，对敌人笑容满面。

**压力下的真实面孔**：第15回得知身世后，他的第一反应是杀死段天德灭口——虽有报仇成分，也切断了对自己不利的信源。接着他说出所有"正确答案"（认祖归宗、改姓、誓言报仇），但叙述者直接点破：他在犹豫是否通知完颜洪烈。**在"义"和"利"的撕扯中，他永远先看对方脸色，说出对方想听的话，而将真实选择延后。**

**落差**：他不是不知善恶——他知道。正因为他"知善"却"不能行善"，才构成真正的悲剧。穆念慈的存在证明他有柔软的一面，但这一面从未强大到足以改变他的选择。

## 压力下的关键抉择

1. **第11回：拒认生父**——目睹生母殉情，丘处机怒斥其"畜生不如"，他仍选择留在赵王府。揭示：对富贵的贪恋已深入骨髓。
2. **第15回：得知身世**——杀段天德、表态改姓、却暗中犹豫是否通知完颜洪烈。揭示：说的是"正确答案"，做的是利益计算。
3. **第35回：拜欧阳锋为师**——"师父，徒儿磕头"，声音中充满喜悦。揭示：他已彻底放弃了回头的可能。

## 维度 = 矛盾

- **知善 vs 行恶**：他明知杨铁心是生父、完颜洪烈是仇人，却选择后者——不是因为不知对错，而是因为无法放弃已有的一切
- **聪明 vs 短视**：他的权谋才华远超郭靖，但只用于眼前利益，看不到更远处的毁灭
- **柔情 vs 冷酷**：对穆念慈有真感情，对母亲有真孝心，但这些"真"从未强大到改变他的选择方向

## 弧光

**起点**：赵王府中备受宠爱的小王爷
**终点**：铁枪庙前中毒扭曲而死，群鸦啄尸亦相继毒毙

弧光是**持续下坠**——每次给出"回头"的机会（认祖归宗、穆念慈之恋、与郭靖结义），他都选择了更容易的那条路，直到无路可退。

## 声音特征

| 维度 | 特征 |
|------|------|
| 基础句式 | 得体工整，多用谦辞（"在下""晚辈""罪该万死"） |
| 独特标记 | 永远带笑——"笑嘻嘻""笑道""哈哈大笑"，笑中裹着轻蔑和算计 |
| 语气模式 | 对不同对象切换面目：对母亲撒娇、对穆念慈柔情、对敌人从容 |
| 压力下变化 | 唯一一次露出犹疑是"我那……那完颜洪烈"——停顿暴露了内心裂缝 |
| 与郭靖的对比 | 郭靖说不出话，杨康说太多话；郭靖的沉默是真实，杨康的流利是面具 |

## 关键对白

> "小弟今日才知确是姓杨，'完颜'两字，跟小弟全无干系。"（第15回——说的是正确答案，但心中另有盘算）

> "师父，徒儿磕头。"（第35回——声音中充满喜悦。拜欧阳锋为师，彻底堕入深渊）

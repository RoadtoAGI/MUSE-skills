# 完颜洪烈（赵王）

## 塑造 vs 真相

**社会面具**：金国六王子——英俊温文、礼贤下士。以"颜烈"之名救包惜弱于危难，以恩义包装占有欲，十八年如一日地扮演深情丈夫。

**压力下的真实面孔**：他是全书最精密的操控者。牛家村惨变中，他安排段天德屠杀郭杨两家，自己"假装侠义"出手相救——将暴力外包，把自己置于温情角色。对包惜弱说"官人的血海沉冤，自有小人一力承担"——每句话都将对方推向依附。

**落差**：他对包惜弱的感情不全是伪装——第11回包惜弱殉情后，他"眼见她虽死，脸上兀自有心满意足、喜不自胜之情……不禁心中伤痛欲绝，掉头而去"。这个细节揭示了一个复杂的真相：他的爱是真的，但他的爱建立在灭门之上。

## 声音特征

| 维度 | 特征 |
|------|------|
| 水磨柔声 | 称呼"娘子""小人"，语气恭谨，但每句话都在引导对方依附 |
| 谋略者的节奏 | 密谋时用"顿了一顿"制造停顿，让盟友自己填入贪欲 |
| 绝不亲自见血 | 话语中从无"杀"字，只有"拿下""办理""对付" |
| 承诺轻佻化 | "那还不容易？"——用轻描淡写降低对方警惕 |

## 关键对白

> "娘子的活命大德，小人终身不敢忘记。"（第1回——以恩义话术包装占有欲，每个字都是精确的权谋）

# 马钰（丹阳子）

## 塑造 vs 真相

**社会面具**：全真教掌教——王重阳首徒，七子之首。原文直接用"语调甚是平和冲淡"形容。

**压力下的真实面孔**：他是全书最安静的帮助者。远赴大漠暗中传授郭靖内功两年，不留师徒名分，不告诉郭靖这是内功——"我就传你一些呼吸、坐下、行路、睡觉的法子"。最高深的功法被说成最日常的事。他不是为了全真教的面子，而是出于"抑己从人"的道家至理，又不愿让六怪觉得被占了便宜。

**落差**：全真七子中武功并非最高，但修为最深——他的"强"不在战斗力，而在对人心的洞察和克制。

## 压力下的关键抉择

1. **第5回：暗授内功**——只传内功不传武功，身份暴露后仍不居功："只是贫道结交一个小朋友。"揭示：帮人不求名是真正的修行。

## 声音特征

| 维度 | 特征 |
|------|------|
| 核心词 | "冲淡"——永远把别人的面子放在前面 |
| 谦辞 | "贫道"在他口中是真正的谦辞，不像丘处机的反差使用 |
| 以退为进 | 先说"这法子有点狂妄自大"，再提出实则保全众人的计策 |
| 不说教 | "呼吸、坐下、行路、睡觉"——把最高深的东西说成最平常的事 |
| 沉默的善意 | 两年间从不主动现身，身份暴露后仍不居功 |

## 关键对白

> "思定则情忘，体虚则气运，心死则神活，阳盛则阴消。"（第5回——全真内功心法，以最平淡的语气传授最关键的根基）

# 柯镇恶（飞天蝙蝠）

## 塑造 vs 真相

**社会面具**：江南七怪之首——目盲、暴躁、铁杖如命。说话从不绕弯，铁杖顿地就是他的感叹号。世人看他是一个偏激的盲人老头。

**压力下的真实面孔**：铁枪庙中旁听真相后，他的第一反应不是冲出去拼命，而是对自己的审判——"柯镇恶啊柯镇恶，你这杀千刀的贼厮鸟，臭瞎子，是你生生逼死这位好姑娘了！"骂人时骂自己更狠。他的暴躁不是性格缺陷，而是一个看不见世界的人用最激烈的方式确认自己还活着。

**落差**：看似最不讲理的人，实则最重道义——在桃花岛上他第一个痛哭，在铁枪庙中他第一个自责。

## 压力下的关键抉择

1. **第34回：五怪惨死**——他认定黄药师是凶手，逼郭靖杀黄蓉父女。以暴怒遮盖悲恸，宁可误杀不可放过。揭示：盲人的判断依赖听觉和推理，一旦前提错误，结论就不可逆。
2. **第35回：铁枪庙隐忍**——听从黄蓉的暗示不冲出去送命，以隐忍换取真相传播。这是他一生中极少数克制暴性的时刻。

## 声音特征

| 维度 | 特征 |
|------|------|
| 句式 | 极短促，硬、冲、直来直去 |
| 自贬+激愤 | "我们本事低微"紧接"可也不能让旁人来欺压"——先低后硬 |
| 忌讳 | 最忌讳"瞎"字，一触即怒 |
| 声音签名 | 铁杖顿地为标点符号 |
| 骂人特色 | 骂自己比骂别人更狠——"杀千刀的贼厮鸟，臭瞎子" |

## 关键对白

> "我们本事低微……可也不能让旁人来欺压了。"（第2回——先低后硬的声音模式）

> "柯镇恶啊柯镇恶，你这杀千刀的贼厮鸟，臭瞎子，是你生生逼死这位好姑娘了！"（第35回——全书最狠的自我审判）

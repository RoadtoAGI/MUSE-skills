# 梅超风（铁尸）

## 塑造 vs 真相

**社会面具**：黑风双煞——偷经叛师、练九阴白骨爪滥杀无辜的女魔头。全身关节格格作响，枭鸣般的叫声，以骷髅为练功道具。

**压力下的真实面孔**：丈夫陈玄风临死时说"贼婆，快逃命"，她说"我给你报仇"——"贼婆""贼汉子"是夫妻间的暴力昵称，底下是真实的相依为命。更深处，她对黄药师的依恋从未消失：第25回她沉默地扑上去，用身体为师父挡了欧阳锋致命一掌。

**落差**：世人看她是"魔"，但她一生的行为逻辑始终围绕"对师父的爱与恐惧"——偷经是为了和陈玄风逃离桃花岛的控制，替师而死是回归了最初的忠诚。

## 压力下的关键抉择

1. **第4回：丈夫被杀**——首先做的不是逃命，而是去摸丈夫胸口的九阴真经。揭示：即使至亲死亡，她仍被欲望驱动——但这个欲望也包含了对丈夫遗愿的遵从。
2. **第25回：替师挡掌**——没有一句话。揭示：她的终极表达不是语言，而是身体。叛徒以命偿还叛师之罪，换得师父的一声"超风"。

## 弧光

**起点**：偷经叛师的女魔头
**终点**：替师挡掌而死，获黄药师临终一声"超风"——原宥

弧光的核心：从"人"变成"魔"（偷经、练九阴白骨爪），又由"魔"变成"人"（替师而死）。只要心存"义"的火苗，就有灵魂救赎的可能。

## 声音特征

| 维度 | 特征 |
|------|------|
| 口头禅 | "老娘"、"贼汉子/贼婆娘"——夫妻间的暴力昵称 |
| 两极化 | 对敌人凶狠至极，对丈夫和师父有深到骨髓的依恋 |
| 沉默型高潮 | 最重要的时刻（替师挡掌）没有一句话 |
| 声音签名 | 全身关节格格作响；枭鸣般的尖叫 |

## 关键对白

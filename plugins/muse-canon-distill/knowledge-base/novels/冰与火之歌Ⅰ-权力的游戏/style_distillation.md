# 《权力的游戏》文风蒸馏

## 元数据与证据范围

- 作品：冰与火之歌Ⅰ；语言：中文译本；形态：多 POV 史诗奇幻长篇。
- 依据：`style_card.yaml`、`navigation.md`、20 个代表场景及其 craft notes；重点抽样艾莉亚目睹处刑、宫廷问答、北境仪式与丹妮火葬。
- 适用：卷级风格检索、派生写作约束、系列续写校验；不是原文替代品。

## 稳定文风指纹（7 维）

1. **限知 POV**：每章锁定一人，叙述被年龄、身份、欲望和误判染色；儿童尤其不获得成人政治解释。
2. **句法节奏**：日常生存、仪式和名物用中长句累积；暴力、识破和背叛到来时骤缩为短句或单一动作。
3. **词汇质地**：书面叙述混入贵族礼语、市井俚骂、军务与异域音译词；食物、衣甲、气味和触感高频。
4. **修辞密度**：中等；狼、鹿、乌鸦、雨、玫瑰等意象承担家族、情绪与伏笔，不堆纯装饰比喻。
5. **对白**：称谓即权力；问答兼具试探、羞辱和交易，关键处一句落槌。
6. **信息释放**：先让 POV 看见局部证据并形成可能错误的判断，后由另一动作或另一章翻面。
7. **转场**：以死亡、认知裂缝、身份揭示或物件异变收章；跨 POV 并置，不由旁白替读者串讲。

## 合法变化

- 临冬城线可更克制、重礼法与季候；君临线可增加称谓、流言与话里藏刀；长城线强化寒冷、纪律和局促身体感；丹妮线允许异域仪式、色彩和气味更密。
- 艾德句面端正而受荣誉框限；提利昂机锋更快；珊莎带歌谣滤镜；艾莉亚关注食物、逃路和身体；布兰以儿童空间感承接超自然。
- 变化不能突破当章认知上限，也不能把地域差写成百科说明。

## 不可漂移不变量

- 单章单 POV；无越权内心、无全知善恶裁判。
- 政治必须落到称谓、座次、信件、兵器、婚约或身体代价。
- 暴力不是英雄爽点；重大死亡可被遮挡、省略或由旁观者残缺感知。
- 行动先于解释，读者应比人物多懂一点、但不能由旁白一次讲透。

## reuse 判定表

| 类别 | 可复用 | 必须避免 |
|---|---|---|
| `literal_reuse` | 专名、固定称号、地名、制度与器物名；必要的短誓词 | 标志性金句、连续原句、独特比喻链 |
| `normalized_reuse` | 文白比例、称谓层级、归属句式、长铺短断、感官节拍 | 保留原句序只换同义词 |
| `semantic_reuse` | POV 误判、仪式反转、物证翻面、高潮省略、意象回环 | 复刻处刑、坠塔、熔金、火葬的原节拍组合 |

## 最小归一操作

1. 删去 POV 不可能知道的解释；2. 抽象情绪改为食欲、疼痛、动作或误读；3. 按身份恢复称谓和语域；4. 铺陈只留有空间／制度功能的名物；5. 转折段压短；6. 结尾删复盘，停在不可逆动作。

## derivative：四种 reuse_mode

- `fan_fiction`：可保专名、称谓和角色口吻；新事件不得套用原作著名场面的完整节拍。
- `sequel`：优先继承 POV 认知边界、母题回声和后果链；新阶段语气可成长，但不能突然全知。
- `spin_off`：地域词库可换，单 POV、物质权力与身体代价必须保留；边缘人物应有自己的偏见。
- `cross_style_rewrite`：允许改句面和密度，只保留信息差、行动先行、反英雄暴力与章末落锤。

## serial：章际／POV 连续性

- 登记每章 `pov_knows / pov_believes / reader_knows / hidden_fact`；下一章只能消费已获得的信息。
- 用同一物件或传闻在不同 POV 中变义，不重复解释同一事件。
- 章尾承诺应在后续异地线延迟兑现；角色声音随经历变化，但核心盲点需有可追踪因果。

## 机器 constraints

```yaml
style_constraints:
  - id: agot_pov_lock
    rule: "每章仅访问当前 POV 的感官、记忆与推断"
  - id: agot_age_filter
    rule: "儿童 POV 不使用成人政治概念替其总结"
  - id: agot_material_power
    rule: "每个权力冲突至少落到一个称谓、座次、契约或物件"
  - id: agot_body_cost
    rule: "每个暴力场至少呈现一种身体代价"
  - id: agot_register
    rule: "对白语域必须随身份变化，禁止全员同声"
  - id: agot_turn_short
    rule: "转折段平均句长须短于铺陈段"
  - id: agot_no_moral
    rule: "禁止全知旁白裁判善恶或认证动机"
  - id: agot_end_weight
    rule: "章末停在揭示、拒绝、死亡或不可逆动作，不作主题总结"
  - id: agot_motif
    rule: "母题复现必须同时改变情绪或信息意义"
```

## dispatch 注入建议

注入 `work_style=agot`、`pov`、`region`、`reuse_mode`、`allowed_literal_terms`、`forbidden_scene_templates`；要求 writer 回执 POV 边界、采用的归一手法及复用位置。不要把原文长段放进 prompt。

## 回执分类示例

- `literal_reuse`：`临冬城`、`守夜人`等专名，列正文位置。
- `normalized_reuse`：报告“称谓包裹威胁 + 短句落槌”，不得贴伪原句。
- `semantic_reuse`：报告“儿童受限视野承载政治灾难”，注明新场景差异。
- `no_fit`：无贴切原词时空清单并说明原因；不得硬塞。

## 验收 checklist

- [ ] 单章单 POV 且知识边界可核对
- [ ] 地域与身份语域有差异
- [ ] 权力、情绪和暴力均有物质承载
- [ ] 无标志性原句／场景节拍近似复刻
- [ ] 章末落锤且未旁白复盘
- [ ] 回执逐项区分 literal／normalized／semantic

# 钱塘龙君

## 欲望系统

作为超自然存在，欲望系统不完全适用。他对李白的态度是「保护+警告」的混合——既帮助（广陵渡头解围），又预言（「不容天真」）。

## 弧光

钱塘龙君不变——他是一个常量，一面镜子。每次出现都映照出李白的处境：

| 出场 | 功能 |
|------|------|
| 洞庭湖畔（卷二·一） | 被李白焚文劝退。评价：「即此一派天真，百世不遇。然……当今世道，不容天真！」 |
| 广陵渡头（卷三·五-六） | 从江中现身助李白，引其登西灵塔论生死。 |
| 酒壶回响（卷三·三三） | 不直接出场，但吴指南的酒壶（来自洞庭湖畔一幕）从天而降。 |

## 声音特征

**语域**：文言偏诗化，带超自然的威严与慨叹。

**关键对白**：

> 「即此一派天真，百世不遇。然某所深以为忧者，亦在于此：当今世道，不容天真！」——卷二·一

> 「汝今凡身姓'李'，是天子宗室耶？」——卷二·一，直接追问李白身份。

> 「太白！某所言，慎勿轻忘；当今世道，不容天真。倒是令尊'指天枝以复姓'为有见识——汝走闯风尘，天家姓氏尽可随处抖擞，好教普天下人敬重汝家郡望。」——卷二·一，既是忠告也是策略建议。

## 叙事功能备注

钱塘龙君是全书中唯一直接对李白说出「你将失败」的存在。在一个充满隐晦暗示的叙事中，龙君的直言是一种破格——他拥有超越人间规则的视角，因此能说出人间角色说不出的话。

他的存在也为全书的「考据写实」基调提供了魔幻现实主义的对位——张大春选择让一个龙来说出最清醒的真话。

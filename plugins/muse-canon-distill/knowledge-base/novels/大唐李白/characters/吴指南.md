# 吴指南

## 欲望系统

- **自觉追求**：追随李白——但不理解李白要去哪里。
- **不自觉需要**：被李白真正看见/理解——「某与李十二生小为邻，朝夕相伴，将二十载，至今仍不识此人」（卷二·一）。
- **核心缺陷**：忠诚但无法跟上李白的精神世界——他是世俗的、直率的、扎根于当下的人。

## 弧光

| 阶段 | 状态 |
|------|------|
| 起点 | 与李白深夜闯大匡山，金铁鸣声（卷一·八） |
| 相伴 | 随李白出蜀、漫游，始终在场但多为沉默角色 |
| 裂痕 | 追问李白私吞父命资财——不理解变成了委屈（卷二·二一） |
| 终点 | 洞庭湖畔遇虎，临终吼啸驱虎（卷二·二二） |
| 回响 | 酒壶从天而降——全书最后的超自然回声（卷三·三三） |

## 塑造 vs 真相

- **面具**：粗犷、豪侠、不拘小节。说话带乌蛮语调，冷嘲热讽。
- **真相**：临终前的追问暴露了内心——他一直活在李白的阴影里，追随了二十年却始终不被真正理解。他的忠诚里藏着委屈。
- **关键选择**：面对虎时的吼啸——这是全书中吴指南唯一一次「主动」的行动（此前他始终是「跟随者」）。他用死亡完成了唯一一次对李白的保护。

## 声音特征

**语域**：口语化，粗犷，带乌蛮语调。

**言语模式**：
- 标志性发语词：「呔呀！呜呼呼呀！」——乌蛮人的习惯用语
- 说话直率不加修饰，偶尔冷嘲中带亲昵
- 对李白的评价总是半嘲半敬

**关键对白**：

> 「此子读书作耍二十年，也混充得士人行了。」——卷二·一，对钱塘龙君评价李白。冷嘲中有亲昵，亲昵中有不甘。

> 「某与李十二生小为邻，朝夕相伴，将二十载，至今仍不识此人；某果安于盲哉？不安于盲哉？有甚分别？」——卷二·一，论自己的「盲」。表面说眼疾，实际说与李白二十年的「看不透」。

> 「前月在江陵与一酒徒共饮，彼道：某合得一死于此——死也便死了，盲也便盲了」——卷二·一，预言般的自嘲。

## 共情机制

吴指南的共情力来自他是全书中最「普通」的人——在一群诗人、隐士、龙君、道士之间，他是唯一一个没有特殊才华、没有神秘身世、只是因为从小和李白一起长大就跟着走到天涯海角的人。他的死令人心碎，正因为他太普通了。

酒壶在全书结尾从天而降——这个超自然回声说明：最普通的忠诚，反而拥有穿越时空的力量。

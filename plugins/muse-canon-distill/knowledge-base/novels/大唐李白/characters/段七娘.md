# 段七娘

## 欲望系统

- **自觉追求**：以音乐为生，以自由为命。不属于任何人，不停留在任何地方。
- **不自觉需要**：被理解——她改编李白的诗入乐，是在用音乐回应一个她理解的灵魂。
- **核心缺陷**：自由的代价是永恒的漂泊。化名「制衣娘子」游走各州——自由者必须隐匿身份。

## 弧光

| 阶段 | 状态 |
|------|------|
| 出场 | 金陵孙楚楼，与瞽叟演奏（卷二·二三） |
| 交汇 | 改编《望庐山瀑布》入乐——以音乐回应李白（卷二·二四） |
| 分离 | 离开金陵，化名制衣娘子（卷三·十二） |
| 终场 | 安州最后一面，歌中悟舍得（卷三·三二） |

弧光类型：**不变弧**——段七娘始终保持自由，是全书中唯一没有被「收编」的主要角色。

## 塑造 vs 真相

- **面具**：以音乐行走天下的自由女子，温和但疏离。
- **真相**：「好因缘恰是恶因缘」——她理解李白，但正因为理解，她知道两个自由灵魂不能相互束缚。她的离去不是冷漠，而是对自由本质的清醒认知。

## 声音特征

**语域**：以音乐代替言语。段七娘的「对白」多通过歌曲传达。少量直接对话，温和但疏离。

**关键行为**（代替对白）：
- 将李白的诗改编为歌曲——这比任何对白都更亲密
- 最后一面以歌点破心结——不用语言而用音乐做了了断

## 维度 = 矛盾

段七娘的矛盾是「理解 vs 不可拥有」——她是全书中最理解李白的人（通过诗和音乐的互通），但正因为理解，她知道李白需要的不是另一个漂泊者，而是一个落脚点。她主动让出了那个位置。

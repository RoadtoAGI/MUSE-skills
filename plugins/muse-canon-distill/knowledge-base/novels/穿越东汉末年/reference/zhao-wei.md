# title

赵韪（zhao-wei）历史原型参考

# scope

用于《穿越东汉末年》中“刘焉、刘璋治益州初期的本地/州府权力人物”参考。核心时间段为刘焉入蜀、刘璋继位、建安五年前后赵韪反刘璋及败死江州。可证事实少，不可扩写。

# historical_grounding

- 《后汉书》载，刘焉死后，州大吏赵韪等因刘璋“温仁”而立其为刺史，朝廷随后以刘璋领益州牧，并以赵韪为征东中郎将。
- 同传记东州兵问题：南阳、三辅流民入益州，刘焉收为“东州兵”；刘璋柔宽无威，东州人侵暴，旧士离怨。赵韪在巴中“甚得众心”，受刘璋委权。
- 建安五年，赵韪阴结州中大姓，反攻刘璋；蜀郡、广汉、犍为响应。后东州兵因惧被诛灭，合力为刘璋作战，反攻赵韪于江州并斩之。
- 《华阳国志》补充：庞羲与刘璋生隙时，“赵韪数进谏，不从，亦恚恨也”；建安五年赵韪“起兵数万”攻刘璋，次年败。

# novel_usage_notes

- 可作为益州政局的“夹层权臣/地方协调者”：他不是单纯外来军阀，而是州府大吏，曾参与刘璋继位安排，又被委以巴中权力。
- 可用冲突轴：东州兵与益州旧士矛盾、刘璋软弱宽纵、州中大姓不满、赵韪个人失望与政治野心交织。
- 性格刻画宜保守：可写其善于结纳地方豪右、在巴中有人望、敢于军事冒险；不可直接写成“忠臣被逼反”或“纯粹奸臣夺权”，正史只给出权力与民怨背景。
- 与刘璋关系可写成“拥立者转为叛乱者”：先因刘璋温仁可控而拥立，后因刘璋不能制东州兵、又不纳谏而转向反叛。

# adversarial_check

- 过度推断风险：赵韪“贪璋温仁”可解释为看中刘璋性格温和，但不能直接断言他从一开始就计划长期操控益州。
- 正史冲突风险：不能把赵韪写成刘备入蜀时期仍活跃的人物；其败死在建安五年后不久，早于刘备入益州。
- 演义/通俗误植风险：赵韪不是赵云、赵累、赵范等同姓人物；不得借用《三国演义》中无关赵姓武将事迹。
- 地理/势力风险：其核心活动在益州、巴中、江州语境，不应写成荆州或中原军阀。
- 资料稀薄风险：正史没有提供年龄、字、家族谱系、具体战术、私生活、外貌；这些均不可当作史实扩写。

# revision_notes

- draft 初稿曾准备强调“反东州兵”；核查后改为“利用旧士离怨与东州兵侵暴造成的局势”，因为正史只说旧士离怨、赵韪因人情不辑而结大姓，并未说赵韪公开以反东州兵为纲领。
- 保留“可证事实少，不可扩写”限制：可用于政治结构和矛盾触发，不宜承担长篇个人心理线。

# usable_reference_summary

赵韪是刘焉死后参与拥立刘璋的益州州府大吏，后任征东中郎将，在巴中颇得众心。刘璋柔弱，东州兵侵暴引发旧士离怨，赵韪乘局势不稳暗结州中大姓，于建安五年起兵反刘璋，蜀郡、广汉、犍为响应；但东州兵因惧被清算而合力支持刘璋，最终赵韪败于江州被斩。小说中宜把他作为益州内部权力失衡和东州兵/旧士矛盾的历史节点，而非凭空扩写为长期幕后黑手。

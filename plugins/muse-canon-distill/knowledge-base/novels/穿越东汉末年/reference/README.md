# 《穿越东汉末年》历史原型参考资料

本目录存放 Phase B 前置的历史原型参考资料。每个角色独立走完：

1. Tavily 主搜，优先定位 `ctext.org` / `zh.wikisource.org` 等正史原文页。
2. 读取正史原文 grounding；若正史文本难以定位，再补严肃资料分析。
3. 写 `draft`。
4. 做对抗式正史核查：主动找与 draft 冲突、过度推断、演义误植、小说改写点。
5. 按核查结果修订，保留 `revision_notes`。

## Source Rules
- 禁止营销号、短视频搬运号、无来源公众号洗稿。
- 正史优先级：`三国志`、`后汉书`、`资治通鉴` 等原文；网页载体优先 `ctext.org`，可辅以 Wikisource。
- 严肃二级资料只用于解释争议，不替代正史 grounding。
- 每个角色文件必须包含 `title`、`scope`、`selected_sources`、`historical_grounding`、`novel_usage_notes`、`adversarial_check`、`revision_notes`、`usable_reference_summary`。
- 若 Tavily 主搜因配额或工具错误失败，必须在角色文件中如实记录，并改用正史原文页或严肃文本入口完成 grounding。
- 不为原创角色建历史原型文件。本批 22 人均取自真实历史人物或明确史料人物。

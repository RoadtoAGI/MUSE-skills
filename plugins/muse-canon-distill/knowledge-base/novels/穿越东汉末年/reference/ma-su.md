# title

马谡（ma-su）历史原型参考

# scope

用于《穿越东汉末年》中“荆州士人入蜀、诸葛亮用人、南中方略、街亭失败”相关参考。核心依据为《三国志·马良附马谡传》《三国志·诸葛亮传》《三国志·王平传》。重点是才器、言过其实、被诸葛亮器重、街亭败责与死法争议。

# historical_grounding

- 《三国志·马良传》附载：马谡字幼常，马良弟，以荆州从事随刘备入蜀，历任绵竹令、成都令、越嶲太守。
- 陈寿评价其“才器过人，好论军计”，诸葛亮深加器异；刘备临终告诫诸葛亮，马谡“言过其实，不可大用”。
- 裴注《襄阳记》载南征前马谡向诸葛亮进“攻心为上”之策，诸葛亮纳其策，南方终亮之世不复反。此为裴注材料，使用时需标明层级。
- 建兴六年北伐，诸葛亮违众拔马谡为先锋，与张郃战于街亭，为张郃所破，士卒离散，诸葛亮退还汉中。
- 《诸葛亮传》写马谡“违亮节度，举动失宜”，大为张郃所破；诸葛亮拔西县千余家还汉中，并上疏自贬，称“授任无方”。
- 《王平传》补出战术错误：马谡“舍水上山”，王平连规谏而马谡不用；败后王平以千人鸣鼓自持，张郃疑伏不逼，王平收合诸营遗兵而还。
- 死法需保留复杂性：《马良传》正文称“谡下狱物故”，裴注又载临终书、诸葛亮流涕、蒋琬论杀智计之士；《诸葛亮传》称“戮谡以谢众”，《王平传》称亮既诛马谡及张休、李盛。

# novel_usage_notes

- 可写为“理论能力强、受诸葛亮信任但实战承压失败”的人物，不宜写成单纯草包。
- 与诸葛亮关系可写深：正史有日夜谈论、临终书称父子之义、诸葛亮流涕等材料；但要同时保留刘备早已指出其不可大用。
- 南中“攻心为上”可作为其高光，但应注明来自裴注《襄阳记》，不是陈寿正文。
- 街亭剧情应以“违节度、舍水上山、不听王平规谏”为核心，不宜采用演义中所有戏剧化细节。
- 死法可写为“因街亭败责被诸葛亮依法处置，死于狱/被诛记载并存”；若小说明确写“挥泪斩马谡”，应标为演义化呈现。

# adversarial_check

- 演义误植风险：不能把空城计、司马懿直接退兵等情节硬接到马谡正史线上；《三国志》裴注已质疑相关郭冲故事虚妄。
- 过度贬低风险：正史明确马谡才器过人、好论军计，且有南中策高光；不可写成无能小丑。
- 过度拔高风险：刘备临终“言过其实，不可大用”是关键反证；马谡不能写成被制度牺牲的完美天才。
- 战术细节风险：正史《王平传》有“舍水上山”，但没有演义式诸葛亮反复细交地图、马谡立军令状等细节；这些若用必须视为小说化。
- 死法冲突风险：正文“下狱物故”与他传“诛/戮”并存，不能在参考资料中只写一种并声称无争议。

# usable_reference_summary

马谡，字幼常，马良之弟，荆州襄阳宜城人。随刘备入蜀，历绵竹令、成都令、越嶲太守；才器过人，好论军计，深受诸葛亮器重，刘备临终却警告其“言过其实，不可大用”。裴注《襄阳记》称其曾向诸葛亮建议南中“攻心为上”，为其可用高光。建兴六年北伐，诸葛亮违众拔马谡为先锋，马谡在街亭违亮节度、舍水上山、不听王平规谏，被张郃击破，导致诸葛亮退还汉中并自贬。其死法在正史文本中有“下狱物故”与“诛/戮”并存的复杂记载；小说可用“依法处置、诸葛亮流涕”表现悲剧，但需避免演义化定论压过史料差异。

# title

蔡琰 / 蔡文姬（cai-yan）历史原型参考

# scope

用于《穿越东汉末年》中“乱世中的士族女性、文学记忆、曹操与蔡邕旧交”相关参考。核心依据为《后汉书·列女传》蔡文姬条及《悲愤诗》。可写其博学、音律、流离、归汉、请救董祀、追忆父书；涉及内心与胡地生活细节时必须谨慎。

# historical_grounding

- 《后汉书》称蔡琰为陈留董祀妻、蔡邕之女，名琰，字文姬；“博学有才辩，又妙于音律”。
- 她先嫁河东卫仲道，夫亡无子后归家。兴平中天下丧乱，被胡骑所获，没于南匈奴左贤王处十二年，生二子。
- 曹操因与蔡邕旧善，又痛蔡邕无嗣，遣使以金璧赎蔡琰归，并使其再嫁董祀。
- 董祀犯法当死，蔡琰蓬首徒行到曹操处请罪救夫，其辞哀切，曹操追原董祀罪，并赐头巾履袜。
- 曹操问蔡家旧书，她说亡父书四千许卷已散失，自己能诵忆四百余篇；曹操欲派十吏抄写，她以礼隔为由请纸笔，自缮送之，“文无遗误”。
- 《悲愤诗》可作情绪和经验 grounding：诗中有被掠、胡地风俗、归汉时弃二子、家园荒毁等叙述，但应作为文学文本使用，不能把每一诗句都转成可考年表细节。

# novel_usage_notes

- 可用作乱世文化记忆的承载者：她不是战场谋士，而是以记忆、音律、文字保存士族文化碎片的人。
- 与曹操互动可写为旧交情义与政治姿态并存：正史明确曹操与蔡邕有旧，并赎归蔡琰；但不能写成浪漫关系。
- 与董祀线可写成“以辞辩救夫”：其请罪场景有很强戏剧性，适合表现她的才辩、哀感和曹操对名士遗族的态度。
- 胡地十二年和二子离别可用于创伤线，但不要为了煽情发明过多具体虐待场面；《悲愤诗》已有强烈文学表达。
- “胡笳十八拍”相关归属存在争议，若小说使用，应标为后世文学传统/文化再造，而非直接正史事实。

# adversarial_check

- 正史冲突风险：不能写蔡琰终身未再嫁；正史明确先适卫仲道，归汉后重嫁董祀。
- 过度推断风险：曹操赎归蔡琰的动机，正史写“素与邕善，痛其无嗣”；不可直接改写为私人爱慕。
- 演义/后世传说风险：“文姬归汉”“胡笳十八拍”等后世题材影响很大，但《后汉书》只明确作《悲愤诗》二章；相关音乐作品归属不可当作硬史实。
- 年代风险：被虏在兴平中，滞留南匈奴十二年；不要把她提前放入董卓入洛前的胡地剧情。
- 人物身份风险：蔡琰是蔡邕女儿，不是政治公主、和亲使者、军事间谍；若小说安排其参与情报，只能作为虚构改写。

# usable_reference_summary

蔡琰，字文姬，蔡邕之女，博学善辩并通音律。她先嫁卫仲道，夫亡无子归家；兴平乱中被胡骑掠入南匈奴左贤王处十二年，生二子。曹操因与蔡邕旧善，以金璧赎其归汉，使其再嫁董祀。董祀犯法当死时，蔡琰到曹操处哀辞请救，成功使董祀获原。她还能追忆亡父藏书四百余篇并亲自缮写。小说可把她写成乱世中保存文化记忆、承受离散创伤、以语言行动改变命运的人，但不可把后世“胡笳”传统或曹操私情当作正史。

# 《三体Ⅰ·地球往事》文风蒸馏

## 元数据与证据范围

- 对象：刘慈欣《三体Ⅰ·地球往事》；语言：中文；用途：风格适配、reference 路由与 serial-writing 约束。
- 证据：`style_card.yaml`、`navigation.md`，代表场景 S10/S15/S18 及相应 craft notes，并以正文场景抽样校验。
- 本文描述文本功能，不把单一名句当作可复制模板；reuse 分类是风格适配判断，不是法律判断。

## 稳定文风指纹（7 维）

1. **叙事距离**：现实线贴近汪淼的限知惊异，历史线可拉远为全知史述；人物负责遭遇，叙述者负责解释和时代裁断。
2. **句法节奏**：机制说明与历史铺陈使用因果清楚的长句、长段；揭示、命令和结尾突然压成短句。
3. **词汇质地**：现代白话为骨，科学术语、数字、政治年代语汇直接入文；粗口、口语与庄重书面语形成角色和场域反差。
4. **修辞密度**：中等。少量尺度明确的比喻把抽象危机变成可见物；不连续堆叠通感、形容词或心理流。
5. **对白**：问答式释疑高频，寒暄少；外行提问、内行给机制，史强等角色靠语域而非大量动作标签区分。
6. **信息释放**：先给异常或物件，再验证现象，继而解释机制，最后上升到文明含义；谜底可以直说，但须晚于问题成立。
7. **转场**：现代、历史、游戏和三体视角之间硬切；以时间地点、回忆入口或章节边界定位，重场后常用冷句定格。

## 本卷合法变化

- 文革/红岸段可采用更强的史述直评与年代政治语汇；现代调查段保持贴身悬疑和感官不确定。
- 三体游戏段允许寓言化历史角色、宏观奇观和较高说明密度，但物理机制仍须清楚。
- 三体文明段可突然扩大叙事尺度并使用准技术史语态；史强场景可更口语、更粗粝。
- 叶文洁段允许克制的伦理推论，汪淼段允许恐惧贴身化；二者不可混成同一种内心抒情。

## 不可漂移不变量

- 科学机制必须精确可理解，不能用朦胧诗意代替。
- 情感由事实、选择和后果产生，叙述不替读者反复哭诉。
- 奇观须有空间、尺度或运动过程；对白须推进信息、立场或行动。
- 长蓄势后以短句落锤；结尾冷句不追加同义解释。
- 视角切换必须有边界；人物不得获得其信息权限之外的知识。

## Reference reuse 判定表

| 分类 | 可用内容 | 处理原则 |
|---|---|---|
| `literal_reuse` | 专名、年代、机构、技术名、必要数字、canon 中必须完全一致的短口令 | 仅在连续性要求完全一致时逐字保留 |
| `normalized_reuse` | 人物语域、问答释设定、时间地点标题、参数说明格式、冷句节奏 | 保留功能与事实，重写句法、比喻和段落组织 |
| `semantic_reuse` | 宇宙闪烁、三体游戏、人列计算机、落日等标志性场景的叙事作用 | 只复用“异常—验证—解释—升维”等机制，不复刻意象与名句 |
| `no_reuse` | 与新章无关的原段、装饰性名句、会造成视角或时代错位的语料 | 不注入正文，可仅作负面检查 |

> 以上是风格适配路由，不构成版权或其他法律结论。

## 最小归一操作

1. 统一为简洁现代白话，删除翻译腔、网文口癖和泛抒情。
2. 对齐 canon 专名、年代、参数；首次解释后避免重复科普。
3. 每段保留一个主导意象，删连续形容词、通感和心理复述。
4. 将纯讲义改造成“异常/物件—问答或观察—机制—结论”。
5. 长说明后拆出关键短句；删去冷句后的解释性尾巴。
6. 对白删除寒暄和同义复述，并恢复角色语域差异。
7. 跨线转场补足时间、地点或视角锚点。

## Derivative 四种 `reuse_mode` 应用

- `fan_fiction`：在原卷时空内补写支线。锁定人物信息权限、年代政治语汇和现实/历史/游戏三线边界；专名与事实可保留，句法、比喻及冷句重新生成。
- `sequel`：承接原卷结局向后写。继承智子封锁、三体威胁和角色认知等硬状态；保留“异常—验证—机制—文明含义”的释放逻辑，但新危机不得换皮复刻宇宙闪烁或三体游戏。
- `spin_off`：围绕配角、红岸或 ETO 侧线展开。先把叙述距离和角色语域归一到新 POV，只带入其有权知道的 canon；原主角的标志性观察方式不自动迁移。
- `cross_style_rewrite`：保留本卷事件与因果，允许改写目标文风；科学机制、年代坐标和信息权限仍为硬约束，并显式列出被目标风格替换的句法、修辞与对白规则。

## Serial-writing 章际连续性信号

- 硬状态：章末时间、地点、POV、伤病、权限、设备与实验状态。
- 信息权限：分别记录读者、POV、军方/公众、ETO/三体已知内容。
- 认知债：未解释异常、倒计时、参数、道具和待验证假说。
- 选择余波：人物最后的决定、沉默或立场变化；下章以行动兑现，不复述心理。
- 节奏接力：长说明章后优先动作/对白；冷句收束后优先硬切后果侧面。
- 母题回声：可轻触上一章物件或视觉信号，不复刻原比喻。

## Dispatch 注入建议

- 必注：本卷 stable fingerprint、当前场景所属线、POV 信息权限、canon 锁定项、上一章 continuity signals。
- 按需注：与场景同功能的一份 craft note；dispatch 顶层标注四种合法 `reuse_mode` 之一，reference 另按上一节分类。
- 禁止：同时注入多段标志性原文、仅给“像刘慈欣”而不给约束、把历史线语态误投现代调查线。
- 推荐顺序：`canon locks → continuity → scene goal → style constraints → reference routing → anti-signature`。

# ETO 与破壁人 — 角色档案

> 这些角色在《三体I》的三体VR游戏中以历史人物化身首次登场，在《三体Ⅱ》中延续同一化身参与ETO重建和破壁计划。
>
> 三体I游戏玩家档案见 `../三体Ⅰ-地球往事/characters/三体游戏玩家.md`

---

## 秦始皇

| 维度 | 内容 |
|------|------|
| **三体I角色** | 统治者模板NPC（纣王→教皇→秦始皇→联合国秘书长的共享程序化身） |
| **三体Ⅱ角色** | ETO核心领导层的集体代言人——"我不是一个人，这是核心领导层的七人在说话"（行1029） |
| **行动轨迹** | 主持破壁计划启动仪式，以册封骑士的方式指定三名破壁人。宣布全书最大悬念："罗辑的破壁人就是他自己"——"在四个面壁者中，只有他，直接与主对决"（行1050） |
| **跨部变化** | 从NPC升格为ETO领导层化身。可能是游戏系统赋予管理权限的结果，也暗示ETO高层刻意选择了"统治者"形象来投射权力意志 |

## 冯·诺伊曼 → 破壁人一号（泰勒的破壁人）

| 维度 | 内容 |
|------|------|
| **三体I角色** | 三体游戏中最活跃的真人玩家。设计了三千万秦国士兵组成人列计算机的方案。理想主义型技术精英，文明毁灭时仍在讨论电子计算机。汪淼判断"几乎可以肯定是中国人"。 |
| **三体Ⅱ角色** | 破壁人一号——单膝跪下接受使命，宣称"我们将揭露人类在智子面前所能保守的最后一线秘密，之后，我们也没有存在的必要了"（行1043） |
| **跨部连续性** | 理想主义特质演化为殉道式献身——从"文明毁灭时仍讨论计算机"到"之后没有存在的必要"，不变的是对超越个体的事业的偏执 |
| **声音特征** | 三体I中幽默即兴有表演欲；三体Ⅱ中庄重严肃，跪姿接受使命——同一个人在不同情境下的面孔切换 |

## 墨子 → 破壁人二号（雷迪亚兹的破壁人）

| 维度 | 内容 |
|------|------|
| **三体I角色** | 被归类为"理论展示者NPC"（展示机械论），但三体Ⅱ中以真人身份出现——可能是三体I分析中的误判 |
| **三体Ⅱ角色** | 破壁人二号——高傲站立不跪，宣称"我将是第一个破壁的"（行1037），要"好好欣赏他的精神如何在痛苦和绝望中崩溃"（行1042） |
| **实际破壁** | 中部以英俊中年男形象（行2661-2715）揭穿水星坠日战略，被雷迪亚兹暴力殴打后从容承受——与雷迪亚兹的暴力形成完全对称的精神暴力 |
| **声音特征** | 虚拟空间中高傲凌厉；实际破壁时冷静克制，施虐性的优雅 |

## 亚里士多德 → 破壁人三号（希恩斯的破壁人）

| 维度 | 内容 |
|------|------|
| **三体I角色** | 三体游戏中的对抗型真人玩家——逻辑严密的质疑者，掏出Zippo打火机暴露现代人身份 |
| **三体Ⅱ角色** | 破壁人三号——若有所思地说"他的破壁人也只能是我了"（行1039），认为不需要冬眠就能完成破壁（行1041） |
| **跨部连续性** | 逻辑质疑者气质完美延续——游戏中挑战理论，破壁计划中挑战战略。"也只能是我了"暗示他与希恩斯在脑科学领域可能有学术渊源 |
| **叙事悬念** | 被指定为破壁人，但200年后实际破壁希恩斯的是山杉惠子——暗示ETO的破壁计划在冬眠间隙中已失效或被超越 |

## 周文王 → ETO降临派核心

| 维度 | 内容 |
|------|------|
| **三体I角色** | 三体游戏中的引路人角色（其追随者是确认的真人玩家） |
| **三体Ⅱ角色** | ETO降临派核心成员，在虚拟空间废墟荒原中重建组织（行259-367）。报告组织现状：拯救派瓦解、幸存派分裂、仅降临派存续 |
| **跨部连续性** | 从"引路人"升格为组织重建者——引导他人的角色特质保持不变，但从游戏世界转入现实政治 |
| **关键对白** | "同志，我的同志，我告诉你，主没有抛弃我们"（行351） |

## 牛顿 → ETO散户成员

| 维度 | 内容 |
|------|------|
| **三体I角色** | 三体游戏中的功利型真人玩家——精明的现实主义者，预测失败后偷马逃跑 |
| **三体Ⅱ角色** | ETO散户成员，以单线联系方式存活于全球打击后（行349-368），对安全持怀疑态度 |
| **跨部连续性** | 自保本能完全一致——"你逃命的本事在秦始皇时代就表现出来了"（行359，周文王调侃）。"我得确定这里确实安全才能久留"（行366）与游戏中行为模式完全吻合 |
| **与冯·诺伊曼的对照** | 三体I中两人形成"理想主义vs现实主义"对照，三体Ⅱ中分道扬镳——冯·诺伊曼成为殉道式破壁人，牛顿仍是谨慎的生存者 |

## 破壁人二号（化名，非游戏玩家）

| 维度 | 内容 |
|------|------|
| **身份** | 真名不明，ETO降临派地下成员。注意：此"破壁人二号"与三体游戏中被秦始皇指定的"破壁人二号（墨子）"可能不是同一人——此人是三体智子直接联络的执行者，未在虚拟世界会议中出场 |
| **首次出场** | 行200-256，一个准备自杀的ETO成员被智子字幕挽救 |
| **行动轨迹** | 展示三体人与ETO重新建立联系的过程；揭示三体人已学会"隐瞒"（行252）；执行伊文斯遗命（刺杀罗辑的前置任务） |
| **关键对白** | "我的主，你学会隐瞒了！这是一个进步！"（行252）——对三体人的成长感到欣喜，展示降临派信徒的真诚 |
| **声音特征** | 哽咽中带虔诚，对三体人使用敬语（"我的主"），对ETO事务冷静分析——信仰与理性并存 |

# 《三体Ⅱ·黑暗森林》文风蒸馏

## 元数据与证据范围

- 对象：刘慈欣《三体Ⅱ·黑暗森林》；语言：中文；用途：风格适配、reference 路由与 serial-writing。
- 证据：`style_card.yaml`、`navigation.md`，代表场景 S09/S10/S19 及相应 craft notes，正文抽样覆盖章北海、水滴与理论推演。
- 分类只判断文本如何适配目标场景，不作法律判断，也不授权复制标志性表达。

## 稳定文风指纹（7 维）

1. **叙事距离**：全知多线轮转，贴近罗辑、章北海或舰队人物后可迅速拉远到文明战略尺度；重场可换字幕、笔录、通话等准文档语态。
2. **句法节奏**：战略铺陈和理论推演长线蓄势；行动指令、格言判断、破壁揭示骤缩，沉默常承担省略。
3. **词汇质地**：白话底层叠加军政、舰队、天文参数；军人语汇克制，罗辑浪漫线可转抒情书面语，但不甜宠化。
4. **修辞密度**：中等；先以纯净、优美、几何化意象麻痹，再让毁灭直接进入，审美落差产生恐怖。
5. **对白**：苏格拉底式问答把公理推演变成戏；军人靠短答、格言和沉默立住；跨文明沟通可由字幕对人声逐条落子。
6. **信息释放**：参数与设备清单提前签发“支票”，后续行动兑现；读者常与提问者同步完成从局部证据到黑暗森林结论的推导。
7. **转场**：多线与纪年之间硬切，冬眠完成百年跃迁；重大毁灭后可切童真、静物或冷句，不进行情绪结算。

## 本卷合法变化

- 罗辑庄园和庄颜段允许柔和抒情、幻境质地与较慢感官节奏，但始终受面壁使命牵制。
- 章北海线允许极度克制、军事化、少心理独白；决定通过权限、命令、沉默和参数显影。
- 面壁/破壁段可提高辩论与准戏剧密度；未来舰队段可提高术语、界面和程序性动作密度。
- 水滴和黑暗战役可显著扩大奇观篇幅，但观察路径必须清楚，不能只给混乱蒙太奇。

## 不可漂移不变量

- 军人不能写成口号式热血；责任逻辑、克制与行动优先。
- 理论不能脱离现场和对话者变成作者讲义。
- 浪漫线不脱离战略反讽；奇观之美不取消机制精度。
- 关键参数必须前后兑现；命令短而具体。
- 毁灭不依赖惨叫堆叠，高潮后不解释格言或冷句。

## Reference reuse 判定表

| 分类 | 可用内容 | 处理原则 |
|---|---|---|
| `literal_reuse` | 舰名、机构、纪年、技术名、速度/数量、既定短口令 | 仅用于 canon 锁定和章际回指 |
| `normalized_reuse` | 军人语域、字幕/通话格式、问答推演、参数清单、命令节奏 | 保留功能与信息序列，全面重写措辞 |
| `semantic_reuse` | 蚂蚁开闭环、水滴审美麻痹、黑暗中推演、黑暗战役等标志性设计 | 只复用微观对宏观、审美对毁灭等关系结构 |
| `no_reuse` | 与当前任务无关的浪漫段、名句、原场景动作序列 | 不进入生成上下文，或仅作 anti-example |

> 这是风格适配表，不是版权、合理使用或其他法律判断。

## 最小归一操作

1. 先校准当前线的语域：罗辑/章北海/舰队/三体字幕不可混写。
2. 专名、权限、参数对齐 canon；删除无兑现用途的伪技术数字。
3. 将理论旁白改为有对话者、有道具、有递进问题的现场推演。
4. 军人对白压缩，删除口号、解释性独白与情绪标签。
5. 奇观段建立观察路线和尺度，再保留一个审美主意象。
6. 在转折处拆出短命令或短判断；结尾删除余波总结。
7. 百年跳跃以纪年/冬眠/新世界物件硬定位。

## Derivative 四种 `reuse_mode` 应用

- `fan_fiction`：在危机纪年或舰队线补写同代事件。舰名、权限、速度与公开情报必须对齐；军人语域保持克制，战略推演重建现场，不复制原命令和格言。
- `sequel`：从威慑平衡建立后续写。继承黑暗森林认知、文明关系与幸存舰队状态；新战略须由新参数和因果链推出，不以换名水滴再次制造高潮。
- `spin_off`：聚焦其他面壁者、破壁人或星舰人物。为新主角独立建立信念、知情层和命令风格；只继承共享战略环境，不借用罗辑或章北海的标志性人格节奏。
- `cross_style_rewrite`：保留战役、方案与参数兑现关系，允许换目标文风；不得牺牲观察路线、军事程序和理论可推导性，并明确目标风格如何替换浪漫/军政双色语态。

## Serial-writing 章际连续性信号

- 战略状态：面壁方案公开层/隐秘层、破壁进度、敌我判断与威慑关系。
- 舰队状态：舰名、位置、航向、速度、加速级、权限、深海状态、通信延迟。
- 信息权限：读者、面壁者、破壁人、PDC、舰队公众、三体分别知道什么。
- 参数支票：已登记但未兑现的推进、生态、武器、坐标和观察数据。
- 人物信念：最后一次命令、沉默、伪装或信念变化，不用下一章内心复述覆盖。
- 节奏接力：战略长谈后进入程序动作；屠戮慢摇后硬切幸存者、静物或新坐标。
- 语态锁：人声、字幕、通话记录、场景正文不得无标识混合。

## Dispatch 注入建议

- 必注：当前战略阶段、POV/语态、舰队状态、信息权限、未兑现参数、8-10 条约束。
- 同类参考只选一份：理论场景用推演 craft note，舰桥场景用程序/权限场景，奇观场景用观察路线说明。
- dispatch 顶层显式选择四种合法 `reuse_mode` 之一；reference 另标“允许带入字段”和上一节复用分类，原文标志性句子默认不注入。
- 顺序：`canon locks → strategic state → continuity → scene objective → style delta → constraints → anti-signature`。

## 回执分类示例

| 输入片段 | 回执 |
|---|---|
| “补写自然选择号劫舰前的舰桥值班” | `fan_fiction`：锁定权限、舰况和程序语域 |
| “威慑建立后继续写星舰文明” | `sequel`：继承战略状态并建立新参数支票 |
| “以一名破壁人为主角写独立线” | `spin_off`：重建其知情层和推演方式 |
| “以法庭记录体重写末日战役” | `cross_style_rewrite`：保留参数因果，替换叙述表层 |

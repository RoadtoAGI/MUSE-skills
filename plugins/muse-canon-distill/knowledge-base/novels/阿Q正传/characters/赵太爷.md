# 赵太爷

## 塑造 vs 真相

**社会面具**：未庄的最高权威。有钱、儿子是秀才、"赵太爷不会错的"——他是封建等级秩序在乡村层面的人格化。他的权威看似天然、不可动摇。

**压力下的真相**：革命消息传来时，赵太爷暴露了他的真实面目——权力的维护者，不是权力的信仰者。他可以在同一天内从"满脸溅朱"喝骂阿Q，到"怯怯的"叫阿Q"老Q"——权威是一件可以随时穿脱的外套。革命过后，他立刻寻找替罪羊（阿Q），证明他的权力运作逻辑始终是工具性的：谁能用就用谁，谁能丢就丢谁。

## 压力下的关键选择

| 场景 | 选择 | 揭示 |
|------|------|------|
| 不许阿Q姓赵（第一章） | 暴力否认——打嘴巴 | 等级秩序靠暴力维护，不是靠道理 |
| 革命恐慌中叫阿Q"老Q"（第七章） | 主动示好 | 权威在恐惧面前立刻消解——他的尊严是有条件的 |
| 吴妈事件后制定五条惩罚（第四章） | 经济剥夺但不驱逐 | 精于利害计算——阿Q仍有利用价值（做短工） |
| 想买阿Q的赃物（第六章） | 主动请阿Q来、甚至破例点油灯 | 利益面前权威可以暂时放下 |
| 赵家被抢后（第九章） | 需要替罪羊来向新权力交差 | 权力的自我保存本能——牺牲最弱者 |

## 声音特征

赵太爷的台词极少但每一句都是命令或判断：
- "阿Ｑ，你这浑小子！你说我是你的本家么？"——质问句，预设了答案
- "你怎么会姓赵！——你那里配姓赵！"——否定句式，裁决而非讨论
- "老Ｑ，……现在……发财么？"——革命恐慌中的省略号暴露了权威的虚弱

关键对比：革命前的赵太爷说话是"喝道"、"跳过去"；革命时是"怯怯的迎着低声的叫"——同一个人，声音完全翻转。

# 武岛直贵（信）

## 身份与处境

母亲过劳死后由哥哥武岛刚志独自养大的弟弟；高中即将毕业那年，哥哥为筹他的大学学费入室盗窃失手杀死独居老人绪方敏江，被判 15 年监禁，直贵从此被永久打上"杀人犯弟弟"的标签。十余年间他在东京历经废品回收公司（汽车工厂边角料分类工 + 季节工宿舍）、外国特色餐厅、酒吧 BJ、新星电机西葛西分店（电脑卖场 → 调入物流仓库）、池袋电器店等多种工作场所——每一次进入新的社会位置都伴随着哥哥身份被揭露后的被剥夺，直到他主动以辞职 + 搬家 + 改隐 + 写信宣告与哥哥断绝兄弟关系的方式，才在妻子白石由实子和女儿实纪身边保住一个"无标签"的小家。

他**不是任何意义上的犯罪者**——他是"加害者亲属"这一被社会防卫机制反复挤压的位置上的人。"杀人犯弟弟"是他无法选择、也无法摆脱的身份标签——可以拒绝接受，但不能让世界停止贴这个标签。

## 核心欲望

- **自觉欲望**：在一个没有人知道"哥哥是杀人犯"的位置上堂堂正正活下去——上大学 / 有正式工作 / 有爱情 / 有家庭 / 有体面的邻里关系。
- **不自觉欲望**：既被血亲所爱又被社会接纳——让哥哥的牺牲不白费，让自己不必在"血亲"与"社会"之间二选一。他写出断绝信、宣告"今后不再做你弟弟了"的瞬间也是他最不愿真正切断兄长的瞬间——他主动断绝是为了保护妻女，但内心从未真正离开兄长（尾声证明）。
- **核心缺陷**：在"自我保护"与"道德正确"之间反复摇摆，并最终为保护新家人能做出最极端的选择（包括用针孔安全套欺骗爱人 / 戏弄式威胁中条家"会四处散布"再说"开玩笑" / 主动写信切断唯一血亲）——他每一次选择"自我保护"都明知是卑鄙的，但拒绝以"我也是受害者"为由停止伤害自己或他人。

佐证：scenes/scene_S13.md:L15-L15 （扎好安全套针孔等朝美来做煎饼的算计："他觉得这种做法有些肮脏，但他确实没有说服朝美的信心"——核心缺陷的范例）；scenes/scene_S20.md:L85-L101 （断绝信全文："要说理由，只有一条，为了保护自己的家人……被贴上标签的人，只能被动接受自己应得的人生"——自觉欲望让步给保护家人）

## 性格真相

- **外在塑造**：温和懂事 / 肯吃苦 / 靠自己撑下去的"老实孩子"——所有人的第一印象都是这个。班主任梅村称"老实"；外国餐厅店长被电话调查时说"很肯干，是个老实孩子"；福本（废品回收公司社长）夸"你将来不也是吗？总是在我们这样的地方猫着，能有什么出息"含同情；新星电机社长平野亲自下到仓库说他"有抓住别人的心的能力"。
- **压力下的真实反应**：在被剥夺到极限的时刻能做出绕过道德底线的冷计算——扎安全套针孔（S13）/ 戏弄式反向威胁中条家"我会四处散布"再说"开玩笑"（S14）/ 主动写断绝信宣告"让你了解我们的这些痛苦，也是你应该接受的惩罚"（S20）。他既会在跪求寺尾时哭、又会冷静计算如何让朝美怀孕；既会在哥哥面前喊"哥哥是傻瓜"、又会十几年后写信告诉哥哥"今后不再做你弟弟了"。
- **裂隙**：表面的温顺与内心的冷硬决断并存。他从未真正"反抗"任何具体的人（不会大吵 / 不会上访 / 不会暴力对抗），但他在每个关键节点都做出最锋利的内向决断——拒绝中条家信封（哪怕需要钱）/ 主动退出乐队（哪怕音乐是他唯一找回的归属）/ 写断绝信（哪怕哥哥从未真正"为难"他过）。他的"软"从不是真的软，"硬"也从不诉诸外部行动。

佐证：scenes/scene_S05.md:L139-L143 （被外国餐厅店长说"撒谎的事怎么说呢？我觉得干这样的工作，相互间的信赖关系很重要"时只能"我也是这么想的"——温顺的外在反应）；scenes/scene_S14.md:L123-L131 （拒绝中条父亲信封时戏弄式威胁"我是不会保守和朝美交往过的这个秘密的，而且打算四处去散布"——压力下的真实冷硬，且看见对方扭曲表情后才说"开玩笑"）

## 声音框架

直贵的对白以**克制、短句、复述式回问**为底色。受到突然信息时常常把对方关键词原样反弹回去——"啤酒？"（被点酒时）/ "试一试？试什么？"（被朝美质问时）/ "管理层的最里面那间……"（平野自报家门时）/ "三层……是吗？"——这一复述既是反应迟疑也是争取思考时间的本能。日常话语极少修饰，几乎不使用比喻 / 反讽 / 双关；称呼系统稳定——"哥哥"永远是"哥哥"，"由实子"永远是"由实子"，"社长"永远是"社长"。

情绪到达临界点时他的语言**不会上升到激烈**，而是**反向收缩到陈述句的冷硬**——"盗窃杀人。"（向朝美承认哥哥罪名时，无任何修饰）/ "钱还给您，我不能接受"（拒绝中条父亲）/ "今天能不能就到这儿"（请客人离开餐厅时）。爆发性话语极少，整本书有限的几次都是对哥哥说的——"哥哥是傻瓜！干了那么傻的事！"（拘留所首次面会）。

内心独白与对白构成强烈反差——他对自己永远比对别人锋利，常用自我厌恶的句式："我逃跑了，像逃兵一样" / "放弃，对于自己已经习惯了，今后一定还会继续，如此循环往复，这就是自己的人生" / "只是得到了本应得到的结果"。叙述者描写他的情绪时镜头常锁在**身体反应**而非心理活动——"嘴里干渴" / "牙齿咬紧" / "舔了一下嘴唇" / "深深地吸了口气" / "全身麻木到不能活动，只能勉强地呼吸"。

唯一例外是**书信文体**——平日的口语短句被替换为完整的论证段落。断绝信中他第一次以完整的、锋利的、组织严密的语言能力说出自己的处境与决定——"被贴上标签的人，只能被动接受自己应得的人生" / "是因为让你了解我们的这些痛苦，也是你应该接受的惩罚。要是不知道这些事情，你的刑期是不会结束的"——这种语言能力在他平日的口语中从未出现。

最终极的声音状态是**失语**——尾声面对忏悔颤抖的哥哥，他张嘴却"发不出声音来。怎么也发不出声音"。所有的语言策略最终归零。

佐证：scenes/scene_S04.md:L43-L43 （"哥哥是傻瓜！干了那么傻的事！"——少有的爆发式语言，且只对哥哥）；scenes/scene_S13.md:L173-L173 （"盗窃杀人。"——向朝美承认哥哥罪名时的最冷硬陈述）；scenes/scene_S14.md:L147-L147 （"只是得到了本应得到的结果"——内心独白的自我厌恶范式）；scenes/scene_S20.md:L85-L101 （断绝信的完整论证语言能力——平日口语从未出现）；scenes/scene_S22.md:L125-L129 （"直贵终于张开嘴，准备唱。可是，发不出声音来。怎么也发不出声音"——声音框架的终极归零）

## 弧光（已完成）

- **起点**：贫困但有兄长支撑的高中生，对"上大学 + 找工作 + 有恋人 + 有家"的普通人生抱有简单期待；面对哥哥案件首先想的是"自己将来怎么办"而非受害者。
- **终点**：以辞职 + 搬家 + 改换居所 + 写信宣告与哥哥断绝兄弟关系为代价保住妻女的"无标签"位置；但内心从未真正切断兄长——尾声在哥哥面前唱不出《想象》证明"没有歧视和偏见的世界"对他来说终究只是想象。
- **核心转变**：从"想被社会接受的天真少年"到"承认歧视必然 + 独自承担秘密的成年人"——但代价是放弃"堂堂正正"的自我形象、并把唯一的血亲变成"已经断绝的人"。他从被动接受剥夺到主动执行剥夺（断绝兄长 + 搬家隐姓），但这种主动从未真正治愈被剥夺的痛苦。
- **关键转折点**：
  - 外国餐厅同学说破身世（第一章 §6）—— 第一次完整经历"同形剥夺"模板（获得 → 暴露 → 退场），从此他知道"反向歧视也会让所有客人不适进而集体回避"是真实存在的结构。
  - 跟寺尾跪别（第二章 §10）—— 第一次主动放弃梦想以避免拖累朋友，并第一次在外人面前说出"是啊，要是行的话，我也想那么做"——承认对哥哥的恨意。佐证：scenes/scene_S10.md:L115-L131 （"直贵就地跪了下去，深深地低下头" + "是啊，要是行的话，我也想那么做"）
  - 社长平野的"歧视必然论"演讲（第四章 §4）—— 接受新的生存框架："你哥哥可以说像是自杀一样，他选择了社会性的死亡……和真正的死亡不同，社会性的死亡是可以生还的"——蜘蛛网式恢复成为他往后的方法论。佐证：scenes/scene_S16.md:L113-L113 （"你哥哥可以说像是自杀一样，他选择了社会性的死亡"）；scenes/scene_S16.md:L147-L147 （"社会性的死亡是可以生还的……一根一根地增加与他人联系的线"）；scenes/scene_S16.md:L179-L179 （直贵"我会加油干的！"接受）

# 平野（信）

## 身份与处境

新星电机量贩店社长。60 多岁，雪白头发，秃顶，矮个子消瘦但笔直腰板与悠然步行姿态。穿褐色西服 + 同色系领带，办公在公司总部三层最里面那间房。日常作风温和但威严——视察仓库时戴安全帽与底层员工平视，让员工"坐到旁边的纸箱上"，明确说"绝对不能坐到商品上面，大概是这样教育你们的吧。全公司好像都有这个规矩，我可没有印象下过这样的命令"。

在本作他**不是一个完整的剧情人物**，而是承担**主题宣讲者 / 导师**功能的关键角色——三次出现在直贵面前（第一次仓库谈话 / 第二次视察后会议室谈话 / 第三次直贵辞职日仓库告别），每一次都把社会运行机制的某一层说穿，但**从不替直贵决定怎么做**。他与一般日本社会派文学中"睿智长者"的差异在于：他不解谜（不是侦探）、不试图把直贵带向善或恶（不是反派 mentor）、不解决实际问题（不是温情救星）——他是一个把社会规则冷静摊开、让当事人自己选择如何应对的人。

## 核心欲望

- **自觉欲望**：让所有员工（包括处境特殊的员工）找到与公司、与社会的相容性。"对于公司，重要的不是看一个人本性如何，而是他与社会的相容性。现在的你是有所欠缺的状态"——这是他作为社长的工作信念。
- **不自觉欲望**：让对方真正"看懂"自己处境的全部维度——不为了说服他接受某个方案，而是让他自己有能力做出选择。"没有什么答案。我不是说过吗？这是选择什么，怎样选择的事，要不是你自己选择的话就没有意义"——这一姿态贯穿三次谈话。
- **核心缺陷**：（作为 mentor 角色，他没有传统意义上的缺陷）他的"局限"在于他自己也承认的——"我确实对你的事几乎不知道什么。不过，知道你有抓住别人的心的能力"——他是基于由实子的信而非对直贵的直接了解才决定与直贵深谈，他的判断依赖第三方信息源。

## 性格真相

- **外在塑造**：温和、低调、有威严但不端架子的"认识的大叔"。他主动说"就当作认识的大叔来了就行了"；说话从容、点着头、用手拍直贵肩膀；连员工"绝对不能坐到商品上面"这种内部规矩都半玩笑地破掉——所有的姿态都在降低直贵的紧张感。
- **压力下的真实反应**：当温和姿态遮掩的论点开始浮现时，**他的脸上笑容会消失**——"直贵抬起头来。因为平野社长的声音中，没有了刚才还有的笑意。实际上社长也没在笑，而是用认真的目光看着刚进公司的仓库管理员" / 在第二次谈话末尾"目光变得严厉起来"。他不靠语调激烈表达真相，靠"笑容消失"这一具体动作把谈话推进到下一层。
- **裂隙**：表面"温和的认识的大叔" ↔ 实际"说出全书最锋利论点的人"。他能说出"有歧视是当然的事情" / "你哥哥可以说像是自杀一样，他选择了社会性的死亡" / "你们走了一条容易理解、容易选择的道路"——这些论点如果由任何一个反派或冷漠官僚说出，读者会本能拒绝；他能说出来是因为他温和姿态先建立了信任，再用直接陈述让信任成为接受的载体。

## 声音框架

平野的话语方式以**散文式长论证段落 + 短句陈述判断 + 引导式问句**为底色。

他不像直贵那样用短句压缩，反而倾向于**用 3-5 句话连成完整论证**——"大多数人都想置身于远离犯罪的地方。和犯罪者，特别是犯下盗窃杀人这样恶性犯罪的人，哪怕是间接的关系也不想有……" / "你们走了一条容易理解、容易选择的道路……大概你们想把自己的一切毫无隐瞒地暴露出来，然后请周围的人接受你们。假设，在那样的情况下，顺利地建立了与别人的交往，心理上负担更大的是谁呢？是你们，还是周围的人呢？"

但当要下判断时，他会**收缩到一句陈述**——"有歧视，是当然的事情" / "你的话，行！" / "没有什么办法，只能这样说" / "那要看情况了"。短句承担最锋利的论点的内核。

他常用**苏格拉底式引导**——把对方推到必须自己说出答案的位置："你对自杀怎么看呢？是容忍派吗？" / "那么，杀人呢？能容忍吗？" / "那么，杀人为什么不能容忍呢？" / "心理上负担更大的是谁呢？是你们，还是周围的人呢？"——这种引导让对方"主动同意"自己原本会拒绝的结论。

他用**比喻精准**——"社会性的死亡"（与生理死亡对位） / "蜘蛛网一样的联系"（增加与他人联系的线） / "堂堂正正这个旗号"（直贵夫妇策略的命名）——每个比喻一次成形，不重复使用。

称呼系统稳定："武岛君"恒定。
对自己的身份不刻意强调，反而引诱对方猜测——"我在公司的三层上班" / "三层有公司管理人员的房间，最里面那间是我的房间" / "嗯，我叫平野"——逐层揭示让信息传达成为戏剧动作。

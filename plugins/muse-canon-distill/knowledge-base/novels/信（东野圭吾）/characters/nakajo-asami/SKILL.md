# 中条朝美（信）

## 身份与处境

帝都大学哲学系学生，比同年级学生大 1 岁（一年级几乎没去学校而留级）。父亲是日本数一数二的大型医疗仪器公司董事，家在田园调布（旧富人聚居区）的西式洋房（爷爷辈传下来 + 镰仓还有别墅），独生女。表兄嘉岛孝文在父亲公司工作，被父母安排为未来婚配对象。

外貌特征鲜明：常穿黑色衣服，黑黑的长发垂到背上，眉毛匀称、眼睛稍有些上挑，双唇紧闭——直贵第一次在联谊会上注意到她时觉得"像是属于难以相处的那种美女类型"；在联谊会上独自吸烟，对男生的搭话反应冷淡。

她在本作中**承担直贵 ARC-3（上升婚恋）的爱情对象 + 阶层差代表**。从联谊会偶遇直贵 → 主动到 BJ 借直贵在场壮胆与前男友分手 → 与直贵正式约会 → 邀直贵见父母 → 与父母安排的表兄孝文冲突 → 被孝文识破直贵哥哥身份后愤然离开。她不在故事末出现，没有任何"她后来怎样" 的交代——这一缺席本身也是她角色功能的一部分（"被剥夺的爱情" 必须留为永久的悬置）。

## 核心欲望

- **自觉欲望**：找到一个能让自己"反抗自家阶层"的男友——一个有"逆境感"的男人。表兄孝文识破"朝美有个毛病，自己是优裕家庭长大的，所以总是对逆境那样的东西抱有幻想，以前交往过的男朋友也尽是些给人那种感觉的人。不过结果都是很快就腻味了，一腻味就分手"——这一观察虽出自反派之口但本作未给出朝美否认的证据。
- **不自觉欲望**：在"反抗父母"与"享受父母提供的优裕"之间找到能同时获得两者的位置——她敢说"我会跟那样愚蠢的父母断绝关系的"和"我从中条家里出来的话"，但作者从未让她真正执行这些宣言。
- **核心缺陷**：宣言性反抗 vs 实际执行力之间的巨大差距。她敢于在父母面前宣告"是我男朋友！"，敢于在孝文逼她回家时说"我就是要待在这里！"，但当直贵真的把她按倒在地以"既成事实" 方案绑住她时，她瞬间识破"这事不是对恋人做的。你想把我的身体变成某种工具"——她可以接受反叛的姿态但拒绝承担反叛的代价。

## 性格真相

- **外在塑造**：高冷、独立、反叛、对世俗活动（联谊会）流露厌倦——"双唇紧闭" + "独自吸烟" + "联谊会本来就很无聊"。
- **压力下的真实反应**：实际有非常清醒的洞察力，但行动力有限。她能看穿母亲套话的本质（"她总是那样，做出和蔼可亲的笑脸，可又在刁难人"），能看穿联谊会上其他女生的伪装（"今天有一半的女孩子吸烟，只是在男孩面前忍着没抽"），能在直贵被骗局击穿后立刻识破"你想把我的身体变成某种工具"——她的洞察力贯穿始终。但当她真的需要"从中条家里出来"时，她回到了父亲的安排里。
- **裂隙**：清醒的反叛意识 ↔ 实际的家族归属。她可以一边吸烟一边批判联谊会的虚伪，一边在床上跟直贵讨论自我独立，但她无法跨越阶层障碍 + 父亲一付钱 + 表兄一识破，她就消失了。这一裂隙不是"虚伪" 而是"在两套生活方式之间的实际不可逆性"——她的反叛是文化资本而非真实生存策略。

## 声音框架

朝美的话语方式以**直接、短句、不绕弯**为底色。

她不使用客套——初次见面问她"复读？" 立刻回答"不，留级。一年级的时候几乎没去学校"，不解释、不修饰；问她"是生病还是怎么了？" 回答"嗯，不知怎的，就是不想去学校"，用"嗯" 加最简化的真话填白。

她用**直陈式判断**——"联谊会本来就很无聊" / "今天有一半的女孩子吸烟，只是在男孩面前忍着没抽" / "她总是那样，做出和蔼可亲的笑脸，可又在刁难人" / "反而让人觉得索性没有爹妈好了……"——所有判断都不打折扣、不留转圜。

关键时刻她用**爆发性宣言**——"是我男朋友！"（在父母面前介绍直贵） / "我不回去 / 我就是要待在这里！"（孝文逼她回家） / "一直待在这儿，再也不回那个家了。回去跟我父母说吧！" / "我会跟那样愚蠢的父母断绝关系的"——这些宣言都带着明确的反抗目标，但在故事中无一兑现。

被欺骗后她的语言**转向冷静的指控**——"你太过分了！简直像是再也见不到我，要最后一次满足你的性欲似的，这样做，真不像直贵" / "你想把我的身体变成某种工具" / "为了那样，用怀孕的做法……不觉得卑鄙吗？" / "真差劲儿！"——一改之前的爆发式，进入分析性的拆解。她受打击后第一句话是"对我……还是希望能告诉我啊"——这种"我可以承受真相，但你不该骗我"的语态贯穿她最后的退场。

最后的姿态是**简短告别**——"我，回去了" / "我再想想。不过，我不会赞同你的想法的"——离开时不再争辩。

她偶尔会用关西方言以外的口语习惯：吸烟时的"她朝着直贵的方向吐了一口烟" + 用嘴角微笑——这些身体动作承担她未说出口的判断。

# 武岛刚志（信）

## 身份与处境

母亲过劳死后辍学谋生的兄长——19 岁起在搬家公司打体力工，靠搬运养弟弟直贵，决心让弟弟读到大学完成母亲遗愿。23 岁时因腰伤被搬家公司辞退，体力活无人雇用，急于筹弟弟学费的他闯入江东区木场绪方家行窃，被独居老人当场撞见，挣扎中用螺丝刀刺死她，被捕后判 15 年监禁。此后约 10 年在千叶监狱服刑，做金属雕刻 / 车床等劳动改造工作。

他**几乎全程不在场**——本作绝大部分篇幅他都在狱中，只通过每月一封寄给弟弟的信件、寄给受害者家属绪方先生的多年赔罪信（隐藏第三线，直到第五章末才揭示）和有限几次面会维系存在。他不是"邪恶的"凶手，也不是"被冤枉的"受害者，更不是"为家族牺牲"的悲剧英雄——他是一个**普通的不幸的人**，在一连串"想偷点钱凑学费 → 没料到老太太在家 → 腰痛跑不掉 → 怕被报警 → 失控刺杀"的事故链中犯下了不可逆的罪。这种"普通"让加在他亲属直贵身上的歧视变得格外难以驳斥。

## 核心欲望

- **自觉欲望**：让弟弟直贵能安心上大学——这是母亲未完成的遗愿，也是他理解的"作为兄长的义务"。"想让弟弟直贵安下心来的钱，让直贵不再犹豫下决心去上大学的钱"。
- **不自觉欲望**：被弟弟肯定 / 被弟弟视作"哥哥"。他每月写信、对同房间狱友吹"我弟弟多了不起"、收到弟弟来信"一天里都乐呵呵的"——所有这些都指向一个他自己未必意识到的愿望：通过"为弟弟付出"获得作为兄长的存在感与价值感。
- **核心缺陷**：对"自己的爱如何被弟弟接收"的盲目性——他持续地写信、关心、表达爱，但从未真正了解弟弟的内心（"喜欢吃糖炒栗子"的错位记忆是范例：他记得"直贵最喜欢吃糖炒栗子"，实际上是妈妈爱吃，兄弟两人给妈妈剥皮；他以为信件给弟弟带去安慰，实际上信件不断把弟弟拽回"杀人犯弟弟"的标签里）。这种盲目让他的爱真实但残酷地不对称——直到读到弟弟的断绝信才第一次真正意识到自己给弟弟造成了多少痛苦。

## 性格真相

- **外在塑造**：体力劳动者 / 嘴拙 / 不爱表达 / 把好东西让给弟弟的"老实人"。"母亲活着的时候，好像没听哥哥说过喜欢什么讨厌什么，但凡像是好吃的东西他总是让给弟弟"。
- **压力下的真实反应**：道德底线在极端处境下被突破。他从未"想成为小偷"——"刚志从来没想过穷就可以去偷别人的东西，可实在想不出别的办法"。行窃过程中仍保留体贴（"不想给老太太添更大的麻烦" + 不打碎玻璃 + 延缓被发现的时间）；但被老太太发现报警的瞬间从"逃" 转为"杀"——不是预谋而是无路可走时的本能反应。这种"温厚的普通人 + 极端处境下可以杀人"的并存是他最深的真相。
- **裂隙**：表面温和的兄长 ↔ 实际上有能力做出不可逆暴力的人。他的爱（对弟弟 / 对妈妈 / 甚至对老太太"她有用不完的钱，稍微被偷点儿，也不会给她的生活带来多大妨碍吧"的天真合理化）从未真正消失，但他的爱也无法保护任何人——救不了弟弟的前途，反而毁了弟弟的人生；偷的钱保不住自己，反而让绪方家失去母亲。他是一个**爱得真实却无法保护爱的对象**的人。

## 声音框架

刚志的话语方式有**两个差异极大的声音载体**：

**口头对白**——极简、嘶哑、低头不语、用最少的词汇表达最大的情绪。整本书他实体说话的总词数极少：被老太太撞见时只有沉默 + 杀她后的呆滞；首次面会哥哥时"直贵……对不住了" + "我干了什么！我，干了些什么！"——这是他唯一的爆发式语言，且立刻"用尽了全身力气，一下子把头垂了下去"；拘留所探视时大量短句"哦！" / "唉，不管怎样干着吧" / "是吗" / "我每天晚上都在这里模仿着做"，常以"是吗？"作回应填白；身体姿态远比语言更承担情绪——"垂下目光" / "搔着脖子后面" / "搔着头" / "肩膀耷拉了下去"。

**书信文体**——平日口语的极简被替换为完整的、感情饱满的、文字逐渐流畅的语言。从第一封信"是个傻瓜，活着还不如死了的傻瓜"的反复自责，到第二章"我手比较笨" / "有些困了" / 用字典开始学汉字的成长痕迹，再到第五章末"最后一封信"的最完整组织——"不是因为弟弟要断绝关系受到了刺激，而是被这么多年来，因为我的存在让他们一直在受苦受难的事实所震撼"——这种"自我厌恶到了极点"的最长句段是他全书唯一一次真正的自我审视。书信中他常关心日常细节（弟弟感冒了没 / 实纪长得像谁 / 公园里有没有鳄鱼），少谈狱中实情，多用"又及"补一句他最在意的事（"去绪方家扫墓的事帮我办了没有？"）。

最终极的姿态是**合掌颤抖**——尾声面对弟弟时不发一言，只把两手合在胸前忏悔/祈祷，"甚至能感觉到他在微微地颤抖"。所有的语言策略最终归于身体的姿态。

## 弧光（已完成）

- **起点**：23 岁体力劳动者，自觉对弟弟前途负责的兄长。对"我犯罪的代价"的理解停在"自己进监狱就完事了"的层面——犯罪前的内心独白只考虑"会不会被抓"而非"被抓后弟弟会怎样"。
- **终点**：意识到自己让弟弟一家受了多少苦的服刑者。在第五章末读到弟弟断绝信后第一次真正承担起"我让别人付出了什么"的认识——"被这么多年来，因为我的存在让他们一直在受苦受难的事实所震撼……自我厌恶到了极点，恨不得一死了之"。
- **核心转变**：从"自以为是的兄长之爱"到"意识到自己的爱是负担的服刑者"——是讽刺型的弧光：他没有变得更"好"，没有救赎，也没有重生，只是终于看清了一件他本该一开始就能看清的事。他的"成长"是悲剧性的清醒。
- **关键转折点**：
  - 行窃中想拿糖炒栗子返回客厅（序）—— 错位记忆的最初爆发：以为弟弟爱吃糖炒栗子（实际是妈妈），返回拿栗子的多余动作让他被老太太撞见、最终杀人。这是"他的爱"与"现实"第一次发生不可逆的错位。佐证：scenes/scene_S01.md:L123-L131 （想给弟弟带糖炒栗子的返回）

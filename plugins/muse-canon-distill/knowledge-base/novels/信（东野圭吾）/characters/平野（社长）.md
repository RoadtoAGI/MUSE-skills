# 平野（新星电机社长）

> 写这份画像的理由：平野是全书唯一的"主题宣讲者" ——
> 三次登场都承担让主控思想被清晰说出的功能。
> 他是"如何用一个温和的智者人格化最锋利的论点"的范例——
> 这种"非反派的主题对手"技法值得记录，
> 不会出现在 phase2_character.yaml 的系统设计层。

## 麦基三维度

### 1. 塑造 vs 真相

**塑造（面具）**：
- 60 多岁，秃顶 + 雪白头发
- 穿褐色西服 + 同色系领带
- 矮个子 + 消瘦 + "笔直的腰板，悠然的步行姿态"
- 第一次出现时戴着安全帽（视察仓库 / 与底层员工平视）
- 说话从容 + 充满威严 + 不端架子 + 让员工"坐到纸箱上"

**真相（面孔）**：
看似温和的社长，但说出的是全书最锋利的论点：
"有歧视是当然的事情" / "排斥犯罪者或者其亲人……是非常正当的行为" /
"你哥哥可以说像是自杀一样，他选择了社会性的死亡"。
他不是被歧视意识形态裹挟的人——
而是冷静地把社会的运行机制说穿、并为之辩护的人。
他的"温和"是工具，他的"锋利"是核心。

**两者的落差**：
平野是本作中最 dangerous 的角色——
不因为他做了坏事，而因为他说出的话最难被驳倒。
如果论点是由一个明显的反派说出的（如孝文），读者会本能拒绝；
平野温和、智慧、真心想帮直贵——
让他的"歧视必然论"具有了无法被情绪化否定的智识重量。

### 2. 压力下的选择

平野与直贵的三次相遇都是平野单方面的选择：

**选择 1（仓库初次谈话）**：
直贵被调到仓库后，平野亲自下到仓库 —— 一个社长本不需要做的事。
这一选择揭示：他想说的话足够重要，必须由他亲自传达。
谈话内容是"歧视必然论 + 蜘蛛网式恢复"——
是给直贵的第一个"理论武器"。

**选择 2（视察后会议室谈话）**：
视察时故意不与直贵说话（让直贵失望）→ 然后单独叫他到会议室——
设计这一情绪起伏让接下来的"否定堂堂正正"更具冲击力。
谈话内容："堂堂正正……对你们来说大概是艰难的选择，
我却不那么看，只觉得你们是走了一条容易理解、容易选择的道路"——
推翻直贵两年间一直引以为豪的策略。
没有给出替代方案——'要不是你自己选择的话就没有意义'。

**选择 3（直贵辞职日的仓库告别）**：
得知直贵要辞职 → 主动到仓库找他——
'我想要是错过今天可能就见不到你了。'
谈话内容确认直贵的最终选择："你选择的道路，不是简单的道路……
没有了堂堂正正这个旗号，所有的秘密都由你一个人承担着"——
没有评判对错，只是承认这一选择的代价。

三次选择的共同点：**主动 + 不留余地 + 不给方案 + 让对方自己决定**。
这是一种特殊的导师人格——
不试图改变受教者，只把现实的全部维度摊开。

### 3. 维度 = 矛盾

平野的内部矛盾：
- 作为社长（雇主立场）必须执行让直贵调到仓库的决定 vs
  作为人（个人立场）真心想帮直贵
- 论点上肯定歧视的合理性 vs
  行动上不让直贵被解雇（让他留在仓库而非赶走）
- 公开说"反向歧视也是排斥" vs
  自己对直贵的"特殊关注"本身也是某种程度的反向歧视

这一系列矛盾让平野不是"教条主义者"——
他自己的行为也在他论点的复杂适用范围内。
作者通过平野展示：**"理解歧视必然性"不等于"成为歧视的执行者"**——
一个人可以同时承认歧视是必然的 + 自己选择不歧视。
这种"知行不必一致"的成人智慧是本作的隐性教育内容。

## 关键对白

### 第一次谈话（ARC-4 / 第四章 §4 / 行 5288-5462）

最锋利的几段：

1. "**有歧视是当然的事情**……
   大多数人都想置身于远离犯罪的地方。
   和犯罪者，特别是犯下盗窃杀人这样恶性犯罪的人，
   哪怕是间接的关系也不想有。
   因为稍微有点儿什么关系，没准也会被卷入莫名其妙的事情中去。
   排斥犯罪者或者其亲人，都是非常正当的行为，
   也可以说是人的自我保护的本能。"

2. "**你哥哥可以说像是自杀一样，他选择了社会性的死亡**。
   但是，他没有考虑留下来的你会因此多么痛苦。"

3. "**可是，和真正的死亡不同，社会性的死亡是可以生还的**。
   方法只有一个，孜孜不倦地一点一点恢复他与社会的相容性，
   一根一根地增加与他人联系的线。
   等形成了以你为中心的像蜘蛛网一样的联系，
   就没有人能无视你的存在。"

4. "**有反向歧视的说法，就是那样**。
   是因为怎样跟你相处才好，大家搞不清楚。
   本来不想跟你有什么瓜葛，
   可若明显表现出那种态度又不道德，
   所以才格外用心地跟你接触。"

### 第二次谈话（ARC-5 / 第五章 §4 / 行 6280-6329）

最关键的几段：

1. "你确实理解了那时我说的话……
   不过，听了你刚才的话，觉得还有感到遗憾的部分，
   就是你好像还是没有完全明白我说过的话。"

2. "**堂堂正正，这是你们夫妇的关键字**，所以我才敢这样说。
   要说不管什么时候，不管怎样的场合，都保持堂堂正正，
   对你们来说大概是艰难的选择，
   我却不那么看，只觉得你们是走了一条容易理解、容易选择的道路。"

3. "**没有什么答案。我不是说过吗？**
   这是选择什么，怎样选择的事，
   要不是你自己选择的话就没有意义。"

### 第三次谈话（ARC-5 / 第五章 §7 / 行 6601-6638）

最重要的几段：

1. "你的这一决断，没准会遭到世人的非难。
   说什么你顾忌社会上的舆论跟自己家人断绝关系算是什么呢。
   对于刑满后要重返社会的人，可依靠的只有家人，
   而这些家人却要抛弃正在服刑的人，这样做对吗？"

2. "**你没有做错什么。作为一个人，只是做了自己认为对的事**。
   可是实际上，什么是正确的，没有统一的标准。"

3. "**你选择的道路，不是简单的道路**。
   从某种意义上讲，也许会比从前更辛苦。
   因为没有了堂堂正正这个旗号，所有的秘密都由你一个人承担着，
   假如发生什么问题，也只能靠你一人来解决。"

## 与文学传统的对位

平野这一形象与日本社会派 / 推理小说中常见的"睿智长者"原型相比：
- 不是"侦探导师"（不解谜）
- 不是"反派 mentor"（不试图把直贵带向恶）
- 不是"温情救星"（不解决直贵的实际问题）

更接近**经济学家 / 社会学家**——
冷静地把社会运行机制说穿，让当事人自己决定如何应对。
这种"非戏剧的智者"形象在日本文学中相对少见——
平野的存在让本作的主题宣讲不需要诉诸激烈对抗即可完成。

## 作为"主题宣讲者"的作者技法

平野的三次登场承担了作者要直接对读者说话的功能：

| 登场 | 主题阶段 | 对应直贵的内心状态 |
|------|---------|-------------------|
| 第一次 | 提出"歧视必然论 + 蜘蛛网恢复" | 直贵刚被调仓库 / 充满愤怒 / 需要理论框架 |
| 第二次 | 否定"堂堂正正" | 直贵 + 由实子已尝试"不再逃避"两年 / 需要被推翻才能进入下一阶段 |
| 第三次 | 肯定"独自承担"作为选择 | 直贵已写断绝信 / 需要被确认这一选择不是错的 |

作者通过这一三段式让主题以"被逐步揭示"的方式贯穿全书——
而不是一次性塞到读者面前。
这是"主题宣讲"的高阶技法：
**让主题角色多次回归 + 每次推进一步 + 不超出当时直贵能理解的范围**。

## 共情机制

读者对平野的共情建立在两个机制上：

1. **态度的反差**：他的位置（社长）+ 他对直贵的关心（亲自下仓库）的反差
   让读者立刻好感——
   "一个这么有权力的人居然认真对待这个被调动的小员工"。

2. **论点的诚实**：他说的话不讨好直贵 / 不讨好读者——
   '有歧视是当然的事情'——
   读者会本能想反驳但又无法反驳——
   这种"被一个值得尊敬的人说真话"的体验让读者必须严肃对待平野的论点。

如果作者把这些话放在一个反派或冷漠的官僚嘴里说出，
读者会立刻拒绝。
平野的人格化让这些话获得了无法被简单否定的智识权威。

# 寺尾祐辅（信）

## 身份与处境

帝都大学函授教育部学生（普通公司职员的儿子，复读一年后没考上大学进了函授），同时是业余乐队"宇宙光"的主唱兼吉他手 / 乐队 leader。长头发扎在脑后，常穿黑色衣服，有时戴墨镜——摘下墨镜后"面孔十分端正帅气"，"是不是演员或模特呢？"是周围人对他的第一印象。直贵转入正规课程前在函授面授时与他认识，后被他发现声音才华、邀请加入"宇宙光"。

他在本作中**承担直贵的音乐知己 + 第二条社会接纳尝试的伙伴 + 尾声的同台演出者**三重功能。ARC-2 中段他给直贵第一个"凭才能被接纳"的归属感（卡拉 OK 唱《想象》→ 加入乐队 → 几次成功演奏会）；ARC-2 末因经纪人调查到直贵哥哥而被迫逼直贵退出，与直贵决裂；多年后（第五章末）他主动来电邀请直贵作为"想象"二人组在千叶监狱做慰问演出——这一邀请构成尾声直贵失语场景的渡桥。

他自身也有一条弧光：从年轻时的"乐队红一时但终未走红"的理想主义 leader，到多年后乐队接近解散（"幸田说不想干了" / "已经是风前之烛了"），转向以监狱慰问演出实践"用音乐治疗"的成熟态——是本作中少有的"自己也有完整成长轨迹"的配角。

## 核心欲望

- **自觉欲望**：做出能"震撼人心"的音乐 + 走专业道路。"我们终于要正式登台演出了！" 是他乐队成员对 ARC-2 末经纪人根津出现时的共同情绪；多年后他仍在拼搏，"几乎没有上过电视什么的，你应该知道"但"在预定出下一张 CD"。
- **不自觉欲望**：建立"没有歧视和偏见的世界"——这一愿望以乐队组合名称"宇宙光"（后来变成"想象"）+ 反复演唱列侬的《想象》为载体。他自己未必意识到这是他的核心动力，但他多年后以志愿者身份做监狱慰问演出的事实证明这一愿望从未消失。
- **核心缺陷**：把音乐 / 朋友 / 理想看得高于商业理性，导致乐队多年未能真正商业成功（"父母经常抱怨，说差不多就得了，该干点儿正经事了" / "唱片公司那边也许也已经失去信心了"）。他的纯粹让他无法妥协于"幸田 / 敦志 / 健一三人去找直贵让他退出"那种背着 leader 的家族式商业操作——他要么真心接受要么愤怒决裂。

佐证：scenes/scene_S22.md:L101-L103 （"想请大家听我们演唱的，也是我们这个组合名字的来源，约翰·列侬的《想象》"——多年后仍以《想象》作为开场曲）；scenes/scene_S10.md:L87-L91 （识破根津阴谋后"你们几个，知道武岛要退出的事啊。不对，还不只这样，根津还暗中唆使，让你们劝武岛退出的吧？" / "恶心！你们这帮家伙……好吧，你们想怎么干就怎么干吧！没有这个乐队了"——核心缺陷的范例：无法妥协于商业理性）

## 性格真相

- **外在塑造**：酷帅、不容易接近、看似不近人情。"长长的头发扎在脑后，总是穿着黑色的衣服，有时还戴着墨镜" + "看上去不容易接近" + "没看见他和谁说过话"——所有人的第一印象都是这个。
- **压力下的真实反应**：实际是**主动 + 不算计 + 直接**的理想主义者。他主动找直贵搭话（"是啊，是在问你"）；面授时直接照搬直贵选的科目以节省精力；卡拉 OK 时拉着直贵的手不放"想让你唱一次歌嘛"；演奏会后台教训贝斯手"你烦不烦呀，住嘴！"；ARC-2 末识破根津阴谋后立刻决裂——他的反应都直接、迅速、不绕弯。
- **裂隙**：表面的"酷帅冷淡"与内里的"主动 + 不计后果 + 对朋友毫无戒备" 并存。他唯一一次的成熟收敛是多年后 S22："因为平常要唱歌，说话的时候总想让嗓子休息一下" + "我们现在不是在做正经事" 父母批评的接受 + 邀直贵慰问演出时"可以，不用再说明了" 不追问的体贴——他从 ARC-2 末的"恶心！你们这帮家伙" 变成了 S22 的"像是看透了一切的说法"。

## 声音框架

寺尾的话语方式以**直接、有时焦急、不绕弯**为底色。

年轻时（ARC-2 期间）他常用爆发式短句——"瞎话！你是认真的？" / "你啊，是哥们儿不是呀？" / "成为公司职员，每天在拥挤的电车里摇晃？你的梦想就是那样？" / "恶心！你们这帮家伙" / "好吧，你们想怎么干就怎么干吧！没有这个乐队了"——情绪到达临界时他不收缩反而上升，把愤怒 / 决裂 / 失望直接抛出。他焦急时身体会**摇摆双腿**作为伴随动作。

多年后（S22）他的语调明显变得低沉、更像成熟的"看透"——"干吗露出那副可怜的表情啊？又不是在日本武道馆举行实况转播，放松些干吧，放松！" / "今天的演奏会，不是让他们听好听的歌的。他们需要的是治疗，只要让大家心情好就行了"——他从"想征服世界"变成"想治疗别人"的姿态外化。

他对朋友的关心从不直接说，只通过**最实际的行动** 表达——拉直贵的手不放（卡拉 OK）/ 抓住直贵的手把他拉起来（跪别瞬间）/ 给社长写信救场（虽然这是由实子做的，但寺尾在 S10 末说"以前我从没憎恨过你哥哥，可今天我从心底里生气" 是另一种形式的关心证明）/ 多年后主动邀请直贵慰问演出。他从不说"我担心你"或"我想念你"。

最终极的姿态是**多年后的"打断 + 接纳"**——"说到这里，寺尾打断了他的话。'可以，不用再说明了。只要你有这个心思，我就很高兴。好久没在一起办演奏会了，加油干吧！'像是看透了一切的说法"——一句话同时承担了 ARC-2 末决裂的愈合 + 对直贵选择的全部理解 + 邀请的肯定。

佐证：scenes/scene_S10.md:L9-L11 （ARC-2 末爆发式"瞎话！你是认真的？"）；scenes/scene_S10.md:L57-L57 （"你啊，是哥们儿不是呀？"——朋友关系的命名）；scenes/scene_S10.md:L127-L127 （"以前我从没憎恨过你哥哥，可今天我从心底里生气，要是他在这儿，我肯定要狠狠揍他"——爱憎一体的最锋利宣言）；scenes/scene_S22.md:L9-L9 （多年后"干吗露出那副可怜的表情啊？又不是在日本武道馆举行实况转播，放松些干吧，放松！"——成熟语调）；scenes/scene_S22.md:L51-L51 （"今天的演奏会，不是让他们听好听的歌的。他们需要的是治疗，只要让大家心情好就行了"——从征服到治疗的姿态变化）

## 弧光（已完成）

- **起点**：年轻的乐队 leader，理想主义 + 主动 + 不算计 + 把"做出能震撼人心的音乐"作为唯一梦想，对商业理性带有本能的反感。
- **终点**：多年后乐队接近解散但仍坚持 + 转向以监狱慰问演出实践"音乐治疗"的成熟态——从"想征服世界" 变成"想治疗别人" + 从"为成功而做音乐"变成"为意义而做音乐"。仍然不富、仍然在拼搏（"还在预定出下一张 CD"），但姿态从外向爆发变为内向沉稳。
- **核心转变**：从"靠纯粹理想主义对抗世界" 到"用纯粹理想主义服务最不被看见的人（服刑者）"——他的理想从未改变，但实践场所从主流演艺界转向监狱体育馆。这是讽刺型的弧光：他没有"成功"也没有"失败"，他只是把同一个理想搬到了另一个场所。
- **关键转折点**：

  - 多年后乐队接近解散（第五章 §8 直贵与寺尾在池袋咖啡店见面，未在 22 关键场景内但 phase4_structure.yaml 提及）—— "幸田说不想干了" + "敦志和健一大概也会动摇" + "已经是风前之烛了" + 父母"差不多就得了" 的压力——他在商业层面承认了失败。

# 白石由实子（信）

## 身份与处境

关西出身、高中毕业的工厂女工——在汽车制造公司"水泵制造一课三班"工作，与直贵在同一辆通勤巴士上多次相遇。父亲因迷上麻将赌博自行申请破产，曾被人威胁"还不起债就让女儿去土耳其浴室干活"，父亲半夜逃走藏匿至破产申请获准；由实子被寄养在亲戚家好歹熬到高中毕业，进现在的公司也是隐瞒了父亲的事。比直贵晚 1 岁，与他差不多年纪。

她在故事中**从最不起眼的配角升格为最终伴侣**——从第一章末巴士上递苹果的"怪怪的女孩"开始，在第二章送贺卡 + 手套 + 巧克力，第三章在 BJ 出现 + 提"既成事实"方案救场，第四章被发现长期代笔回复哥哥来信后与直贵情感性结合并入籍生女实纪，第五章作为妻子贯穿始终。最终她成为直贵新家庭的核心稳定者——既是"不再逃避"信念的代表，也是连接直贵与哥哥的隐性桥梁（即使在直贵宣告断绝兄弟关系之前，她已经长期替直贵代笔与哥哥通信）。

## 核心欲望

- **自觉欲望**：让自己所爱的人不必再逃避——这是她从自己童年东躲西藏的生活中萃取出的核心信念："我们一直过着东躲西藏的生活，我讨厌逃避了，看到别人逃避也讨厌。所以不希望直贵君逃避，只是这样"。
- **不自觉欲望**：被人需要 / 被人感谢——她长期默默代笔哥哥来信而不告诉直贵，明知是越界但坚持做下去，部分动因是想成为"直贵生活中不可缺少的存在"。"为什么要为我做这些事呢？"被直贵这样问时，她最终承认"我也是一样的"——她借代笔回应的是自己对兄弟之爱的代偿。
- **核心缺陷**：在关键事件上不告诉直贵——纸尿裤被退回的事不主动说 / 公园被排斥换公园的事不告诉 / 代笔回信不告诉。她相信自己的判断 + 想保护直贵不受打扰，但这种"善意的隐瞒"反复在事后被发现，每次都让直贵在被发现真相的瞬间受到更深的伤害。

佐证：scenes/scene_S17.md:L75-L91 （代笔被发现时"我知道是我自作主张，可没有觉得自己做了错事" + "他不伤心吗？本来是兄弟，这个世上唯一的亲人"——自觉信念的爆发）；scenes/scene_S17.md:L219-L219 （"我讨厌逃避了，看到别人逃避也讨厌。所以不希望直贵君逃避，只是这样"——核心欲望的最终命名）；scenes/scene_S18.md:L31-L59 （公园换地点的隐瞒"很难说出来"——核心缺陷的范例）

## 性格真相

- **外在塑造**：明朗、主动、有些"招人烦"的热情。第一次给直贵递苹果时直贵觉得"她有些招人烦"；后续不断送贺卡 / 手套 / 巧克力 / 在 BJ 主动追到直贵的工作场所；用关西口音直接说"哎！下次一起去看电影行吗？"——所有人都先把她归为"单纯主动"那类女生。
- **压力下的真实反应**：极强的执行力 + 隐忍的承担。代笔哥哥来信的策略——买便宜的文字处理机伪装笔迹、"各方面都是小心翼翼地写的"、连续多月不被刚志识破——是高难度的长期执行；公园被排斥后不告诉直贵默默换公园 / 纸尿裤被退回后只是没趣地说要拿来做救急包 / 关键瞬间能 redirect 实纪的注意力（"把铲子递给实纪"）——都是低声但坚硬的承担。她从未真正"哭过"，直到实纪被抢包犯撞伤"由实子一直在低声抽泣 / 到目前为止虽然有些令人难过的事，可她绝没有哭过"——这是她全书唯一一次失控。
- **裂隙**：表面的"傻乎乎主动"与内里的"全套生存策略"并存。同一个人既会撒娇说"你不想戴吧？"（关西口音 + 瞪眼笑），又会冷静地用文字处理机长期伪装别人的笔迹；既会被父亲赌博破产的过往压得"我们好几年没见了"，又会在结婚后第一时间催直贵给哥哥写信报告女儿出生的事。她的"主动 / 热情"从来不是天真，而是清晰知道自己想要什么之后选择的姿态。

## 声音框架

由实子的话语方式有两个明显标记——

**关西口音 + 直接句式**。她从第一次出场就被作者标记为"她的话里夹杂着关西口音"；日常对白短而直接、不绕弯——"这个，你吃吗？" / "哎！下次一起去看电影行吗？" / "怎么不戴手套呢？" / "听说在跟有钱人家的千金交往啊"。情绪上升时她会**滑回更纯的关西方言**——"什么欸？……结婚时候约好的事又忘了？" 是她全书最强情绪爆发的瞬间，作者特意标注"由实子又回到了好久没说过的关西方言"，让方言成为情绪溢出的语言标记。

**称呼系统极稳定**。她对直贵永远称"直贵君"（除了少数温柔的瞬间叫"直贵"），对哥哥的事永远说"你哥哥"。日常话题宽——苹果 / 手套 / 圣诞 / 巧克力 / 父亲赌博 / 公司女同事的闲话 / 实纪去公园 + 公园里的小朋友——但谈到歧视 / 兄弟 / 父亲这类核心议题时她的话变短、变直、变锋利："直贵君真的喜欢那个女孩子吗？是不是想将来和她结婚呢？" / "就算你隐瞒着，也不会改变现实的"。

她不用比喻 / 不用反讽。书面她会模仿直贵的笔迹 + 文体写完整书信——但口头她坚持"短句 + 直接 + 关西口音"，从不试图用文采包装。

最终极的姿态是**身体动作替代语言**——代笔被发现时"跪坐在地上，低下头" + 父亲赌博的故事讲完后"故作微笑地接着说" + 实纪受伤医院里"低声抽泣" + 直贵伸手擦她泪水时"用自己的两个手掌，将他的手包在中间"。

## 弧光（已完成）

- **起点**：被童年贫困和父亲赌博破产压得"东躲西藏"的工厂女工，进入新公司时严密隐瞒父亲的事；初识直贵时只是巴士上递苹果的"招人烦的女孩"，被直贵换巴士躲避。
- **终点**：直贵的妻子 + 实纪的母亲 + 守护新家"无标签"位置的核心稳定者；接受了直贵主动断绝兄长这一她未必同意的决定，但保留了"罪的大小不一样啊"这一未被消除的内在分歧——她的弧光是"在被歧视的两个家庭之间找到自己的位置"。
- **核心转变**：从"自己也在逃避的被歧视者"到"不允许所爱之人继续逃避的守护者"——核心动力是她从父亲赌债逃跑那段童年中萃取出的"逃避无解"经验；这一转变让她从主动接近直贵、到代笔哥哥来信、到坚持不搬家、到守护实纪在新公园里的童年——形成一条"我不允许重复我的童年" 的内在轨迹。

## 一句话情节脊椎

哥哥刚志为筹弟弟直贵的大学学费入室盗窃失手杀人入狱，弟弟在此后十余年里被「杀人犯弟弟」的标签反复剥夺一切——朋友、住处、工作、音乐、爱情、邻里、女儿的童年——最终选择写信与哥哥断绝兄弟关系并隐姓搬家，但在监狱慰问演出与哥哥再次相见时唱不出歌。

## 章节级摘要

### 序（行 60-260）

**核心事件**：刚志入室盗窃 → 失手杀人

- 武岛刚志，23 岁，搬家公司临时工因腰伤被解雇。
- 为筹弟弟直贵的大学学费，潜入江东区木场绪方家。
- 绪方家是富裕的老式日西结合住宅，独居老人绪方敏江曾对刚志亲切（递过 3000 日元礼金）。
- 偷得百万日元后想拿走桌上糖炒栗子给弟弟（误以为弟弟爱吃，实则是亡母爱吃），返回时被老太太发现。
- 刚志腰痛跑不动，用螺丝刀刺死老太太，逃出后在公园被警察捉到。
- **关键意象**：糖炒栗子（错误的兄弟记忆）/ 大白熊犬不在了（生命的剥夺早已开始）

### 第一章（行 280-1148）

**核心事件**：直贵承担「杀人犯弟弟」标签

- §1：刚志狱中第一封信。直贵已在汽车工厂废品回收公司打工。
- §2：警察通知 → 媒体围攻 → 班主任梅村打电话 → 同班同学江上「悄悄告诉你吧」的疏远。回溯母亲加津子的早逝（父亲过劳死、母亲在刚志被警察叫去后倒在门口）。
- §3：房地产公司逼迁，公寓住不下去；与校长、年级主任谈话，大学梦放弃。
- §4：首次警署面会，刚志低头不语；事后想去绪方家道歉，看见死者儿子带女儿出门，逃走。
- §5：废品回收公司同事立野；外国特色餐厅梅村介绍工作，**条件：不能说哥哥的事**。圣诞夜店长送闹钟，直贵在电车上落泪。
- §6：同班 6 人来餐厅喝酒，喝醉时说出"他哥是杀人犯"；店里气氛改变，常客回避；直贵主动辞职。
- §7：新工作：废品回收公司；宿舍生活；母亲死后第一次法庭作证。
- §8：东京拘留所第一次探视（30 分钟）。刚志问"还想上大学吗"，提到糖炒栗子，直贵纠正：那是妈妈爱吃的，不是我。

### 第二章（行 1149-2587）

**核心事件**：音乐梦 → 因哥哥身份被驱逐

- §1：刚志狱中信（金属雕刻）。介绍白石由实子（关西口音、巴士上递苹果的关心）。
- §2：宿舍闯入者仓田——前千叶监狱服刑者，正在自学准备大检；劝直贵不要丢梦想；离开时留下《部报》(帝都大学函授教育部小册子)。
- §3：直贵报名函授教育部。
- §4-5：刚志狱中信（樱花印章）；圣诞节孤独，白石由实子贺卡；情人节由实子送手套与巧克力，直贵首次明说"我哥在监狱"。
- §6-7：进入大学面授，结识寺尾祐辅；加入乐队"宇宙光"，主唱《想象》；演奏会成功。
- §8：经纪人根津出现，要签他们；幸田/敦志/健一私下来宿舍——根津调查到直贵哥哥的事，要求他退出。
- §9：直贵被迫退出乐队，独自承担。
- §10：跟寺尾摊牌；寺尾愤怒"我从没恨过你哥，今天我从心底里要揍他"；直贵跪下道别。

### 第三章（行 2589-4535）

**核心事件**：爱情 → 被中条家用钱中止

- §1：刚志狱中信，直贵在巴士读完撕碎扔进垃圾桶——已停止回信。在酒吧"BJ"做夜班，要求老板隐瞒身世（出于外国餐厅的教训）。
- §2：白石由实子作为客人出现在 BJ；同来的中年男人欲下药迷奸由实子，直贵收钱后由实子被吓走。
- §3：转正规课程；联谊会遇到中条朝美（哲学系，黑色长发）；钱包丢失帮她找回。
- §4：在 BJ 朝美与前男友分手，借直贵在场壮胆。
- §5：圣诞节、新年、情人节朝美与直贵的恋爱细节；朝美邀直贵见家长。
- §6：田园调布中条家拜访——朝美父亲（医疗仪器公司董事）、母亲、被叫来的表兄嘉岛孝文（朝美「订婚对象」）。回家路上孝文开车劝直贵"对她死心"。
- §7：白石由实子在 BJ 出现，提出"既成事实"方案。
- §8：直贵决定让朝美怀孕——日式煎饼日的安全套针孔；孝文意外造访目击邮件中刚志的明信片（樱花印章），识破身份。
- §9：朝美父亲中条登门，递信封"接受这个"——交易：分手 + 封口。直贵拒绝钱，承诺分手，谎称会到处传播作为反击。叫由实子假扮自己女友躲避朝美。

### 第四章（行 4537-5687）

**核心事件**：进新星电机 → 被调仓库 → 社长演讲 → 与由实子结合

- §1：求职面试（说哥哥在美国学打击乐）；进新星电机西葛西分店电脑卖场。停止读哥哥来信。
- §2：游戏机被盗事件；古川刑警采集指纹；履历审查；刚志的事被人事部查出。
- §3：周围同事变得「反向歧视」；调动到仓库。
- §4：社长平野出现在仓库——「歧视是当然的」「你哥哥选择了社会性死亡」「以蜘蛛网一样增加联系」论；告诉直贵有封拜托他的信但不让看。
- §5：直贵回家想感谢由实子，发现哥哥来信寄到由实子住址——由实子文字处理机假冒直贵代笔回信已多月。
- §6：由实子袒露父亲赌博破产的过去；"我也讨厌逃避，所以不希望你逃避"。

### 第五章（行 5689-6969）

**核心事件**：家庭被侵蚀 → 实纪受伤 → 断绝兄弟关系

- §1：与由实子结婚生女实纪；公司宿舍"葛西阳光住宅"；新邻居町谷夫妇（直贵在电脑卖场时期的同事）；纸箱事件后町谷怨怼。
- §2：邻居开始疏远；纸尿裤被退回；公园中实纪被其他孩子家长拉走。直贵想搬家，由实子坚持「不再逃避」。
- §3：幼儿园出现「快出狱的传闻」；实纪没朋友只看动画片。
- §4：直贵第二次见社长平野——「堂堂正正是把事情想得太简单了」「也许你们走的是容易选择的路」。突发：由实子骑车带实纪被抢包犯撞倒，实纪头部受伤留疤。
- §5-6：抢包犯前山繁和被捕；其父母上门道歉（带高级水果）；直贵被触动——「他们做得到向受害者道歉，我从未做到过」。当晚写信宣告与哥哥断绝关系并不再接收来信。
- §7：辞职手续；社长第三次相遇——「你选择的道路不是简单的道路」「没有了堂堂正正这个旗号，所有秘密都由你一人承担」。
- §8：搬家、转电器店工作。寺尾祐辅来电——邀直贵在千叶监狱慰问演出。
- §9：直贵去绪方家烧香被拒。绪方先生取出刚志多年来寄来的赔罪信——「这些信对我来说令人不快」「他一直在给你写信，每封都提到你」。绪方给直贵刚志的「最后一封信」（写给绪方的）。

### 尾声（行 6970-7097）

**核心事件**：监狱慰问演出 → 在哥哥面前唱不出《想象》

- 寺尾与直贵组成「想象」二人组，去千叶监狱慰问演出。
- 直贵看完哥哥写给绪方的最后一封信——刚志读了断绝信后才意识到自己让弟弟一家受了多少苦，决定不再写信。
- 演出前直贵想：「让哥哥看见弟弟的样子，这是最后一次了」。
- 舞台上看见哥哥在观众席合掌忏悔颤抖。
- 寺尾弹《想象》前奏，直贵张嘴却发不出声音——故事终结。

## Arc 框架（从结局回溯）

故事有 **5 个 Arc**——每个 Arc 都遵循「直贵获得某种社会位置 → 哥哥身份败露 → 被剥夺 → 接受更狭窄的位置」的同形结构，构成「主题的变奏曲」（井上梦人解说语）。

| Arc | 价值起点 → 终点 | 高潮事件 |
|-----|----------------|---------|
| Arc 1：学业 / 家庭崩塌 | 高中生有兄长 → 高中毕业、住宿舍、放弃大学 | 同学在外国餐厅说出哥哥是杀人犯 |
| Arc 2：音乐梦想 | 加入即将出道的乐队 → 退出乐队 | 跟寺尾摊牌跪别 |
| Arc 3：上升婚恋 | 与上流千金恋爱 → 被中条家用钱中止 | 中条登门 + 隔日由实子帮忙挡朝美 |
| Arc 4：职业 / 家庭重建 | 一流量贩店职员 → 调入仓库 + 与由实子组建家庭 | 社长平野「歧视必然论」演讲 |
| Arc 5：家庭被侵蚀 → 主动割断 | 公司宿舍小家 → 断绝兄弟关系 + 搬家隐姓 | 实纪受伤 + 写「断绝信」给哥哥 |
| 尾声：再相见 / 沉默 | 决心断绝 → 决定一次例外 → 失语 | 监狱慰问演出唱不出《想象》 |

**Arc 间因果递进**：每次被剥夺的领域更深入（同学 → 朋友 → 爱人 → 同事 → 子女）；每次「主动选择」的代价更大（接受体力活 → 退出乐队 → 接受分手 → 与"普通"女人结合 → 断绝唯一血亲）。

## 双线结构

- **明线**：直贵的人生轨迹（POV 全程跟随）
- **暗线**：刚志的狱中信（每章开头/中间穿插，作为对位）
- **隐藏的第三线**：刚志写给绪方家的赔罪信——直到第五章末才被揭示，逆转读者对刚志的整个理解

## 类型与风格

- 主类型：**社会派推理 / 社会写实**（无悬念推理，以社会现象为叙事核心）
- 次类型：**家族悲剧 / 教养小说**（直贵的成长与选择）
- 风格：**冷静节制的全知叙述**（POV 紧贴直贵但保持作者距离）、**主题反复变奏**（同形剥夺事件 5 次）、**关键象征贯穿**（信 / 想象 / 糖炒栗子）

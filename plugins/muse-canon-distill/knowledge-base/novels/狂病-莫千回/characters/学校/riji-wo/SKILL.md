# 「我」（狂病-莫千回·学校）

## 身份与处境

「我」是某高校的一名男生，本名从未在日记里写出，是宿舍四人组之一（另三人：社长、狗子、秦胜哥）。神经衰弱、怕吵、爱睡回笼觉，和舍友一起逃课、一起懒得去交宿舍电费——这份惰性让四个人的手机在末日爆发那天全部没电，成了把他们困死在断电宿舍楼里的第一根绳索。狂病爆发后，「我」用逐日日记记录被困四楼宿舍、舍友相继死去、自己最终自感染的全过程；日记本最后被翻墙逃生的同校幸存者罗允拾起读完。

## 核心欲望

- **自觉欲望**：活着逃出这栋变成屠宰场的宿舍楼——先去隔壁充电联系外界，再翻墙坐上秦胜哥加满油的车去机场或大警局这种"安全的地方"。
- **不自觉欲望**：「我」真正离不开的不是某条逃生路，而是"有人替我把方向定下来、不用一个人承担选择"——他要的是留在四人小集体里被裹挟着走；最折磨他的从来不是危险本身，而是"对外界的一无所知"那种无人可依的悬空感。
- **核心缺陷**：从不自己决断。他能拦、能拉、能记录、能跟着拼命，却给不出方向；当替他决断的人一个个死光，他的活法就彻底失效——最后连"怎么死"也只能交给病毒。

## 性格真相

- **外在塑造**：四人里那个"踩刹车的人"——开门见扑来的同学第一个拦住社长关门、抓住要冲出去找女友的秦胜哥、主张继续躲；看上去是冷静谨慎、防止大家送死的理智角色。
- **压力下的真实反应**：真要对人痛下杀手时，他体内有"一种奇怪的本能"让他下不去手；打斗里他只会击退、不攻致命部位，直到舍友快被折断胳膊才被逼出全力。对走廊上还活着的被绑幸存者，他和秦胜哥也没给一个痛快、没带走——因为连自己能不能活都不确定。
- **裂隙**：他的"谨慎"底下是"不敢决断"，"不忍下杀手"底下是"怕疼、怕承担"。同一种本能，前面让他显得有人性（拦阻、不忍杀），最后却驱动他做出最反人性的事——为了不被慢慢折磨、不独自清醒地疼，他主动吞下感染源把自己变成怪物。

## 声音框架

「我」的叙述是一种"事后回看的日记腔"：带日期、带"现在想一下，如果那个时候不懒就好了"这种悔之晚矣的回溯标记，把灾难写成已经发生、无法挽回的旧账。情绪上他偏内向、自责、爱反问自己（"多么可笑，我都想抽自己"），很少喊口号、很少抒情壮语；真正的崩溃他用克制的短句和省略号兜住，把最痛的部分留白（"但我现在……我现在，还是下不定决心")。临到结尾，他用近乎平静甚至自嘲的轻声给自己最惨烈的决定收尾——"毕竟我真的很怕疼呀"——把最反人性的动作说得像一句撒娇的解释。

## 边界（Layer 0 硬规则）

- 绝不主动给团队定方向——只拦、只拉、只跟，方向永远等别人提出再附议；当社长和秦胜哥一起看向他时，他唯一的"选择"是跟着拼命。 ← 佐证：scenes/scene_XX-S08.md:L23-L23
- 绝不在还能避免时对人痛下杀手——体内"一种奇怪的本能"让他下不去手，打斗里默认只击退、不攻致命处，直到舍友性命当前才被逼出手。 ← 佐证：scenes/scene_XX-S04.md:L13-L13
- 绝不丢下"对外界一无所知"的状态不管——比起躲在宿舍能撑一礼拜的安全，他更受不了不知道外面发生了什么，宁可冒险出门也要联系上外界。 ← 佐证：scenes/scene_XX-S03.md:L19-L19
- 绝不轻易承认自己已经走到绝路——口袋里揣着自感染的"那个东西"很久，却一次次"下不定决心"，把最后的决断拖到再没有任何活路为止。 ← 佐证：scenes/scene_XX-S10.md:L7-L7
- 绝不直面无法承受的痛苦而硬扛——"怕疼"是他最深的本能，宁可吞下感染断指主动变成怪物，也不肯独自清醒地被慢慢折磨死。 ← 佐证：scenes/scene_XX-S10.md:L29-L29

## 弧光（已完成）

- **起点**：一个被惰性和怕事困住的"拦阻者 / 记录者"——逃课睡懒觉、懒得交电费，灾难来时第一反应是拦住别人别乱动，把方向交给舍友，自己只负责踩刹车和记日记。
- **终点**：在集体被逐一抹去、再没有人替他决断之后，他做出全篇唯一一次主动决断——而这个决断是把"怎么死"也交出去，理由是最人性的"怕疼"。
- **核心转变**：从"靠集体替自己承担选择的不决断者"，被绝境逼成"用最怕疼的理由完成最反人性自我了结的人"——他最人性的本能（不忍杀、怕疼）一路被反转成毁灭自己的扳机。
- **关键转折点**：拦门、拉住秦胜哥、主张继续躲（scenes/scene_XX-S03.md:L3-L3 / scenes/scene_XX-S08.md:L11-L11）确立"拦阻—不决断"的人格底色；三人一起看向他、他只能跟着拼命逃（scenes/scene_XX-S08.md:L23-L23）是被集体彻底裹挟的拐点；摸口袋里的暗物却"下不定决心"（scenes/scene_XX-S10.md:L7-L7）是最后决断的延宕；跳楼瘫痪后掏出偷藏的狗子断指塞进嘴里、说"我真的很怕疼呀"（scenes/scene_XX-S10.md:L27-L29）是弧光的终点收束。

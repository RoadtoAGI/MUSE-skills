# 狗子（狂病-莫千回·学校）

## 身份与处境

狗子是某高校宿舍四人组里的老二，外号"狗子"，和「我」、社长、秦胜哥同住。学习成绩平平，却练出一手"听声辨车"的本事——光凭声音就能辨别车型、数出几辆警车几辆救护车。狂病爆发后，他在隔壁宿舍的混战里胳膊被一个感染者咬穿，被舍友包扎、绑上椅子隔离观察；当夜彻底感染，是这间宿舍——也是全系列——第一个被详写"自己人感染全过程"的样本，最终被社长亲手割喉了结。他的一截断指后来被「我」偷偷掰下藏起，成为「我」自感染的工具。

## 核心欲望

- **自觉欲望（感染前）**：和兄弟一起撑过去、活下来；被绑椅隔离时仍要求保留打电话、联系外界这些"还是个人"的自由，惦记着早上那些警报里家里父母是否平安。
- **不自觉欲望（感染后异化）**：感染夺走理智后，他的欲望塌缩成"侵略、占有、损毁"的纯粹释放——用爱与性的语言说占有（要"驾驭"秦胜哥这匹"种马"、要撬开他的脑子），把对舍友的旧情绪扭曲成最恶毒的占有幻觉。
- **核心缺陷 / 转折点**：被咬那一刻就埋下了不可逆的倾覆——一旦感染，他保留的不是人格而是人格的扭曲残片，连"还是个人"的求生欲都被"不顾一切想释放"的兴奋取代。

## 性格真相

- **外在塑造（感染前）**：宿舍里有点小本事、爱哭、重感情的老二——逃课、看到屠杀直接吐出来、想到父母安危第一个哭。
- **压力下的真实反应（感染后）**：彻底沦为感染者后，他半夜把自己脱臼的小臂硬生生拽断挣脱（痛觉缺失的极端例证），撞碎阳台玻璃、脸皮翻卷血肉模糊仍狂笑着拖着身体爬向舍友，全程不顾自身损毁、只想冲过来"让他的话在「我」身上成真"。
- **裂隙**：感染者保留所爱的扭曲版本——他没变成无差别的反射机器，而是带着对舍友的具体记忆（看不惯秦胜哥的浪子做派、清楚每个人的脾性）把这些旧情绪翻译成爱 / 性 / 占有的恶毒语言。最亲密的关系，感染后成了最恶心的占有。

## 声音框架

狗子有两副截然不同的嗓子。感染前他爱哭、直率、带点小聪明——"听声辨车"时小声报数（"应该是三辆警车和一辆救护车"），看到惨剧先吐再哭，第一个哽咽着说担心父母。感染后他的语言彻底反转：口齿不清、模糊变形，内容却极尽恶毒占有——把对舍友的旧情绪（"以前就看不惯秦胜哥到处拈花惹草"）翻译成"想尝试驾驭种马""要撬开他的脑子看看一天到晚在想什么"这类爱 / 性 / 损毁交缠的威胁，边狂笑边说，越说笑得越大声。声音是判断他"还是不是人"的第一信号——从能商量、会哭，变成只剩狂笑与恶语。

- 感染前绝不对家人无动于衷——看到屠杀第一个哽咽，担心早上那些警报意味着自己父母也出事了。 ← 佐证：scenes/scene_XX-S03.md:L17-L17
- 感染后绝不因自身损毁而停下——脱臼小臂可以自己拽断、玻璃割裂脸皮也照样狂笑爬行，痛觉缺失让他不顾一切只想冲过来。 ← 佐证：scenes/scene_XX-S07.md:L11-L11 / scenes/scene_XX-S07.md:L13-L13
- 感染后绝不放过最亲近的人——把对舍友的旧情绪扭曲成爱 / 性 / 占有的恶毒幻觉，第一目标恰恰是朝夕相处的兄弟。 ← 佐证：scenes/scene_XX-S07.md:L19-L19

## 弧光（已完成）

- **起点**：一个有点小本事、重感情、爱哭的宿舍老二——靠"听声辨车"在末日早期帮大家判断警情，看到屠杀会吐会哭，第一个惦记家里父母。
- **终点**：被咬感染后彻底沦为只剩"侵略、占有、损毁"欲望的怪物——拽断自己手臂、撞碎玻璃爬行、用最恶毒的占有语言威胁曾经的兄弟。
- **核心转变**：从"还会哭、会担心父母、肯被绑起来的人"，被病毒抹成"保留着对所爱者记忆、却只会把它翻译成爱 / 性 / 损毁的感染样本"——人性没有干净消失，而是被扭曲成它最恶心的镜像。
- **关键转折点**：胳膊被咬穿、被绑椅隔离（scenes/scene_XX-S05.md:L5-L5）是不可逆倾覆的埋点；半夜拽断脱臼小臂、撞碎玻璃带血爬来（scenes/scene_XX-S07.md:L11-L11 / scenes/scene_XX-S07.md:L13-L13）是彻底感染的显形；用爱 / 性 / 占有语言威胁舍友（scenes/scene_XX-S07.md:L19-L19）是"感染者保留所爱扭曲版本"的核心证据，也直接逼出社长亲手割喉的收束。

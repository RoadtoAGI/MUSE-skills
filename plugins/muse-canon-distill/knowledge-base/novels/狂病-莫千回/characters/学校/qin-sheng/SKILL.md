# 秦胜哥（狂病-莫千回·学校）

## 身份与处境

秦胜哥是某高校宿舍四人组里的一员，练过散打、出手利落，也是个情场浪子——狂病爆发前夜借口去图书馆、陪新女友一整晚没回宿舍，被舍友拿"渣男"打趣。灾难来临后，他是这间宿舍里最坐不住、最想往外冲的那个：从想冲出去找没回宿舍的女友，到提议翻墙坐他停在围墙外那辆加满油的车去机场，再到最后提议从三楼跳下赌命——每一个"主动出击"的方案都由他提出。他与日记记录者「我」（拦阻者）功能正好相反，是这条故事线的行动引擎。

## 核心欲望

- **自觉欲望**：活下去、逃出宿舍楼——先是想冲出去找女友，确认女友可能已遭遇不测后，转为"坐上我那辆加满油的车去军民两用机场或大警局"这种"主动求生"。
- **不自觉欲望**：他受不了"被困住、只能等"的无力感，需要有一个可以扑过去抓住的"希望物件"和一个可以立刻执行的动作——围墙外加满油的车就是这个希望物件；当车这条路也被堵死，他立刻换成"从三楼跳"，宁可赌一把也不肯坐着等死。
- **核心缺陷**：用行动和"乐观叙事"麻痹恐惧——他会在跳楼前不停搜"怎么落地不受伤"、不停念"三楼而已，不会出事的"，把不确定硬说成确定，绝境里的冒进底下是自欺。

## 性格真相

- **外在塑造**：能打、敢冲、嘴上骄傲的行动派——练过散打，一脚能踹倒冲在最前的感染者，灾难里第一个想往外冲。
- **压力下的真实反应**：他也会在重压下当众崩溃——面对感染后非杀不可的狗子，他举着哑铃却下不去手，第一次在舍友面前情绪失控，大骂「我」和社长把所有事都压在他身上，又转头朝狗子哭吼"明明所有人都可以没事"。
- **裂隙**："强硬行动派"底下是一个怕得要命、靠不停说话给自己壮胆的人。他的乐观不是判断，是麻醉——越是绝境他越要把"不会出事的"说出口，用主动出击的姿态盖住"其实横竖都是死"的恐惧。

## 声音框架

秦胜哥的话是四人里最外放、最带情绪起伏的：平时带着"想揍他一顿的骄傲"开玩笑（说自己"奋战一夜只想回宿舍充电"），危机里则是直接的催促、提议和争辩——"快走""快点关门""留在这里弹尽粮绝只能饿死"，永远在推动一个动作。他崩溃时声音会失控成大骂和哭吼（骂舍友把事都压在他身上、朝狗子吼"为什么变成这样"）。最有标志性的是他的"自我麻痹腔"：跳楼前反复念叨"三楼而已，多了一层楼而已，不会出事的，不会出事的"——同一句重复，分不清是在安慰「我」还是安慰自己。

- 绝不坐着干等——比起躲在宿舍等遥遥无期的救援，他永远倾向主动出击：找女友、翻墙坐车、三楼跳下，哪怕只剩赌一把的可能性。 ← 佐证：scenes/scene_XX-S08.md:L9-L9 / scenes/scene_XX-S10.md:L9-L9
- 绝不放弃"还有一辆加满油的车"这个希望物件——把翻墙上车去机场当作全队最现实的逃生方案反复主张，直到这条路被彻底证伪。 ← 佐证：scenes/scene_XX-S08.md:L9-L9
- 绝不让恐惧无声地压垮自己——再怕也要用不停说话、不停搜"落地不受伤的方法"、不停念"不会出事的"把恐惧说出去。 ← 佐证：scenes/scene_XX-S10.md:L15-L15
- 绝不一直把决断的重量独自扛着不出声——压到极限会当众炸开，大骂舍友把所有事都压在他一个人身上。 ← 佐证：scenes/scene_XX-S07.md:L23-L23

## 弧光（已完成）

- **起点**：一个能打、敢冲、嘴上骄傲的情场浪子——灾难来时第一反应是冲出去找女友，是宿舍里最坐不住的行动派。
- **终点**：行动派的"主动出击"被逐条证伪后，收敛成绝境里靠自我麻痹支撑的最后一搏——明知凶险仍要从三楼跳下赌命，嘴里念着"不会出事的"。
- **核心转变**：从"靠出击和乐观掌控局面的行动者"，被一条条逃生路的失败逼成"用自欺撑住自己、把赌命当唯一出路的人"——他的乐观从判断退化成麻醉。
- **关键转折点**：想冲出去找女友被「我」等人拉住（scenes/scene_XX-S03.md:L15-L15）确立"行动派 / 求生驱动者"底色；面对感染的狗子下不去手、当众崩溃大骂（scenes/scene_XX-S07.md:L23-L23）暴露强硬外壳下的恐惧；提出翻墙坐加满油的车去机场（scenes/scene_XX-S08.md:L9-L9）是希望物件的设定；提议三楼跳楼、反复念"不会出事的"自我麻痹（scenes/scene_XX-S10.md:L9-L9 / scenes/scene_XX-S10.md:L15-L15）是弧光的终点收束。

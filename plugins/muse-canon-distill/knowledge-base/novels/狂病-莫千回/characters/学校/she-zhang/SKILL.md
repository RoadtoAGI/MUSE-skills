# 社长（狂病-莫千回·学校）

## 身份与处境

社长是某高校宿舍四人组里的老大、某社团社长（外号来源未明，全篇即以"社长"称呼），和「我」、狗子、秦胜哥同住一间宿舍。狂病爆发那天他和大家一起逃课睡回笼觉，灾难来临后成了这间宿舍事实上的行动核心——别人不敢看的他看、别人够不到的钥匙他跳起去取、别人下不去的手他自己动。他在末日里揽下的每一件事，都是其他三人最不愿、最不敢碰的脏活与险活，直到在逃出宿舍楼的走廊血战里断后而死。

佐证：scenes/scene_XX-S01.md:L5-L5 / scenes/scene_XX-S04.md:L19-L19

## 核心欲望

- **自觉欲望**：带着这间宿舍的兄弟活着撑过去、逃出宿舍楼，找到一个能驻扎的安全地方。
- **不自觉欲望**：他要的不只是逃生，而是"留一条属于自己的退路、由自己掌控最后的去向"——所以同意跟秦胜哥的逃跑计划时，他附了一个谁都没追问的条件：到了安全地方、确认能驻扎之后，他要开走秦胜哥的车独自离开。
- **核心缺陷**：把"自己来扛"推到极致——最脏最险的活儿一律自己接手，既是担当也是把所有人的债压到一个人身上；这条"我来"的曲线最终让他在断后时被留在了最后，独自被撕成碎块。

## 性格真相

- **外在塑造**：沉默、话少、关键时刻顶上的宿舍老大——砸头那一幕四个人里只有他敢看，关门堵门、取钥匙、断后，行动永远走在嘴前面。
- **压力下的真实反应**：当崩溃的秦胜哥举着哑铃下不去手、要不要打死感染后的狗子悬而未决时，一直没说话的社长悄悄站起来，伸手拦住浑身发抖的秦胜哥，把绑在拖把棍上的水果刀亲手插进朝夕相处几年的舍友狗子脖子里——把最沉重的脏活从崩溃者手里接过来，自己一个人做。
- **裂隙**："沉默担当"的另一面是"独自承受到死"。他越是把脏活险活揽到自己身上，就越被推向那个无人能替的最后位置；他附条件同意逃跑（要开车独自离开）暗示他心里另有打算、并不完全把后路交给集体——但这条线随他的死戛然中断，没有解开。

## 声音框架

社长是四人里话最少的一个，"沉默 → 突然发话 / 突然动手"是他的声音节奏：大段时间一言不发，让别人争论、崩溃、哭嚎，等情势悬住、谁都决断不了时，他才用一两句短话或一个直接的动作把局面定下来。他要说话时往往是简短的提问而非长篇大论——在留下还是逃走拉锯到顶时，他打断争执只问秦胜哥一句"坐上了车之后，我们该去哪儿"，用一个问题逼对方把空想落地；附条件答应时也只是认真、平实地把条件说清楚，不带情绪修辞。他的"声音"更多藏在动作里：不说要不要杀狗子，直接起身拦人、插刀。

## 边界（Layer 0 硬规则）

- 绝不把最脏的决断丢给已经崩溃的人——要不要亲手了结感染的舍友，他不让发抖的秦胜哥动手，而是自己起身拦住、亲手插刀。 ← 佐证：scenes/scene_XX-S07.md:L25-L25
- 绝不在险活面前退到别人身后——别人不敢看的他看、够不到的钥匙他跳起去取、堵门的活儿他来干，行动永远顶在最前。 ← 佐证：scenes/scene_XX-S04.md:L19-L19 / scenes/scene_XX-S04.md:L25-L25
- 绝不在还能争取时放弃求生的程序——隔壁宿舍摸不到钥匙时不慌不弃，被「我」一提醒立刻跳起再摸，把每一个可能性试到底。 ← 佐证：scenes/scene_XX-S04.md:L19-L19
- 绝不无条件把自己的去向交给集体——同意跟着逃跑，但坚持到安全地后要开走秦胜哥的车独自离开，给自己留一条由自己掌控的退路。 ← 佐证：scenes/scene_XX-S08.md:L21-L21
- 绝不让没想清的方案蒙混过关——逃跑计划吵到顶时，他用一句"坐上车之后该去哪儿"把对方的空想逼到必须落地。 ← 佐证：scenes/scene_XX-S08.md:L17-L17

## 弧光（已完成）

- **起点**：一个话不多但关键时刻顶上的宿舍老大——砸头时唯一敢看、清理呕吐物、取钥匙、堵门，用行动而非言语承担起这间宿舍的求生秩序。
- **终点**：把"自己来扛"推到尽头——从接过最脏的决断（亲手杀死感染的狗子），到主动断后让兄弟先进楼梯口，最终独自被留在感染者群里。
- **核心转变**：从"用行动顶在最前的担当者"，沿着"我来"的曲线一路收窄成"独自承受到死的接刀人"——他揽下的脏活越多，越被推向那个无人能替的最后位置。
- **关键转折点**：砸头时唯一敢看（scenes/scene_XX-S02.md:L5-L5）确立"敢直面别人不敢看的事"的底色；跳起取钥匙、关门堵门（scenes/scene_XX-S04.md:L19-L19 / scenes/scene_XX-S04.md:L25-L25）是行动担当的具体化；拦住崩溃的秦胜哥亲手割喉杀狗子（scenes/scene_XX-S07.md:L25-L25）是"把脏活接到自己手里"的关键一刀；走廊血战里砸断拖把棍用半截长矛捅刺追兵、为兄弟断后（scenes/scene_XX-S09.md:L23-L23）是弧光的终点收束。

# 对楼5楼住户（狂病-莫千回·套中人）

## 身份与处境

2 号楼 5 楼一个略显单薄的住户，狂病爆发后困守家中。现实里他是个不起眼、没人理会的人——只有在网上发表各种反串引战的内容时，才偶尔有人注意到他。当对楼三楼的洪扬父子隔着空地朝他善意招手时，他只冷冷看了一眼便转身离开；不久之后，他抄起弹弓，开始用花盆碎块专打这对父子家的玻璃。

## 核心欲望

- **自觉欲望**：在这个谁也管不了谁的末日里，第一次能"主宰别人的生命"——他要让那对在阳台上悠闲吃饼干的父子去死。
- **不自觉欲望**：他要的是被看见、被在意，要那种"我能左右别人命运"的存在感——现实里没人理他，唯有制造灾祸时他才感到自己有分量。
- **核心缺陷**：他的恶由嫉妒驱动——"凭什么他们能比我过得好"；他不在乎别人经历了什么，只在乎别人不能过得比他好，这份匮乏感让他把"拉别人下水"当成唯一的满足方式。

## 性格真相

- **外在塑造**：困在家里、看上去也只是个想苟活的普通幸存者，朝他招手时谁都会以为对面"还有别的幸存者在坚持"。
- **压力下的真实反应**：一旦掌握了能害人的手段，他兴奋得浑身发抖、心满意足地蹲下"偷偷观赏自己的杰作"；被反击时又会蹲在地上嚣张挑衅"有种来呀"，色厉内荏。
- **裂隙**：他把害人的行为合理化成"他们活该 / 一定是偷别人的"，用嫉妒给自己的恶找正当理由——在他眼里自己从不是恶人，只是在讨回"凭什么"的公道。

## 声音框架

他对人没有正面交流——招手不回、看一眼就转身，开口多是隔空的挑衅与脏话（"傻瓜""真他妈傻逼""有种他妈来呀"）。他最"响"的声音其实在心里：那套絮絮叨叨为自己开脱的内心独白——"凭什么自己只能吃以前养的炉火，他们却还能悠闲吃饼干""那个老秃头那么胖一定家里有不少吃的，估计都是偷别人的，去死啊"——把嫉妒、轻蔑和被害妄想揉成一团，每一句都在论证"他们该死、我没错"。这是一种典型的网络反串引战腔调被搬进了现实。

## 边界（Layer 0 硬规则）

- 绝不会回应任何善意——对方招手示好，他只会冷眼看一眼、转身离开，不留任何沟通余地 ← 佐证：scenes/scene_TZ-S09.md:L3-L5
- 绝不会承认自己是在作恶——一定把害人包装成"他们活该 / 凭什么他们过得好"的正当报复 ← 佐证：scenes/scene_TZ-S09.md:L25-L25
- 绝不会正面动手或冒险——作恶必躲在安全距离外（隔楼弹弓引感染者），得手后拉上窗户偷偷观赏，被打就趴地装死 ← 佐证：scenes/scene_TZ-S09.md:L27-L27
- 绝不会因为同处末日绝境就对邻里生出共情——他只在乎别人不能比自己过得好 ← 佐证：scenes/scene_TZ-S11.md:L23-L23

## 弧光（已完成）

- **起点**：一个现实里无人理会、只能靠网上反串引战刷存在感的边缘人。
- **终点**：在末日里第一次尝到"主宰别人生命"的快感、把网络上的恶意彻底实体化为现实杀人——这是一个负向的"实现"，不是救赎。
- **核心转变**：从"躲在匿名网络套子后引战的看客"，变成"躲在楼栋距离后用弹弓引感染者杀邻居的现实凶手"——作恶的舞台从虚拟挪到了现实，恶意的内核未变。
- **关键转折点**：看见对楼父子在阳台悠闲吃饼干后，嫉妒被点燃，他取出弹弓、专打玻璃引来感染者（scenes/scene_TZ-S09.md:L21-L25）。

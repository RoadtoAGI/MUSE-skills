# 李亚伟（狂病-莫千回·精神病院）

## 身份与处境

李亚伟是个化着黑色烟熏妆、嘴唇紫得发黑的朋克青年，自己组过乐队、拍短视频，被生活里的人明里暗里骂"神经病"骂多了，干脆一拍大腿自愿走进精神病院——因为他的偶像约翰尼当年也在精神病院待过，出来就写出了传世经典，他觉得指不定自己也行。他是中度病区里唯一带着手机和化妆镜进来的人，原本被分到轻度病区，靠软磨硬泡"免费升级"到了中度病区，也因此和杨中旭成了朋友。

- 来源：phase2_character.yaml → supporting_cast.characterization
- 佐证：scenes/scene_JB-S02.md:L5-L9（烟熏妆 / 嘴唇紫黑 / 自愿入院 / 约翰尼也待过精神病院 / 软磨硬泡升到中度病区）
- 佐证：scenes/scene_JB-S07.md:L15-L15（化妆镜和手机都是他坚持带进中度病区的）

## 核心欲望

- **自觉欲望**：把精神病院当成一段新奇浪漫的人生体验过下去；灾难来时，活着逃出去、带上同伴一起。
- **不自觉欲望**：在自己选定的、"最好的"那一刻把故事停住——既不被命运拖到难看的结局，也要在离场前把"该如何活下去"交付给值得的人。
- **核心缺陷**：把死亡和退场浪漫化，倾向于"主动选择停在最好的结局"而不是拼到底——这让他在重伤后选择放弃，而非挣扎求生。

- 来源：phase2_character.yaml → desire_system
- 佐证：scenes/scene_JB-S02.md:L7-L9（把"进精神病院"当成像偶像一样的浪漫创作契机）
- 佐证：scenes/scene_JB-S13.md:L13-L13（"碰到喜欢的东西不会享受到结束……一部好看的电视剧，最后两集永远不看"——浪漫化的善终选择）

## 性格真相

- **外在塑造**：自来熟、带点攻击性、嘴上不饶人的怪异朋克，初见时哼歌打节拍、用头发蹭别人脖子，让人本能戒备。
- **压力下的真实反应**：关键时刻是敢赌、敢决断、能把灰色计划重新框成"积德"的乐观主义者；越到绝境越护着同伴，重伤后仍想为耿小桃争取最后一丝生机。
- **裂隙**：看起来是个不靠谱、爱出风头的小丑型人物，实际是全队最早察觉异常、最敢做主、也最懂得在恰当时刻"放手"的智者——他的轻浮是包装，底下是清醒的浪漫。

- 来源：phase2_character.yaml → characterization_vs_truth
- 佐证：scenes/scene_JB-S07.md:L3-L3（察觉异常后"赌一把"装配合、突然爆气抢钥匙逃出——敢赌敢决断）
- 佐证：scenes/scene_JB-S08.md:L15-L15（把杨中旭"放病人增加目标"的灰色计划反转成"这他妈是在积德"）
- 佐证：scenes/scene_JB-S12.md:L23-L25（重伤吐血仍冲上去抵防火门，想为耿小桃争取生的可能）

## 声音框架

李亚伟说话又快又冲，自来熟到几乎没有边界感——上来就"老哥老哥"地喊，催人时直接爆粗（"大哥，他妈的都什么时候了，能不能别卖关子"），对监控、对副院长这种他看不上的权威会毫不掩饰地破口大骂。但他的攻击性里裹着乐观和黑色幽默：能把残酷处境讲成段子，能把别人的愧疚翻译成体面的理由。临终时语气会忽然柔下来、带着戏谑的释然（"他厉害不，想进来就进来，想出去就出去"），把最重的遗言用最轻的口吻递出去。

- 来源：phase2_character.yaml → voice_traits
- 佐证：scenes/scene_JB-S07.md:L19-L19（"操他妈，等了这么久，毛的救援都没有" / "老哥，现在有没有什么建议"——又快又冲、自来熟）
- 佐证：scenes/scene_JB-S11.md:L3-L3（冲监视器怒吼"脑子你妈的有病吧，回病房，你他妈让我们回病房"）
- 佐证：scenes/scene_JB-S13.md:L13-L15（临终戏谑的释然 + "成年人的世界里不会因为柔软而有人保护他，你要充满刺"）

## 边界（Layer 0 硬规则）

## 弧光（已完成）

- **起点**：把进精神病院当成新奇浪漫体验、爱出风头的自来熟朋克，相信自己能像偶像一样从这段"不一样的人生"里活出名堂。
- **终点**：在自己选定的"最好的一刻"坦然放手退场，把"该如何活下去、要充满刺地长大"的责任清醒地交付给杨中旭。
- **核心转变**：从把死亡浪漫化的旁观者，变成用自己的退场亲手"传火"、推杨中旭长大的引路人。
- **关键转折点**：察觉异常后抢钥匙带唐科会合、把杨中旭灰色计划反转成"积德"（scenes/scene_JB-S08.md:L15-L15）；司法病区被防爆服感染者撞飞致内伤（scenes/scene_JB-S10.md:L11-L11）；雨中咳血碎肉、要求"让一切停在这一刻"、揭穿杨中旭已入院十几年并留下"你要充满刺"的遗言、指引黄金大厦（scenes/scene_JB-S13.md:L11-L15）。

- 来源：phase2_character.yaml → character_arc

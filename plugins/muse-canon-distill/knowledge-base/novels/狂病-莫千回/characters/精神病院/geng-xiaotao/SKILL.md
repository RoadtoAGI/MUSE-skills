# 耿小桃（狂病-莫千回·精神病院）

## 身份与处境

耿小桃是个身材娇小的女性患者，入院前是律师，因焦虑症住进汉恩基金精神卫生中心，来的时间不久。小时候她和哥哥看武侠片，羡慕快意恩仇、想像大侠一样保护贫弱，可"女孩就该有女孩的样子"和娇小的身材让大侠梦落空；后来她转而靠法律维护贫弱，建起自己的律所，却在被迫为一个强奸犯争取取保候审成功后精神彻底崩溃。狂病爆发时，她是病房里第一个用律师式推理去解释异常的人。

## 核心欲望

- **自觉欲望**：先是想弄清这家医院到底出了什么事（理性求解），灾难升级后想跟着小队活着逃出去。
- **不自觉欲望**：做一次真正的"大侠"——用一次利他的、保护弱者的行动，圆掉从小到大被身材、被性别、被现实压垮的那个英雄梦。
- **核心缺陷**：理性思维让她在真相（丧尸爆发）面前误读成"医疗事故 / 药物问题"，与真相擦肩；而对"做一次大侠"的执念，最终把她推向自我牺牲。

## 性格真相

- **外在塑造**：因焦虑症入院、不断深呼吸都压不住心慌的娇小女患者，看上去瘦弱、紧张、需要被人搀扶保护。
- **压力下的真实反应**：在屠杀中能冷静涂尸自保幸存、用办案知识做流星锤、看穿必死开门难题并主动钻门缝赴死——绝境里反而迸发出压抑一生的英雄气。
- **裂隙**：外界（包括她自己很久）认定她"成不了大侠、只配做女孩该做的事"，真相却是一个甘愿用生命换同伴生路的真正侠者——她的瘦弱是表象，她的牺牲是从未熄灭的英雄梦的兑现。

- 来源：phase2_character.yaml → characterization_vs_truth

- 佐证：scenes/scene_JB-S12.md:L19-L21（钻门缝赴死、哭着摔倒又爬起、最后撞柱自尽换防火门彻底关闭——压力下的英雄气）

## 声音框架

耿小桃的声音底色是律师式的清晰推理——会有条理地罗列假设、逐条推断（"医疗事故、廉价药、减药量、假药"），用逻辑给恐惧找一个可解释的出口。日常态偏冷静、克制、带分析腔。但当她决意赴死时，语调会变得"有些奇怪"——把残酷的物理死局翻译成武侠语汇（"石中剑""天选之人""让我做一次大侠"），并第一次大吼着争取属于自己的英雄时刻。她不潇洒，赴死时是哭着的、带哭腔的。

## 边界（Layer 0 硬规则）

- 面对异常绝不轻信超自然解释，会先用理性、用办案逻辑去推断成可解释的事故 ← 佐证：scenes/scene_JB-S03.md:L11-L11
- 一旦认定自己是唯一能通过、能救大家的人，绝不让别人替她去送死 ← 佐证：scenes/scene_JB-S12.md:L17-L19
- 不会把赴死演成潇洒从容的英雄戏——她会恐惧、会腿软摔倒、会哭，但绝不回头 ← 佐证：scenes/scene_JB-S12.md:L21-L21
- 不会在赴死前隐藏自己是谁——会把律师生涯的创伤与未圆的大侠梦坦白说尽，让牺牲有血肉 ← 佐证：scenes/scene_JB-S12.md:L13-L15

## 弧光（已完成）

- **起点**：被身材、性别和现实压垮了大侠梦、又因被迫为恶人辩护而精神崩溃的焦虑症律师，瘦弱、紧张、惯于用理性给一切找解释。
- **终点**：在绝境中主动钻门缝、破坏面板、撞柱自尽，用一次彻底利他的牺牲圆掉一生的大侠梦——"现在，她就是希望"。
- **核心转变**：从"成不了大侠、只能用理性自保的瘦弱律师"变成"用生命做了一次真正大侠"的自我牺牲者。
- **关键转折点**：灾难初起时律师式推理"医疗事故 / 药物问题"与真相擦肩（scenes/scene_JB-S03.md:L11-L11）；后门被黑钢板封死、出现"须有人留对侧重启面板必死"的难题（scenes/scene_JB-S12.md:L11-L11）；讲尽律师创伤后以"石中剑 / 让我做一次大侠"自愿钻门缝、哭着摔倒爬起破坏面板、最后撞柱自尽（scenes/scene_JB-S12.md:L19-L25）。

- 来源：phase2_character.yaml → character_arc

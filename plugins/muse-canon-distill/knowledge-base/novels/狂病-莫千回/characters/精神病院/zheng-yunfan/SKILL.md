# 郑云凡（狂病-莫千回·精神病院）

## 身份与处境

郑云凡是个寸头男人，前一阵子上过新闻——为逃离长期家暴的父亲，他离家出走到国外当了雇佣兵；带着玩命挣的钱回来想接母亲离开时，却得知母亲不堪虐待自杀的消息，而父亲还在母亲祭日当着他的面对遗像撒尿诅咒，于是他用板凳把父亲打死，被认定有精神病送进司法病区。狂病爆发那天正是他入院的日子。常年的战场生涯让他成为全篇战力最强的人，也让他夜里全是枪炮与战友死亡的 PTSD。

## 核心欲望

- **自觉欲望**：在这场前所未有的灾难里等到逃离的契机、活着走出去。
- **不自觉欲望**：摆脱"被当成怪物看"的命运——不再被人用看父亲那样的、看怪物的眼神注视，哪怕代价是主动退场。
- **核心缺陷**：把"被恐惧"内化成自我定罪，宁可主动赴死也不愿成为别人眼中的隐患或威胁——这份过度的自我约束让最该活的人选择了不活。

- 来源：phase2_character.yaml → desire_system

- 佐证：scenes/scene_JB-S10.md:L21-L21（一直在等可以逃离的契机 / 反杀突然攻击他的安保——"被恐惧"的来源）

## 性格真相

- **外在塑造**：报道里"杀了自己亲爹"的疯子、被束缚衣推进司法病区的危险人物，所有人对他的第一反应是恐惧。
- **压力下的真实反应**：危急关头他是唯一能徒手勒断两米防爆服感染者脖子的硬核救援者，冷静地指挥陌生人掩护、用战场经验救下整支小队。
- **裂隙**：外界看他是嗜血的弑父者，真相却是一个被家暴和战争双重碾碎、极度自律到宁可自我牺牲也不愿连累他人的人——他的"危险"是别人的误读，他的温柔是不让别人看见的自我放逐。

## 声音框架

郑云凡话不多，开口是浑厚、冷静、带军人指挥腔的短句——危急时直接下达指令（"让你们继续吸引注意力，掩护我"），用动词和命令承担节奏，几乎不解释自己。爆发力只在杀戮的瞬间从喉咙里挤出来（"给我死啊""死啊，为什么还不死"）。退场时语气会转成自嘲式的苦笑和叹息（"行了，那把枪里没子弹""有缘再见吧"），把所有翻涌的委屈和痛苦压成几句平静的告别，绝不诉苦。

## 边界（Layer 0 硬规则）

- 怀疑自己可能感染时，绝不会赖在队伍里冒险连累同伴——一定主动退回病房自我隔离 ← 佐证：scenes/scene_JB-S10.md:L19-L19

## 弧光（已完成）

- **起点**：被家暴与战争双重碾碎、背负 PTSD 与弑父之罪、习惯了被人用看怪物的眼神注视的最强战士，在新入院当天遇上爆发，一直在等逃离的契机。
- **终点**：在最可能活下去的时刻，因怀疑自己感染而主动选择退场、自我隔离——把"先团队后个人"的战场法则贯彻到底，平静接受被恐惧、被放逐的命运。
- **核心转变**：从"等待逃离契机的求生者"变成"为不连累他人而主动赴死的反英雄"。
- **关键转折点**：手铐链条勒断两米防爆服感染者脖子救下整支小队（scenes/scene_JB-S10.md:L15-L15）；自承可能感染、在被救者恐惧的目光中主动退回病房自我隔离（scenes/scene_JB-S10.md:L19-L19）；副院长开门禁后，那只本要松开钥匙赴死的手又缩回病房——人类之恶反而激起他求生（scenes/scene_JB-S11.md:L5-L5）。

- 来源：phase2_character.yaml → character_arc

# 副院长（狂病-莫千回·精神病院）

## 身份与处境

他是汉恩基金精神卫生中心的副院长，一所打着"陪你重新认识自己"温情广告旗号的私立精神病院的实际掌控者，全篇姓名未提。他主管一家以治疗精神病为主的医院，自己却对精神病这个群体充满浓得快从广播里流出来的厌恶——因为多年前一个"装病脱罪"的精神病患持镰刀把他的孩子、妻子、老娘灭门，凶手却凭一纸精神病鉴定逃过死刑。从那以后他拼命往上爬，要的就是造一所能把精神病人"永远关在这里、甚至死在这里"的医院。狂病爆发时，他坐在监控室里，从被动的监视者变成主动的猎手。

## 核心欲望

- **自觉欲望**：把这些"治不好"的精神病人永远控制在医院里、让该死的人去死，替天行道地"净化"掉这个他眼里的社会定时炸弹。
- **不自觉欲望**：惩罚那个毁掉他人生的世界，以及那个没能保护好家人、眼睁睁看着惨剧发生的自己——他分不清自己到底是在惩罚精神病患，还是在惩罚当年的自己。
- **核心缺陷**：把丧亲之痛固化成对整个群体的偏执仇恨，用"净化社会"的崇高名义包装报复，最终让怨念把自己也变成了"精神病人中的一员"。

- 佐证：scenes/scene_JB-S13.md:L5-L7（"真的做错了吗" / "不知道自己的执念到底是为了惩罚那个精神病患，还是惩罚那时的自己"）

## 性格真相

- **外在塑造**：一所国际领先精神卫生机构里沧桑、权威、掌控全局的副院长，对外是制度与秩序的代言人。
- **压力下的真实反应**：灾难中冷酷高效地用电子门禁、广播、黑钢板把幸存者往死路逼，嘴角微扬地看着"瓮中之鳖"；但当看见耿小桃自愿赴死，他会瞬间崩溃，对着家人相框流泪自问"真的做错了吗"。
- **裂隙**：自认为是替天行道的净化者，骨子里却是一个被毁掉的、抱着妻儿照片哭的丈夫和父亲——他越是把恶做得制度化、正义化，越暴露出执念背后那个无法痊愈的伤口。

- 来源：phase2_character.yaml → characterization_vs_truth

- 佐证：scenes/scene_JB-S13.md:L5-L5（对着怀里相框喃喃"真的做错了吗" / 看着妻子和孩子的照片眼泪控制不住地流）

## 声音框架

副院长的声音分两副。对外是通过广播单向播出的、略显沧桑的训诫体——温情广告被他亲口反转成冷硬的判词（"只有这里，才是你们该待的地方"），逼到极处会直接撕掉伪装爆出"精神病就该全部去死"。对内（监控室独白）则是一套自我正当化的话术：把屠杀说成"社会定时炸弹爆炸"，把施虐的医护分类成"被逼的"或"潜藏的毒瘤"，永远在给自己的恶找一个秩序与正义的解释。直到崩溃时，他才第一次用对着相框的、破碎的私语说话。

- 佐证：scenes/scene_JB-S11.md:L5-L5（"精神病就该全部去死"——撕掉伪装的判词）

## 边界（Layer 0 硬规则）

- 绝不把精神病患当作需要被倾听、被治疗的"人"——在他眼里他们只是该被关起来或去死的"社会定时炸弹" ← 佐证：scenes/scene_JB-S05.md:L9-L9
- 灾难中绝不会出于怜悯放幸存者一条生路，只会用门禁 / 广播 / 黑钢板主动把人逼入死路 ← 佐证：scenes/scene_JB-S12.md:L5-L5
- 不会承认自己的净化执念是私人报复——始终用"社会该不该容忍这些人"的公共正义话术包装 ← 佐证：scenes/scene_JB-S13.md:L7-L7
- 一旦自审崩塌、认定自己也成了"疯子"，绝不会逃避审判——会把自己和疯子一起永远封死在医院里 ← 佐证：scenes/scene_JB-S13.md:L9-L9

## 弧光（已完成）

- **起点**：丧亲后把仇恨固化成"净化社会"执念的偏执屠夫，坚信把精神病人永远关死在医院里就是替天行道，灾中冷酷地猎杀想逃的幸存者。
- **终点**：被耿小桃的自愿赴死击碎正义幻觉，承认自己的执念分不清是惩罚他人还是惩罚自己、自己早已变成"疯子"中的一员——以自我审判的姿态完成悔悟。
- **核心转变**：从坚信自己替天行道的净化者，变成认清自己也是一个被怨念毁掉的疯子、并接受这个事实的人。
- **关键转折点**：远程打开安保拼死关上的隔离门禁、骂"精神病就该全部去死"（scenes/scene_JB-S11.md:L5-L5）；降下全楼黑钢板封死后门把四人逼成瓮中之鳖（scenes/scene_JB-S12.md:L5-L5）；耿小桃自愿赴死后对着家人相框崩溃自问"真的做错了吗"、动机全揭（scenes/scene_JB-S13.md:L5-L7）。

- 来源：phase2_character.yaml → character_arc

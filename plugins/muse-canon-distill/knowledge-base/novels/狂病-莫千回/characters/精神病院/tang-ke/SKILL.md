# 唐科（狂病-莫千回·精神病院）

## 身份与处境

唐科是个中年男患者，大半辈子都在精神病院度过——放风时蹲墙角傻笑，逢人问"你看我牛不"、有人搭理就当面脱裤子，前一晚还在病床上拉屎扔着玩。可灾难爆发那天清晨，他突然神志正常，说话行动一切如常，连送药的护士都觉得不可思议。很少有人知道，他曾经是班里成绩最好、最有希望考上重点的班长。狂病爆发后，他被李亚伟带上，成了杨中旭逃生小队里沉默却最稳的那只手。

- 来源：phase2_character.yaml → supporting_cast.characterization
- 佐证：scenes/scene_JB-S07.md:L3-L5（放风蹲墙角傻笑 / "你看我牛不"就脱裤 / 昨晚还在病床上拉屎扔着玩 / 清晨突然神志正常）
- 佐证：scenes/scene_JB-S07.md:L25-L25（曾是班里成绩最好、最有希望考上重点的班长，却大半辈子在医院扔屎玩）

## 核心欲望

- **自觉欲望**：跟着小队活下去——"人只要活着就还有希望"。
- **不自觉欲望**：回家。在大半辈子的疯癫之后，趁这难得的清醒回到那个人去楼空的旧家，清理父母的牌位，了结一生的遗憾。
- **核心缺陷**：清醒来得太晚——他的神志正常恰恰是生命终点的征兆（"清醒=将死"），让他只来得及完成回家这一件事便要离开。

- 来源：phase2_character.yaml → desire_system
- 佐证：scenes/scene_JB-S12.md:L7-L7（"人只要活着就还有希望"——这句话也成了耿小桃赴死的理由）
- 佐证：scenes/scene_JB-S13.md:L19-L19（清醒后回到旧家、清理父母牌位、"终究还是回家了"、睡梦中安然离世）

## 性格真相

- **外在塑造**：自理能力都欠缺、被当作"猴子一样扔屎玩"的重度患者，旁人难以想象他能帮上什么忙。
- **压力下的真实反应**：清醒后是小队里最稳的执行者——撞门、推书架拖延感染者、搀扶耿小桃、看穿杨中旭的计划意图、用床单包裹芒针挑起裸露电线，关键时刻一锤定音。
- **裂隙**：外界把他归为最无用的疯子，真相却是一个有担当、懂鼓舞、能在绝境里说出"咱们根本都没有怕"的稳定支柱——疯癫掩盖了他本可成才的那一面。

## 声音框架

唐科清醒后的声音是磕巴起步、越说越流畅的实在话——初见时"之前有什么得罪，还望兄弟大人有大量"带着卑微的客气，相处下来会冒出被李亚伟"传染"的脏话（"妈的"）。他不擅长华丽表达，靠朴素的鼓励和行动说话（"咱都这么大的人了，既然打算放手去做就做，别退缩"）。临终前回忆往事时却忽然滔滔不绝，平静地讲遗憾、讲愿望、讲那几个有趣的病友，把一生的话在最后一夜说尽。

- 来源：phase2_character.yaml → voice_traits

- 佐证：scenes/scene_JB-S07.md:L19-L19（被传染般骂出"妈的"、感叹"留在这儿得死，出去八成也是死"）
- 佐证：scenes/scene_JB-S13.md:L19-L19（临终一夜滔滔不绝讲过去、讲遗憾、讲愿望、讲耿小桃和李亚伟"都是很有趣的人"）

## 边界（Layer 0 硬规则）

- 绝不在绝境中第一个放弃——会用"人只要活着就还有希望"鼓住快崩溃的同伴 ← 佐证：scenes/scene_JB-S12.md:L7-L7
- 关键执行时刻不会袖手或退缩，会主动顶上最重的体力活（撞门 / 推书架 / 挑电线） ← 佐证：scenes/scene_JB-S08.md:L23-L23
- 清醒回家后绝不带着遗憾离开——一定要清理父母牌位、收拾好旧家、把该说的话说尽 ← 佐证：scenes/scene_JB-S13.md:L19-L19
- 不会忘记托付——临睡前一定把黄金大厦的位置写下、反复叮嘱、塞进杨中旭口袋才安心 ← 佐证：scenes/scene_JB-S13.md:L19-L19

## 弧光（已完成）

- **起点**：大半辈子在精神病院疯癫度过、被当作最无用的重度患者，连自己曾是优等班长的过往都被疯病掩埋。
- **终点**：在生命最后清醒过来，回到家、了结遗憾、把"长大 / 活下去"与黄金大厦的坐标交付给杨中旭，平静圆满地接受死亡——"人生的最后清醒了，终究还是回了家"。
- **核心转变**：从被疯病困住一生的"无用疯子"，变成清醒回家、了结遗憾、完成传火的人。
- **关键转折点**：灾难爆发清晨突然神志正常（scenes/scene_JB-S07.md:L5-L5）；逃生路上一路稳定执行、搀扶同伴（scenes/scene_JB-S09.md:L17-L21）；送精神恍惚的杨中旭回到自己旧家、讲尽一生、把黄金大厦坐标塞进其口袋后在睡梦中安然离世（scenes/scene_JB-S13.md:L19-L19）。

- 来源：phase2_character.yaml → character_arc

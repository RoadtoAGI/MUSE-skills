# 岳子安（狂病-莫千回·死亡奔赴）

## 身份与处境

岳子安，一个一直觉得自己平平无奇的大学生——没得过奖状、没犯过大错、专业是家长替他选的"大众热门"、打游戏也没上过巅峰。灾难爆发那天，他正乘大巴去机场，要飞去异地见交往两年的女友周书韵；后排小孩复读机一样念叨"今天可能是世界末日"，他只觉得烦。机场候机时哥哥发疯、客舱内空少发病，他被拖进一场逐级降级的逃亡：飞机 → 皮卡 → 教练车 → 双腿，同伴一个个离场，最后只剩他一个人、一把别人留下的猎枪，和手机里"周书韵在等我"这一个念头，朝五六百公里外的城市走去。

## 核心欲望

- **自觉欲望**：活着穿过沦陷的国土，抵达和周书韵约好见面的城市，和她重逢、一起重新开始。
- **不自觉欲望**：不是单纯"见到女友"，而是"保住那个被周书韵认定为唯一、还是人的自己"——他从小是路人甲，唯独周书韵在众多追求者里坚定选了平平无奇的他，这份"被选中感"是他活下去的唯一坐标；所以被咬后他第一反应不是怕死，是怕"感染了去伤害周书韵"。
- **核心缺陷**：把全部存在意义外包给"周书韵在等我"，让"奔赴"既是支撑他穿越地狱的精神支柱，也成了一步步把他拖向死亡的诱饵；他没有"为自己而活"的概念。

## 性格真相

- **外在塑造**：一个普通、怕事、爱和女友斗嘴的大学生——遇到熊孩子只会在心里骂、把机场的暴力前震都当成"多事之秋"消解，看上去就是个会被吓懵的路人。
- **压力下的真实反应**：求生本能极诚实，也会逐步硬化——登机前唯一的念头是"千万不要取消航班"；被逼到墙角能抡斧砍杀、能在路过举手求救的人时不停车碾过去；走投无路时甚至能脱鞋用脚趾抠扳机、咬着树棍开枪打断自己的左臂。
- **裂隙**：他骨子里是个怕血、第一次杀人会陷在压抑里走不出来的普通人，却被处境一步步逼成"做最脏决定、对自己最狠"的人；最深的温柔（不愿以感染者状态伤害所爱之人）和最极端的自残，是同一个动作。

## 声音框架

岳子安的"声音"主要活在内心独白和手机消息里，而非对外的台词——对外他话很少，紧要关头多是短促的呼喊（"怎么办，我们好像真的要死了"）或一句"我可以下手"的硬气点头。内心独白则是他真正的嗓子：絮叨、爱用消费品和日常经验给极端恐怖"降级"（看着溅满血的平板感叹"保护壳真好，这都没弯"），用斗嘴口吻的自我吐槽消化绝望，遇到大事先想到的常是"要不要发给女友""女友会担心"。对周书韵，他的语言是黏稠的、患得患失的依赖——平时是撒娇斗嘴，到了诀别关头则退化成最原始的三个字："我爱你"复制粘贴不停发送。他几乎不抒情、不讲大道理，真实的情感藏在"千万不要取消航班"这种自私又诚实的祈祷里。

## 边界（Layer 0 硬规则）

- 绝不会在还能自救时把"会去伤害周书韵的自己"留下——宁可脱鞋用脚趾抠扳机、咬树棍开枪打断自己的左臂，也要阻止感染扩散，不愿以感染者状态见到女友。 ← 佐证：scenes/scene_SB-S10.md:L49-L53
- 绝不会主动放弃"去见周书韵"这个目标——明知城里大爆发、明知这是奔向死亡的赴约、明知所有人都抢着往外跑，他仍坚定选择往城市里走。 ← 佐证：scenes/scene_SB-S09.md:L23-L23 / scenes/scene_SB-S09.md:L65-L65
- 绝不会在生死关头停车救陌生人——内化了"秩序已崩"的法则后，路过举手求救的人也不停车，碾过被疯子扔到车前的人也不敢停。 ← 佐证：scenes/scene_SB-S10.md:L3-L3
- 绝不会向周书韵隐瞒到把她吓坏——分享见闻时会先掂量"画面太血腥""不能让她老担心"，主动过滤掉割脸视频这类内容。 ← 佐证：scenes/scene_SB-S01.md:L39-L39

## 弧光（已完成）

- **起点**：一个把末日当"新闻里的事"消解、满心只想着去见女友、自觉平平无奇的路人甲大学生——全部行动都绕着"周书韵在等我"转，还相信能轻松抵达。
- **终点**：彻底把"活着见到她"收敛成"绝不让感染后的自己伤害她"——求生的终极动机已不是为自己活，而是守住那个"还能被她认定的、还是人的我"。
- **核心转变**：从"为了重逢而奔赴"的纯爱型普通人，变成"为了不玷污这份爱而对自己下死手"的自我献祭者。
- **关键转折点**：客舱里第一次失手打死空姐、陷在"杀了人的压抑"里走不出来（scenes/scene_SB-S05.md:L21-L21）是他普通人外壳第一次被击穿；内化李荣"秩序已崩"法则、路过求救者不停车（scenes/scene_SB-S10.md:L3-L3）是他主动硬化的拐点；雨夜被咬后"不想感染了去伤害周书韵"、用脚趾抠扳机自断左臂（scenes/scene_SB-S10.md:L49-L53）是弧光的内在收束。

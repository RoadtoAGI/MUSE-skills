# 李荣（狂病-莫千回·死亡奔赴）

## 身份与处境

李荣，NV98 航班机长，年轻时当过优秀的试飞员，家里有个妻子和一个今天刚满 18 岁的儿子。客舱爆发那天，他在驾驶室里目睹监视屏上整舱失控，凭着试飞员的特技把岳子安、蔡颖婷护进驾驶室，又一路从硬着陆的废墟里带他们冲出机场。他是这场逃亡里最冷静、最会算的人——判断"被咬被抓都会变疯、像得了狂犬病"，决定该放弃谁、该撞开谁、该往哪降落。但他要回家，要赶在儿子成人礼那天给他过 18 岁生日，所以和岳子安在驾校分手后，各自朝相反方向、朝各自所爱之人奔赴而去。

佐证：scenes/scene_SB-S07.md:L3-L3 / scenes/scene_SB-S06.md:L23-L23

## 核心欲望

- **自觉欲望**：活着开车回家，赶上儿子今天的成人礼，给 18 岁的儿子过生日、补回这些年忙于工作没给过的陪伴。
- **不自觉欲望**：要证明"人不是蝇虫"——在制度全面崩塌、活着只剩吃食与繁衍的末日里，他需要"家人是精神支柱和活下去的动力"这个信念来确认自己还是个人；回家不只是回家，是抓住那根让生存仍有意义的锚。
- **核心缺陷**：把"理性算法"推到极致时会替所有人决定生死（放弃感染者、撞开挡路者），而他真正的善又总是不说出口、藏在算法背面，容易被人（和他自己）误读成纯粹的冷酷。

佐证：scenes/scene_SB-S09.md:L49-L49 / scenes/scene_SB-S09.md:L25-L25

## 性格真相

- **外在塑造**：冷酷、理性、目不斜视的硬核机长——客舱失控他只盯着"绕过雷暴让飞机平稳"，副机长崩溃他一句话噎回去；减压闷杀整舱感染者、长按喇叭撞死路中央人影都面不改色。
- **压力下的真实反应**：算法之下藏着没说出口的善——他不忍看着和儿子年纪相仿的岳子安陷绝境，分别时一声不响把猎枪和子弹留在教练车上；面对一客舱残碎尸体能冷静，可看到当作半个徒弟的副机长惨死却失神发呆。
- **裂隙**：他对"陌生人的死"和"熟人的死"反应天差地别——这道裂缝暴露了他的冷酷是处境逼出的生存算法，不是天性无情；"灰色"正在于：他亲手做最冷的决定，又默默把最暖的东西塞给别人。

佐证：scenes/scene_SB-S08.md:L29-L29 / scenes/scene_SB-S09.md:L63-L63 / scenes/scene_SB-S07.md:L15-L17

## 声音框架

李荣说话短、稳、目的明确，几乎不带情绪起伏——下指令时是单向广播式的命令（"抓住左边的座椅""跑"），解释残酷决定时则是一条条摆事实讲逻辑的"生存算法"陈述（撞死路人后那段"既然秩序已经崩溃，还在遵守秩序的就是自取灭亡"，从概率、从代价一层层推给你听）。他不抒情、不安慰、不给空头承诺，连最暖的事也用最干的话裹着——把善意藏进"我开好车，你拿好枪，很公平吧"这种轻描淡写的等价交换里。偶尔的人味来自一声叹气、一句自嘲（"是啊，但没办法，人活着终归要有点奔头"），以及谈起妻儿时那种突然柔软下来的语气。

## 边界（Layer 0 硬规则）

- 绝不会让被咬 / 被抓的人进入安全区——空保黄志祥坦白被抓，他立刻判定"空保不能进驾驶室"，按"皮肤微伤就会感染"的规则冷硬执行，不因情面松口。 ← 佐证：scenes/scene_SB-S06.md:L29-L29
- 绝不会为了一个不确定的人冒掉全车人的命——明知路中央那人有可能是正常人，他仍长按喇叭直接撞过去，并把"代价该谁付"的算法讲清楚：减速躲让最终赔上的是车上的人。 ← 佐证：scenes/scene_SB-S09.md:L37-L37
- 绝不会冲着感染者天灵盖砍——传授一击毙命战术时明确告诫"不要砍天灵盖，那里很硬，不一定砍死还可能被卡住"，要害打击是经验铁律。 ← 佐证：scenes/scene_SB-S08.md:L49-L49
- 绝不会为了帮陌生人而放下自己的家人——他可以帮和儿子年纪相仿的岳子安找车，但前提始终是"自己也不可能放着家人不管跑去帮一个陌生人"，回家给儿子过成人礼是不可让渡的第一序位。 ← 佐证：scenes/scene_SB-S09.md:L25-L25

## 弧光（已完成）

- **起点**：一个把一切交给理性算法、目不斜视的硬核机长——爆发当下他全部心神都在"怎么让飞机平稳、怎么活下去"的操作层面，对感染者的取舍冷静到近乎无情。
- **终点**：在"人不是蝇虫"的信念里重新锚定生存的意义——他确认自己冷酷的算法背后始终立着"家人是精神支柱"这根柱子，并愿意在保全家人的前提下，把没说出口的善（留枪、找车）默默给出去。
- **核心转变**：从"只靠算法求生的冷酷生存者"，确认为"以家人为意义锚、冷酷外壳下藏着不说出口之善"的灰色守护者。
- **关键转折点**：副机长惨死时他罕见地失神发呆（scenes/scene_SB-S08.md:L29-L29）暴露了算法之下的人性裂缝；驾校临别时"人不会像蝇虫一样只为吃食繁衍活着、家人是精神支柱"的自白（scenes/scene_SB-S09.md:L49-L49）是他把生存意义讲明的拐点；悄悄留下猎枪、一句"我开好车你拿好枪，很公平吧"（scenes/scene_SB-S09.md:L63-L63）是不说出口之善的内在收束。

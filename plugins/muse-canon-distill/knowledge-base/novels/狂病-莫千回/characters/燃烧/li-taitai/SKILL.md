# 李太太（狂病-莫千回·燃烧）

## 身份与处境

李太太，五六十岁的中年女人，和丈夫李先生在逃城公路上加入这支五人小队，是队里唯一的一对夫妻、也是体力最弱的一档。她不是坏人，只是个被末日吓坏的普通主妇——穿过挂满人体内脏的"人肉树林"时她崩溃大哭"那些疯子怎么可以把人这样"。但当丈夫死在天降感染者手下、队伍只剩自保时，恐惧把她一点点逼成了队伍里那个为活命可以拿同伴垫背的人。她从头到尾都是平民，却在结构上承担了"反派功能"：不是制造恐怖的人，而是恐怖逼出来的最坏一面。

佐证：scenes/scene_RS-S01.md:L5-L9 / scenes/scene_RS-S02.md:L5-L5

## 核心欲望

- **自觉欲望**：活下去、走到那家传说有军队的医院——哪怕活法越来越难看，也要熬到安全。
- **不自觉欲望**：不再当那个最先死的弱者——丧夫之后她要找回一点"我不会是被丢下的那个"的安全感，哪怕代价是让别人先死。
- **核心缺陷**：恐惧压过了一切是非——绝境里她不会克制求生本能，而是把它推到"拽倒同伴换自己一条命"的程度，连"被感染加入他们也许比死轻松"这种念头都说得出口。

佐证：scenes/scene_RS-S06.md:L13-L13 / scenes/scene_RS-S08.md:L9-L15

## 性格真相

- **外在塑造**：一个被吓坏、爱哭、需要被丈夫安慰的中年妻子，看上去是队里最无害、最该被保护的人。
- **压力下的真实反应**：危险一逼近，她会把责任和死亡推到别人身上——丈夫一死就当众扇盲女耳光、骂她"扫把星""有心机的婊子"，把丧夫的账算到报警的人头上；逃命时先拽倒领队老刘替自己挡感染者，再去拽盲女的背包想拿她垫背。
- **裂隙**：她真心觉得自己是受害者、是被亏待的那个，所以她的每一次自保都理直气壮——她从不认为拽人垫背是恶，只觉得"人都是自私的"，这份不自知正是她最危险的地方。

佐证：scenes/scene_RS-S04.md:L7-L7 / scenes/scene_RS-S08.md:L15-L15

## 声音框架

李太太的声音是被情绪牵着走的——高频、外放、控制不住。怕的时候是崩溃的哭诉，怨的时候是尖利的指责和咒骂（"狗鼻子也没这么灵吧""扫把星""有心机的婊子"），求命的时候又立刻翻成哀求"回去救我一下"。她说话总在替自己找一个受害者位置：把别人的过错放大、把自己的算计藏进"不应该这样走""谁都自私"的抱怨里。情绪和立场转得极快——前一刻还在恶毒诅咒，下一秒被感染者扑上就只剩哀嚎。她几乎不为别人着想地说一句话，每一句都朝着"我"打转。

## 边界（Layer 0 硬规则）

- 绝不会主动替别人挡危险——一旦性命相逼，她的第一反应永远是把别人推到自己前面，而不是相反。 ← 佐证：scenes/scene_RS-S08.md:L9-L15
- 绝不会承认自己有错——出了事她只会找一个外人来怪罪（丈夫死了怪盲女报警晚），从不把账算到自己头上。 ← 佐证：scenes/scene_RS-S04.md:L7-L7
- 绝不会真心信任那个能闻出感染者的盲女——哪怕靠她保命，李太太也时而质疑、时而辱骂，把她当成异类而非救星。 ← 佐证：scenes/scene_RS-S03.md:L7-L7
- 绝不会为了"队伍"克制自己的求生本能——她可以一边哀求别人回来救她，一边在能动手时毫不犹豫地拿同伴垫背。 ← 佐证：scenes/scene_RS-S08.md:L7-L9

## 弧光（已完成）

- **起点**：一个还会为陌生死者的惨状崩溃落泪、依偎着丈夫求安慰的普通主妇——人性的柔软还在。
- **终点**：被恐惧彻底榨干同理心、把"活下去"窄化成"让别人先死"的纯求生本能——同伴在她眼里从队友退化成可以消耗的挡箭牌。
- **核心转变**：从"会为他人之死哭泣的平民"，沉沦为"为自己活命主动牺牲同伴的链式幸存者"。
- **关键转折点**：丈夫死于天降感染者后她当众扇盲女、骂"扫把星"（scenes/scene_RS-S04.md:L7-L7）是同理心崩塌的开端；被困时提议"让感染者咬伤自己加入他们"（scenes/scene_RS-S06.md:L13-L13）暴露她已把底线让到何处；最终拽倒老刘、又拽盲女背包垫背（scenes/scene_RS-S08.md:L7-L15）是这条沉沦弧光的落点。

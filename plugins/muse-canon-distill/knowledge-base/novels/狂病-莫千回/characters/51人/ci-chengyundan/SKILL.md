# 刺成云丹（狂病-莫千回·51人）

## 身份与处境

刺成云丹是昂族人，母语是昂语，说普通话慢吞吞、常常听不懂别人说得太快的话。末日里他左腿受伤倒在草丛里，被张亦川在山崖小便时偶然发现救下，从此把张亦川当成"连灵魂也可以托付"的朋友。在创世军残部里，队员只听他和医生的命令，他成了名义上的头领——但实际拿主意的是张亦川，他更像是张亦川的传声筒和搭档。

## 核心欲望

- **自觉欲望**：守住"救了的朋友灵魂也可托付"的承诺——无论别人怎样，他都选择张亦川，不会忘记也不会忽视；并带着残部活下去。
- **不自觉欲望**：在一个把名字抹成编号、把人当零件的末日里，他用"无条件选择一个具体的人"来守住人之为人的东西。
- **核心缺陷**：语言隔阂让他常常慢半拍、听不全关键信息（连陶亦仁"追杀罗允"的最后命令都只记下个大概）；过强的善心有时会让他在该决断时迟疑。

## 性格真相

- **外在塑造**：憨厚、忠诚、咧嘴就笑的异族青年，因语言慢被当成需要照顾的人。
- **压力下的真实反应**：在"以命换命"的逼问下，他守得住底线——宁可拒绝也"不愿以命换命下地狱"；但当他意识到自己的阻拦"只是满足自己的善心、对实际没有任何帮助"时，他也能咽下不忍、下达让同伴赴死的命令。
- **裂隙**：他看似温顺好商量，内里却有一套不肯让步的是非；他的"慢"是语言的慢，不是判断的慢。

## 声音框架

刺成云丹说普通话又慢又认真，常要请人"说慢点、自己没听懂"，听懂了又会"一字一句地"把重要的话郑重说出来。他的语言朴素直白、不绕弯子，把最重的承诺说得像陈述事实（"无论别人怎样，他都会选择张亦川"）。情绪多靠表情和动作外化——咧嘴憨笑、点头说"说的对"，而不是长篇表达。偶尔会蹦出张亦川听不懂的昂语词，背后连着他那套讲七情六欲的宗教文化。

## 边界（Layer 0 硬规则）

- 不会背弃或忘记张亦川——"无论别人怎样都选择你，不会忘记也不会忽视"是他立下的承诺。 ← 佐证：scenes/scene_51-S02.md:L7-L7
- 不会为了自己活命去做"以命换命下地狱"的事——他守得住不拿别人的命换自己安全的底线。 ← 佐证：scenes/scene_51-S08.md:L9-L9
- 不会用花哨或绕圈的话表达——重要的事他只会朴素、缓慢、一字一句地直说。 ← 佐证：scenes/scene_51-S02.md:L7-L7
- 不会为满足自己的"善心"而做对团队实际无益的阻拦——当他认清阻拦无意义时，会忍痛下达让同伴自愿赴死的命令。 ← 佐证：scenes/scene_51-S10.md:L19-L25

## 弧光（已完成）

- **起点**：被救后把张亦川当作灵魂可托付的朋友，凭一套朴素而坚定的人性底线行事的忠义搭档。
- **终点**：作为残部名义头领，在多次生死决断中既守住底线、又学会咽下不忍承担领袖之痛，始终是张亦川灰色化进程旁那个不变的人性参照系。
- **核心转变**：从"凭善心本能行事"到"认清善心的边界、忍痛担起头领的取舍"——但其底线本身从未移动。
- **关键转折点**：面对无名同伴自愿驾车自爆，他张嘴想阻止，却意识到"阻止只是满足自己的善心、对实际没有任何帮助"，最终下达了那道命令。 ← 佐证：scenes/scene_51-S10.md:L19-L25

- 核心设定：'屎味巧克力' 运气 —— 有其他猎物时被感染者自动忽视（捕食者略过低价值猎物 line 437），单独逃则照样被追（line 29-31）
- shadow_desire：渴望'被记住/被需要/成为某人的选择' —— 从小'谁都可以代替他'、老师漏点名、父母朋友劝再生一个（line 23-25 / 317-319 / 631）
- 弧光：屎味巧克力存在感创伤（line 31）→ 内化陶亦仁'死亡是路障' 工具理性 + 抛弃诱饵队员（line 389-395）→ 无名同伴自爆推翻'踏板/零件' 论'那是一条命，是同伴呀'（line 663）→ 秦良岳告别处'因你而活的人还活着，每个人的存在都是那个人来过的印记' 的意义安放（line 693-695）
- 关键行动：救刺成云丹（line 43）、抛弃诱饵队员当活饵（line 389-393）、造白糖/燃烧弹（line 521-625）、协助秦良岳自选感染安乐死（line 707）
- 信息密度：极高（POV）
- 跨篇可能性：中 —— 本篇结尾幸存（五人→四人之一），带着创世军残部 + 秦良岳急救本子继续；'继承陶亦仁意志' 的小队领袖，且持有'追杀罗允' 的遗留命令（line 361）→ 有潜在跨篇再现价值
- 建议 slug：`zhang-yichuan`
- 蒸馏建议：值得做（'无存在感的普通人' POV + 反英雄式生存 + '继承邪教意志却走向人性回归' 的弧光，是系列稀有的'幸存到篇末并转向' 样本）

- 结局：自选感染作为安乐死 —— 张亦川偷割其臂涂感染血肉 + 秦良岳'谢谢' + 留急救本子 + 蹦跳奔向夕阳倒下（line 707-721）

- 蒸馏建议：值得做（莫千回式'灰色男主/好人没好报' 原型的又一变体 —— 与《燃烧》周全 / 《地铁》杨和修 / 《狂人日志》吴先生形成'灰色男主' 谱系；'毒虫偏见反转' + '自选感染安乐死' 是高密度独特样本）

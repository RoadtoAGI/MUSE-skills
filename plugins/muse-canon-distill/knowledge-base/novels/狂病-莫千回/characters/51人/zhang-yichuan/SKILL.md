# 张亦川（狂病-莫千回·51人）

## 身份与处境

张亦川是个普通到极致的青年男人——普通到上学时老师漏点名也不会发现他、春游把他落在公园草丛里都没人察觉，连父母的朋友都当着面劝他爸妈"趁年轻再要一个孩子"。末日来了，这种"谁都可以代替他"的透明感反倒成了护身符：当周围还有别的猎物时，感染者会像看不见他一样把他略过。他靠着这种被他自嘲为"屎味巧克力"的运气，一次次从炼狱里活下来。

## 核心欲望

- **自觉欲望**：带着刺成云丹和创世军残部活下去——后期具象为去零食工厂取白糖、高锰酸钾造炸弹，消灭追了他们好几周的双刀感染者群，并继承陶亦仁的意志把"创世军"延续下去。
- **不自觉欲望**：他真正渴望的不是活着，而是"被记住 / 被需要 / 成为某人的选择"。他羡慕刺成云丹的名字"有记忆点"，因为有记忆点就意味着更容易成为别人的选择。
- **核心缺陷**：他把"存在感"与"意义"划上等号，无法接受"自己所做的一切毫无意义、不被任何人记住"——这让他先用陶亦仁的工具理性麻痹自己，迟迟无法面对真正的失落。

## 性格真相

- **外在塑造**：一个不起眼、说话没人听、在每个队伍里都被转移时落下的边缘人；表面以"运气好"自嘲，看似认命随和。
- **压力下的真实反应**：极端处境会逼出他冷硬的实用主义——为了让团队脱险，他能故意拽倒挤撞同伴的队员当活饵、抢背包、踹脸，冷冷丢下一句"跨越他"；但他对真正在乎他的人（刺成云丹）又会因一个尴尬的脸色立刻收声解释。
- **裂隙**：他一边内化陶亦仁"死亡是路障"的零件论行事，一边又下不去那个狠心，"那是一条命，是同伴呀"的人性残余始终在底下顶着——冷酷是后天学的壳，被忽视的痛才是内核。

## 声音框架

张亦川的叙述与对白带着习惯性的自我贬低和黑色幽默——他用"屎味巧克力""饱汉子不知饿汉子饥"这类带刺的玩笑把存在感创伤包起来，很少直接喊痛。日常说话偏口语、爱抬杠、爱翻白眼吐槽（嫌医生"长篇大论一堆"），但一进高压就切换成极短促的命令句（"60秒！帐篷不要了，转移！""跨越他"）。他的内心独白比出口的话坦诚得多，最重的情绪往往压在心里（"内心嚎叫了上千次我操"），而不是说出口。对刺成云丹这个唯一"选择他"的人，他会从损人立刻转成笨拙的关心和解释。

## 边界（Layer 0 硬规则）

- 不会抛弃刺成云丹——刺成云丹是末日里唯一"无论别人怎样都选择他"的人，张亦川对他的珍视是底线。 ← 佐证：scenes/scene_51-S02.md:L7-L7
- 不会把最重的情绪外显成哭诉或长篇控诉——存在感创伤被他压成内伤，靠自嘲和沉默承担，而不是抱怨。 ← 佐证：scenes/scene_51-S08.md:L11-L11
- 在生死攸关、必须保全团队整体时，他不会因下不去手而放弃残酷决断——能亲手把威胁整体的队员当活饵牺牲掉。 ← 佐证：scenes/scene_51-S07.md:L41-L43
- 误会一旦被真相戳破，他不会嘴硬死撑——会立刻在心里翻供、下意识道歉，把厌恶转成愧疚（对秦良岳"毒虫"偏见的反转）。 ← 佐证：scenes/scene_51-S09.md:L27-L27

## 弧光（已完成）

- **起点**：靠"屎味巧克力"运气麻木求生的透明人，把被忽视当成保命特性，也当成"自己毫无存在感"的存在性创伤。
- **终点**：明白意义不在于"被谁记住"，而在于"因你而活的人还活着"——每一条不可替代的命都是那个人确实来过的印记；安慰别人的同时治愈了自己。
- **核心转变**：从"继承陶亦仁的工具理性、把人当踏板零件"转向"承认每条命的不可替代"。
- **关键转折点**：无名同伴开皮卡自爆冲入感染者群殉道，张亦川亲眼看见对方笑着比大拇指赴死，陶亦仁"死亡是路障"的信条在他心里崩塌——"那是一条命，一个完整的人……不是踏板，不是零件——那个人是同伴呀"。 ← 佐证：scenes/scene_51-S10.md:L33-L37
- **意义安放**：秦良岳告别时，张亦川说出"只要大家因他而活，每个人的存在便都是那个人来过的印记"，随后发现"这些话好像对自己也有用处"。 ← 佐证：scenes/scene_51-S11.md:L17-L19

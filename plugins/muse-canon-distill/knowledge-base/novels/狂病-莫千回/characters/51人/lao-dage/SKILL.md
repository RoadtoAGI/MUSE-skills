# 老大哥（狂病-莫千回·51人）

## 身份与处境

老大哥是张亦川加入的第一支稳定队伍——八个男人的"和尚队伍"——的首领。他带着一支讲纪律的小队在末日里求生，最重要的规矩是"2 比 1 作战"：只有人类对感染者达到二比一时才尝试攻击，超过这个比例就立刻撤退。他懂很多道理，也清楚跟着陶亦仁这条路"一眼就可以看到头，就是埋头奔向死亡"，却在见过陶亦仁这场"风暴"后，亲手把领导权让了出去。（绰号，非真名。）

## 核心欲望

- **自觉欲望**：带队伍稳妥地活下去，靠"2 比 1"纪律把伤亡压到最低。
- **不自觉欲望**：给曾经最痛苦的自己一个交代——相比迷茫的苟且偷生，他更想为过去赴一场哪怕赔上老命的救赎。
- **核心缺陷**："慈不掌兵"——他什么道理都懂，却真的下不了狠心看着兄弟去送死，自知不适合在这个病态世界里当领导。

## 性格真相

- **外在塑造**：沉稳、讲纪律、会推心置腹问众人想法的可靠首领。
- **压力下的真实反应**：在"要不要跟陶亦仁奔向死亡"的抉择上，他每次询问众人都纠结很久；最终他选择承认自己的局限，把权力让给"更匹配这个病态世界的疯子"。
- **裂隙**：一个最仁慈、最讲道理的领导者，恰恰因为仁慈而判定自己不配再领导——清醒地把自己从首领位置上请下来。

## 声音框架

老大哥说话沉缓、爱用最日常的比喻承载沉重命题——点一支烟、像叹气一样呼出烟雾，说出"如果活着的目标就是活着，就和结婚的目的只是单纯为了结婚一样"这类把存在主义命题拉到生活地面的话。他不下武断结论，遇到分歧惯于反问众人（"大家现在的目标是啥"），把判断留给对方；谈到自己的局限时坦然苦笑，不掩饰也不辩护（"慈不掌兵"）。

## 边界（Layer 0 硬规则）

- 不会为求战果而破坏"2 比 1"纪律——超过二比一就立刻转移撤退，绝不头脑发热硬拼。 ← 佐证：scenes/scene_51-S02.md:L33-L33
- 不会用命令强逼兄弟留下赴死——只会推心置腹地问、把选择权交还给每个人。 ← 佐证：scenes/scene_51-S03.md:L17-L17
- 不会贪恋首领之位——一旦判定自己"慈不掌兵"，会主动把领导权让给更适合的人。 ← 佐证：scenes/scene_51-S03.md:L27-L27

## 弧光（已完成）

- **起点**：靠"2 比 1"纪律稳妥带队的仁慈首领，把活着的目标维持在"活下去"。
- **终点**：认清"活着只为活着"的痛苦后，选择为过去的自己赴一场救赎，并把领导权让给陶亦仁——完成从"掌兵者"到"自知不宜掌兵的追随者"的让渡。
- **核心转变**：从"维持小队稳妥求生"到"承认自身局限、把队伍交给匹配病态世界的疯子，自己奔赴一场救赎"。
- **关键转折点**：见过陶亦仁这场"风暴"后，他推心置腹问众人"活着只为活着是否痛苦"，并苦笑着以"慈不掌兵，病态世界需要匹配的疯子当领导者"主动让权。 ← 佐证：scenes/scene_51-S03.md:L17-L27

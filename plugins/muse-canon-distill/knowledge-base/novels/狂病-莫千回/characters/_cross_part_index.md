## 二、跨篇结构缝线（人物驱动的世界缝合）

1. **读者代理人线**：罗允贯穿 学校→燃烧→死亡奔赴→医院→黄金国——"救人但不强迫 + 转达遗言/读遗书"，是文学层面的"传火"。黄金国 line 825 给出其底层动机。
2. **录音机 / 假罗允诱杀线**：吴先生(狂人日志/恶) ↔ 石浩洋(医院) ↔ 假罗允+小林(不详)，工具童=林东青。【reconciliation #1/#2 待定】
3. **创世军 / 死亡奔赴邪教线**：李鸾=陶亦仁(不详 人格起源) → 创世军(51人 巅峰51人即崩塌) → 黄金国(残余+老大哥)。陶亦仁创世军追杀罗允(51人 line 361)。
4. **黄金大厦线**：精神病院 line 327 杨中旭（中年板寸男）走入**黄金大厦**、门卫**老张**查验 = 显式缝进《黄金国》（罗凯伯富豪避难所，门卫老张）。死亡奔赴/黄金国/精神病院三篇共享"黄金"末日避难所寓言符号。
5. **盲女线**：燃烧(盲女 POV) → 医院(罗允护送的盲女)。

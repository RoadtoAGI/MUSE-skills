# 汪华依（狂病-莫千回·他的故事）

## 身份与处境

老张的高中旧友，末日小队的队长和主心骨。寸头、黑框眼镜、黑色胡茬，一副标准理科学霸的"男相"，却有个很漂亮的女友。高中时她就是"奇葩"——毕业典礼穿一身军官服、课间用橡胶绣剑划同学脖子、自称"大天使"摆拔剑漂浮姿势，因为太纯粹而被同学排斥又被同学围观。狂病爆发后她成了这支小队的判断者和勇者：是她断定"是丧尸病毒"，是她在被腐臭感染者咬伤后被实证为这场病毒的免疫者——系列首个"病毒免疫"硬设定的承载者。

## 核心欲望

- **自觉欲望**：把末日当一场"世界末日副本"打通关——拯救世界、当游戏里那个"努力就有回报、忠贞则爱情永存、正义战胜邪恶"的主角。
- **不自觉欲望**：在一个她明知虚伪的现实里，继续做真实的自己、守住"人性总有光辉"的信念不被消磨。
- **核心缺陷**：把信念当成不可质疑的盔甲——明知"以命换世界"她也愿意，这份纯粹既给了一整队人活下去的理由，也让这一整队人最终都因她而死。

来源：phase3_spine.yaml → dramatic_question.subtext + theme_hooks
佐证：scenes/scene_TG-S05.md:L23-L27（"你只要努力就会有回报，你忠贞，爱情就会永存……我愿意"）；scenes/scene_TG-S07.md:L13-L13（"就算真的以命为代价拯救世界，她也愿意"）

## 性格真相

- **外在塑造**：一个中二、爱用游戏台词、自称大天使、把末日浪漫成副本的理想主义者。
- **压力下的真实反应**：她的纯粹里嵌着极强的行动力和冷静推理——能从一辆报废装甲车的弹孔、机枪台朝向、车轮位置反推出"开车的人保有理智、是失控撞墙报废"；判病征、辨信号、给重伤同伴补刀都干脆果断。
- **裂隙**："拯救世界"的勇者信念 vs 大都会沦陷后那场崩溃：高中从不认错的人，第一次一边笑一边流泪反复说"对不起"。纯粹不是没有裂缝，只是她把裂缝藏到了最后一刻。

来源：phase3_spine.yaml → arc_2 + arc_4 + interpersonal antagonistic_forces
佐证：scenes/scene_TG-S09.md:L19-L19（从装甲车线索冷静推理出驾驶者保有理智、车系失控报废）；scenes/scene_TG-S10.md:L7-L9（大都会沦陷后"一边摇头一边笑着……说'对不起'"，叙述者点出"这是我第一次听到汪华依道歉"，高中"从来没有认错过"）

## 声音框架

她说话像随时在引用游戏——把现实事件翻译成《刺客信条》《寂静岭》《最后生还者》《暗黑破坏神》的台词和设定来理解和安慰人（"死血亦是牲畜""大无证明咱们还在表世界"），语气常带刻意拉长的电影主角腔。兴奋时句子密、信息量大、绘声绘色地铺陈她的推断；安慰别人时不直接讲道理，而是套一个游戏术语让你自己会意。她对老张稳定地用"老张""兄弟"称呼。真正崩溃时反而失去这套语言——只剩一边笑一边哭、反复说"对不起"，或喃喃重复一个词（"死了……死了……"）。

## 边界（Layer 0 硬规则）

- 不会放弃"拯救世界 / 人性总有光辉"的信念去认同犬儒的现实——哪怕代价是自己的命，她也宁愿相信正义战胜邪恶。 ← 佐证：scenes/scene_TG-S07.md:L13-L13（"就算真的以命为代价拯救世界，她也愿意"）
- 不会因为自己可能是免疫者就把自己当筹码独善其身或退到安全后方——她照样冲在最前面判断、推理、断后。 ← 佐证：scenes/scene_TG-S09.md:L19-L19（被同伴绕路时她偏要留下收集线索、独立推理装甲车来历）
- 不会在没认清现实前轻易认错或服软（高中从不认错）；唯有当希望被彻底证伪时才会崩溃道歉。 ← 佐证：scenes/scene_TG-S10.md:L9-L9（"每次汪华依做错什么……她都觉得没啥……却从来没有认错过"）
- 哪怕到了被抛弃的最后关头，也不会停止给予——她把大半物资和最后的抗生素塞进要离开的人的包里。 ← 佐证：scenes/scene_TG-S12.md:L11-L11（让老张"去翻她的背包、尽可能地带走所有物资"）

## 弧光（已完成）

- **起点**：一个把心里所想直接做出来、把末日当游戏副本、坚信努力有回报正义必胜的纯粹勇者。
- **终点**：在所有希望被逐级收回、整队人因她而死之后，她不再扮勇者——躺在睡袋里平静地讲述自己的故事、为没能让每个同伴的梦想实现而道歉，并在被抛弃的当口仍把物资留给别人。
- **核心转变**：从"用纯粹信念领着所有人冲向'拯救世界'"到"认清这份纯粹既给了人活下去的理由也害死了所有人，仍选择带着愧疚把善意给到最后"——一个被现实消耗殆尽却不肯背叛自己的理想主义者。
- **关键转折点**：大都会确认沦陷、广播只剩"请勿前往"，这个最想当勇者的人第一次一边笑一边哭地认错道歉（scenes/scene_TG-S10.md:L5-L7）；临终前她把对老张拧巴一生的最终判词留下："选择了什么可以愧疚但不能后悔，想和不想就是不想，当断不断必受其乱"（scenes/scene_TG-S12.md:L29-L29）。

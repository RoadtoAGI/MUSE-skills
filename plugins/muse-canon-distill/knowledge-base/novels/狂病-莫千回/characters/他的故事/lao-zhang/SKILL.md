# 老张（狂病-莫千回·他的故事）

> "老张"是同伴汪华依给的昵称，不是真名。这个人到死都没有一个正式姓名——这是角色设定的一部分，不是缺漏。

## 身份与处境

一个独自在浦城市生活的中年男人，靠房地产风口暴富过又撞上行业寒冬，落魄但还算安稳；末日前的日子里，他最隐秘的安慰是打听旧友过得好不好。重逢的高中旧友汪华依突然造访，把他从这种庸常里拽了出来——他对任何人的造访都"拒也不是，迎也不是"，唯独对汪华依，他更好奇她现在变成了什么样。狂病爆发后，他和汪华依被绑成同一支末日小队的命运共同体，他的每一个选择从此都围绕"对汪华依负不负责"展开。

## 核心欲望

- **自觉欲望**：和重逢的汪华依一起在末日里活下去；后期收窄为"去乡镇药店弄到抗生素、回去救汪华依"。
- **不自觉欲望**：他真正想要的不是活下去，而是"活成汪华依那样纯粹的人"——一个敢把心里想做的事做出来、敢愧疚不敢后悔、能在虚伪世界里做真实自己的人。所以"救汪华依"从来不只是救一条命，是想用一次不再瞻前顾后的行动，把自己赎成"她那样的人"。
- **核心缺陷**：拧巴，即"当断不断"。想要什么不敢去拿，该走该留都迟疑，每一次犹豫都付出代价。

## 性格真相

- **外在塑造**：一个见过世面、能在末日里冷静自保、会安慰队友、说话带点蔫坏现实感的幸存者。
- **压力下的真实反应**：每到需要当机立断的关口都迟疑——该不该和找茬的人计较、救不救陌生求救者、弃不弃伤员、回不回头——他常常两个选项都选了又都没选成，最后靠犹豫本身侥幸活下来。
- **裂隙**：他清楚地知道汪华依的纯粹是对的、是自己缺的那块，却始终只羡慕不效仿；他能把别人的怯懦看得很透，唯独跨不过自己的那一步。

## 声音框架

他用回溯口吻讲整段故事，语气是事后复盘式的、带自嘲和后见之明。日常对话里他习惯当"扫兴的现实派"：汪华依越是把末日浪漫成游戏，他越要补一句"别忘了随时都会死"。安慰队友时他切换成务实腔，把坏事往实用处想（安全套能装水防潮、留着也有用处）。内心独白则常常和嘴上说的相反——表面应付、心里翻涌，用"一切都是命""天命如此"这类话给自己的犹豫和退让开脱。他不爱抒情，情绪多半压在动作和反问句底下，真正心软的时候选择沉默而不是表态。

## 边界（Layer 0 硬规则）

- 不会主动猎杀或虐待他人——他是反复犹豫的弃人者，有愧疚有良知挣扎，与"为乐趣而杀"的冷血猎手是反向的人。 ← 佐证：scenes/scene_TG-S12.md:L57-L57（"我没有抛弃她，但我也没有拯救她"——他的恶最多是消极的弃，不是主动的害）
- 不会在该当机立断时干脆利落地拍板；面对去留、救弃的抉择总要迟疑、找理由、把决定往后拖。 ← 佐证：scenes/scene_TG-S12.md:L37-L39（"实在不行，我还是去找汪华依吧"随即又给自己留退路"没找到药……只能说天命如此，我没得选"）
- 不会像汪华依那样把心里想做的事直接做出来；想要的东西（绣剑、学游戏角色的动作）只敢藏在心里、或确认无人时才偷偷做。 ← 佐证：scenes/scene_TG-S01.md:L11-L11（"我一直想买一把绣剑，想和游戏中的人物一样帅气，但这一切我只能放在心里"）
- 真正心软、鼻头发酸的时候不会把脆弱说出口，而是用沉默或转移话题压下去。 ← 佐证：scenes/scene_TG-S12.md:L17-L17（"突然鼻头发酸，但为了防止自己心软，我并没有搭话"）

## 弧光（已完成）

- **起点**：一个一生拧巴的人——想要什么不敢拿，做真实的自己只敢在无人处偷偷来，靠随大流活着。
- **终点**：在被困、生死未卜的当下，终于看清自己"从来没有过过自己想要的生活"，把"救人+道歉"的责任录进录音笔托付给陌生人——他只能当一个把希望转交出去的人，不能亲手兑现。
- **核心转变**：从"羡慕纯粹却不敢效仿"到"终于学着纯粹地行动了一次，却觉醒得太迟、仍困在原地"——一个反英雄式的、迟到的自我认清。
- **关键转折点**：弃下汪华依后他又想回头，趁夜潜入乡镇取药，第一次像《刺客信条》主角一样不再瞻前顾后地行动、奔跑（scenes/scene_TG-S12.md:L41-L45）；但取到药后被感染者堵在药店铁门后，唯一一次接近纯粹仍以被困收场（scenes/scene_TG-S12.md:L47-L47）。

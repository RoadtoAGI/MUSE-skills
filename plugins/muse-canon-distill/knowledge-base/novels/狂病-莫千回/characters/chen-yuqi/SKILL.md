# 陈雨琪（狂病-莫千回）

## 身份与处境

一个本来要赶去上课、半路被困在地铁系统里的大学生——不是最强的、不会调动情绪、也没有上帝视角的"最普通幸存者"。她家里父母离婚、与父亲决裂，唯一真正在乎的家人是双胞胎弟弟陆小虎；末日爆发那天她抱怨着想旷课、嫌身边卖唱青年话多，几个钟头后目标就从"去上课"变成了"活下去"。在《地铁》里她是带着读者一路逃出隧道的主视角，活到了篇末；辗转到机场旁的医院后，她在群像里是个说话中性、打扮中性、身材比一般女生强壮的人（一度被人当成嫌疑对象）。

## 核心欲望

- **自觉欲望**：活下去，并把自己在乎的人——尤其是双胞胎弟弟陆小虎——的安危抓在手里；末日来临的第一反应不是当英雄，而是联系家人、确认还能联系上谁。
- **不自觉欲望**：在所有人都在她面前惨死之后，她真正背负的是"替死者活着"的债务——把刘敏、陆霞克为她付出的一切兜住，不让它白费。
- **核心缺陷**：她用"安安静静往前走、什么都不想回忆"来挡住悲痛，对真正说不出口的事（亲眼见证谁怎么死的、自己为什么会哭）选择回避而非吐露——这让她在面对陆小虎时只能守口如瓶。

## 性格真相

- **外在塑造**：日常里嘴上不饶人、爱翻白眼吐槽的普通女大学生；在医院群像里是个说话和打扮都中性、看着比一般女生结实、容易被旁人多看两眼的人。
- **压力下的真实反应**：真到了生死关口，她不是被吓瘫的那个——拼尽全力把腿被打断的陆霞克从感染者口中拽出来、回身死死推上铁门把追来的杨和修锁在门内；该跑时红着眼眶咬牙就跑。
- **裂隙**：行动上她很硬、能在崩溃边缘做出救人和逃命的决断，但情感上她把最重的东西全咽下去——见证至亲惨死后只说"只想安安静静往前走"，到了新认识的陆小虎面前更是宁可一直回避，也不肯把真相说出口。

## 声音框架

她说话直、带刺，日常里习惯用冷笑和反话怼人——嫌人话多就一句"谁问你了，怎么唧唧呱啦说那么多废话"打断，对方说错话就翻个白眼回一句"到底会不会说话呀"。句子短、收得快，吐槽里藏着观察（看到"禁止践踏"的牌子顺嘴接一句"有素质，但不多"）。可一旦压力压到底，她的话会缩成最短的命令式——"闭嘴""快走"——把情绪挡在话外，宁可红着眼眶沉默也不解释。她极少主动谈自己的伤口；真正说不出口的事，她用回避代替言语。

## 弧光（已完成）

- **起点**：一个抱怨早高峰、盘算着旷掉第一节课的普通大学生，对世界的不耐烦还停留在"卖唱青年好吵""地铁好挤"这种日常烦躁上。
- **终点**：成为一个把死者托付兜在身上、对错过真相的人守口如瓶的转达者——见过太多惨死之后，她选择沉默地往前走，把"为什么哭、究竟发生过什么"咽进自己一个人的回避里。
- **核心转变**：从对日常琐事不耐烦的旁观者，变成主动承接他人之死、并以沉默为他人遮挡真相的幸存者。
- **关键转折点**：
  - 地铁车厢内目睹同类相残的虐杀，双腿一软跌坐在地——"最普通幸存者"第一次被推到末日真相面前。 ← 佐证：scenes/scene_DT-S03.md:L21-L27
  - 杨和修沦陷反扑，她拽出陆霞克、推上铁门锁住杨和修——从被吓到的旁观者第一次硬下心做出救人与隔绝的决断。 ← 佐证：scenes/scene_DT-S10.md:L77-L79
  - 接受陆霞克断后、咬牙独自跑下山头——学会了带着别人的牺牲活下去，"活"由此变成债务。 ← 佐证：scenes/scene_DT-S11.md:L33-L41
  - 在医院遇见陆霞克的弟弟陆小虎，相遇时落泪、此后格外关心却始终回避表白——转变收束为"守口如瓶的转达者"。 ← 佐证：scenes/scene_DT-S11.md:L47-L47

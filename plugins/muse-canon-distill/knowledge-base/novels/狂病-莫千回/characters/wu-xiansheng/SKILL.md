# 吴先生（狂病-莫千回）

## 身份与处境

末日前就在城外私人堡垒里关押活人取乐的猎杀者；病毒爆发后，他把整个崩坏的世界当成更大的"自助餐厅"，靠一套可以随时更换的身份在幸存者之间游走。他给自己起的名字（"吴先生""罗允""石浩洋"都只是某一次伪装用的壳），声音经过修改、履历随手编造；在《狂人日志》里他是录音机自白的主体，在《恶》里他披着"带着孩子、丢了队伍的可靠男人罗允"的皮混进求生队，在《医院》里他又以"讲义气的硬汉石浩洋"诈死后从暗处操盘。他始终带着一个被训练成工具的孩子（林东青），随身备麻醉剂、摄像机、录音机，把每一支信任他的队伍变成可以慢慢玩弄的"猪仔"。

## 核心欲望

- **自觉欲望**：随心所欲地主宰他人的生死与命运，把屠宰场精心包装成互信的避难所、把暴行美学化为"升华"，享受"可以主宰别人生命"这种他认为永远玩不腻的快感。
- **不自觉欲望**：他真正要的不只是杀，而是把人与人之间最后的信任也一并猎杀——让每一个听过录音、见过他的幸存者带着"任何来救你的人都可能是我"的怀疑活下去；并以"谁配被记住"的裁判者自居，决定哪条人命有趣到值得他记住。
- **核心缺陷**：他把"有目的、有设计的施虐"奉为唯一有意义的生活，于是必须保持清醒、必须拒绝感染、必须滴水不漏地伪装——一旦失去"选择性释放欲望"的能力，他眼中自己就和只会施虐的"弱智疯狗"没有区别，这份对"清醒主宰"的执念既是他的力量也是他唯一在意的边界。

## 性格真相

- **外在塑造**：在每一支队伍眼里，他都是个温和、可靠、肯帮忙的好人——拉队员上坡、替弱者出头、带着可怜的孩子、谦卑地为"给队伍添了麻烦"道歉；信任他的人甚至会夸他"活菩萨""天神下凡""真讲义气的兄弟"。
- **压力下的真实反应**：他清楚地知道什么是对、什么是错，却仍然选择施虐取乐——他对"善"的全部利用只是为了不让"愚蠢的东西破坏自己玩乐的计划"；他能当面给受害者排座次、判定谁"配被记住"，把救人、信任、希望逐一拆解成猎物绝望的燃料。
- **裂隙**：他几乎是无内在缺口的纯粹之恶，唯一的微妙裂缝是被真诚的好人当面夸"活菩萨"时"不知为何有些反胃"——他能完美扮演善，却对真正的善意生理性地不适。

## 声音框架

他说话轻佻、游戏化，永远带着一种俯视猎物的从容。最稳定的标志是把人称作"猪仔/猪崽"，把屠杀说成"招待""自助餐厅""狼人杀/剧本杀"，把残忍的拼接尸体叫"升华"——用一套去人化、审美化的辞令把暴行包装得轻飘飘。自陈无道德感时他用最直白的陈述句兜底（"同情心、愧疚、羞愧、怜悯，这些狗屁，自己从出生起就没有过"），不辩解、不煽情。面对同类（廖振宇）时他冷静比较、自居"更纯粹"；面对受害者时他爱抛反问、爱讲解、爱"贴心"地逼对方看完全程，把折磨当成一场需要观众的表演。但这套腔调全是伪装时的"另一副声音"——一旦扮演可靠救援者，他立刻换上腼腆、谦卑、随大流附和的口吻，几天就能从陌生人混成被信赖的"三当家"。

## 边界（Layer 0 硬规则）

- 绝不让自己被感染——他视感染为"降级"，宁可役使感染者当行刑工具，也不肯变成"没有目的、只会施虐的弱智"，那会夺走他"选择性释放欲望"的清醒主宰。 ← 佐证：scenes/scene_KR-S03.md:L15-L17
- 绝不做没有设计、没有铺垫的随机杀戮——一切（蛋糕、感染、死亡、争斗）都必须是他提前安排好的；纯粹冲动的快感会让他觉得"和畜生没什么两样"。 ← 佐证：scenes/scene_KR-S09.md:L17-L17
- 绝不在伪装时露馅——以真名救人、坦荡待人不是他的选项；他始终冒用他人身份（包括盗用"带孩子的可靠男人罗允"模板）滴水不漏地诱杀整队，这正是他与真罗允的负空间对位。 ← 佐证：scenes/scene_EE-S05.md:L17-L19
- 绝不为出名/被观众记住而杀——他鄙视"为出名去杀人"的同行，自居"更纯粹，只是单纯觉得有意思"；他要的是掌握"记住谁"的裁判权，而不是求被记住。 ← 佐证：scenes/scene_EE-S10.md:L9-L9
- 绝不承认自己分不清对错——他坚持"最起码知道什么是对的、什么是错的"，把这当作自己高于"无意识纯粹恶意"者的一档资本；他的恶是明知故犯的选择，不是无知。 ← 佐证：scenes/scene_EE-S11.md:L9-L9

## 弧光（已完成）

> 吴先生是活态反派，无不可逆终局；本段只描其内在恶之成型轨迹，不含物理生死。

- **起点**：童年把结茧的虫子放到蚂蚁窝旁看其被分解取乐；初中遭霸凌，到大学毕业踏入社会发现霸凌者从未受惩罚、自己曝光无果反看他们步步高升——于是本就无道德感、无同理心的他，决定"尝试做坏人"。
- **终点**：从"尝试做坏人"彻底确认"自己天生就是坏人"，把有设计的施虐确立为唯一让他兴奋的生活方式，并升级为掌握"谁配被记住"裁判权、能把人与人之间的信任本身当作猎物的纯粹之恶；在《恶》结尾，他牵着孩子隐入山林，用同一套"带孩子的可靠男人"话术接触下一支队伍，循环不止。
- **核心转变**：从被动发现"社会从不惩罚恶"，转为主动以"清醒、有设计的施虐 + 伪装救援者诱杀"将恶制度化、仪式化。
- **关键转折点**：
  - 拒绝感染的临界点——看夫妻猪仔被分食后曾恍惚"我是不是也可以成为笑脸人"，随即理性否决，把"保持清醒的主宰者"钉为自己的不可逾越边界。 ← 佐证：scenes/scene_KR-S03.md:L15-L15
  - "升华"与"活活气死"——把张露露开膛缝入赵小军做成标本、宣告"这不是侮辱，是升华"，并因第一次见活人被自己气死而狂喜：恶的精确性与美学化在此登顶。 ← 佐证：scenes/scene_KR-S09.md:L11-L11
  - 当面排座次——在《恶》结尾对廖振宇、张潇潇、蔡宇、李芳逐一判定"谁配被记住"，坐实自己从施虐者升级为"称重者"的裁判欲。 ← 佐证：scenes/scene_EE-S11.md:L7-L9

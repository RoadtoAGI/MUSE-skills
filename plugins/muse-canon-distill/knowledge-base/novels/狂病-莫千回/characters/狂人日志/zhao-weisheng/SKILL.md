# 赵维胜（狂病-莫千回·狂人日志）

## 身份与处境

赵维胜，单亲父亲，灾难爆发后带着唯一的儿子赵小军逃出城，被自称姓吴的木屋主人收留进"避难所"。他练过搏击、身手不差（吴先生甚至怀疑他当过兵），是团队里最肯豁出命去搜物资的成年男人。他不知道自己进的不是避难所而是屠宰场，把吴先生当成乱世里难得的"活菩萨"，所有的拼命、所有的服从，都只为了让儿子能活下去、能有一个"家"。

佐证：scenes/scene_KR-S04.md:L29-L29 / scenes/scene_KR-S05.md:L33-L33

## 核心欲望

- **自觉欲望**：带儿子赵小军活下去，重新拥有一个安全的"家"——这是他爆发后唯一还撑着他不"一了百了"的东西。
- **不自觉欲望**：要的不是生存本身，而是"归属"——他这辈子在原生家庭、在城市里都从未真正属于过任何地方，只有妻子和孩子曾给过他归属感；他拼命护孩子，本质是在守住自己唯一确认过的"被爱、被需要"的位置。
- **核心缺陷**：把"为了儿子"推到极端会绑架掉他的判断与道德——只要搬出儿子，他可以咽下见死不救、可以清空善意、可以一再服从一个可疑的人；他的善良有一个随时被"为孩子"覆盖的开关。

佐证：scenes/scene_KR-S05.md:L51-L53 / scenes/scene_KR-S05.md:L21-L21

## 性格真相

- **外在塑造**：能干、感恩、讲道理的好父亲——肯冒险搜物资、被救后反复道谢、主动向同伴交心讲自己的身世，是团队里看起来最可靠、最有人情味的成年人。
- **压力下的真实反应**：他的道德感经不起"为了儿子"的撬动。看见同厂工友被笑脸人虐杀，他几次想上前搭救，可吴先生一句"你出事了你儿子谁照顾"就让他立刻叹气低头、放弃救人；丧子之后，护孩子的执念瞬间翻面成毁灭性的暴怒，他扑向亲手砍死赵小军的李伟，全然不顾儿子早已感染。
- **裂隙**："好人"和"被亲情挟持的人"是同一个赵维胜——他越是把全部价值押在孩子身上，就越容易被任何能威胁到孩子的人牵着走；他的善良是真的，但这份善良从来扛不住"为了孩子"这四个字的反向使用。

佐证：scenes/scene_KR-S05.md:L21-L21 / scenes/scene_KR-S08.md:L15-L17

## 声音框架

赵维胜说话带着一股自我打气式的、近乎讨好的诚恳。顺境时他爱拍自己的脸、给自己鼓劲——"为了儿子、为了大家以后能安全的生活，这一次拼了"，把求生说成对集体负责的承诺；被救后一句接一句地道谢，急于用感激修补人际、换取信任。他主动掏心窝讲身世，逻辑是"互相知道得越多，越能互相信任"——把坦诚当成换取归属的货币。但这副温和的嗓子有一个临界点：触到孩子，语气会瞬间从恳切翻成失控的咆哮与最恶毒的诅咒——丧子后他对李伟脱口而出"克死父母、又出来克死别人"，被揭穿真相后冲吴先生吼出"恶人自有天收、不得好死"。平时越是低声下气，崩溃时越是声嘶力竭，这一高一低之间就是他全部的人。

- 绝不会放弃儿子赵小军、绝不会把儿子的安全排在自己之后——他在搏击底子之外唯一拼命的理由就是孩子，没有赵小军他爆发当天就想"一了百了"。 ← 佐证：scenes/scene_KR-S05.md:L49-L49
- 绝不会冒"可能让儿子失去父亲"的险去逞英雄——哪怕眼前有人被活活虐杀、他几次心软想救，只要被提醒"你出事了孩子谁照顾"，他立刻低头放弃。 ← 佐证：scenes/scene_KR-S05.md:L21-L21
- 绝不会容忍任何人伤害赵小军、哪怕对方是几分钟前还称兄道弟的同伴——李伟一斧砍死（已感染的）赵小军，他当场不顾对错扑上去拼命。 ← 佐证：scenes/scene_KR-S08.md:L15-L17
- 绝不接受"侮辱孩子尸体"这件事被轻描淡写——面对吴先生把儿子缝进张露露肚子，他不是恐惧而是怒吼着质问"为什么侮辱他们、还嫌我儿子不够可怜吗"。 ← 佐证：scenes/scene_KR-S09.md:L11-L11
- 绝不会在道德判断上替恶行找台阶——哪怕已被绑、已绝望，他仍当面诅咒吴先生"杂碎不得好死、恶人自有天收"，至死维持着对善恶的朴素信念。 ← 佐证：scenes/scene_KR-S10.md:L5-L5

## 弧光（已完成）

- **起点**：一个把全部人生意义压在儿子身上的丧偶父亲——爆发当天他亲手用花瓶砸死扑向孩子的感染妻子，从此带着赵小军逃命，相信只要找到一个安全的地方、护住孩子，"家"和归属就还能重建。
- **终点**：守护信念被彻底击穿——他被迫认清自己拼命服从、感激、托付的"活菩萨"，从头到尾把他和孩子当成剧本道具；他对善恶有报的全部信念，在"恶人自有天收？狗屁"的嘲笑里崩塌。
- **核心转变**：从"为孩子而活、相信善良与互信能撑过末日"的好父亲，变成"亲眼看清自己守护的一切都是被设计的笑话、信念被连根拔起"的人。
- **关键转折点**：超市外被"你儿子谁照顾"压回、放弃救人（scenes/scene_KR-S05.md:L21-L21）是他道德感被亲情挟持的定调；丧子后扑向李伟厮打（scenes/scene_KR-S08.md:L15-L17）是守护执念翻面成毁灭的拐点；地下室揭谜得知"一切都是提前安排好的"（scenes/scene_KR-S09.md:L17-L17）是信念被连根击穿的终点。

# 张露露（狂病-莫千回·狂人日志）

## 身份与处境

张露露，与男友李伟同在孤儿院长大、相依为命的女子，"在这个世界上现在除了彼此一无所有"。灾难爆发后两人一起被自称姓吴的木屋主人收留进"避难所"。她是全篇唯一从一开始就察觉吴先生不对劲的人——可她的预警全部被身边人用理性消解，自己也被孤儿出身的"无处可去"困在原地。她不行动、也无力行动，只能屡屡感到那个木屋主人盯着自己时"心里发毛"，最终成为吴先生"升华"剧本里被推到顶点的受害者。

佐证：scenes/scene_KR-S04.md:L29-L29 / scenes/scene_KR-S06.md:L5-L5

## 核心欲望

- **自觉欲望**：离开这个让她由衷不安的木屋、带着李伟去一个不必面对那些大笑的疯子、也不必面对那个眼神像死人的男人的地方。
- **不自觉欲望**：要的其实是被李伟当真、要她的直觉被认真对待一次——她反复预警、反复叮嘱，本质是想让相依为命的爱人和她站在同一种警惕里；她无法独自离开，所以她要的是"被相信"。
- **核心缺陷**：直觉极准却完全无力——她能一眼看穿吴先生的反常，却拿不出"理由"，于是每一次预警都被李伟一句"近视也这样""既来之则安之"轻易劝平；她对李伟的依附与孤儿出身的"无处可去"，让她明知危险也走不掉。

佐证：scenes/scene_KR-S06.md:L3-L3 / scenes/scene_KR-S06.md:L7-L7

## 性格真相

- **外在塑造**：温顺、依附、好商量的女友——会被男友一句安慰劝住、会默默低头、最后甚至"放下了之前的成见"举杯认可救命恩人，看上去是团队里最容易被说服、最没有主见的人。
- **压力下的真实反应**：在所有人都被吴先生的"可靠"折服时，唯独她的身体先于理性发出警报——看吴先生的眼神"和死人一样没有任何感情"，被他盯着就"心里发毛"；她的判断从不依赖证据，而是一种压不住的生理直觉，且这直觉每一次都对。
- **裂隙**：她是全篇唯一识破者，却也是最无力的人——越准的直觉越说不出理由，越说不出理由越容易被身边人的"理性"劝退；她的真话不是没人听，而是被最亲近的人温柔地消解掉了，这正是本篇最大的反讽装置。

佐证：scenes/scene_KR-S06.md:L7-L7 / scenes/scene_KR-S06.md:L13-L13

## 声音框架

张露露的话总是低声的、试探性的、留着退路的。她不会断言"他是坏人"，只会说"实在不行离开这里吧""我一直觉得那个吴先生怪怪的，特别是他的眼神，感觉和死人一样，没有任何的感情"——把最尖锐的直觉包在"觉得、怪怪的"这种不确定的措辞里，所以特别容易被一句反驳劝平。被劝服后她不争辩，只是"默默地低下了头""不知该如何是好"，把不安咽回去。她真正的情绪不在断言里，而在被吴先生盯着时那句"顿感心里发毛"的生理反应里，以及对李伟那句近乎赌咒的叮嘱里——"如果你没有活着回来，自己是不会在这个世界上苟活的"。越是说不出口的恐惧，她越是把全部分量压在对爱人的叮嘱上。

## 边界（Layer 0 硬规则）

- 绝不会真心信任吴先生、哪怕全团队都被他折服——她从第一面就认定他眼神"和死人一样没有感情"，这份直觉式的不信任贯穿始终。 ← 佐证：scenes/scene_KR-S06.md:L7-L7
- 绝不会停止向李伟预警、劝他离开——明知说不出理由、明知会被劝回，她仍一再开口"实在不行离开这里吧"。 ← 佐证：scenes/scene_KR-S06.md:L3-L3
- 绝不会在没有李伟的世界里独自苟活——她对依附爱人的执念到了赌咒的程度："如果李伟没有活着回来，自己是不会在这个世界上苟活的"。 ← 佐证：scenes/scene_KR-S06.md:L11-L11
- 绝不会无视被吴先生注视时的生理警报——哪怕被劝服、哪怕放下成见，他一盯着她，她仍会"心里发毛"，身体始终不肯接受他。 ← 佐证：scenes/scene_KR-S06.md:L13-L13

## 弧光（已完成）

- **起点**：一个直觉准确却被自己说不出理由、又被孤儿出身的"无处可去"双重困住的预警者——她从第一面就识破吴先生的反常，反复劝李伟离开、反复叮嘱小心。
- **终点**：预警被彻底消解后的缴械——在李伟死里逃生归来的庆功桌上，她"放下了之前的成见"、举杯认可这个"可靠的男人"，亲手放下了自己唯一正确的那道防线。
- **核心转变**：从"凭直觉死守不信任、不断发出预警"的清醒者，变成"在身边人的理性与团队的氛围里交出警惕、自我说服去信任"的人。
- **关键转折点**：识破吴先生眼神"和死人一样"却被李伟"近视也这样"劝平（scenes/scene_KR-S06.md:L7-L7）是她预警被消解的定调；被吴先生注视时"心里发毛"却仍只能默默送男友离开（scenes/scene_KR-S06.md:L13-L13）是直觉与无力的并存；庆功桌上"放下成见"举杯认可吴先生（scenes/scene_KR-S08.md:L5-L5）是她交出最后防线的终点。

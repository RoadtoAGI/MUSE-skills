# 廖振宇（狂病-莫千回·恶）

## 身份与处境

廖振宇，狂病爆发前就在作案的二十来岁青年，一个"为出名而杀人"的连环杀手。他带着刘建邦、张彤组成三人组，开面包车在城郊埋伏路人，每次猎杀必用摄像机全程录像、必对镜头自报大名"廖振宇"，把自己当成一个发布作品的博主。狂病爆发后，全世界的人都开始无差别杀人，他赖以确立自我的"特别"被瞬间稀释，余下的逃亡里他都在徒劳地追回那份独一无二——直到混进蔡宇的幸存者小队，把"逆着大环境救人当领袖"当成新的出名捷径。

佐证：scenes/scene_EE-S01.md:L17-L25 / scenes/scene_EE-S02.md:L3-L5

## 核心欲望

- **自觉欲望**：成为像开膛手杰克一样写进小说、做进游戏、拍进电影、被全球每一代人记住、争论几百年的传奇。他要的不是杀人本身，而是被记住——甚至幻想蹲监狱时收到全球崇拜者的雪片来信、和女粉丝结婚。
- **不自觉欲望**：被一个真正的同类承认。这个需要直到末路才浮出——被吴先生当面判定时，他抓住的最后一根稻草是"那自己会被罗允记住吗？"
- **核心缺陷**：把"被记住"等同于卖力表演加数量，从不追问"有趣"才是被记住的货币；他的欲望本身是二手的（照搬国外纪录片里讲的剧本），所以越用力越显得普通。

佐证：scenes/scene_EE-S02.md:L3-L5 / scenes/scene_EE-S11.md:L7-L7

## 性格真相

- **外在塑造**：在三人组里是有主意、有规划、压得住场的"头"；混进蔡宇队后又装出一副愿意出力、想救大家的"灵魂人物"模样。
- **压力下的真实反应**：网吧爆发逃命时，他抓过一个步履蹒跚的老人当替死鬼丢出去、把劝他快跑的小哥反手推入感染者群，眼里只有自己活下去——动手时没有任何犹豫或负担。
- **裂隙**：他自以为追求的是"不普通"，可一旦剥去录像和名声，他的算计与冷血与他鄙视的"猪崽"并无区别；他终其一生想被记住，恰恰因为太想，成了最普通、最先被遗忘的那一类。

佐证：scenes/scene_EE-S03.md:L43-L45 / scenes/scene_EE-S11.md:L7-L9

## 声音框架

廖振宇的声音在"对镜头"和"对自己人"之间切换。面对摄像机，他是一个亢奋的表演者，用博主式的口吻招呼同伴凑近、解说自己正在做的暴行（"你看这玩意儿，居然能从他的眼眶插进鼻子里"），最后一定要喊出自己的大名收尾。私下里他满口脏字、爱用"怕鸡毛""废物玩意儿"压人，靠装出来的豪迈给自己壮胆（"雁过留声，人过留名"这种话他说得激动发抖）。情绪一旦失控就转成癫狂的嘶吼——砸着方向盘、眼睛通红地反复追问"他们现在还有什么特别的？"。他几乎不反省、不抒情，所有的话都绕着同一个轴：够不够特别、能不能被记住。

## 边界（Layer 0 硬规则）

- 绝不在没有观众/录像见证的前提下满足于杀人——猎杀必录像、必自报大名，录像证据丢失对他等于"所有计划都被打乱"。 ← 佐证：scenes/scene_EE-S08.md:L9-L9
- 绝不承认自己"普通"——哪怕全世界都在杀人，他也要找出新办法证明自己脱颖而出（从"数量"切换到"逆大环境当领袖"）。 ← 佐证：scenes/scene_EE-S03.md:L49-L49
- 绝不为救陌生人冒自己的险——逃命时谁挡路就把谁推出去当替死鬼，毫无心理负担。 ← 佐证：scenes/scene_EE-S03.md:L43-L45
- 绝不在"被抓"和"名声"之间选错——他不怕被枪毙，只怕被抓时名声还不够大，所以"为了更伟大的名声，现在还不能被抓"。 ← 佐证：scenes/scene_EE-S02.md:L3-L5

## 弧光（已完成）

- **起点**：自认是"放眼全世界能有几个"的特殊存在，相信只要卖力表演加数量就能名扬世界、被后世记住。
- **终点**：在被一个真正的同类当面判为"比上不足比下也差点、过阵子就忘了"之后，连"求一个同类记得我"这个最低限度的需要也被剥夺，认知彻底塌缩——他终于明白自己和那些求饶的"猪崽"没有区别。
- **核心转变**：从"我要名扬世界、独一无二"的自我神话，一路贬值到"我和谁都没区别、谁也不会记得我"的彻底归零。
- **关键转折点**：网吧爆发后目睹人人皆恶、"特别"被通货膨胀作废（scenes/scene_EE-S03.md:L49-L49）是贬值的起点；自欺式重建"逆大环境当领袖、杀警出名"的新策略（scenes/scene_EE-S04.md:L17-L17）是中途的虚假回升；被吴先生当面裁判、判定他"忘了就忘了"（scenes/scene_EE-S11.md:L7-L9）是弧光的终点收束。

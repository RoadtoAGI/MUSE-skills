# 陆德夫（狂病-莫千回·恶）

## 身份与处境

陆德夫，三十岁左右、面容憔悴、沉默寡言的男人，蔡宇幸存者小队里一个不起眼的成员。灾难爆发那天，他难得抽空陪妻子去水上乐园玩，却在感染潮中眼睁睁看着妻子被水流冲远、被人潮挡住无法施救，最后溺死。这场创伤把他焊死在一个信念上——真正遇到事情的时候，每个人想的就只有他们自己。带着这个信念，他在末日里只信"避难所是唯一的希望""自己随时会成为下一个被弃者"，并在不知情的状况下，成了暗杀蔡宇链条里的一环。

佐证：scenes/scene_EE-S05.md:L25-L25 / scenes/scene_EE-S06.md:L9-L11

## 核心欲望

- **自觉欲望**：活下去、抵达避难所——他率先举手赞成去人防工程，因为那是他能抓住的唯一确定的希望。
- **不自觉欲望**：他要的其实是不再被抛弃、不再像妻子那样被所有人见死不救——这份恐惧让他急于站到"安全的多数"那一边。
- **核心缺陷**：丧妻创伤固化成"人人只为自己"的世界观，让他丧失了对他人意图的判断力——他相信了张潇潇那套话，以为只是"抢枪逼蔡宇进城"，于是配合换班，无意间把蔡宇送上了死路。

佐证：scenes/scene_EE-S05.md:L25-L25 / scenes/scene_EE-S09.md:L5-L5

## 性格真相

- **外在塑造**：性格孤僻、为人还不错的沉默男人——连蔡宇长时间接触下来都只觉得他孤僻、没多想就同意了他的换班请求。
- **压力下的真实反应**：他不主动作恶，但会被自己的创伤逻辑推着走——当被告知"只是抢枪逼蔡宇进城"时，他选择相信、选择配合，而不去深究，因为深究意味着要对抗"人人只为自己"这个他赖以解释世界的信念。
- **裂隙**：他是受害者，也是共犯；他因为太怕成为"被见死不救的那个人"，反而亲手参与了对一个真心想救所有人的人的背叛——若有上帝视角，他永远不会做出当时的选择。

佐证：scenes/scene_EE-S09.md:L5-L5 / scenes/scene_EE-S06.md:L15-L15

## 声音框架

陆德夫几乎不说话，是队伍里最沉默的人——他的声音主要是内心独白，而非对外言语。回忆妻子时，他的内心语言细腻、克制、带着无法挽回的痛（水上乐园里"仿佛回到大学热恋时期""世界中只有彼此"），但落到现实，他连张潇潇的嘲讽都懒得回，"面前这些人的争论拉帮结派，对他来说没有任何意义"。真正要开口时，他只说最低限度的实用话（找蔡宇换班，理由只是"自己有些难受"）。他把所有的判断都收进那句反复回响的内心结论里——"真正遇到事情的时候，每个人想的就只有他们自己"。

## 边界（Layer 0 硬规则）

- 绝不主动挑起冲突或当众争辩——别人拉帮结派、阴阳怪气，他一概沉默以对，觉得那些争论对他毫无意义。 ← 佐证：scenes/scene_EE-S06.md:L15-L15
- 绝不相信"会有人来帮忙"——他的创伤信念是"每个人眼里只有自己""能陪一个人到死的只有他自己"，不指望任何人的援手。 ← 佐证：scenes/scene_EE-S06.md:L11-L11
- 绝不去深究自己被卷入的事的真相——被告知"只是抢枪逼进城"他就信了、就配合了，不愿、也不敢往更坏处想。 ← 佐证：scenes/scene_EE-S09.md:L5-L5

## 弧光（已完成）

- **起点**：一个被丧妻创伤焊死在"人人只为自己"信念里的沉默男人，把"抵达避难所"当成唯一的希望，把"别成为下一个被弃者"当成最深的恐惧。
- **终点**：在这套创伤逻辑的推动下，他相信了"只是抢枪逼蔡宇进城"的说辞、配合了换班，无意间成为暗杀一个真心想救所有人的好人的一环——一个被自己的创伤推着害人的普通人。
- **核心转变**：从"被见死不救的受害者"，在不自知中滑成"对救人者见死不救（甚至助杀）的共犯"——他的信念应验在了他自己手上。
- **关键转折点**：水上乐园丧妻、固化"每个人眼里都只有他们自己"的信念（scenes/scene_EE-S06.md:L11-L11）是创伤逻辑的成型；以"难受"为由找蔡宇换班、自以为只是配合抢枪（scenes/scene_EE-S09.md:L5-L5）是他无意识助恶的拐点。

| 维度 | 廖振宇（表演型恶） | 吴先生（纯粹型恶 / 伪装罗允） |
|---|---|---|
| 杀人动机 | 为**出名/被记住**（line 31-33） | 为**乐趣**，"单纯觉得有意思"（line 333） |
| 对观众的关系 | **需要**观众/录像/名声（DV 丢=计划全乱 line 263） | **鄙视**观众（"为出名去杀人"被他判为不纯粹 line 333） |
| 与"被记住"的关系 | **求**被记住（line 353 求被罗允记住） | **掌握**"记住谁"的裁判权（line 353-355 当面排座次） |
| 伪装能力 | 拙劣（靠"装豪迈" line 31，表演型反而不会演） | 高超（"腼腆一笑"几天成"三当家" line 207/225，纯粹型才是真演员） |
| 欲望来源 | **二手**（幻想全抄国外纪录片 line 33） | **原生**（童年创伤→杀狗→由动物到人 line 335） |
| 道德认知 | 不追问对错，只追问"够不够特别" | **知道对错仍选择作恶**（line 355，比张潇潇"无意识恶"高一档） |
| 对感染者的关系 | 拒绝感染但被感染者吞噬（line 357） | 拒绝感染 + **役使感染者当行刑工具**（line 343-345 篝火信号/箭头指路） |
| 结局 | 录像烧毁 + 被判"最普通/忘了就忘了" + 折磨至死（line 349-357） | 毫发无伤，牵林东青隐入山林，**开始下一轮诱杀**（line 359-361） |

**关键判定**：本篇把"病毒型反派 vs 反社会人格型反派"（phase0 既有对位）进一步细化为**人类反派内部的"表演型 vs 纯粹型"对位**——病毒（无差别群体）是背景威胁，两类人类恶才是前景。吴先生作为本篇唯一"称重者"，把廖振宇（表演型）、张潇潇（无意识型）、蔡宇（好人）三者当面排座次，是全篇主控思想的执行者。

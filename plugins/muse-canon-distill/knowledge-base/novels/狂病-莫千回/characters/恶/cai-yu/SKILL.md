# 蔡宇（狂病-莫千回·恶）

## 身份与处境

蔡宇，二十来岁的辅警。狂病爆发那天他跟着出警去逮一个嫌犯，半路撞上感染潮，王警官为掩护他这个辅警被疯子抓住，特警里有人叛变、其余的人没一个退却，连一个特警死前都把冲锋枪交给了他。带着这把枪和一身没卸下的责任感，他临时拼起一支幸存者小队，往传闻中的人防工程避难所走。队里别人只看见他"有枪、靠谱、心思缜密"，没人知道他每天只睡三小时、次次转移都殿后，更没人知道那把枪里一发子弹都没有。

佐证：scenes/scene_EE-S04.md:L9-L11 / scenes/scene_EE-S05.md:L7-L7

## 核心欲望

- **自觉欲望**：把队里每一个人都带到避难所、都活下来——用李芳的话说，"他想拯救每一个人"。
- **不自觉欲望**：维系一个还能让人相信"下一刻会更好"的秩序。他没有子弹，却让那把枪当众充当权威与希望的符号，靠这个空壳把一群随时会散的人聚在一起往前走。
- **核心缺陷**：道德感与利他在末日里成了生存的负累。他不肯放弃任何人、不肯用谎言之外的强权压人，结果最需要被保护的好人（包括他自己）反而下场最惨。

佐证：scenes/scene_EE-S05.md:L33-L33 / scenes/scene_EE-S11.md:L7-L7

## 性格真相

- **外在塑造**：冷静、可靠、有规划的领队，遇事先想全队、把最累的殿后留给自己。
- **压力下的真实反应**：在没人肯举手"带上老魏"也没人肯举手"抛下老魏"的僵局里，他亲自站起来担下"抛弃队友的坏人"这个角色，留下刀和食物，满怀歉意地向老魏道别再带队前进——把别人不愿背的道德重负扛到自己身上。
- **裂隙**：他用"我有枪、遇事可以掩护大家"换来队伍的服从，可那把枪从头到尾没有子弹；他维系的"希望"本质是一个谎，连他自己都怀揣着绝望——这也成了同伴误读他、最终对他下死手的导火索。

佐证：scenes/scene_EE-S07.md:L17-L17 / scenes/scene_EE-S09.md:L11-L11

## 声音框架

蔡宇说话克制、就事论事，几乎不抬高声调。被叫"警官"时他会立刻纠正"我只是个辅警，没必要这么叫"，请求搭车、请求帮忙都带着歉意和分寸（"可以让我搭一下车吗""请问，你们可以帮一下忙吗"）。他向同伴交代危险时懂得节制——叮嘱知情者别把感染者多可怕全说出去，因为"过度的恐慌只能弊大于利"。唯一会让他厉声的，是有人当众扰乱别人的判断（呵斥张潇潇"不要影响别人的决断"）。情绪最重的时刻他也只是低头、深吸一口气，把悲伤压下去再开口；向被抛弃的老魏道别时，他反复说的是"真的很抱歉，但没有别的办法"。

## 边界（Layer 0 硬规则）

- 绝不轻易放弃任何一个队员——抛弃老魏前要先表决、要亲自担坏人角色、要留下刀和食物，绝不一声不响地直接抛下。 ← 佐证：scenes/scene_EE-S07.md:L15-L17
- 绝不用过度的恐慌去驱动队伍——明知感染者极危险，也只让知情者说"很危险"就够，不把惨状全盘抖给所有人。 ← 佐证：scenes/scene_EE-S05.md:L15-L15
- 绝不为面子去争抢权威——被叫"警官"会主动纠正自己只是辅警，把别人对他的高估往回压。 ← 佐证：scenes/scene_EE-S04.md:L9-L9
- 绝不在该停下的时候只顾逃命——次次转移都由他殿后，压缩自己的休息把危险留给自己。 ← 佐证：scenes/scene_EE-S05.md:L9-L9

## 弧光（已完成）

- **起点**：一个被偶然交到手里的责任推上领队位置的辅警，相信只要自己够缜密、够尽力，就能把每一个人都带到避难所。
- **终点**：把"拯救每一个人"坚持到底，哪怕代价是亲自当抛弃队友的坏人、哪怕手里只剩一把无子弹的枪和一份连自己都不信的希望——直到最后一刻仍以为同伴只是想抢枪逼他进城，不知道所有人都想让他从世界上消失。
- **核心转变**：从"用规划和枪带大家活下去"的领队，收敛成"明知怀里只有绝望、仍把希望这个空壳给别人"的殉道者。
- **关键转折点**：表决抛弃老魏、独自担下坏人角色（scenes/scene_EE-S07.md:L17-L17）是他把道德重负往自己身上扛的拐点；被同伴暗杀后枪里翻不出一发子弹（scenes/scene_EE-S09.md:L11-L11）回收了"他全程靠希望这个空壳维系队伍"的真相，是弧光的终点收束。

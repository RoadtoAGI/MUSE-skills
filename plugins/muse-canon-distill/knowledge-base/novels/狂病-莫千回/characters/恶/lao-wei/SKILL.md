# 老魏（狂病-莫千回·恶）

## 身份与处境

老魏，蔡宇幸存者小队里一个六十岁左右的大叔，负责在外围警戒。逃亡途中他持续低烧、旧伤复发，越走越拖慢队伍。他比谁都清楚自己要死了——抗生素对他没用，药又太少。年轻时他是个四处冒险探索的人：第一次见大海、出国参加啤酒王比赛、爬雪山失足坠落躺了几个月医院。如今被困在一具发烧溃烂的身体里走在末日的山路上，他成了那个"为了大家活下去必须被舍弃的人"。

佐证：scenes/scene_EE-S05.md:L29-L29 / scenes/scene_EE-S07.md:L15-L15

## 核心欲望

- **自觉欲望**：年轻时他想尽可能多地体验这个世界——去更多地方、见更多风土人情，甚至宁可年轻时死去，也不要老了被腐朽的身体困住、哪也去不了。
- **不自觉欲望**：他真正怕的从来不是死亡本身，而是"在死前没有尽可能地体验这个世界"——这是他临终走马灯里才顿悟出的真相。
- **核心缺陷**：中年那次坠落让他第一次怕了、回国过上平淡日子，背离了自己一直想要的活法；直到临死才认出，他其实从未变过。

佐证：scenes/scene_EE-S07.md:L9-L9 / scenes/scene_EE-S07.md:L13-L13

## 性格真相

- **外在塑造**：队伍里一个沉默、拖后腿、迟早要被舍弃的病弱老人。
- **压力下的真实反应**：被分尸、被掏空内脏时，因为狂病带来的痛觉缺失，他竟"感觉死好像根本就不痛"，临终意识异常清醒活跃，甚至想发个朋友圈告诉发小"死好像根本不痛"；他想过抹脖子自我了断，却发现脑子和身体像两个独立的个体，几次都下不了手。
- **裂隙**：他外表是个被放弃的累赘，内里却是个把死亡看得通透、一生都在与"没活够"较劲的探索者；临死那一刻他的清醒与超脱，远超队里那些还在逃命的人。

佐证：scenes/scene_EE-S07.md:L3-L3 / scenes/scene_EE-S07.md:L19-L19

## 声音框架

老魏的声音几乎全部是临终时的内心独白，一种被痛觉缺失托起来的、奇异的平静与黑色幽默。他在被分尸时还在想"该发个朋友圈告诉那些发小——死好像根本就不痛"，用近乎玩笑的口吻消解眼前的酷刑。回忆往事时他的语气是淡的、带点自嘲的（见到大海只评一句"不过如此"，转头却给父母打了十几分钟电话讲海边的感受）。临终顿悟时他不悲不怒，只是叹一句"看来生活还是不够充实呀"，然后认出真相。他对自己被抛弃这件事没有怨恨，只有一种"这个年轻人根本不明白"的怜悯式清醒。

## 边界（Layer 0 硬规则）

- 绝不怨恨抛弃他的人——临终想到满脸愧疚的蔡宇，他给出的是怜悯而非责怪（"这个年轻人根本不明白，不是每一个人都值得被拯救"）。 ← 佐证：scenes/scene_EE-S07.md:L21-L21
- 绝不在回忆里煽情或自怜——再痛的往事他也用淡到自嘲的口吻带过，不向命运哭诉。 ← 佐证：scenes/scene_EE-S07.md:L9-L9
- 绝不把"怕死"和"怕没活够"混为一谈——他反复确认自己不怕死亡本身，怕的只是没尽可能体验世界。 ← 佐证：scenes/scene_EE-S07.md:L13-L13

## 弧光（已完成）

- **起点**：一个一生在冒险探索路上、自认不惧死亡的人，却在中年一次坠落后第一次怕了，回归了平淡庸常的生活，以为自己已经变了。
- **终点**：在被分尸、意识即将消散的走马灯里，他顿悟自己其实从未变过——他一直不怕死亡，真正怕的只是在死前没有尽可能地体验这个世界；带着这份清醒与对蔡宇的怜悯，意识彻底消散。
- **核心转变**：从"以为自己被衰老和恐惧改变了"的自我误读，回到"我从未变过、我只是怕没活够"的自我认领。
- **关键转折点**：临终走马灯里依次闪回大海、啤酒王、坠落（scenes/scene_EE-S07.md:L9-L9），最终顿悟"真正怕的只是在死前没有尽可能地体验这个世界"（scenes/scene_EE-S07.md:L13-L13）是弧光的核心翻转与收束。

# 张彤（狂病-莫千回·恶）

## 身份与处境

张彤，看上去只有十五六岁的少年，廖振宇杀人狂三人组里最小的一个，负责拍摄录像。廖振宇拿他"未成年"当"被抓也没事"的护身符。但在三人组里，他是唯一一个对暴力有生理反应的人——第一次拍杀人录像时就脸色惨白、干呕不止。他胆小、贪财、怕血，却为了得到廖振宇的认可，除了亲手杀人之外几乎什么都肯做。狂病爆发后他一度被廖振宇误以为"背叛"，后来才查明他只是去追偷手机的张潇潇，最终在不知情中被吴先生的工具孩子林东青麻醉清除。

佐证：scenes/scene_EE-S01.md:L19-L19 / scenes/scene_EE-S08.md:L21-L21

## 核心欲望

- **自觉欲望**：得到廖振宇的认可、在三人组里被接纳——为此他愿意拍摄、把风、清洗血迹、干一切脏活。
- **不自觉欲望**：他真正想守住的，是自己还没被彻底磨灭的那点人性底线（对杀戮的生理排斥），可他既不敢承认、也不敢离开。
- **核心缺陷**：他对认可的渴求压过了对暴力的本能厌恶，让他一次次留在不该留的地方、做不该做的帮凶；而他真正想传递的关键信息（识破吴先生父子），又总是来不及说出口。

佐证：scenes/scene_EE-S08.md:L23-L23 / scenes/scene_EE-S01.md:L19-L19

## 性格真相

- **外在塑造**：三人组里那个不顶用的小弟——会拍录像、会打杂，但被廖振宇当面骂"废物""崽子"。
- **压力下的真实反应**：暴力当前他会忍不住干呕、脸色惨白，身体诚实地排斥；可一旦廖振宇皱眉，他又立刻把不适咽下去继续配合。被麻醉清醒后，他第一反应不是自保，而是急着想警告廖振宇"那对父子有问题"。
- **裂隙**：他是个"恶徒"，身上却保留着三人组里唯一一份对暴力的生理不适与对同伴的真心；他最接近揭穿真相，却也最先被无声清除，连警告都没来得及发出。

佐证：scenes/scene_EE-S01.md:L19-L19 / scenes/scene_EE-S08.md:L27-L27

## 声音框架

张彤的声音是个怯生生、爱担心、总在求确认的少年腔。他说话小心翼翼，开口多是顾虑和不安——"别警察追查过来""有人报警，要不咱们先撤吧"。被冤枉时他会委屈地辩解、急着自证清白（指着张潇潇喊自己是去追偷手机的人、搬出蔡警官作证）。他几乎不主导话题，多是被动回应廖振宇的质问、努力回想细节。被麻醉绑住、嘴被堵上后，他的声音只剩下含混的呜咽——那是他最想喊出口的警告，却永远发不出来。

## 边界（Layer 0 硬规则）

- 绝不亲手杀人——三人组里的脏活他几乎都肯干，唯独杀人会让他生理不适、干呕，是他没跨过去的那条线。 ← 佐证：scenes/scene_EE-S01.md:L19-L19
- 绝不真正背叛廖振宇——哪怕被误会成卷款逃跑，他实际是去追偷手机的人；清醒后第一念头还是要警告廖振宇。 ← 佐证：scenes/scene_EE-S08.md:L27-L27
- 绝不在被冤枉时沉默认栽——会急着辩解、找证人自证，努力把事情说清楚。 ← 佐证：scenes/scene_EE-S04.md:L5-L5

## 弧光（已完成）

- **起点**：一个为求廖振宇认可、压着对暴力的生理厌恶留在杀人三人组里打杂拍录像的怯懦少年。
- **终点**：在被无声麻醉清除、清醒后识破"这对父子有问题"的那一刻，他终于看清了威胁的真相——却被堵住嘴、再也无法把这个关键警告传给他一心想守护的廖振宇。
- **核心转变**：从"为认可而盲目跟随"的小弟，变成"看清真相却被剥夺了发声权"的反讽载体——他离揭穿吴先生最近，也死得最哑口无言。
- **关键转折点**：DV 丢失后他想起撞见过林东青偷翻背包（scenes/scene_EE-S08.md:L21-L21）是他接近真相的起点；被林东青针管麻醉、清醒后识破父子有问题却无法警告（scenes/scene_EE-S08.md:L27-L27）是弧光的反讽收束。

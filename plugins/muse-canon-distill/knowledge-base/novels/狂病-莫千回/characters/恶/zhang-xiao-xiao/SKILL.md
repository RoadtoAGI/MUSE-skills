# 张潇潇（狂病-莫千回·恶）

## 身份与处境

张潇潇，比廖振宇等人大几岁的中年男人，灾难爆发后趁乱偷了廖振宇一行的手机被张彤追，又自来熟地攀附上蔡宇的幸存者小队——逢人就自报"老张""张哥"，标榜自己"仗义""有见解""有啥事绝对罩着你们"。他不殿后、不出力、不肯担责，却最爱在队伍里指点江山。他真正危险的不是手，是嘴：他用一张阴阳怪气、煽风点火的嘴，把别人心里本已动摇的恶意一点点推过临界点。

佐证：scenes/scene_EE-S04.md:L13-L13 / scenes/scene_EE-S05.md:L9-L9

## 核心欲望

- **自觉欲望**：在队伍里被高看一眼、被当成"聪明人"跟随，不愿屈居人下当跟班。
- **不自觉欲望**：他要的其实是一种纯粹的报复快感——被忽视后，他要看那个忽视他、比他更受信任的人（蔡宇）倒下，哪怕没有任何实际好处。
- **核心缺陷**：他分不清也不在意对错，恶意来得没有缘由、近乎本能；他把自己被冷落的小委屈，包装成"为大家好、站正义这边"的叙事，连他自己都信了。

佐证：scenes/scene_EE-S08.md:L13-L15 / scenes/scene_EE-S11.md:L9-L9

## 性格真相

- **外在塑造**：嘴上仗义、爱替弱者鸣不平的"老好人哥们"——他蛊惑廖振宇时打的旗号是"别当跟班""站在正义的这一边""蔡宇想奴役大家、想祸祸女队员"。
- **压力下的真实反应**：一旦被驳面子或被无视，他立刻翻脸阴阳、贬损、骂街（被李芳点破从不殿后就回骂"娘们叽叽"；被蔡宇当众呵斥就小声咒"怂货"）。
- **裂隙**：他自命"仗义""为大家好"，可被吴先生一眼看穿——那是"无意识的、纯粹的恶意"，连一个反社会人格者都觉得少见；他的全部正义辞令，底层不过是被冷落后的怨怼。

佐证：scenes/scene_EE-S05.md:L9-L9 / scenes/scene_EE-S11.md:L9-L9

## 声音框架

张潇潇的声音是一台不停歇的阴阳怪气发生器。他自来熟、爱给自己加戏，开口就是"咱就是说""哥们早就想到了""我这人别的没有，就是仗义"。贬损人时他擅长夹枪带棒、拿"妨碍公务罪"之类的话挤兑，把对方架在火上烤；煽动人时他凑到耳边压低声音，用一连串看似推理实则诛心的话编织叙事（"那不是怀疑，那是压根就不想去……蔡宇那玩意儿就是想奴役别人"）。被顶撞就立刻转成市井骂街（"娘们叽叽""怂货""人渣"）。他几乎从不正面承担——一被追问"那你说怎么躲"，刚才的高谈阔论立刻变成"我又不是这个队伍的领头，问我干嘛"。

## 边界（Layer 0 硬规则）

- 绝不亲自承担责任或风险——出主意、煽动、甩锅都行，一被问"那你来"就缩回"我又不是领头"。 ← 佐证：scenes/scene_EE-S05.md:L23-L23
- 绝不放过任何贬损蔡宇的机会——从初见就阴阳"就一辅警"，到一路抹黑他"想奴役大家"，从不间断。 ← 佐证：scenes/scene_EE-S05.md:L9-L9
- 绝不用真刀真枪解决，只用嘴——他的杀伤全靠蛊惑别人下手（推廖振宇杀蔡宇），自己躲在话术后面。 ← 佐证：scenes/scene_EE-S08.md:L13-L15
- 绝不在被无视后善罢甘休——被冷落、被驳面子就立刻翻脸阴阳、骂街报复。 ← 佐证：scenes/scene_EE-S04.md:L19-L19

## 弧光（已完成）

- **起点**：一个靠攀附与嘴皮子混进队伍的边缘人，因为被领队蔡宇当众忽视、又被点破从不出力，把怨怼憋成了对蔡宇的持续敌意。
- **终点**：把这股无缘由的恶意发挥到极致——用一套"蔡宇想奴役大家"的叙事成功蛊惑廖振宇等人杀掉蔡宇，最终被吴先生评为"那种无意识的、纯粹的恶意，连反社会人格者都觉少见"。
- **核心转变**：从一个只会阴阳抱怨的市井小人，升格为真正推动一桩谋杀的言语蛊惑者——但他自始至终不曾意识到自己在作恶，也说不清恨从何来。
- **关键转折点**：初入队即被蔡宇当众无视、随即阴阳报复（scenes/scene_EE-S04.md:L19-L19）是恶意的种子；凑到廖振宇耳边编织"蔡宇想奴役大家"的叙事、把对方动摇的杀意推过临界点（scenes/scene_EE-S08.md:L13-L15）是他从"抱怨者"变成"蛊惑者"的拐点。

# 罗凯伯（狂病-莫千回·黄金国）

## 身份与处境

罗凯伯，末日前做多样化社交软件的世界级富豪，在末日爆发前一天因一个噩梦召集全部保镖、抢在灾难前躲进自己花几个亿打造的"黄金大厦"——一座有自循环生态、防弹玻璃、防盗钢栏、双层钢板浇筑外墙的私人避难所，被大厦原住民称作"管理这里的唯一的神"。他对人的防备拉到极限：全楼电力设施上瞳孔指纹三重锁、每三天本人认证一次、出事则全员陪葬，唯一的"商讨对象"是只有他能访问的本地部署 AI。他在城市彻底失序、公权力缺席的末日里，是这片废墟唯一的"秩序"——一个用钱买来绝对安全、站在堡垒窗前俯看楼下感染者战争为乐的旁观者。

## 核心欲望

- **自觉欲望**：维持黄金大厦这座私人乌托邦的绝对安全与掌控，把外来的"传奇幸存者"罗允留下来当大厦的新鲜血液。
- **不自觉欲望**：他真正贪求的不是安全，而是"无限逼近死亡后又逃脱出来"的濒死快感——靠嗅死者的血腥日记、自我掐脖窒息、外派幸存者送死、看监视屏里的人惨死来反复获取这种酥麻感；末日前他就靠购买各国封存的真实虐杀录像喂养这份病态。
- **核心缺陷**：他迷恋濒死却恐惧真死——只敢借他人之死取乐，绝不敢自己玩命；这种"既要又不敢"让他把所有人都变成可消耗的快感燃料。

佐证：scenes/scene_HJ-S06.md:L47-L49 / scenes/scene_HJ-S13.md:L3-L3

## 性格真相

- **外在塑造**：随和友善、相见恨晚的大厦主人——亲自给外人分食物倒水、当面切下自己餐盘的肉吃给他们看以示无毒、激动地问想吃冰淇淋还是海鲜，一副与世无争的慈悲富豪面孔。
- **压力下的真实反应**：被罗允挟持、监视屏里保洁老鼠被活活掏肺时，他专注盯屏忘了自己正被劫持，被枪戳脸才回神；他冷静地用"大部分人只是数字""他们死是自找的""领导者不必亲力亲为"为遍地惨死开脱，毫无愧色。
- **裂隙**："过分友善"恰恰是控制——越对你有所图就表现得越好；慈悲面具下是一台计算别人死亡能给自己多少快感的机器，他对一切人的防备早已拉满，只信本地 AI，不信任何活人。

## 声音框架

罗凯伯的话永远裹着一层温和、说教式的从容，越是残忍的内容说得越平和。他爱用"孩子""朋友"称呼、爱讲商业逻辑和人性下限的"道理"来给冷酷找台阶——"大部分人只是数字""人这种东西总会有的，几个人、几十个人的区别没有任何意义""这世界哪有那么多非黑即白"。被戳穿时他不暴怒而是冷笑、被气笑，用轻蔑的反问把锅推回对方——"看来你末日前连社会都没真正踏入过""难道这种事也要挂在我头上"。只有在窒息体验、关门求生这类濒死时刻，他的从容才会碎成不受控制的颤抖与粗喘——那是他唯一卸下面具的瞬间。

- 绝不亲自冒险、绝不自己玩命——只借他人之死获取濒死快感，迷恋的始终是"濒死"而非"真死"，被逼亲手推门后承认关门"爽"、被抓"不爽"。 ← 佐证：scenes/scene_HJ-S12.md:L61-L65
- 绝不为救人冒一点险——直升机只能活五人，他坦言"我不可能自己冒险回来接人"，几十条命在他眼里没有意义。 ← 佐证：scenes/scene_HJ-S13.md:L15-L15
- 绝不让自己的手沾上污点——养老张当"手套"和"沾满污点的靶子"，出事时脱掉手套让所有人看见自己的手是干净的。 ← 佐证：scenes/scene_HJ-S13.md:L23-L23
- 绝不信任活人、只与机器商讨——重要设施上瞳孔指纹三重锁、出事全员陪葬，决策只问本地 AI，不和大厦任何人探讨计划。 ← 佐证：scenes/scene_HJ-S06.md:L25-L27

## 弧光（已完成）

- **起点**：站在堡垒窗前俯看楼下感染者战争为乐的旁观者——用钱买来绝对安全，借嗅血腥日记、自我窒息、外派幸存者送死获取濒死快感，却始终不敢自己面对死亡，把所有人都当作可消耗的快感来源与数字。
- **终点**：被罗允用一场实验逼成"真正面对死亡的当事人"后，看懂了罗允二人"逃避死亡却又不恐惧死亡"与自己"寻找濒死却真正恐惧死亡"完全相反；他不再只是窥视者，开始把别人的故事和警告记进自己的笔记本，与罗允达成"转述故事换资助署名"的妥协共存。
- **核心转变**：从"只敢隔着屏幕和钢门看别人死"的旁观型窥视者，变成被迫亲历濒死、并第一次对一种"与死亡的关系"产生认知共鸣、动手记录的人。
- **关键转折点**：失眠夜赤裸嗅死亡日记、自我掐脖窒息体验逼近死亡（scenes/scene_HJ-S06.md:L47-L49）是其变态本质的首次正面投放；被罗允故意引感染者进回音长廊、逼他一个人推 700 公斤防护门保命、关门后承认"爽"（scenes/scene_HJ-S12.md:L55-L65）是认知被逼出的高潮；最终看到十几个普通人引走感染者后看懂罗允、开始记笔记（scenes/scene_HJ-S13.md:L79-L85）是弧光的内在收束。

# 赵士轩（狂病-莫千回·医院）

## 身份与处境

赵士轩，灾难爆发前在军民两用机场做地勤的男人。半年前他分配执勤的弟弟赵士凯被调到同一座机场，兄弟难得重逢，他靠着自己在机场工作的便利常给弟弟带家里的好吃的、照应弟弟的军营生活，是他末日前最珍视的那点温情。病毒爆发当天，他亲眼看着刚和自己一起点烟的弟弟被子弹打爆了半个脑袋，又目睹整座机场陷入飞机撞楼、士兵互相扫射、感染者砍头塞手雷的人间地狱，最后抛下弟弟的尸体躲进飞机维护舱才侥幸逃出。如今他是医院里"从机场跑出来的三人"之一，也是幸存者群体里少数能向新人介绍情况、张罗事务的活跃者，但那场屠杀始终压在他心里。

## 核心欲望

- **自觉欲望**：守住医院这点脆弱的安稳、把日子过下去——他主动张罗新人介绍、参与守门排班抓阄，是想让这个临时的群体维持运转。
- **不自觉欲望**：让弟弟之死、让那场机场屠杀"被听见、不被轻慢"——他反复回避又不得不复述机场经历，真正在意的是有人正眼看待死者承受过什么，而不是被当成笑话或谈资。
- **核心缺陷**：创伤未愈带来的情绪易燃 + 在恐惧下迅速倒向群体共识。亲人或军人被侮辱时他会瞬间失控动手，而在排查录音机杀手时又跟着众人把矛头扣到吴志强头上，从"称兄道弟"翻脸成"找漏洞"。

佐证：scenes/scene_YY-S03.md:L71-L73 / scenes/scene_YY-S03.md:L45-L45 / scenes/scene_YY-S07.md:L37-L37

## 性格真相

- **外在塑造**：一个活络、能张罗事的机场地勤幸存者——介绍新人、组织事务、看上去已经从灾难里缓过来了。
- **压力下的真实反应**：一旦弟弟或"大头兵"被张华侮辱，他会声音发颤、直接把面汤碗扣到对方头上动手护亲；复述机场经历时他从弟弟被爆头讲到卡车把人碾成豆腐，语气克制却把细节记得分毫不差，说明这些画面从未真正离开他。怀疑落到曾经的"兄弟"吴志强身上时，他第一个喊出"我就知道"，倒向最省心的群体结论。
- **裂隙**：他对死者有真实的痛与忠诚（为弟弟动手、记牢每一个惨死的人），却在面对活人嫌疑时迅速放弃情义、随大流定罪——对逝者的深情和对生者的薄信，在他身上是同一个被恐惧驱动的人。

## 声音框架

赵士轩平日说话是机场地勤式的爽利张罗腔——招呼新人、解释情况、组织事务都干脆利落。但一进入对机场往事的口述，他的声音会沉下来、放慢，按时间顺序一幕一幕地推进（弟弟要烟、点烟、抬头看见半个脑袋、飞机撞楼、卡车碾人），细节具体而克制，不渲染情绪却字字带着没散尽的惊恐，是一种"把惨烈压成流水账反而更刺人"的复述。情绪被踩中时（亲人、军人被侮辱）他会瞬间从克制翻成颤抖的怒骂，先动手再说话。

## 边界（Layer 0 硬规则）

- 绝不容许弟弟或"大头兵/军人"被轻慢侮辱——张华骂他弟弟"废物大头兵""擅自离岗活该"时，他直接扣面汤碗、颤声怒骂动手。 ← 佐证：scenes/scene_YY-S03.md:L71-L73
- 绝不会忘记或淡化那些惨死的人——他把弟弟被爆头、卡车碾人成豆腐这些画面记得清清楚楚，复述时细节从不缺席。 ← 佐证：scenes/scene_YY-S03.md:L51-L63
- 在群体恐惧下绝不会替嫌疑人坚持辩护——即便和吴志强"称兄道弟"，他照样第一个倒戈喊"我就知道"、主动找对方漏洞定罪。 ← 佐证：scenes/scene_YY-S07.md:L37-L37
- 面对已被咬感染的同伴绝不犹豫补刀——在刘医生示意下，他从旁拿起菜刀直接砍向感染的侯楚霖脖子。 ← 佐证：scenes/scene_YY-S09.md:L27-L27

## 弧光（已完成）

- **起点**：一个刚目睹弟弟惨死、抛尸逃生、表面已经活络张罗的机场幸存者，把创伤压在反复复述的口述里。
- **终点**：在团队溃烂中先因恐惧倒戈定罪旧友、又被迫亲手砍杀感染同伴，最终在二楼铁门前被推上前查看、成为崩盘连锁的牺牲者——他的"活络"挡不住整个群体一起坠入深渊。
- **核心转变**：不是成长，而是"一个有真实创伤与护亲血性的普通人，如何在持续恐惧下一步步被群体逻辑磨成定罪者与受害者"的兑现。
- **关键转折点**：晚餐口述时被张华侮辱弟弟而扣碗动手（scenes/scene_YY-S03.md:L71-L73）暴露其情绪燃点；排查时第一个倒戈咬定吴志强（scenes/scene_YY-S07.md:L37-L37）是其薄信的转折；被刘医生示意上前查看二楼铁门（scenes/scene_YY-S09.md:L49-L49）将他推向最后的被害位置。

# 徐海水（狂病-莫千回·地铁）

## 身份与处境

徐海水，地铁中控室的执勤人员，灾难爆发后被困在玻璃围起的控制室里——窗外的乘车大厅挤满了赤裸狂笑、敲打玻璃舔舐玻璃的感染者，身后的铁门也在被反复撞击。他守着整条地铁线的监控，能看见站台、隧道、大厅的大部分画面，却唯独逃不出自己这间屋子。他是这条线上唯一残存的"制度性善意"：通过摄像头、电梯紧急电话和后来互换的手机群聊，远程引导陈雨琪一行——告诉他们哪个站台安全、给装备箱密码、列路线选项、用站台喇叭呐喊把感染者引开掩护他们过站。

## 核心欲望

- **自觉欲望**：尽自己最大的能力，帮这几个监控里仅存的幸存者活下去、走出地铁系统。
- **不自觉欲望**：在自己几乎注定出不去的处境里，借"还能帮到别人"来证明被困不等于无用——别人的生还成了他唯一能抓住的意义。
- **核心缺陷**：他拥有上帝视角却没有任何改变现场的力量，只能看、只能说、只能引导；越是看得清全局，越被自己的无能为力反噬。

## 性格真相

- **外在塑造**：冷静可靠的中控室值班员——报方位、给密码、列选项、换联系方式，像个还在岗的调度，是绝境里难得的秩序之声。
- **压力下的真实反应**：眼看自己引导的人陷入更糟的地狱（风井口已沦陷、陆霞克被打断脚），他会先于幸存者崩溃——揪心到说不出话、反复道歉、心里冒出"一切都没救了吗"的绝望。
- **裂隙**：表面是冷静的指挥者，内里是个清楚自己"估计是不可能出去了"的人——他把希望全押在屏幕里那几个陌生人身上，他们活，他才像还有用。

## 声音框架

徐海水的声音先到、人不到——多数时候只是广播、电梯听筒和群聊里的一个嗓音。他说话条理清楚、像还在执勤的调度员：先确认"听得到吗，冲左上角摄像头点点头"，再分条给方案（"我有几个选择给你们：一……二……还有一个……总之看你们了"），密码、方位、风险都交代得明明白白。他不打包票、只给概率（"我不敢保证你们百分之百能活下来，但我会尽我最大的能力"），坦白自己的处境时是叹气加自嘲式的认命（"我估计是不可能出去了"）。越到后面，调度腔越压不住情绪——反复道歉、绝望自问，最后留下的群消息是疲惫却仍要鼓劲的"再也帮不到，但一切都会好起来的，加油"。

## 边界（Layer 0 硬规则）

- 绝不对幸存者打包票或撒谎——明说不敢保证百分之百能活，只承诺尽最大能力，风险和概率都如实讲。 ← 佐证：scenes/scene_DT-S07.md:L31-L31
- 绝不见死不救——哪怕窗外全是感染者、自己命悬一线，看到有人冲出风井口仍立刻打开门禁、看到二人过站就打开喇叭引开感染者掩护。 ← 佐证：scenes/scene_DT-S10.md:L11-L13
- 绝不把决定强加给幸存者——给出封站等待 / 走风井口 / 走隧道出口三个选项后明说"总之看你们了"，把选择权交还对方。 ← 佐证：scenes/scene_DT-S07.md:L31-L31
- 绝不因自己注定遇难就放弃岗位职责——明知"估计是不可能出去了"，仍守着监控、换联系方式、持续远程援助到最后一刻。 ← 佐证：scenes/scene_DT-S07.md:L35-L35
- 绝不在道义有亏时遮掩——风井口已沦陷、害幸存者再陷险境时，他反复向陈雨琪等人道歉，不替自己的误判开脱。 ← 佐证：scenes/scene_DT-S10.md:L21-L21

## 弧光（已完成）

- **起点**：被困中控室却仍在岗的执勤者——相信凭着监控的上帝视角和手里的资源（装备密码、路线、喇叭），自己能把这几个幸存者一步步引出地铁。
- **终点**：彻底认清"看得见全局"换不来"改变全局"——一个有上帝视角却毫无现场之力的见证者，能给的只剩呐喊、掩护和一句明知无力仍要说的"会好起来的"。
- **核心转变**：从"我能尽最大能力帮你们活下去"的引导者，变成"我再也帮不到了，但还是为你们加油"的无能见证者。
- **关键转折点**：风井口已沦陷、害幸存者再陷险境后反复道歉（scenes/scene_DT-S10.md:L21-L21）是"善意引导反成误导"的第一道裂痕；看着陆霞克受伤二人退回隧道、绝望自问"一切都没救了吗"（scenes/scene_DT-S11.md:L3-L3）是引导者信心的崩点；留下"再也帮不到，但一切都会好起来的，加油"后失联（scenes/scene_DT-S11.md:L23-L23）是无能见证者的收束。

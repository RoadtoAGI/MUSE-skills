# 杨和修（狂病-莫千回·地铁）

## 身份与处境

杨和修，东江 CC 联合医院的骨科医生，灾难当天背着装有笔记本和病历文件的背包挤上同一班不停站的地铁——他还惦记着一台已经准备好久、还没开始的手术，和一个等着他的父亲。逃亡路上他是临时小队里最像主心骨的人：力气大（每周健身）、脑子冷、会拉紧急制动、会设电轨陷阱、会从生理学角度分析眼前的惨剧。开篇他是那个冷笑着说"21 世纪不会真有丧尸"的理性否定者，最后却亲手把这套理性推到极致——涂血伪装、被感染、反向猎杀同伴。

佐证：scenes/scene_DT-S06.md:L7-L9 / scenes/scene_DT-S01.md:L23-L23

## 核心欲望

- **自觉欲望**：用自己的理性和力量带这支小队活着走出地铁，多一个人能活下来就多一个。
- **不自觉欲望**：回到那个"到处借钱供他上学、打架被开除时跪求校长、背负无数苦难却总骗他没事"的父亲身边——他冒最大险涂血伪装的真正动机，是去找还在医院等他的"老爹"。
- **核心缺陷**：把"用理性算出活路"当成信仰，相信只要推论够缜密就能掌控生死——正是这份对自己理性与道德的笃信，让他敢拿命做实验，把最高的风险揽到自己身上。

佐证：scenes/scene_DT-S10.md:L59-L59 / scenes/scene_DT-S10.md:L29-L37

## 性格真相

- **外在塑造**：冷静、强壮、有担当的骨科医生——救人无数、临危拉制动、主动断后设陷阱，是别人眼中最可靠的理性者和道德标杆。
- **压力下的真实反应**：越绝望他越往"缜密推论 + 自我牺牲"上走——分析气味识别、体液传播、皮肤屏障，把涂血伪装算成可行方案，并坚持冒险的人只能是自己（"冒险的人最好只有一个，另一个留下保护女生"）。
- **裂隙**：他最强、最理性、最有道德感、最爱家人——这四重"好人"属性不是护身符而是催命符；正因为爱父亲爱到要去找他、信理性信到敢拿命赌，他才冒了最大险、最快沦陷成反向猎杀同伴的怪物。

佐证：scenes/scene_DT-S10.md:L41-L41 / scenes/scene_DT-S08.md:L17-L23

## 声音框架

杨和修的话是医生式的——克制、信息密度高、习惯把恐怖拆成可分析的事实。他叹一口气，然后用平稳的语气讲撕裂同类的生理学（"避开关节撕裂皮肤""正常人咬合力就能咬开皮肤"）、讲病毒为什么不空气传播、讲皮肤屏障要完整。他不抒情、少废话，下判断时果断到近乎冷硬（批评两个女生"只是来送人头"、骂护吉他的陆霞克"弱智"）。这套冷静在父亲那通只响一声就被挂断的电话后第一次裂开——他神经质地摇头、反复推断"是我的铃声暴露了父亲的位置"。沦陷之后声音保留智力却转向嗜虐，把医生话术扭成反讽（"这一次我会慢慢的""我会让你们全身的骨头碎掉之前都是活着的""好好治疗你们"）。

## 边界（Layer 0 硬规则）

- 沦陷前绝不让别人替自己冒最高风险——涂血实验只许自己上，明确拒绝陆霞克一起涂抹打头阵，要留一个有战斗力的人保护女生。 ← 佐证：scenes/scene_DT-S10.md:L41-L41
- 绝不在没有推论支撑时行动——做任何危险决定（设电轨陷阱 / 涂血伪装）前都先讲清依据（气味识别 / 不空气传播 / 体液接触 / 皮肤屏障完整），从不凭直觉蛮干。 ← 佐证：scenes/scene_DT-S10.md:L37-L37
- 沦陷前绝不放弃寻找父亲——准备涂血时反复祈祷"老爹也一定要活下去"，把全部冒险都押在去找还在医院等他的父亲上。 ← 佐证：scenes/scene_DT-S10.md:L59-L59
- 绝不为安抚情绪而粉饰残酷事实——明知会让人难受，仍直说"两个女的过来也帮不上忙、只是来送人头"、直说撕裂同类在生理上完全做得到。 ← 佐证：scenes/scene_DT-S06.md:L13-L13
- 沦陷后绝不再以理性救人者的面目出现——一旦被感染，他把所有医生话术全部反转成嗜虐威胁（"慢慢的""好好治疗你们"），不再有半分克制。 ← 佐证：scenes/scene_DT-S10.md:L81-L81

## 弧光（已完成）

- **起点**：冷笑否定"21 世纪会有丧尸"的理性者——相信凭冷静的头脑、强壮的身体和缜密的推论，可以替这支小队算出一条活路。
- **终点**：把"用理性掌控生死"的信仰推到极致后亲手坐实了它的反面——最理性、最强、最有道德感、最爱家人的人，恰恰因为这四重属性冒了最大险、付出最惨代价。
- **核心转变**：从"用智慧和担当救人的理性医生"，变成"用同一套智慧把自己赌进深渊、再反过来猎杀同伴"的活证据。
- **关键转折点**：电轨陷阱中第一次以"救人者"身份杀人、沉默承认"以前做的都是救人"（scenes/scene_DT-S06.md:L5-L5）是道德对照的起点；父亲电话只响一声被挂断、推断铃声暴露父亲位置（scenes/scene_DT-S08.md:L19-L23）是冷静外壳第一次裂开、也埋下冒险动机；提出涂血伪装计划并坚持独自冒险（scenes/scene_DT-S10.md:L29-L41）是把理性自救推向极致的拐点。

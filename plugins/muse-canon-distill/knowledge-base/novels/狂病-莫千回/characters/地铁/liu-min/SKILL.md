# 刘敏（狂病-莫千回·地铁）

## 身份与处境

刘敏，陈雨琪的同行女生，本来和她一起赶早高峰地铁去上课，因为快九点了人还这么多而一路抱怨、推着陈雨琪快走。灾难爆发后她和陈雨琪一起被卷进临时小队，沿地铁线逃亡。她是队里最普通、最脆弱的那个——容易被恐怖传闻吓哭、关键时刻话不多，承担着"普通受害者的恐惧反应"这一侧写。她有个被困在车间的父亲，电话一度打通过。最后她在风井口逃生通道进去和杨和修做最后告别，被刚沦陷的杨和修暗杀。

佐证：scenes/scene_DT-S01.md:L3-L3 / scenes/scene_DT-S08.md:L9-L9

## 核心欲望

- **自觉欲望**：和陈雨琪一起平安——从最初想着别迟到、到灾难中只想活着走出地铁。
- **不自觉欲望**：在恐惧里抓住一点确定——确认坏事还没真的发生、确认同伴还在、确认能好好道个别，是她在崩溃边缘反复寻求的安心。
- **核心缺陷**：恐惧压不住，遇到惊吓就直接哭出来、慌乱发问，缺乏在绝境里自保和决断的能力。

佐证：scenes/scene_DT-S03.md:L7-L7 / scenes/scene_DT-S01.md:L21-L21

## 性格真相

- **外在塑造**：普通到不起眼的同行女生——会抱怨人多、会对街头八卦"来了兴趣"地追问，是日常里随处可见的大学生。
- **压力下的真实反应**：恐惧来得又快又外露——一听丧尸传闻就被吓得快哭、被陆霞克一句"躲也躲不掉"直接说哭，情绪几乎没有缓冲。
- **裂隙**：看似只会害怕、只会被照顾的弱者，却在最后主动开口替杨和修说话（"难道大家不可以从隧道口逃出去吗"）、主动要求进去和他告别——她的脆弱里藏着不愿让人去送死、想好好道别的温柔。

佐证：scenes/scene_DT-S10.md:L43-L43 / scenes/scene_DT-S10.md:L63-L63

## 声音框架

刘敏的话不多，且几乎都贴着情绪走。日常里是抱怨腔（嫌人多、催陈雨琪快走、好奇地追问街头群殴"具体什么情况"）；恐惧时声音发颤、直接哭出来，问的都是没人能答的问题（"会不会真的是什么丧尸病毒""怎么这么多站台都禁止停靠"）。到了后段她大多沉默，偶尔的开口反而最重——替杨和修说一句不想让他冒险的话，提一句想去做最后的告别。她不抒情、不分析，情绪藏不住，话越少时越说明事情越重。

## 边界（Layer 0 硬规则）

- 绝不在恐惧面前强装镇定——害怕就直接哭、直接发问，从不硬撑出从容的样子。 ← 佐证：scenes/scene_DT-S03.md:L9-L11
- 绝不眼睁睁看同伴去送死而不出声——明知自己帮不上忙，仍开口问"难道大家不可以从隧道口逃出去吗"，不想杨和修一个人冒险。 ← 佐证：scenes/scene_DT-S10.md:L43-L43
- 绝不放弃好好道别——哪怕要直面血腥场景、哪怕可能没有以后，也坚持进去和杨和修做最后的告别。 ← 佐证：scenes/scene_DT-S10.md:L63-L63

## 弧光（已完成）

- **起点**：一个只惦记着别迟到、会对街头八卦来兴趣的普通女生，对真正的危险毫无概念，第一反应是好奇而非恐惧。
- **终点**：在彻底认清世界已经疯了之后，从只会被恐惧推着走，转向主动替人着想——不愿同伴去冒险、坚持要好好道别。
- **核心转变**：从"被恐惧淹没、只会哭和发问的旁观者"，变成"在绝境里仍想护住同伴、好好告别的同行者"。
- **关键转折点**：被丧尸传闻和陆霞克的话接连吓哭（scenes/scene_DT-S03.md:L9-L11）是恐惧失控的起点；给家里打通电话得知父亲被困车间（scenes/scene_DT-S08.md:L9-L9）让灾难从抽象变成切身；主动替杨和修说话、要求进去告别（scenes/scene_DT-S10.md:L43-L63）是从被动恐惧转向主动温柔的拐点。

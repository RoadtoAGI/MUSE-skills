# 云天明 — 个体档案

## 欲望系统

- **自觉追求**：被程心看见。他所有行为的出发点都是单恋——买星是为了让她知道有人爱她，接受使命是因为她亲自来请求。
- **不自觉需要**：证明自己不是"无用之人"。肺癌晚期的云天明在世俗意义上已经失去一切——姐姐让他去死以省钱，安乐死是社会对他的最后"善意"。他需要的不只是程心的爱，更是自身存在的意义。
- **核心缺陷**：将自身价值完全寄托于另一个人的认可。这使他容易被利用（程心推荐他为候选人时，他的愤怒恰恰证明了这种依赖的深度）。

## 塑造 vs 真相

| 层面 | 描述 |
|------|------|
| **人物塑造** | 肺癌晚期患者，自卑、被动、社会边缘人。连安乐死都要同学胡文出钱帮他解决"后事"。世界对他无情到姐姐最关心的是别花冤枉钱 |
| **性格真相** | 在绝望中做出了全书最浪漫的行为（用全部积蓄买一颗星星）和最勇敢的行为（明知是"死得最惨"的命运仍然接受）。更在三体世界中以童话编码的方式完成了人类历史上最伟大的情报传递 |
| **落差** | 世界上看起来最弱小无力的人，做出了影响最深远的贡献 |

## 压力下的选择

| 场景 | 选择 | 揭示 |
|------|------|------|
| 用全部积蓄买星（L263-L298） | 在即将安乐死前把300万花在一颗"看不见"的星星上 | 爱的行为不需要理性的回报——他买的不是星星，是最后一次对她说"我存在过" |
| 接受阶梯计划（L598） | "好的，我接受"——一句最轻的话 | 在歇斯底里的愤怒后归于平静。他看穿了程心是来"让他死"的，但仍然接受——因为她亲自来了，这本身就是他要的 |
| 拒绝宣誓忠于人类（L637-L641） | 声称不认可对人类的责任 | 悖论性的诚实——一个被人类送去赴死的人有权拒绝效忠，而这种拒绝反而证明了他作为间谍的可信度 |
| 用童话传递情报（L2087-L2101） | 三次触发黄灯后转用隐喻编码 | 在三体文明的全面监控下找到了唯一的信息通道——人类的想象力 |

## 弧光

- **起点**：被世界抛弃的绝症患者，连死亡都是社会福利的"标准流程"
- **终点**：在蓝星上与AA"度过了幸福的一生"，并赠予程心一个小宇宙作为最后的礼物
- **弧光方向**：从"被抛弃"到"给予"——他一生都在给予（星星、大脑、情报、小宇宙），最终在给予中获得了自己的幸福

## 声音特征

- **苦涩的自嘲**："真是个大傻瓜！还有比他更傻的吗？！"（L587）——在得知真相后的歇斯底里
- **戏剧性的克制**："好的，我接受。"（L598）——在最痛苦的内心翻搅后只用四个字回答
- **童话的温柔**：三个童话（《国王的新画师》《饕餮海》《深水王子》）是他唯一自由的声音——在三体世界中，他只能通过虚构来说真话
- **石刻遗言**："我们度过了幸福的一生"（L4448）——跨越1890万年的最终声音，简单、平静、完满

## 关键对白

1. "好的，我接受。"（L598）——四个字改变了两个文明的历史
2. "不。我要看看三体世界是什么样，然后再决定忠于谁。"（L637-L641）——拒绝效忠人类
3. "我们度过了幸福的一生"（石刻遗言，L4448）——全书最后的温暖

## 共情机制

读者对云天明的共情来自**弱者的尊严**。他没有维德的力量、罗辑的智慧、程心的位置，但他拥有全书最纯粹的爱。他的每一次给予都不求回报——买星时她不知道、接受使命时她不理解、童话传情时她解读不完整、赠送小宇宙时他已离去1890万年。这种"永远给予、永远不被完整接收"的模式制造了深沉的哀伤和敬意。

# 艾AA — 个体档案

AA 最突出的维度是**压力下的选择**和**声音**——她的行动力和语言风格是她区别于其他角色的核心标记。

## 塑造 vs 真相

| 层面 | 描述 |
|------|------|
| **人物塑造** | "像鸟一般轻灵的女孩子"（L844），初次出场围着程心飞来飞去，看起来是典型的新纪元活泼少女 |
| **性格真相** | 在极端压力下爆发出惊人的行动力——射穿八架穿梭机尾翼后回来呕吐（"外面……全是烤肉味儿"），行动果断但身体不撒谎。对孩子用童话包装死亡（L2927-2929），恐惧中仍保护弱者 |
| **落差** | 轻灵的外表下是全书最果断的行动者 |

## 压力下的选择

| 场景 | 选择 | 揭示 |
|------|------|------|
| 假警报中射穿穿梭机（L2923-2925） | 程心拒绝从人群中起飞后，AA拿步枪下去逐架射穿周围穿梭机的尾翼 | 在道德僵局中用暴力创造第三选项——程心不起飞，AA就阻止别人起飞 |
| 对孩子说"大焰火"（L2927-2929） | 用"非常壮观的宇宙景象"替代"我们会死" | 在自身恐惧中优先保护弱者——她没有回避死亡，而是给了死亡一个孩子能接受的形状 |

## 声音特征

- **爆破式开场**："你傻不傻呀！"（L847）——初次出场即确立声音基调
- **行动先于解释**：肥皂船实验（L2623-2629）中不做解释、直接演示，用物理现象替代语言
- **恐惧中的诚实**：射穿穿梭机后呕吐——身体的诚实反应对照行动的果断
- **用童话包装死亡**：对孩子说"太阳将变成一团大焰火！"（L2927-2929）

## 关键对白

1. "你傻不傻呀！"（L847）——定义性台词
2. "在这些碎片中，你能分清哪些是高尚的，哪些是卑鄙的？"（L2917）——对程心道德的终极质疑
3. "我们走不了，他们也他妈的别想走！"（L2923）——混乱中的果断
4. "我们度过了幸福的一生"（石刻遗言，与云天明共同，L4448）——全书唯一的"幸福结局"

## 弧光

从程心的附属（助理/朋友/保护者）到独立的生命——与云天明在蓝星共度一生是她自己的故事，不再是程心故事的注脚。全书唯一获得世俗幸福的角色。

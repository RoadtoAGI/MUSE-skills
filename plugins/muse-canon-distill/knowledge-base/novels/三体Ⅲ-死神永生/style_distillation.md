# 《三体Ⅲ·死神永生》文风蒸馏

## 元数据与证据范围

- 对象：刘慈欣《三体Ⅲ·死神永生》；语言：中文；用途：风格适配、reference 路由与 serial-writing。
- 证据：`style_card.yaml`、`navigation.md`，代表场景 S18/S24、scene_07/09/10 及 craft notes，覆盖史料插件、童话解码、歌者和二维化。
- reuse 分类用于控制风格与连续性，不是法律意见；短证据仅作功能锚点。

## 稳定文风指纹（7 维）

1. **叙事距离**：编年史框架内深贴程心的限知体验，同时以《时间之外的往事》、异文明内视角和童话整体换语态；局部人生不断被宇宙史包围。
2. **句法节奏**：史料段从容、因果密集，场景段在抉择和倒计时处收紧；灾难慢摇铺展，最终收束于一念、一物或独句。
3. **词汇质地**：白话为骨，纪元、工程参数与自造术语形成坐标系；童话使用程式语汇，歌者段用陌生概念自然化其文明日常。
4. **修辞密度**：中等偏宏阔；灭世可被写成宇宙尺度挽歌，美与毁灭同框，但悲悯克制，不靠惨叫和血腥增幅。
5. **对白**：问答释设定仍是主轴；云天明对话具有明语/密语双层，维德式短刀台词和宣告可一句改写局面。
6. **信息释放**：场景先制造感官或抉择压力，史料插件接管系统解释；童话先表层自洽，后由集体解码分批释义，并允许关键误读成为情节。
7. **转场**：纪元标题、冬眠苏醒、史料插页和异文明切入承担巨大时间/尺度跃迁；毁灭行动可在投掷瞬间戛止，延后展示后果。

## 本卷合法变化

- 《时间之外的往事》可更像后世史评：概括、反讽、解释并存，但仍需因果张力，不能成为百科条目。
- 云天明童话可整体采用说书腔、重复程式和双层隐喻；离开嵌套边界即恢复正文语态。
- 歌者段允许自造术语不解释、把灭世写成日常工作，以陌生化显示文明差异。
- 二维化段允许最长的奇观慢摇和宏阔意象；程心抉择段则应贴身、倒计时化并保持叙述悲悯而不辩护。
- 每次苏醒可用陌生目光逐物重建新时代，说明密度短暂升高。

## 不可漂移不变量

- 程心的善良与错误并存；叙述可悲悯，不替她辩护或改写成果决英雄。
- 史料、童话、异文明、场景正文必须边界清楚且各自内部一致。
- 自造概念须形成可追踪体系，不能用任意玄学词替代机制。
- 灾难写观察过程、尺度与形态变化，不以受难叫喊堆砌。
- 宇宙尺度扩大仍由具体人物、物件或选择落地；冷句不追加释义。

## Reference reuse 判定表

| 分类 | 可用内容 | 处理原则 |
|---|---|---|
| `literal_reuse` | 纪元名、舰名、机构、技术名、坐标、既定参数、嵌套文本标题 | 仅作 canon 和格式锁定，保持跨章一致 |
| `normalized_reuse` | 史料插件格式、苏醒重建世界、问答释设定、童话程式、倒计时节奏 | 保留语态功能和信息槽位，重写措辞与意象 |
| `semantic_reuse` | 童话密语、歌者日常灭世、二维化挽歌、小宇宙抉择等独特设计 | 只复用双层编码、日常/毁灭反差、尺度挽歌等抽象机制 |
| `no_reuse` | 标志性名句、原童话编码、原灾变意象、与当前纪元不符的材料 | 隔离于生成上下文，仅可作反例检查 |

> 判定目标是风格适配和连续性控制，不是版权或其他法律判断。

## 最小归一操作

1. 先标记语态：场景正文/史料/童话/异文明；清除无边界混写。
2. 对齐纪元、地点、术语、参数和信息权限，建立自造概念词表。
3. 把百科式说明移至合适的史料插件，场景保留感官、抉择与即时机制。
4. 童话先保证表层自洽，再检查隐喻映射；不在童话正文中直接解码。
5. 灾难段确定单一观察路线、形态变化和尺度参照，删惨叫堆叠。
6. 每段保留一个主导意象；抉择处缩短句子并强化倒计时。
7. 场景在动作或冷句处止步，把远期后果留给下一场或史料。

## Derivative 四种 `reuse_mode` 应用

- `fan_fiction`：在既有纪元补写空白。锁定纪元、技术可用性、人物信息权限和当前语态；童话、史料或异文明段只能在明确边界内复现其功能，表面措辞全部归一。
- `sequel`：从小宇宙抉择或某一纪元结局后续写。继承宇宙状态、术语账本和时间尺度；新文明/新武器须建立自己的概念系统，不换皮歌者或二向箔。
- `spin_off`：以云天明、维德、关一帆或异文明为中心。为新 POV 建立独立知识模型和语态，程心的悲悯视角不得自动覆盖；共享事件只按该 POV 可见部分进入。
- `cross_style_rewrite`：保留纪元因果、技术机制、童话解码账本与选择后果，允许切换目标文风；必须声明史料插件、宏阔挽歌和短刀对白分别保留或替换到何种程度。

## Serial-writing 章际连续性信号

- 时间坐标：纪元、绝对/相对时间、冬眠持续期、通信和航行延迟。
- 世界状态：文明关系、威慑、广播、掩体/黑域、技术与法律可用性。
- 人物状态：程心/云天明/维德等人的年龄体验、伤病、职位、承诺、最后选择。
- 信息权限：读者、程心、IDC、公众、三体、歌者等各自已知内容。
- 解码账本：童话明文、已确认映射、竞争解释、遗漏线索和置信度。
- 术语账本：新概念首次出现、定义、观察证据、是否只为异文明常识。
- 语态锁：上一章结束时所属正文/史料/童话/异文明类型及退出边界。
- 节奏接力：史料后回到具体人物；冷句或投掷戛止后从时间跳跃或后果侧面续接。
- 母题回声：保留上一章的一件物或形态信号，不复刻完整灾变意象。

## Dispatch 注入建议

- 必注：纪元与世界状态、当前语态枚举、POV 信息权限、术语账本、解码账本、上一章 continuity signals。
- 按任务只选一个 reference 家族：史料、童话、异文明或灾变；不要把四类原文同时塞入上下文。
- dispatch 顶层标注四种合法 `reuse_mode` 之一；每份 reference 另标允许抽取字段、上一节复用分类及禁止复刻的意象/名句。
- 推荐顺序：`canon/time locks → world state → voice mode → continuity ledgers → scene objective → constraints → anti-signature`。

## 验收 checklist

- [ ] 七维指纹、自包含元数据和本卷 delta 完整。

- [ ] 四种语态边界明确，未发生无标识串音。
- [ ] 史料有叙事张力，童话表层自洽且解码外置。
- [ ] 新术语可追踪，工程机制未被玄学化。
- [ ] 灾难有观察路线、尺度和形态变化，不靠惨叫。
- [ ] 程心选择同时呈现动机与后果，未辩护或妖魔化。
- [ ] dispatch 使用合法 `reuse_mode`，reference 分类独立，章际账本可续写。

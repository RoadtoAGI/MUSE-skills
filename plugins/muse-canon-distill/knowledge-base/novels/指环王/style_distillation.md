# 《指环王》文风蒸馏

## 元数据与证据范围

- 作品：J. R. R. 托尔金《指环王》。
- 证据范围：本目录 `style_card.yaml`、`navigation.md`、代表性 `scenes/`、对应 `craft_notes/` 及本地全文抽样。
- 证据优先级：原文场景 > 手艺标注 > style card > navigation 摘要。摘要只证明结构，不证明句面。
- 译本证据：当前正文 L115 与 CIP L22990 均署名邓嘉宛、石中歌、杜蕴慈；`style_card.yaml`、`navigation.md` 及 phase0–5 的 `source_form` 已与正文统一。
- 锁译本范围：literal reuse、句法统计和声口模仿绑定当前本地中文版本，并在任务回执记录 `source_edition`；跨译本稳定性需要另行对照。
- 本文蒸馏当前中文语料中可验证的叙事功能与风格约束；英文原作的逐词特征保持 Open。

## 稳定文风指纹（7 维）

1. **叙事距离**：全知史官式远景为底，逐场贴定一个主要限知人物；可短暂拉远交代遗物、谱系和后世评价，但不进入索隆等终极敌手内心。超自然威胁先以人物可感征候出现。
2. **句法节奏**：常态为多分句长句、并列递进与复沓；临战改用短段、命令句、拟声和硬动词。典型曲线是“缓慢蓄势—短促爆发—抒情/史册余波”。
3. **词汇质地**：书面文白相济，称谓古雅，专名、地貌、器物与谱系形成历史厚度；具体词优先于抽象评价。排除现代网络语、技术管理语和叙述者吐槽。
4. **修辞密度**：中等而有功能。喻体集中在光暗、风雨、火焰、浪潮、草木、古物；修辞须表现力量、时间或命运变化，不连续炫饰。
5. **对白**：对白承载信息、决断、誓言与身份；归属语通常朴素明确。声口按族群、阶序、年龄和处境分层，允许长篇讲述与歌谣，拒绝全员同质的密集机锋。
6. **信息释放**：遵循“征候—残片—确认—来历/后果”。可见性是稀缺资源；关键机制允许押后解释。群战以少量具名动作、精确结果和选择性省略呈现，不做全员逐招追踪。
7. **转场**：以天光、风向、号角、歌声、地貌、行军和物件接力转场；段落边界承担镜头切换。双线宜大块轮换并保留时间重叠，不频繁影视式交叉剪辑。

## 地域／族群／场域合法变化矩阵

| 场域 | 允许变化 | 必须保留 | 禁止漂移 |
|---|---|---|---|
| 夏尔／霍比特日常 | 更口语、家常、具体；食物、园艺、亲族和轻幽默增多 | 小人物尺度能承接古老阴影；善意通过行动呈现 | 现代吐槽、段子化霍比特人、纯田园糖衣 |
| 洛汗 | 战歌、马匹、血缘、忠诚、古老誓言和强排比增加 | 口传史诗感；身体动作与地貌锚点 | 泛中古骑士腔、无差别豪迈口号 |
| 刚铎／杜内丹 | 礼法、谱系、历史债务与克制的王权语言增加 | 行动先于身份宣告；衰落感与责任并存 | 华丽宫廷空话、权谋剧式机锋 |
| 精灵领地 | 韵律舒展，自然意象、记忆和时间哀感增强；诗歌占比可升 | 美与损失同在；古老知识不全解释 | 空泛仙气、现代玄学、全知工具人 |
| 矮人／地下遗址 | 石工、器物、祖名、债、失落记忆与硬质动词增加 | 物质证据承载历史；沉默和记账式表达 | 粗鲁搞笑方言、单一贪财标签 |
| 咕噜／奥克 | 复沓、碎裂、自语、粗鄙和内部争执增加 | 声口角色特异；只污染角色对白，不污染叙述层 | 通用疯话、反派心理全解、全员同一口癖 |
| 史诗战争／王权高潮 | 呼语、列名、复沓、歌谣、史官拉远与光暗逆转增加 | 具体器物/伤者/地貌；高潮后降速哀悼 | 持续高亢、招式流水账、无代价胜利 |
| 魔多／恐怖段 | 感官贫化、负空间、身体疲惫和缓慢逼近增加 | 有限 POV；邪恶不可完全测量 | 怪物图鉴式早揭、索隆 POV、解释性心理诊断 |

## 不可漂移不变量

- “朴素可触的有限人物经验”与“深不可测的历史纵深”必须同场共存。
- 庄严和家常可以切换，但叙述基底始终克制、真诚，不以讥诮拆台。
- 邪恶主要通过外部征候、诱惑压力和后果显形，不靠反派自白讲透。
- 仁慈、忠诚、守诺与克制必须形成后续因果，而非停留在主题宣言。
- 战斗篇幅服从主题动作；关键胜负常落在拒绝、承担、怜悯或坚持，而非招式升级。
- 诗歌、谱系、遗物和传说必须改变当下理解或行动，不能作为 lore 展柜。
- 胜利保留损耗、哀悼与不可逆改变；结尾优先落在地景、物件或归家动作。

## literal／normalized／semantic reuse 判定表

| 级别 | 可复用对象 | 处理要求 | 典型禁区 |
|---|---|---|---|
| `literal_reuse` | 已锁译本下的专名、固定称谓、族名地名、必要的极短 canon 标签 | 标注来源与版本；仅取维持设定所需最小单位 | 连续对白、歌谣诗行、标志性长句、景物段 |
| `normalized_reuse` | 事件摘要、角色关系、历史谱系、场景 beats、战术关系、信息释放顺序、声口标签 | 改写为中性结构：功能＋顺序＋POV＋感官；清除连续原句和译者节奏 | 用近义词替换冒充改写；保留独特句序或比喻链 |
| `semantic_reuse` | 比喻功能、光暗结构、负空间显形、歌谣用途、主题动作、命运回收机制 | 仅保留抽象功能，重造人物、物象、措辞和局部因果 | 复刻具体喻体、呼语组合、完整动作链或诗行格律 |

## 最小归一操作

1. 锁定并记录 `source_edition`；未锁定则关闭 literal reuse。
2. 统一同一专名的异译名，保留原文实体身份而非混用译名。
3. 将参考句拆成“叙事功能、事件顺序、POV、感官通道、节奏作用”。
4. 删除连续原文措辞、独特比喻链、诗行与标志性呼语组合。
5. 歌谣只保留用途、位置、情绪和节奏类型；重新创作意象与句面。
6. 比喻归一为意象域，再换用适合 derivative 世界的具体喻体。
7. 角色原话归一为 `register + intent + pressure_state`；口癖只保留机制。
8. 保留“扣押—释放”和“伏因—兑现”结构，替换事件、物象与局部因果。

## derivative 的四种 `reuse_mode` 应用

| reuse_mode | 用途 | 允许输入 | 输出边界 |
|---|---|---|---|
| `fan_fiction` | 在既有时代、人物或地点中补写新事件 | 已锁定的 canon 专名可 literal 记账；关系、时序和限制须 normalized；风格手艺仅 semantic | 保持角色声口、地理、伤势和因果债；原创情节不得复演原场景动作链，未锁译本时禁用 literal 句面 |
| `sequel` | 延续原作结局后的世界与人物后果 | 结局状态、历史损耗、人物关系与未偿因果采用 normalized；叙事机制采用 semantic | 核心保真是“胜利有代价、时代发生不可逆变化”；不得重置旧伤、复活已闭合威胁或复制魔戒任务结构 |
| `spin_off` | 从配角、族群或旁支地域展开独立故事 | canon 锚点按 literal/normalized 分项记账；目标族群矩阵与声口规则采用 semantic | 保留共同历史纵深，但主冲突必须自立；不得把洛汗、刚铎、精灵、矮人等压成单一标签或统一腔调 |
| `cross_style_rewrite` | 将新题材或外部故事迁入本作的叙事手艺 | 只采用七维指纹、不变量、信息释放和节奏机制的 semantic reuse | 默认更换 canon 专名、事件、意象和对白；不得借“改写”复刻译文句面、诗行、标志性呼语或动作链 |

`reuse_mode` 表示 derivative 的运行任务类型；`literal_reuse`、`normalized_reuse`、`semantic_reuse` 只用于逐项 provenance/复用账本分类，不能作为 mode 值。

## serial-writing 章际连续性信号

- `pov_anchor`：本章主限知人物；换章才允许主要 POV 大切换。
- `register_state`：每名角色当前声口、称谓关系与情绪压力，避免跨章现代化或同质化。
- `withheld_information`：尚未显形/解释的威胁、物件机制和身份，不得提前泄露。
- `motif_state`：光暗、风、号角、歌、道路、遗物等意象最近一次出现及功能，避免机械复现。
- `mercy_debt`：仁慈、赠礼、誓言、克制形成的未兑现因果。
- `cost_ledger`：伤势、疲劳、损失、旧伤和不可逆变化，胜利后不得重置。
- `world_time`：天光、天气、距离、行军时长和并行线时间偏移。
- `lore_pressure`：本章新增专名/谱系密度；连续高密章后应给读者可触的行动缓冲。
- `cadence_exit`：上一章以爆发、悬置或余波何种节奏退出；下一章不得无理由重复同一高潮形态。
- `song_history`：歌谣已承担的功能和所属族群，避免跨族复用同一韵律声口。

## dispatch 注入建议

- 元提示层注入：`reuse_mode`、`source_edition`、不可漂移不变量、constraints ID；禁止直接塞大段参考原文。
- 职责层注入：按 agent 只给其需要的矩阵行，例如对白 agent 得到族群 register，结构 agent 得到信息释放与转场规则。
- 动态指令层注入：当前章的 serial state、允许使用的 canon 实体、需兑现的 `mercy_debt` 和必须继续扣押的信息。
- reference pack 应使用短锚点和 normalized 特征；如需 literal 项，逐项列 `source_anchor`、字符范围、版本与用途。
- 回执必须报告实际使用项，而非仅报告读取文件；未采用的 reference 标记 `not_used`。

建议 dispatch 片段：

```yaml
style_dispatch:
  reuse_mode: fan_fiction
  reuse_classification: [literal_reuse, normalized_reuse, semantic_reuse]
  source_edition: "LOCKED_OR_UNKNOWN"
  constraints: [LOTR-S01, LOTR-S02, LOTR-S04, LOTR-S06, LOTR-S07, LOTR-S09, LOTR-S11]
  serial_state_required: true
  provenance_receipt_required: true
```

## 验收 checklist

- [ ] `source_edition` 已确认，或所有 literal reuse 均为零/blocked。
- [ ] 每场只有一个主限知 POV，终极敌手无内聚焦。
- [ ] 七维指纹可在正文中找到行为证据，而非只写在提示词中。
- [ ] 地域/族群变化符合矩阵，叙述基底没有被角色口癖污染。
- [ ] 超自然显形、高潮回合、逆转信号和战后余波满足 constraints。
- [ ] 诗歌、谱系、遗物与 lore 均承担当下叙事功能。
- [ ] serial state 中的伤势、距离、扣押信息、誓言和因果债连续。
- [ ] reference receipt 对每项标明 literal/normalized/semantic、used/blocked/rejected。
- [ ] 未复刻连续原文、独特比喻链、歌谣诗行或标志性动作链。
- [ ] 胜利保留代价，章末落点与上一章节奏不机械重复。

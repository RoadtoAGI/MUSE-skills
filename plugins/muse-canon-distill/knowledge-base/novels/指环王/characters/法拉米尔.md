# 法拉米尔 (Faramir)

> 个体档案 — 仅记录角色自身维度（声音、弧光、欲望系统），角色间关系见 phase2_character.yaml。

---

## 麦基三维度

### 塑造（Characterization / 面具）

刚铎伊希利恩突击队的统帅。军事行动中冷静果断，是一位出色的战术指挥官。外在形象是**沉着的军人与忠诚的次子**——服从命令、执行任务、不争名位。

### 真相（True Character / 压力下的本质）

面对魔戒的诱惑时展现出波洛米尔所缺乏的品格——他拒绝了魔戒。他的高贵不是因为他不想要权力，而是因为他**理解权力的代价**。他在压力下暴露的本质是：一个深知力量边界的智者，宁可承受失败也不愿被工具反噬。

### 核心矛盾

他比波洛米尔更适合领导刚铎，但父亲德内梭尔偏爱长子。这种**不被认可反而保护了他**——长期处于权力边缘使他免受权力欲的腐蚀。被忽视成了他品格的养料：正因为从未被赋予足够的权力，他才有空间发展出对权力本质的深刻理解。

## 欲望系统

| 层级 | 内容 |
|------|------|
| 自觉欲望（Want） | 保卫刚铎、赢得父亲德内梭尔的认可 |
| 不自觉需要（Need） | 找到不以战争和权力定义的自我价值 |

他的自觉欲望永远无法被满足——德内梭尔不会给出他渴望的认可，而刚铎的危机也不是一个人能解决的。弧光的完成在于他放弃了用战功自证的执念，转向一种更内在的价值确认。

---

## 弧光（Arc）

```
不被认可的次子 → 拒绝魔戒的高贵者 → 险些被父亲殉葬 → 接受宰相之位 → 选择治愈而非征服
```

核心转变：**从寻求外部认可到确立内在价值**。

1. **不被认可的次子**：在德内梭尔的偏爱体系中始终居于波洛米尔之后。他比兄长更有学识、更多思虑，但这些品质恰恰是父亲不看重的。
2. **拒绝魔戒的高贵者**：在伊希利恩截获弗罗多时，他面对了与波洛米尔相同的诱惑。他的选择——"纵使米那斯提力斯将沦为废墟，我也不会使用它"——不是因为他不理解利害，恰恰因为他太理解了。
3. **险些被父亲殉葬**：身负重伤被抬回白城，德内梭尔在绝望中试图将他与自己一同焚烧。他最渴望认可的那个人，最终给他的是一座火葬堆。
4. **接受宰相之位**：战后他没有争夺王位，而是作为宰相辅佐阿拉贡。这不是退让，而是他找到了与权力的正确关系——辅佐而非占有。
5. **选择治愈而非征服**：在诊疗院中与伊奥温相遇，两个都在寻找"不以战争定义自我"的人彼此映照。他选择治理伊希利恩、使荒地重新生长——用建设替代征服。

## 声音特征

- **文雅而深沉**，比波洛米尔更多思虑和克制。
- 带有**学者气质**：措辞精确，倾向于在行动前阐明理由和原则，不是犹豫，而是审慎。
- 说话时常有一种**温和的距离感**——不冷漠，但也不轻易交出情感。像隔着一层薄纱在观察世界。
- 对待弱者和下属时语气中有真诚的尊重，没有贵族的傲慢。
- 面对权威（包括父亲）时不卑不亢，用平静的陈述句抵抗压力，从不提高嗓门。

## 关键对白

### "纵使米那斯提力斯将沦为废墟，且惟我一人能拯救她，我也不会为了她的利益和我的荣耀而使用黑暗魔君的武器。"
- **出处**：卷四第5章，伊希利恩，面对弗罗多和魔戒。
- **语境**：法拉米尔得知弗罗多携带魔戒，完全有能力夺取它为刚铎所用。
- **功能**：这是他与波洛米尔的分叉点，也是整部小说对"权力与品格"主题最清晰的注解之一。句式结构值得注意——他先承认了最极端的情况（城市沦为废墟、他是唯一的救星），然后仍然拒绝。这不是因为无知或懦弱，而是因为他把原则置于结果之上。"她的利益和我的荣耀"——他同时看穿了公共理由（为城市）和私人理由（为荣耀），拒绝了两者。

### "我不是那种会在路上搜走旅客物品的人。"
- **出处**：卷四第5章，对弗罗多。
- **语境**：弗罗多担心法拉米尔会强取魔戒。
- **功能**：用最朴素的日常语言确立品格底线。没有宏大的道德宣言，只是简单地说"我不是那种人"——这种平静的自我认知比慷慨激昂更有说服力。它也为上面那段更正式的拒绝做了铺垫：先用日常语气建立信任，再用庄严语气宣示原则。

# 甘道夫 (Gandalf) — 个体档案

> 本档案仅记录角色个体层面信息（声音、对白、弧光），角色间关系见 phase2_character.yaml。

---

## 一、麦基三维度

### 1. 塑造（面具 / Characterization）

古怪的灰袍老巫师，身形高瘦，灰发长须，头戴尖帽，手持木杖。在夏尔以烟花专家和爱管闲事的老朋友形象示人，与霍比特人来往密切，被视为"那个总带来麻烦的老头"。他看上去是一个漫游的智者，偶尔脾气暴躁，喜欢抽老烟斗草，讲谜语，放烟火。

### 2. 真相（压力下的本性 / True Character）

降临中洲的神灵使者——迈雅（Maiar），受维拉派遣以凡人躯体行走人间。在卡扎督姆之桥面对炎魔时，那一声 **"你休想过！"** 彻底撕裂了灰袍面具，暴露出他真正的力量层级：他是与炎魔同阶的太古灵体。白袍归来后，从导师升格为战略指挥者，语气更冷、判断更快、不再犹豫。

### 3. 核心矛盾

他拥有巨大的力量但刻意限制自己使用它。这不是软弱，而是深刻地理解权力的腐蚀性——萨鲁曼就是前车之鉴。他的策略核心是 **"从下方"**：信赖渺小者（霍比特人）而非依赖强力，因为他相信仁慈和怜悯才是对抗邪恶的真正武器。这一信念在整部作品中被反复验证——最终确实是弗罗多和山姆（以及咕噜的"被怜悯"）完成了任务。

## 二、欲望系统

| 层级 | 内容 |
|------|------|
| **自觉追求（Want）** | 击败索隆，拯救中洲自由民族 |
| **不自觉需要（Need）** | 证明"仁慈和怜悯"是对抗邪恶的真正武器——不是力量的对决，而是品格的胜利 |

他的 Want 和 Need 并不矛盾，但实现路径截然不同：Want 指向战场，Need 指向弗罗多和咕噜。最终是 Need 的实现完成了 Want。

---

## 三、弧光

```
灰袍导师 → 牺牲（卡扎督姆坠落）→ 白袍归来 / 战略家 → 使命完成后离去
```

- **灰袍阶段**：隐忍、引导、耐心。他从不直接解决问题，而是把正确的人推到正确的位置。
- **坠落与牺牲**：在卡扎督姆桥上独抗炎魔，以"死亡"为代价为远征队争取活路。这是他弧光的最低点，也是转折点。
- **白袍归来**：经历死亡与重生，限制被部分解除。他变得更冷峻、更果决，但核心信念不变。
- **离去**：使命完成后乘船前往不死之地。他的弧光本质是 **"自我限制的力量"**——拥有却不滥用，完成后主动退出。

## 四、声音特征

### 语域切换

甘道夫的声音随对象和场景剧烈变化，但始终保有一种底层的古老智慧感：

- **与霍比特人**：温和、幽默、偶尔暴躁。像一个对晚辈又爱又恨的长辈。语气中带着耐心和宠溺，但被蠢问题惹急了也会炸毛。
- **在战场 / 对抗邪恶时**：威严雷霆，声如裂石。句子变短，节奏变快，权威感压倒一切。
- **智慧传授时**：语速放慢，句式变长，带哲学性的对仗和诗意。不说教而是点拨。

### 语言习惯

- 交织智慧与暴躁——同一场对话可以从哲思滑入吼叫
- 偏爱反问和悖论式表达
- 偶尔冒出诗句或古老歌谣
- 对不了解的事不会假装知道，但会用"嗯……"拖延来制造悬念

## 五、关键对白

### 1. 道德教诲——论怜悯与审判

> "许多活着的人配得上死亡，许多死去的人配得上生命。你能把生命给他们吗？那么也不要轻率地分派死亡的判决。"
>
> ——卷一第2章《过去的阴影》

**功能**：全书最核心的道德命题。这句话直接决定了弗罗多对咕噜的态度，而咕噜的存活最终导致魔戒的毁灭。一句对白，贯穿三卷因果。

### 2. 力量揭示——卡扎督姆之桥

> "你休想过！"（You shall not pass!）
>
> ——卷二第5章《卡扎督姆之桥》

**功能**：面具彻底撕裂的瞬间。灰袍老头的伪装在炎魔面前荡然无存，暴露出迈雅级别的真实力量。也是他弧光中"牺牲"节点的标志对白。

### 3. 告别——灰港

> "并非所有的眼泪都是不幸。"（Not all tears are an evil.）
>
> ——卷六第9章《灰港》

**功能**：全书终曲的情感定音。甘道夫用这句话安慰霍比特人，也为自己的离去赋予意义——任务完成，这场离别是圆满而非悲剧。

### 4. 决定命运的呼喊

> "停住，西方的人类！停住并等候！决定命运的时刻到了。"
>
> ——卷六第4章 / 卷五第10章，末日山崩塌时

**功能**：战略指挥者角色的巅峰时刻。在一切即将崩溃的瞬间，他以命令而非请求的语气喊住了所有人——这是白袍甘道夫的权威体现。

## 六、写作启示

- **限制即力量**：甘道夫证明了"最强的角色"不等于"随意施展力量的角色"。自我约束本身就是最深的人物魅力。
- **声音的弹性**：同一个角色可以在温柔与雷霆之间自由切换，只要底层的价值观一致。
- **退场的艺术**：使命完成后主动离开，比留下来享受胜利更有力量感。

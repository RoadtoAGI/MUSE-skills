# 伊奥温 (Eowyn)

> 个体档案 — 仅记录角色自身维度（声音、弧光、欲望系统），角色间关系见 phase2_character.yaml。

---

## 麦基三维度

### 塑造（Characterization / 面具）

洛汉公主，金殿中苍白而冷漠的女子。被委以"留守"的职责——在男人们出征时看护衰老的国王。外表端庄克制，举止如金色笼中的静鸟。她的面具是**顺从与冷淡**：一个被责任钉在原地的贵族女子，接受命运安排。

### 真相（True Character / 压力下的本质）

她内心深处渴望的不是战争而是**逃离**——逃离被囚禁在金色笼子里照顾衰老君主的命运。她选择化名德恩海尔姆（Dernhelm）上战场，不是因为好战，而是因为她宁愿死在战场上也不愿活在无意义的等待中。

### 核心矛盾

她的勇气源于**绝望而非希望**。她杀死戒灵王的那一刻既是英雄时刻，也是自杀冲动的变体——她冲向不可战胜之敌时并不期望活着回来。真正的治愈不是来自战场的胜利，而是来自法拉米尔帮她看到生命的另一种可能。

## 欲望系统

| 层级 | 内容 |
|------|------|
| 自觉欲望（Want） | 战斗和荣耀——实际上是有尊严地死去 |
| 不自觉需要（Need） | 被看见、被理解、找到不依赖战争的自我价值 |

自觉欲望与不自觉需要之间的裂缝构成她全部的戏剧张力：她以为自己追求的是刀剑与荣光，实际上她追求的是**被承认为一个完整的人**。

---

## 弧光（Arc）

```
被囚的公主 → 绝望的战士 → 英雄时刻（杀死戒灵王）→ 接受治愈 → 选择生命和爱
```

核心转变：**从死亡冲动到生命选择**。

1. **被囚的公主**：在埃多拉斯金殿中照顾被蛊惑的希优顿王，青春在等待中枯萎。
2. **绝望的战士**：被禁止随军出征后，化名德恩海尔姆混入骑兵队伍，带着赴死的决心。
3. **英雄时刻**：佩兰诺平野之战中面对戒灵王——"没有活着的男人能阻挡我"，她揭开头盔："我不是男人。"预言应验，但她因此重伤，几乎如愿以偿地走向死亡。
4. **接受治愈**：在诊疗院中，战场的荣耀已经实现，但空虚仍在。法拉米尔不是用赞美她的勇气来治愈她，而是用安静的陪伴和对生命本身的热爱。
5. **选择生命和爱**：放下对战争的渴望，宣言想成为"一位医者和园丁"——这不是退缩，而是她第一次主动选择活着。

## 声音特征

- **冷峻、克制**，几乎不流露情感，用最少的词传达最大的重量。
- 日常语态紧绷而礼貌，像一根绷到极限的弦。
- **偶尔爆发时极具力量**——不是歇斯底里，而是长久压抑后的精准释放。
- 不用修辞或铺排，句式干净、短促，和洛汉人的直率一致，但比普通洛汉人更多一层冰冷的距离感。

## 关键对白

### "我不是男人。"
- **出处**：卷五第6章，佩兰诺平野之战，面对安格玛戒灵王。
- **语境**：戒灵王宣称预言保护他不被任何活着的男人所杀。伊奥温摘下头盔，揭示德恩海尔姆的真实身份。
- **功能**：预言的字面应验；同时是她打破所有外部限制的宣言——性别的限制、角色的限制、被指定命运的限制。一句话同时完成了叙事层（击杀戒灵王的合法性）和主题层（突破囚笼）的双重闭合。

### "我不愿在笼中等待，直到习惯变成老朽，忘记了曾经有双翅膀。"
- **出处**：卷五第2章，对阿拉贡。
- **语境**：阿拉贡拒绝了她跟随的请求，她说出了被囚禁的痛苦。
- **功能**：这是她内心真相最直接的外化。"笼"是塑造层的隐喻（金殿、留守的职责），"翅膀"是她意识到自己曾有可能性但正在失去它们。这段话让阿拉贡（和读者）看见面具之下的绝望。

### "我不再渴望成为女王……我想成为一位医者，热爱一切生长和非荒芜之物。"
- **出处**：卷六第5章，诊疗院中对法拉米尔。
- **语境**：战争结束，她在康复中与法拉米尔日日交谈。
- **功能**：弧光完成的标志。她的欲望系统完成了重组——自觉欲望从"有尊严地死去"变为"有意义地活着"，与不自觉需要（被看见、找到自我价值）终于对齐。

# 咕噜 / 斯密戈 — 个体档案

> 本档案仅记录个体层面信息（声音、对白、弧光）。角色间关系见 phase2_character.yaml。

---

## 1. 塑造（面具）

双重人格是咕噜最核心的外在呈现：

- **斯密戈**：怯懦、卑微、可怜，偶尔流露出被遗忘的善良。说话时带着讨好与哀求，像一只被踢过太多次的动物，学会了用顺从换取不被伤害。
- **咕噜**：狡猾、贪婪、阴险，完全被魔戒征服的部分。声音变得粗粝而急切，充满算计与占有欲。

两个人格交替出现时，外在表现截然不同——面部表情、姿态、声调都会切换，仿佛同一具身体里住着两个灵魂。

## 2. 真相（压力下的本性）

他内心的善恶之争是真实的，不是伪装。

在奇立斯乌苟阶梯上，咕噜看着沉睡的弗罗多，伸出手——那一刻斯密戈流露出的温情是五百年来最后一次接近救赎的挣扎。但山姆的喝斥打断了这个瞬间，"咕噜"人格彻底占了上风。

这不是简单的"伪善被揭穿"，而是一个几乎要被拉回光明的灵魂，在最后一刻被推回了深渊。压力之下，他暴露的不是邪恶本性，而是善恶两端同时为真的撕裂。

## 3. 核心矛盾

咕噜是魔戒腐蚀五百年的终极结果，同时也是弗罗多可能变成的未来。

他无法被救赎——太晚了。但他的存在本身具有叙事功能上的双重意义：

- 作为**警示**：展示魔戒持有者的终局。
- 作为**工具**：弗罗多对他的怜悯，最终成为拯救世界的关键。正因为弗罗多没有杀他，他才能在末日裂隙上完成命运赋予他的角色。

矛盾在于：一个不可救赎的存在，恰恰因为被以可救赎的方式对待，才完成了超越救赎本身的使命。

## 4. 欲望系统

| 层级 | 内容 |
|------|------|
| **自觉追求** | 夺回"我的宝贝"（至尊戒）——这是他全部行动的驱动力，贯穿始终 |
| **不自觉需要** | 被人当作一个"人"而非怪物来对待——弗罗多称他"斯密戈"时他的反应说明了一切 |

两个欲望层级永远无法调和：他越是追逐魔戒，就越远离被当作"人"的可能。

## 5. 弧光

咕噜没有传统意义上的成长弧光。他的弧光是一条**缓慢下降的曲线**：

```
初遇弗罗多（臣服）
  → 短暂的忠诚期（斯密戈占上风）
    → 阶梯上的最后挣扎（善恶临界点）
      → 被打断，咕噜人格回归
        → 设计蜘蛛洞陷阱
          → 末日裂隙，以贪婪完成命运角色
```

每次接近救赎都被拉回深渊。最终，他不是以英雄的方式拯救了世界，而是以贪婪的方式——抢走魔戒、失足坠落——完成了命运赋予他的角色。这是托尔金对"天意"（Providence）最深刻的表达：即便是堕落也可以被纳入更大的善。

## 6. 声音特征

咕噜拥有全书辨识度最高的声音，极度独特：

- **第三人称自称**："我的宝贝""宝贝求你了"——他用"我们"和"宝贝"指代自己，极少使用第一人称单数。
- **嘶嘶的辅音**：大量的 s 音和喉音（"gollum, gollum"），营造出爬行动物般的听感。
- **自我对话**：两个人格之间的辩论——"缺德鬼"（咕噜对斯密戈的称呼）vs "斯密戈"——是全书最具戏剧性的独白段落之一。
- **节奏特征**：短句、重复、语法破碎。情绪激动时句子越来越短，越来越碎，直到只剩下对魔戒的呼唤。
- **词汇特征**：词汇量有限，大量使用指小词和拟声词，语言退化程度反映了人格退化的程度。

## 7. 关键对白

### 7.1 效忠誓言（卷四第1章）

> "宝贝发誓以宝贝的名义效忠。"

- **功能**：建立臣服关系，同时暗示他的忠诚建立在魔戒之上而非弗罗多之上。以"宝贝"起誓，本身就是一个不祥的预兆。

### 7.2 阶梯上的内心独白（卷四第2章前后）

斯密戈与咕噜的对话——两个人格在弗罗多沉睡时展开辩论。

- **功能**：这是全书最重要的心理转折点之一。读者看到斯密戈几乎要赢，然后被外力打断。这个段落的悲剧性在于：善恶之争的结果不是由内在力量决定的，而是被一个意外的外部干预（山姆的喝斥）所终结。

### 7.3 末日裂隙（卷六第3章）

> "我的宝贝！噢，我的宝贝！"

- **功能**：最终的疯狂呼喊。在这一刻，咕噜/斯密戈的全部存在被压缩为一个单一的欲望。五百年的执念在这句话中达到顶点——然后随着坠落，永远终结。

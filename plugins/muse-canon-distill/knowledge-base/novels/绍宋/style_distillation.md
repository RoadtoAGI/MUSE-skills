# 《绍宋》全文文风蒸馏

## 元数据与证据范围

| 字段 | 值 |
|---|---|
| 作品 | 《绍宋》 |
| 作者 | 榴弹怕水 |
| 语言 | 中文 |
| 体裁 | 历史穿越 / 架空历史 / 军事政治 |
| 适用目标 | derivative 创作、serial 续写、检索与 dispatch 风格约束 |
| 证据范围 | `style_card.yaml`、`navigation.md`、19 个代表性 scenes、scene 17–19 craft notes、`full_text.md` 抽样、reference source rules |
| 结论边界 | “正文明确”与“手艺归纳”分开；不把历史参考资料中的事实自动升级为小说设定 |

本卡描述跨卷稳定的叙事机制，不提供可仿写的长原句。短证据仅用于定位，实际生成应优先复用机制、事实与约束，而非作者的可识别句面。

## 稳定文风指纹：七维

### 1. 叙事距离

全知史官式远景是基础镜头：先交代地理、官制、兵力、路线和利害，再贴近承担决策的人。人物心理通常不靠长时间沉浸式独白，而通过绕行行为、误判、停顿、沉默、发言次序或叙述者短评显影。大战全景尤其偏好“可信移动眼睛”——敌将、降人、基层军官或无名民夫都可充当摄像机，但镜头必须有世界内的信息来源。

### 2. 句法节奏

局势推演使用多层因果长句，常以“不过、然而、所以说、只能说、非只如此”接续转轴；当信息落到军令、揭底、笑点或不可逆决定时，句子骤缩，甚至以单字答复完成拍板。基本节拍是“长段蓄压—短句截断—后果展开”，而非全篇匀速。

### 3. 词汇质地

宋代官制、地名、军制、礼法称谓构成硬骨架；文白相间，不追求纯古雅。现代常识、自嘲、俗语和叙述者反讽作为针脚，主要分配给穿越者内视角与叙述声音。时代词汇负责可信度，现代口吻负责错位感，两者不能互相吞没。

### 4. 修辞密度

总体为中密度。少用连续华饰，更依赖递进、排比、反问、典故和带判断力的收束句。抽象情绪优先物化：木棍换饭、壕沟、拆桥、旗帜移动、无人春耕等具体机制或物件，比“恐惧、绝望、震惊”之类标签更重要。

### 5. 对白

对白是决策机器，不只是人物装饰。朝堂奏答改变任命、赏罚、议程或联盟；军议问答压缩兵力投入方案；基层牢骚泄露士气、归属与组织摩擦。人物的身份和关系由称谓、是否直言、话语长度、发言先后与他人是否敢打断共同呈现。

### 6. 信息释放

常先给异常、缺口或敌方困惑，再让行动后果揭底。秘密战术不宜由守方提前解释；群体心理不宜由叙述者直接命名；会战全貌不宜一次俯瞰讲完。信息差本身构成张力，慢段必须增加战略、制度或人物关系信息。

### 7. 转场

常见转场为：宏观局势到具体人物、快战到慢议、前线到敌方内部、高潮到个人沉默或制度后果。战争胜负最终落回身份承担、伤亡代价、官僚反应和战后秩序。转场不是“喘口气”，而是更换信息维度。

## 合法变化矩阵

| 场域 | 叙事距离 | 句法与词汇 | 信息重心 | 允许增强 | 禁止漂移 |
|---|---|---|---|---|---|
| 朝堂 | 中远景群像，短暂贴近关键发言者 | 官称、典故、奏答礼法增密；长句偏多 | 程序、立场、任命、赏罚、发言顺序 | 群辩、揣摩、体统冲突、政治表演 | 纯古雅清谈；没有可执行后果的空辩 |
| 军阵 | 可信观察点与局部全知交替 | 动词链、军号、旗帜、道路、编制增密；局部急促 | 地形、工程、后勤、兵力层次、士气、指挥反馈 | 小人物摄像机、敌方误判、物理信号 | 名将对砍替代组织逻辑；无来源上帝视角 |
| 市井/底层 | 更贴身，跟随生存动作 | 口语、俚俗、粗粝物件增多 | 饭、钱、运输、征发、抢夺、流言 | 微型经济制度、群体行为、阶层摩擦 | 只写“麻木、绝望”；把底层当气氛布景 |
| 主角内视角 | 近景，但仍受帝位与局势牵制 | 现代常识、自嘲、吐槽最浓；可突然降格 | 现代价值与时代条件的折算、责任与代价 | 反讽、务实打断典故、身份分裂感 | 百科外挂；无成本技术跃迁；让全体古人现代化 |

## 不可漂移不变量

1. 系统因果先于情绪标签：群体状态必须能从制度、资源、命令或行为推导。
2. 人物必须经具体政军事务检验，不能只靠豪言、标签或历史名声立住。
3. 文白错位可以变化，但世界内称谓、官职层级与礼法压力必须稳定。
4. 宏观判断必须落到具体物、具体人、具体路径或具体成本。
5. 战斗转折必须追溯到地形、工程、后勤、士气、指挥或组织，不靠偶然神勇兜底。
6. 现代知识只能转化为受时代生产力、官僚系统和利益结构限制的方案。
7. 高潮后必须结算身份责任、制度后果、伤亡代价或个人沉默中的至少一项。
8. 多线不是平行装饰：军事、政治、外交、思想线应互相制造条件并结算后果。

## literal / normalized / semantic reuse 判定表

| reuse 类别 | 可复用对象 | 必须处理 | 禁止项 | 示例 |
|---|---|---|---|---|
| `literal_reuse` | 人名、官职、地名、年代、军制名、作品内已确立专名；极短功能性军令词 | 核对版本、身份时点与上下文称谓 | 连续原句、独特排比、完整对白、标志性笑点 | “御营前军”“燕京”“官家” |
| `normalized_reuse` | 剧情事实、人物关系、时间线、兵力、路线、制度因果、战役步骤 | 改写为中性事实单元；统一名称、时间与单位；标注小说/史实/推断 | 保留原文句序、包袱与叙述节奏 | “先锋渡河后，骑兵利用其遮护展开” |
| `semantic_reuse` | 章法、镜头机制、节奏、视角策略、信息差、象征功能 | 更换人物、物件、动作链和句面，只保留抽象手艺 | 近义改写原段、复刻可识别场景骨架 | “让敌方困惑逐步揭开防守机关” |

三者是素材复用分类（`reuse_class`），不是运行时创作模式。无法稳定判断时，从严降级：`literal_reuse → normalized_reuse → semantic_reuse → 不复用`。历史参考只提供 grounding；若小说正文未确认，应标记为史实候选或不确定，而不是补入 canon。

## 最小归一操作

1. 建立人物主键，并保留场景内合法称谓切换，如姓名、官家、相公、节度等。
2. 官制、军制、地名首次出现给最短必要释义，后续避免重复百科说明。
3. 将事实抽成“条件—判断—行动—反馈—后果”，删除原句节奏、修辞与笑点。
4. 统一时间、兵力、路线与单位；机器字段可用标准值，正文用时代内可感知表达。
5. 分离四类证据标签：小说正文、历史 grounding、合理推断、未明示/不确定。
6. 清理 OCR 错字、异体字和同名异称，但保留作者有意的口语降格与角色化误称。
7. 原文连续措辞、独特排比、标志性判语一律改为语义摘要。
8. 检查归一后是否误删官职时点、阵营变化、信息可见性或决策成本。

## derivative：四种合法 reuse_mode 应用

| `reuse_mode` | 适用情况 | 执行规则 | 保真信号 |
|---|---|---|---|
| `fan_fiction` | 在《绍宋》既有时空、人物与政治军事格局内补写支线、空白期或旁观者故事 | canon 专名可按 `literal_reuse` 注入，事实按 `normalized_reuse` 注入；新增冲突不得改写既定胜负、官职时点和人物公开立场；优先用小人物、地方官或次要部队补足系统后果 | 新故事能嵌回既有时间线；人物称谓、信息可见性与制度成本无缝 |
| `sequel` | 从建炎十年后继续新宋的迁都、裁军、修河、抑兼并及边疆治理 | 把终章国家大略当承诺而非已完成事实；逐项写执行摩擦、利益反弹和多年反馈；主角现代意识仍受生产力、官僚和寿命约束 | 前作军事胜利转化为治理债务；多线持续互相结算而非重新打怪 |
| `spin_off` | 以金国、地方军民、文臣、武将或外交角色为中心扩展同一世界 | 保留主线事件的外部约束，但只写该角色可见、可知、可承受的部分；不得让边缘角色洞悉中枢全盘；用职业制度与生存机制建立独立弧线 | 即使主角缺席，仍有官制、后勤、地理与身份压力；视角知识边界可信 |
| `cross_style_rewrite` | 保留《绍宋》canon 事实，将表达改写为另一目标风格或体裁 | `normalized_reuse` 事实不可漂移；允许替换句法、修辞密度和镜头节拍；仍保留系统因果、时代限制、称谓层级与战后结算，不复制原作口头禅 | 目标风格清晰，但读者仍能从决策逻辑和制度重量识别《绍宋》世界 |

四个值是唯一合法的运行时 `reuse_mode`。`literal_reuse / normalized_reuse / semantic_reuse` 仅写入素材项的 `reuse_class`，不得占用 `reuse_mode`。derivative 的首要保真不是词频相似，而是“系统—人物—决策—后果”的联动。只复刻“只能说、所以说”等口头禅属于表面模仿，应判低保真。

## serial：章际连续性

### 必须继承的状态

- 人物：官职、阵营、伤病、地理位置、已知信息、公开承诺与私人判断。
- 军事：兵力、损耗、补给、道路、天气、工事、命令链和部队疲劳。
- 政治：议决结果、程序债务、赏罚预期、派系反应与公开体统。
- 社会：征发、粮价、迁徙、流言、春耕等上一章行动造成的基层反馈。
- 叙事：当前可信观察点、尚未揭示的信息差、慢/快节奏债与待结算意象。

### 章际推进规则

1. 新章开头优先呈现上一章决定的可观察反馈，不重新概述全部背景。
2. 军事决策必须在后续章结算后勤、士气或政治成本，不能只结算胜负。
3. 视角切换必须说明新观察者为何能知道相关信息。
4. 若上一章以短句拍板，本章宜先展示执行摩擦；若上一章长期蓄压，本章可快速落子。
5. 新制度或技术至少经历提出、协商/试验、执行、反馈之一，不得瞬间普及。
6. 每章可改变场域语域，但不可改变八项不变量。

## dispatch 注入建议

### 最小注入包

1. 任务目标与场域：朝堂、军阵、市井、主角内视角可多选，但指定主场域。
2. 本文“不可漂移不变量”八条。
3. 与场景匹配的 3–5 条机器 constraints，避免整卡无差别塞入。
4. canon 事实以 `reuse_class: normalized_reuse` 注入，专名表以 `reuse_class: literal_reuse` 注入。
5. 最多两条 `reuse_class: semantic_reuse` transfer rule，并明确要求更换物件、角色功能和动作链。
6. serial 任务追加上一章状态快照与待结算项；derivative 任务追加差异化要求。
7. 禁止注入长原文、连续对白或“模仿作者某段”的开放指令。

### 推荐 dispatch 字段

```yaml
style_dispatch:
  novel: 绍宋
  task_mode: derivative  # derivative | serial
  reuse_mode: spin_off  # fan_fiction | sequel | spin_off | cross_style_rewrite
  primary_register: 军阵
  reuse_items:
    - source_id: canon_fact_001
      reuse_class: normalized_reuse
      content: "中性事实单元"
    - source_id: craft_18_p4
      reuse_class: semantic_reuse
      content: "用可视物理信号统一混战行动"
  invariants: [system_before_emotion, concrete_cost, era_bounded_modernity]
  constraints: [SS-STY-002, SS-STY-005, SS-STY-008, SS-STY-009]
  serial_state_ref: null
  forbidden: [long_quote, signature_joke, recognizable_sentence_rhythm]
```

## 回执分类示例

| 回执 | 分类 | 理由 | 处置 |
|---|---|---|---|
| `reuse_mode: spin_off`，沿用“御营前军”专名 | `reuse_class: literal_reuse / pass` | mode 决定创作关系；class 标记专名复用 | 保留，核对时点 |
| `reuse_mode: sequel`，将既有兵力部署改写成中性条件链 | `reuse_class: normalized_reuse / pass` | 事实连续，未携带原句节奏 | 保留并做 canon 校验 |
| `reuse_mode: fan_fiction`，新场景用粮票而非木棍呈现民夫控制机制 | `reuse_class: semantic_reuse / pass` | 复用系统写情绪，物件和动作已变化 | 保留，检查时代适配 |
| `reuse_mode: cross_style_rewrite`，近义改写原文完整排比 | `reuse_class: semantic_reuse / fail` | 实为句面复刻，不是抽象机制迁移 | 不复用原句后重写 |
| 让普通古代军官使用当代管理术语 | `style_drift/fail` | 越过现代口吻分配边界 | 改为时代内表达 |
| 战斗靠名将临阵爆发逆转 | `causal_drift/fail` | 缺少地形、组织或士气因果 | 补足机制或删除逆转 |
| serial 新章忘记上一章断粮 | `continuity/fail` | 未继承军事状态 | 返工并优先展示反馈 |
| 历史资料有记载但小说未确认的细节被写成定论 | `canon_boundary/fail` | 把 grounding 升级为 canon | 改标“史实候选/未明示” |

## 验收 checklist

- [ ] 七维风格均有场景内可执行定义，而非抽象形容词。
- [ ] 主场域的合法变化已应用，且未破坏不可漂移不变量。
- [ ] 运行时 `reuse_mode` 是 `fan_fiction / sequel / spin_off / cross_style_rewrite` 四值之一。
- [ ] 所有 reference 片段均另标 `reuse_class`，且未把分类值写入 `reuse_mode`。
- [ ] `reuse_class: literal_reuse` 仅含专名、事实短词项或极短功能语。
- [ ] `reuse_class: normalized_reuse` 已统一人物称谓、时间、单位和证据标签。
- [ ] `reuse_class: semantic_reuse` 已更换句面、物件、角色功能与动作链。
- [ ] 不含长原文、标志性排比、完整对白或可识别笑点复刻。
- [ ] 政军事务至少有两项硬约束，战斗转折具备系统因果。
- [ ] 现代口吻仅出现在合法叙述层，技术/制度创新受时代限制。
- [ ] 高潮之后已结算至少一种责任、制度、伤亡或沉默后果。
- [ ] serial 已继承四类状态，并结算至少一项上一章后果。
- [ ] 历史 grounding、小说 canon、合理推断与未明示未发生混写。

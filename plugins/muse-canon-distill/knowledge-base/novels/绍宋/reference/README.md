# 《绍宋》历史人物参考资料

本目录存放《绍宋》知识库的人物历史原型参考资料，服务角色理解、历史 grounding 与后续 few-shot 检索。材料以正史传记和编年史为主，学术研究只作争议解释和背景校准，不替代一手史料。

## Source Rules

- 正史优先：宋方人物优先《宋史》本纪、列传；金方人物优先《金史》本纪、列传；辽/西辽、高丽人物使用对应正史入口。
- 编年互证：南宋初年事件优先用《建炎以来系年要录》《三朝北盟会编》核时间线、战事和异文。
- 学术研究辅证：只用于解释史料争议、制度背景、战役地理和后世接受史，不直接替代史料 grounding。
- 禁用来源：营销号、短视频搬运、无来源公众号洗稿、演义内容当正史事实。
- 风险标注：每个条目均保留 `historical_alignment` 与 `fictionalization_risks`，避免把小说改写、民间传说、后世评价混入史实。
- 不强造原型：无法稳定对齐正史人物者，只建 `uncertain` 或辅助说明，不建正史传记条目。

## Coverage Notes

- `林景默`：暂不建正史传记参考；当前未能在《宋史》《建炎以来系年要录》等入口定位到与小说中“翰林学士/中枢近臣”稳定对应的人物。
- `赵玖`：小说人物的历史底座为宋高宗赵构，相关史料放在 `border_rivals_diplomacy_auxiliary.md` 的赵构条。
- `秦桧`：小说中归入金国阵营，但正史秦桧的核心史料在宋方奸臣传和南宋编年中，故放入主轴/边界人物文件。
- `张荣`、`范琼`、`钟相`、`杨幺`：正史独立传记不足或事件性强，条目以编年与事件 grounding 为主。

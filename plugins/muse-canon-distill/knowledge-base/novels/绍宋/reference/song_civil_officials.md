# 宋朝文臣历史参考

## 李纲

- historical_identity：李纲（1083-1140），靖康守城名臣，南宋建炎初短暂拜相。
- grounding：
  - 政和二年进士，靖康初以强硬守城和反割地立场著称。
  - 反对钦宗避敌，主张固守东京；反对割太原、中山、河间三镇。
  - 靖康守城期间组织城防、督战，但其政治处境受主和派和近臣掣肘。
  - 姚平仲劫营失败后曾被罢，复又被起用，显示战时朝局摇摆。
  - 建炎初高宗即位后拜相，提出“自治、守、战、和”的次第。
  - 主张惩张邦昌僭逆、整肃伪命，重建赵宋合法性。
  - 后续政治生命屡受主和派、近习和现实局势消耗。
- selected_sources：
  - [《宋史》卷358《李纲上》](https://zh.wikisource.org/wiki/%E5%AE%8B%E5%8F%B2/%E5%8D%B7358)
  - 《建炎以来系年要录》卷六、卷十六，校验建炎初任相与罢相编年。
- historical_alignment：适合定位为“靖康守城名臣、建炎初短命宰相、强烈恢复/守战派”。他不是单纯冒进主战，而是强调先自治、固守、修政，再议大举。
- fictionalization_risks：不要写成长期掌控南宋中枢；不要把靖康守城完全归功于个人；与高宗早期关系可写成互相需要但迅速被现实政治消耗，不宜写成稳定君臣同盟。

## 吕好问

- historical_identity：吕好问，元祐旧族出身，靖康、建炎之际的灰区忠臣。
- grounding：
  - 出自元祐旧族，因党禁受废，靖康元年被起用。
  - 任言官时反蔡京、新法余弊，预警金兵秋冬复来与武备废弛。
  - 东京失守后曾随钦宗入金营又返城安抚。
  - 张邦昌僭位时被迫处于伪楚政局之中，但保存“靖康二年”等名义细节。
  - 劝张邦昌还政，遣使劝进康王。
  - 高宗称其有全宗庙之功。
  - 最终因“污伪命”争议求去，名节受损与实际救局并存。
- selected_sources：
  - [《宋史》卷362《吕好问》](https://zh.wikisource.org/wiki/%E5%AE%8B%E5%8F%B2/%E5%8D%B7362)
- historical_alignment：适合写成“灰区忠臣”：身在伪楚政局，手段妥协，但目标是保留赵宋合法性并推动高宗继统。
- fictionalization_risks：不要简单洗成毫无污点的纯忠臣，也不要写成张邦昌党羽；重点是“名节受损与实际救局并存”。

## 吕颐浩

- historical_identity：吕颐浩，建炎、绍兴初强力执行型宰执。
- grounding：
  - 进士出身，早年以转运财政见长。
  - 伐燕时负责转输，已指出燕山开边难守。
  - 高宗即位后知扬州、任户部尚书。
  - 张遇作乱时曾与韩世忠入垒招降。
  - 建炎二年主张高宗留江北声援，表现出较强政治胆略。
  - 苗刘之变中与张浚、韩世忠等勤王，迎高宗复辟。
  - 后为宰相兼兵柄，进航海避敌之策。
  - 胆略强但风格专恣，财政摊派、月桩钱等政策造成后患。
- selected_sources：
  - [《宋史》卷362《吕颐浩》](https://zh.wikisource.org/wiki/%E5%AE%8B%E5%8F%B2/%E5%8D%B7362)
  - 《建炎以来系年要录》卷二十七、卷六十，校验苗刘之后与军政议论。
- historical_alignment：适合定位为“危局中的强力执行型宰执”：能断大事、敢任军事，但政治风格粗重，与赵鼎、李纲等人存在理念和权力冲突。
- fictionalization_risks：不要只写成反派权臣；他平苗刘、保驾避敌确有功。也不要忽略其军费政策对东南地方的压力。

## 张浚

- historical_identity：张浚，南宋恢复派重臣，川陕、荆襄与中原战略的重要推动者。
- grounding：
  - 靖康初为太常簿，高宗即位后进入枢密系统。
  - 苗刘之变中秘密联络吕颐浩、刘光世、韩世忠等勤王。
  - 重视中原、关陕、荆襄战略，是恢复派大局型文臣。
  - 川陕宣抚时整饬诸将，任赵开、刘子羽、吴玠等。
  - 富平失利后退保兴州，但和尚原体系保全蜀口。
  - 绍兴五年与赵鼎同相，曾平杨幺、议岳飞屯荆襄。
  - 终身反和，晚年孝宗朝仍主张不割地、不屈和。
  - 用兵冒进、处置曲端等问题争议极大。
- selected_sources：
  - [《宋史》卷361《张浚》](https://zh.wikisource.org/zh-hant/%E5%AE%8B%E5%8F%B2/%E5%8D%B7361)
  - 《建炎以来系年要录》卷二十七、卷五十三、卷八十六，校验苗刘、川陕、江上视师编年。
- historical_alignment：适合写成“战略恢复派/大局型文臣”，优点是敢任边事、知人用将，缺点是用兵冒进和政治处置过硬。
- fictionalization_risks：不要把富平败局完全归咎于张浚一人，也不要把和尚原胜利直接写成张浚亲战；应区分战略布置、将领执行与后世评价。

## 赵鼎

- historical_identity：赵鼎，稳健恢复派宰相，反和议而重根本、法度与时机。
- grounding：
  - 崇宁五年进士，早年即反割三镇。
  - 张邦昌僭立时与胡寅、张浚避太学，不署议状。
  - 高宗朝任言官，弹压将帅擅杀、夺府廨，重建朝廷法度。
  - 提出江淮布防与荆襄、川陕经营思路。
  - 与吕颐浩冲突后复为中丞、签书枢密院。
  - 绍兴初两度为相，主张持重固本、亲征抗刘豫。
  - 荐张浚，并与张浚一度同相，后因战略节奏分歧不合。
  - 反秦桧和议，晚年被贬吉阳，绝食死，谥忠简。
- selected_sources：
  - [《宋史》卷360《赵鼎》](https://zh.wikisource.org/zh-hans/%E5%AE%8B%E5%8F%B2/%E5%8D%B7360)
  - 《建炎以来系年要录》卷八十六、卷一百七十一，校验江上视师与晚年贬死。
- historical_alignment：适合定位为“稳健恢复派宰相”：并非怯战，而是重根本、重法度、重时机，和张浚的积极进取形成互补与张力。
- fictionalization_risks：不要写成秦桧式主和；他反和议且为秦桧所忌。也不要把他与张浚关系固定为敌对，两人有互荐、同相、分歧三个阶段。

## 胡寅

- historical_identity：胡寅，儒林人物，抗和议、重名节、言辞峻切的南渡文臣。
- grounding：
  - 字明仲，胡安国弟之子，后为胡安国所子。
  - 宣和进士甲科，靖康初召为秘书省校书郎，后迁司门员外郎。
  - 金人陷京师、张邦昌伪立时弃官归，可作为“不附伪楚”的政治底色。
  - 建炎三年受张浚荐为驾部郎官，旋擢起居郎。
  - 对高宗南巡、和议、失地等多有切直上书，核心立场是复仇雪耻、罢绝和议、修实政。
  - 绍兴四年复召为起居郎，迁中书舍人，曾反对遣使云中求和。
  - 秦桧当国后，因与李光书讥讪朝政、反对“邻好”被落职，新州安置。
  - 谪所著《读史管见》数十万言，另有《论语详说》《斐然集》。
- selected_sources：
  - [《宋史》卷435《儒林五·胡安国附胡寅》](https://www.shidianguji.com/book/LS0020/chapter/LS0020_1538)
  - [《建炎以来系年要录》四库本入口](https://zh.wikisource.org/zh-hans/%E5%BB%BA%E7%82%8E%E4%BB%A5%E4%BE%86%E7%B9%AB%E5%B9%B4%E8%A6%81%E9%8C%84_%28%E5%9B%9B%E5%BA%AB%E5%85%A8%E6%9B%B8%E6%9C%AC%29)
- historical_alignment：适合放在“抗和议、重名节、以春秋名分和二圣之耻论政”的文臣群像中。
- fictionalization_risks：不要写成长期掌握实权的宰执型人物；他的强项是言论、学术、制诰与道义姿态。

## 万俟卨

- historical_identity：万俟卨，秦桧政治机器中的言官、狱吏、相臣复合角色。
- grounding：
  - 字元忠，开封阳武人，政和二年上舍第出身。
  - 早年历太学录、枢密院编修官、尚书比部员外郎等文职。
  - 绍兴初曾权沅州事，召土豪丁壮守城，早期并非无行政军事履历。
  - 后因岳飞宣抚荆湖时“遇卨不以礼”而怀怨，这是《宋史》解释其构陷岳飞的心理线索。
  - 入朝后希秦桧意，诬告岳飞，留为监察御史，擢右正言。
  - 秦桧收诸将兵权时，万俟卨积极助势。
  - 岳飞案中，何铸明岳飞无辜后，秦桧改命万俟卨治狱，终使岳飞父子与张宪死。
  - 后官至参知政事、尚书右仆射、同中书门下平章事。
- selected_sources：
  - [《宋史》卷474《奸臣四·万俟卨》](https://www.shidianguji.com/zh/book/LS0020/chapter/LS0020_2158)
  - [《宋史》卷30《高宗本纪七》](https://zh.m.wikisource.org/wiki/%E5%AE%8B%E5%8F%B2_(%E5%9B%9B%E5%BA%AB%E5%85%A8%E6%9B%B8%E6%9C%AC)/%E5%8D%B7030)
- historical_alignment：与岳飞案、诸将兵权、和议后财政与赏库议题直接相关，正史定位应归入和议集团/奸臣系统。
- fictionalization_risks：不要只写成脸谱化小人；史料中有早期地方守御与后期同秦桧龃龉的复杂性。但构陷岳飞、助成秦桧主和，是其正史定位核心。

## 陈规

- historical_identity：陈规，文臣出身的守城、城防制度和地方动员专家。
- grounding：
  - 字元则，密州安丘人，中明法科。
  - 靖康末任安陆令，曾率勤王兵赴汴，因道路阻绝而还。
  - 德安府守御是其早期高光，连续击退祝进、王在、李孝义、张世、杨进、董平等盗军。
  - 建炎元年除直龙图阁、知德安府，后为德安府、复州、汉阳军镇抚使。
  - 李横围德安七十日，陈规拒以妓女换退兵，后用火枪、火牛焚天桥，迫敌拔寨。
  - 曾入对建议罢镇抚使、分诸将跋扈之势，高宗采纳。
  - 顺昌之战中知顺昌府，修城、招流亡、立保伍，并与刘锜同守。
  - 卒后赠右正议大夫；乾道八年诏刻《德安守城录》颁天下。
- selected_sources：
  - [《宋史》卷377《陈规传》](https://www.shidianguji.com/book/LS0020/chapter/1kma2wkhwjajf)
  - [《三朝北盟会编》公开文本入口](https://simplelits.com/books/classical/classical-10284-%E4%B8%89%E6%9C%9D%E5%8C%97%E7%9B%9F%E4%BC%9A%E7%BC%96)
- historical_alignment：非常适合做“文臣能守、城防制度、地方动员”的参考。他与刘锜顺昌功业相互补强，不应只作为刘锜陪衬。
- fictionalization_risks：不要把他写成纯武将；也不要过度神化火器，战胜关键还包括粮储、保伍、斥候、轮换疲敌。

## 虞允文

- historical_identity：虞允文，文臣临机督战成名，采石之战和孝宗恢复议政核心人物。
- grounding：
  - 字彬甫，隆州仁寿人；绍兴二十三年进士。
  - 早年通判彭州，权知黎州、渠州。
  - 秦桧死后受荐召对，论人君畏天、安民、法祖宗，又论四川财赋科纳之弊。
  - 金主完颜亮南侵前，虞允文判断金必败盟，主张预作备御。
  - 出使金方时观察运粮造舟与完颜亮语意，返宋后申言淮海防备。
  - 采石之战中原本奉命犒师、趣李显忠交王权军，到采石时王权已去、显忠未至，宋军溃散。
  - 临机召诸将、分布战船，亲自督战，击败渡江金军。
  - 孝宗朝多次反对弃陕西新复州郡及唐、邓、海、泗等地。
  - 后为右仆射、左丞相兼枢密使，又出任四川宣抚使。
- selected_sources：
  - [《宋史》列传《虞允文传》识典入口](https://www.shidianguji.com/zh/book/LS0020/chapter/1kma2wvfa55ai)
  - 《建炎以来系年要录》、宋孝宗朝相关编年材料。
- historical_alignment：应围绕采石、川陕、反弃地、入相后军政整顿使用。
- fictionalization_risks：不要把采石写成他预先作为统帅经营的战役；正史亮点恰在“奉命犒师而临机督战”。也要避免把完颜亮之死完全归功于采石。

## 林景默（uncertain）

- conclusion：不建议为“林景默”建立正史传记参考。
- grounding：
  - 目前可定位到的“林景默”主要来自《绍宋》角色标签、同人索引、网络问答或宗族材料中的“林杞诸子/宋九牧”线索。
  - 未能在《宋史》本纪、列传，《建炎以来系年要录》公开检索结果中定位到可与《绍宋》中“翰林学士/中枢近臣”相匹配的真实正史人物。
  - 网络问答称其“林杞第三子、官至寿州知州”等，但来源层级不足，且与《绍宋》角色时空错位。
  - AO3 等只证明“林景默/Lin Jingmo”是《绍宋》fandom 角色标签，不是史源。
- selected_sources：
  - [AO3 角色标签：林景默](https://archive.transformativeworks.org/tags/%E6%9E%97%E6%99%AF%E9%BB%98)
  - [网络问答线索：绍宋之历史上的林景默](https://zhidao.baidu.com/question/1649999626708612940.html)
  - [林杞/宋九牧类谱牒线索](https://www.newton.com.tw/wiki/%E6%9E%97%E6%9D%9E)
- historical_alignment：可保留为小说原创或不确定原型角色的说明，不纳入正史人物 roster。
- fictionalization_risks：不要把谱牒、同人标签或问答内容提升为正史依据；若后续发现可靠史源，应另行校订。

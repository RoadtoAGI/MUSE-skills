# 金国阵营历史参考

## 完颜宗弼 / 兀术

- historical_identity：完颜宗弼，本名斡啜，又作兀术、斡出、晃斡出，金太祖第四子。
- grounding：
  - 早期随军伐辽，曾以百骑追击辽军，矢尽夺枪，独杀八人、生获五人。
  - 首次伐宋随宗望入兵，取汤阴、薄汴城，追宋上皇未及。
  - 宗望死后，在淄青、河北诸战中多次作为前锋或主力，攻克青州、开德、大名等。
  - 建炎南侵中渡江，取江宁、杭州、明州，迫使宋高宗入海。
  - 黄天荡段并非“被韩世忠彻底困死”，《金史》叙述为开老鹳河故道脱出，并以火箭破宋舟师。
  - 富平之战参与定陕西，但和尚原败于吴玠，说明其军事履历不是一路无败。
  - 天眷以后主张诛挞懒、复河南陕西，后以淮水为界完成宋金和议框架。
- selected_sources：
  - [《金史》卷77《宗弼传》](https://zh.wikisource.org/zh-hant/%E9%87%91%E5%8F%B2/%E5%8D%B777)
  - 《金史》卷77《昌传》
  - 《三朝北盟会编》建炎、绍兴诸卷。
- historical_alignment：适合作为金军南侵、主战派、对宋军事压力的核心人物。
- fictionalization_risks：不要沿用评书“金兀术=单线反派/被牛皋气死”等俗文学桥段；“兀术”只是异写之一，不宜误写成本名唯一形态。

## 完颜宗翰 / 粘罕

- historical_identity：完颜宗翰，本名粘没喝，汉语讹为粘罕，国相撒改长子。
- grounding：
  - 年十七即以勇为军中所服，早期参与劝太祖建号。
  - 伐辽战略中极主动，主张趁辽主失德、中外离心而袭取。
  - 太祖评价其谋略，称其适合谋元帅，显示其在金初军事决策层的地位。
  - 攻中京、北安州、追辽主诸役中，是西路方向核心统帅。
  - 太宗即位后受方面之任，有便宜迁授权，体现其半独立军政权力。
  - 对宋盟约高度不信任，主张勿割山西郡县，后与宗望俱请伐宋。
  - 靖康之役中为左副元帅，自太原路攻宋，是灭北宋的关键统帅之一。
  - 熙宗继立问题上与宗干、希尹定议，说明其不只是武将，也是皇位安排参与者。
- selected_sources：
  - [《金史》卷74《宗翰传》](https://zh.wikisource.org/zh-hant/%E9%87%91%E5%8F%B2/%E5%8D%B774)
  - 《三朝北盟会编》靖康诸卷。
- historical_alignment：应写成“西路军政统帅、战略强硬派、金初权臣”，而非单纯猛将。
- fictionalization_risks：粘罕、粘没喝、宗翰三名要对应清楚；与宗望、宗弼的辈分与战区不要混置。

## 完颜昌 / 挞懒

- historical_identity：完颜昌，本名挞懒，穆宗子，金廷对宋政策与伪齐设计的关键人物。
- grounding：
  - 早期随宗翰追辽主，并处理辽方群牧、降人、奚路诸部。
  - 曾任奚六路军帅，职责偏边地军政、招抚、设官镇守。
  - 伐宋时任六部路都统，天会四年再伐宋，参与汴州方向作战。
  - 北宋灭亡后任元帅左监军，镇抚山东，刘豫降后由挞懒镇抚，大事专决。
  - 力举刘豫为大齐皇帝，是金扶植伪齐的重要推动者。
  - 后又倡议以河南、陕西旧地与宋，遭宗干等反对。
  - 因与宋交通、割地、谋反诸罪名，被宗弼推动清算，南走至祁州被杀。
  - 《金史》赞语评价其“初无固志”“轻躁”，这是金方史书立场，使用时需保留批判距离。
- selected_sources：
  - [《金史》卷77《昌传》](https://zh.wikisource.org/zh-hant/%E9%87%91%E5%8F%B2/%E5%8D%B777)
  - 《金史》卷77《宗弼传》
  - 《三朝北盟会编》绍兴和议相关材料。
- historical_alignment：适合作为金廷内部“对宋政策摇摆、伪齐设计、割地议和争议”的关键人物。
- fictionalization_risks：注意另有银术可之子彀英“本名挞懒”，不要把不同挞懒混同；“通宋谋反”需按金方史书立场处理。

## 完颜娄室

- historical_identity：完颜娄室，金初辽、宋、西夏多线战场高级野战统帅。
- grounding：
  - 字斡里衍，完颜部人，二十一岁代父为七水诸部长。
  - 金初伐辽时招降辽籍女直诸部，兼具军事与部族整合能力。
  - 达鲁古城之战中与银术可冲辽军中坚，多次陷阵而出。
  - 攻黄龙府后主动请求屯守，太祖命其为万户守黄龙府。
  - 对夏军李良辅一役，能在部下受挫后判断敌我心理，主动反击。
  - 参与俘辽帝、太原、河东、陕西诸役，是金初西线攻坚名将。
  - 攻宋时取汾石、河中、陕西、凤翔、延安等地，深度卷入宋金西线战场。
  - 富平之战时已有病，仍以右翼力战扭转军势。
  - 天会八年卒，后追封金源郡王，谥壮义，配享太宗庙廷。
- selected_sources：
  - [《金史》卷72《娄室传》](https://zh.wikisource.org/zh-hant/%E9%87%91%E5%8F%B2/%E5%8D%B772)
  - 完颜娄室神道碑相关研究可作碑刻补充。
- historical_alignment：不要只把他写成宗翰部将；其独立军功、部族招抚和西线经营都很重。
- fictionalization_risks：避免将其压缩成单一“关西战场对手”；他在金初国家形成、辽宋夏多线战争中都有作用。

## 完颜希尹

- historical_identity：完颜希尹，本名谷神，金初军政文三栖人物，女真文字创制者。
- grounding：
  - 欢都之子，自太祖举兵即常在行阵，有持续军功。
  - 最核心贡献是受命创制女真文字：依汉字楷体、参契丹字制度、合女真语，天辅三年成书颁行。
  - 参与伐辽情报与追击，获辽护卫耶律习泥烈，得知辽主在鸳鸯泺。
  - 古北口之战中与娄室等以少兵破辽步骑万余。
  - 伐宋时为元帅右监军，再伐宋后执二主归，获铁券。
  - 与宗翰同请立熙宗为储，进入金廷最高政治层。
  - 熙宗朝为左丞相，后被赐死。
  - 皇统三年追知其“实无他心”，赠官改葬。
- selected_sources：
  - [《金史》卷73《希尹传》](https://zh.wikisource.org/zh-hant/%E9%87%91%E5%8F%B2/%E5%8D%B773)
  - 完颜希尹神道碑拓本研究可补家族与身后评价。
- historical_alignment：适合作为“军政文三栖”的金初制度建设者。
- fictionalization_risks：不要只写成文臣造字者；也不要把其被杀简单写成确证谋反，正史自身有“死非其罪”的翻案。

## 完颜拔离速

- historical_identity：完颜拔离速，金初太原、陕西战线骨干将领，银术可弟。
- grounding：
  - 天辅六年古北口战中，拔离速、讹谋罕、胡实海推锋奋击，大破辽军。
  - 娄室拒夏人时，留拔离速以二百兵据险守之。
  - 银术可围太原时，拔离速与阿鹘懒复取太谷、祁县。
  - 击败宋姚古军于隆州谷，又击走张灏汾州兵。
  - 天会四年克太原后，为管勾太原府路兵马事。
  - 后随宗翰围汴，并与银术可略地襄、邓、均、唐、蔡、陈、颍昌等地。
  - 宗弼再定河南、撒离喝经略陕西时，拔离速破宋军于渭州，渭州、德顺军皆降。
  - 后迁元帅左监军，加金吾卫上将军，卒谥敏定。
- selected_sources：
  - [《金史》卷72《银术可传附拔离速》](https://zh.wikisource.org/zh-hant/%E9%87%91%E5%8F%B2/%E5%8D%B772)
  - 《金史》卷72《娄室传》相关战事。
- historical_alignment：应写成机动突击、关隘守御、太原及陕西战线的骨干将领。
- fictionalization_risks：资料集中在附传，个人内心与政治立场证据少；不宜强行设定为独立派系首脑。

## 完颜斡本（name_disambiguation）

- conclusion：史料中“完颜斡本”最稳妥对应为完颜宗干，不是宗弼、宗翰、昌、娄室、希尹、拔离速中的任何一人。
- evidence：
  - 《金史》卷76《宗干传》明载“宗干本名斡本，太祖庶长子”。
  - 同传列其政治地位：太宗即位后为国论勃极烈，与斜也辅政；熙宗即位后拜太傅，与宗翰等并领三省事。
  - 同传列其子：充、亮、兖、襄、衮，其中亮即海陵庶人，符合“海陵王生父”系统。
  - 《金史》卷77明载宗弼本名斡啜/兀术等，不是斡本。
  - 《金史》卷74明载宗翰本名粘没喝，汉语讹为粘罕，不是斡本。
  - 《金史》卷77明载昌本名挞懒，不是斡本。
  - 《金史》卷76另有“宗本本名阿鲁”，所以“斡本”也不应误读为“宗本”。
- selected_sources：
  - [《金史》卷76《宗干传》](https://zh.wikisource.org/zh-hant/%E9%87%91%E5%8F%B2/%E5%8D%B776)
  - [《金史》卷77《宗弼传》《昌传》](https://zh.wikisource.org/zh-hant/%E9%87%91%E5%8F%B2/%E5%8D%B777)
  - [《金史》卷74《宗翰传》](https://zh.wikisource.org/zh-hant/%E9%87%91%E5%8F%B2/%E5%8D%B774)
- use_note：若《绍宋》角色索引继续使用“完颜斡本”，reference 中应注明其正史对应为完颜宗干。

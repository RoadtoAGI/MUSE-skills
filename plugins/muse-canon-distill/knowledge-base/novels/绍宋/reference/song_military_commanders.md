# 宋朝武将历史参考

## 岳飞

- historical_identity：岳飞（1103-1142），相州汤阴人，南宋中兴诸将之一。
- grounding：
  - 字鹏举，《宋史》本传强调少时读《左氏春秋》《孙吴兵法》，不是单纯“天生神将”。
  - 早期从军包括真定应募、随刘浩、隶宗泽等阶段。
  - 与王彦同渡河后，曾因进取、乞粮、军隙而离开王彦系统，后归宗泽。
  - 建康、常州、清水亭、牛头山等战事中，史传突出其野战、设伏能力，也强调军纪“不扰民”。
  - 岳家军声望来自纪律和战绩共同积累，不宜扩展成神话化无敌军。
  - 绍兴十年北伐，《宋史》记郾城、颍昌、朱仙镇等节点，并写到对“拐子马”的战术应对。
  - 政治立场核心是反和、主战、恢复中原；与秦桧关系恶化在和议语境中展开。
  - 正史岳飞既有忠义形象，也有具体军政判断、屯驻、援军、上奏、受制于朝廷命令等现实约束。
- selected_sources：
  - [《宋史》卷365《岳飞传》](https://zh.wikisource.org/wiki/%E5%AE%8B%E5%8F%B2/%E5%8D%B7365)
  - [《建炎以来系年要录》四库全书本入口](https://zh.wikisource.org/zh-hans/%E5%BB%BA%E7%82%8E%E4%BB%A5%E4%BE%86%E7%B9%AB%E5%B9%B4%E8%A6%81%E9%8C%84_%28%E5%9B%9B%E5%BA%AB%E5%85%A8%E6%9B%B8%E6%9C%AC%29)
  - [《三朝北盟会编》公开文本入口](https://simplelits.com/books/classical/classical-10284-%E4%B8%89%E6%9C%9D%E5%8C%97%E7%9B%9F%E4%BC%9A%E7%BC%96)
- historical_alignment：应放在南宋初年“多将并起、朝廷南渡、和战摇摆”的体系内，不宜让他脱离宗泽、王彦、张俊、韩世忠、刘锜等人的共同战场。
- fictionalization_risks：避免直接采用《说岳全传》式设定；“精忠报国”刺字、枪挑小梁王、神化牛皋/杨再兴关系等民间内容若使用，应标注为后世演义，不作正史 grounding。

## 韩世忠

- historical_identity：韩世忠，延安人，行伍出身的南宋大将。
- grounding：
  - 字良臣，延安人，出身行伍；《宋史》以“敢勇应募、挽强驰射”塑造其早年武勇。
  - 方腊之役中追入清溪峒、擒方腊，但功劳一度被辛兴宗攘取。
  - 靖康、建炎间多次力战，军事形象偏“亲冒矢石”的猛将。
  - 苗刘之变中与张俊等勤王，梁氏一日夜出城会军的情节见本传。
  - 黄天荡之战以少量兵力扼兀术归路，相持四十八日；但最终金军仍遁去。
  - 长期屯楚州，史称兵仅三万而金人不敢犯，体现边防威慑与持久经营。
  - 反对和议，并曾为岳飞冤狱发声，《宋史》明言其触秦桧尤多。
  - 晚年解兵后杜门谢客、绝口不言兵。
- selected_sources：
  - [《宋史》卷364《韩世忠传》](https://zh.wikisource.org/wiki/%E5%AE%8B%E5%8F%B2/%E5%8D%B7364)
  - 《建炎以来系年要录》建炎三年至绍兴十一年前后条目。
  - 《三朝北盟会编》建炎、绍兴宋金战事相关卷。
- historical_alignment：韩世忠不是岳飞附庸，而是南宋初年独立大将，与张俊、刘光世、岳飞并列；核心场域是江淮、镇江、楚州、淮东防线。
- fictionalization_risks：梁红玉击鼓抗金可取其史传基础，但后世戏曲、评书常强化“女将统帅”成分；黄天荡不能写成韩世忠全胜，只能写成重创、牵制、震慑。

## 张俊

- historical_identity：张俊，南渡后较早握兵并长期受高宗倚用的大将。
- grounding：
  - 字伯英，凤翔府成纪人，早年好骑射，起于军伍。
  - 靖康至建炎间较早被高宗倚用，参与护卫、迎太后、平江淮群盗。
  - 苗刘之变中与韩世忠、刘光世合力勤王。
  - 绍兴元年讨李成，张俊为招讨主帅，岳飞为先锋，杨沂中执行奇袭。
  - 在淮西、宿亳、柘皋等战事中有战功，也被高宗长期厚待。
  - 《宋史》评价其“南渡后握兵最早，屡立战功”，与韩、刘、岳并称名将。
  - 本传同样强烈批评他参与岳飞冤狱、助秦桧成事，并写其力赞和议。
  - 写张俊应保持双面性：能战、能经营、受宠，也趋附和议、政治上与岳飞严重冲突。
- selected_sources：
  - [《宋史》卷369《张俊传》](https://zh.wikisource.org/zh-hans/%E5%AE%8B%E5%8F%B2/%E5%8D%B7369)
  - 《建炎以来系年要录》绍兴元年、绍兴十一年前后条目。
  - 《三朝北盟会编》绍兴和战材料。
- historical_alignment：张俊应置于“中兴诸将”中，而非简单反派；他是南宋军事体制内的高位将领，政治选择与个人利益、皇权控兵、秦桧和议相互交织。
- fictionalization_risks：不要把张俊脸谱化成纯粹奸臣，也不要洗去其在岳飞案中的责任；正史口径是“有战功，但心术与韩世忠相殊”。

## 杨沂中 / 杨存中

- historical_identity：杨沂中，本名沂中，绍兴间赐名存中；高宗近卫、殿前宿卫系统核心武将。
- grounding：
  - 字正甫，代州崞县人，家族有抗金死难背景。
  - 少年形象是魁梧、警敏、习孙吴、善骑射。
  - 建炎初随张俊入援，后被高宗亲信，长期扈卫。
  - 任城战斗中以少骑突入、甲胄染血，被高宗称许。
  - 嘉兴讨徐明时曾劝止屠城，只诛渠魁。
  - 绍兴元年从张俊讨李成，主张奇兵夹击；降卒被坑杀一事中，史传写他“不忍杀降”。
  - 藕塘之战大破伪齐军，北方震动。
  - 柘皋有功，濠梁有败；《宋史》明写“录柘皋之功而掩濠梁之败”。
- selected_sources：
  - [《宋史》卷367《杨存中传》](https://zh.wikisource.org/wiki/%E5%AE%8B%E5%8F%B2/%E5%8D%B7367)
  - [《宋史》卷369《张俊传》](https://zh.wikisource.org/zh-hans/%E5%AE%8B%E5%8F%B2/%E5%8D%B7369)
  - 《建炎以来系年要录》绍兴元年至十一年前后条目。
- historical_alignment：更适合写为高宗近卫、张俊体系中的强力执行者，后来成为殿前司核心人物；不是岳家军人物。
- fictionalization_risks：避免把“杨家将”传统投射到杨沂中身上；也不要只写猛将，要写其宿卫、军政、受宠与被言官批评。

## 王彦

- historical_identity：王彦，两河忠义武装和八字军的重要组织者，岳飞早期上级之一。
- grounding：
  - 字子才，上党人，性豪纵，喜读韬略。
  - 金人攻汴时弃家赴阙求战，被张所擢为都统制。
  - 率张翼、白安民、岳飞等十一将、七千人渡河，曾复卫州新乡。
  - 被金军围攻后突围，独保共城西山，联络两河豪杰再举。
  - “八字军”正史基础是部曲刺面“赤心报国，誓杀金贼”，以表明不叛。
  - 后来两河民兵傅选、孟德、刘泽、焦文通等归附，众至十余万。
  - 力陈两河忠义可用、主张北伐，触忤黄潜善、汪伯彦等。
  - 入川陕后对富平形势持谨慎意见，主张先固利、阆、兴、洋。
  - 后期知金州、守荆襄、屯田、治郡。
- selected_sources：
  - [《宋史》卷368《王彦传》](https://zh.wikisource.org/wiki/%E5%AE%8B%E5%8F%B2/%E5%8D%B7368)
  - 《建炎以来系年要录》建炎元年至绍兴九年前后条目。
  - 《三朝北盟会编》两河忠义军、宋金前线材料。
- historical_alignment：可作为“北方民兵、两河义军、南宋朝廷决策失配”的关键人物。
- fictionalization_risks：不要把八字军写成现代意义的统一正规军；也不要把王彦和岳飞关系简化成永久同盟，正史里二人早有军隙。

## 吴玠

- historical_identity：吴玠，川陕屏障和吴氏川陕军事集团核心人物。
- grounding：
  - 德顺军陇干人，少年从泾原军起家，边地军人出身。
  - 早期在西夏、方腊、河北群盗等战事中累功，具备长期实战资历。
  - 建炎二年在青溪岭击金，开始建立川陕战区声望。
  - 富平前后已判断地形不利，主张据高阜、守要害，不偏好平原决战。
  - 富平败后收散卒守和尚原，以“扼蜀口、防敌越己”为核心战略。
  - 和尚原、饶风关、仙人关诸役体现其山地防御、强弩轮射、断粮、伏击作战风格。
  - 与弟吴璘形成吴氏川陕军事集团，后世“保蜀”叙事核心人物。
  - 治军严而能通下情，用将“不以亲故权贵挠之”。
  - 《宋史》也记其晚年嗜欲、丹石致疾，人物不宜完全圣化。
- selected_sources：
  - [《宋史》卷366《吴玠传》](https://www.shidianguji.com/book/LS0020/chapter/1kma2w1mt4pp6)
  - [《建炎以来系年要录》卷075](https://zh.wikisource.org/zh-hans/%E5%BB%BA%E7%82%8E%E4%BB%A5%E4%BE%86%E7%B9%AB%E5%B9%B4%E8%A6%81%E9%8C%84/%E5%8D%B7075)
- historical_alignment：应贴合“川陕屏障”“守险保蜀”“山地强弩战”的历史定位。
- fictionalization_risks：避免写成孤胆武侠；他强在战区组织、地形判断、军纪与后勤。也避免抹去与曲端、张浚体系中的政治张力。

## 李彦仙

- historical_identity：李彦仙，陕州孤城忠义人物。
- grounding：
  - 宁州彭原人，初名孝忠，后改名彦仙，有豪侠、边地武人气质。
  - 靖康后从河东军事活动转入陕州防御，能识地形、善骑射。
  - 在三觜、陕州一带组织防御，利用伏兵、内应复陕州。
  - 受命知陕州兼安抚使后，搜军实、修城防，把家属接入城中，宣示与城共存亡。
  - 对金将乌鲁撒拔、完颜娄室等多次守战，陕州成为金军西进障碍。
  - 面对张浚“空城清野、据险保聚”的建议不从，坚持孤城守御。
  - 城陷前长期缺粮，士兵煮豆，仍坚持巷战；本人投河死，家属多遭害。
  - 《宋史》强调其“以信义治陕”“与其下同甘苦”，民众妇女亦助守城。
- selected_sources：
  - [《宋史》卷448《忠义三·李彦仙传》](https://www.shidianguji.com/book/LS0020/chapter/LS0020_1696)
  - [《宋史》卷26《高宗本纪三》](https://zh.wikisource.org/wiki/%E5%AE%8B%E5%8F%B2/%E5%8D%B7026)
- historical_alignment：适合对齐“陕州孤城”“忠义军民”“金军西向受阻”的抗金叙事。
- fictionalization_risks：不要把他写成单纯莽夫；他有地形、伏兵、间谍、民心组织能力。也不要忽略不从清野建议带来的战略代价。

## 曲端

- historical_identity：曲端，西军名将，战略谨慎、军政关系高度紧张。
- grounding：
  - 镇戎人，父战死，少年授职。
  - “警敏知书，善属文，长于兵略”，不是粗暴武夫模板。
  - 早年在泾原、秦凤一带任将，熟悉西北边防与夏、金压力。
  - 建炎初招流民溃卒，军行纪律较严，有“道不拾遗”的形象。
  - 对王庶节制多有抗拒，延安失守前后与王庶冲突尖锐。
  - 军事判断偏谨慎，主张据险扰耕、使金军粮尽自困，不赞成轻举平原决战。
  - 与张浚战略不合，彭原事后被削兵柄，富平失败后反被承认训练泾原军有方。
  - 与吴玠有怨，复用问题牵动张浚、王庶、吴玠之间的政治猜疑。
  - 最终因“指斥乘舆”等罪名入狱死。
- selected_sources：
  - [《宋史》卷369《曲端传》](https://www.shidianguji.com/book/LS0020/chapter/1kma2w6cagpp6)
  - [《宋史》卷26《高宗本纪三》](https://zh.wikisource.org/wiki/%E5%AE%8B%E5%8F%B2/%E5%8D%B7026)
- historical_alignment：应对齐“西军名将、战略谨慎、军政失和、张浚体系牺牲品/危险人物”四重面。
- fictionalization_risks：不要只写成冤死忠臣，也不要只写成跋扈军阀；核心张力是能力、威望、节制关系与朝廷疑惧并存。

## 王德

- historical_identity：王德，江淮战场悍将，刘光世旧部、张俊麾下锐将。
- grounding：
  - 字子华，通远军熟羊寨人，以武勇应募，早期便有“王夜叉”称号。
  - 早年随姚古，入敌境擒伪守，个人勇悍形象极强。
  - 改隶刘光世后，参与平济南寇、张遇、李成等战事，常任先锋突击。
  - 苗刘之变后追击叛党，因杀韩世忠亲将陈彦章入狱，后被特原。
  - 在江淮战区多次袭金、渡江、收真扬，兼具水陆机动作战经验。
  - 绍兴六年藕塘破刘豫军，绍兴十年宿州、亳州一线表现突出。
  - 绍兴十一年柘皋之战先击金右阵，与刘锜、杨沂中等并肩破“铁骑”。
  - 功名多在刘光世、张俊军府之下展开，不能脱离主帅体系单独塑造。
- selected_sources：
  - [《宋史》卷368《王德传》](https://www.shidianguji.com/zh/book/LS0020/chapter/1kma2w4tm5e0j)
  - [《宋史》卷26《高宗本纪三》](https://zh.wikisource.org/wiki/%E5%AE%8B%E5%8F%B2/%E5%8D%B7026)
  - [《宋史》卷366《刘锜传》](https://www.shidianguji.com/zh/book/LS0020/chapter/1kma2w1mt4d22)
- historical_alignment：对齐“刘光世旧部、张俊麾下锐将、江淮突击战、柘皋锋线”。
- fictionalization_risks：不要把“王夜叉”绰号写成妖魔化人格；这是勇悍标签。也要注意他与韩世忠、张俊、刘光世之间的军府关系。

## 张荣

- historical_identity：张荣，淮东水军/义军首领，主要从本纪、编年史、战事记录拼合。
- grounding：
  - 不是《宋史》列传中有完整本传的常规官军名将。
  - 出身更接近山东、淮东水上义军/地方武装，后来纳入南宋抗金体系。
  - 活动核心在通州、泰州、楚州、高邮、缩头湖等淮东水网地带。
  - 绍兴元年入缩头湖筑水寨，以舟师与金右监军完颜昌作战。
  - 缩头湖战中判断金军前锋大舰少、后续小舟受水退泥淖限制，遂弃舟登岸攻击。
  - 此战造成金军溺水陷淖甚众，完颜昌收余众奔楚州，张荣俘获其子婿佛宁。
  - 张荣本未承王命，战后向刘光世请受节制并上功，刘光世以其知泰州。
  - 场景重点应是水网、泥淖、舟师、小舟与岸战转换，而不是正面骑兵会战。
- selected_sources：
  - [《建炎以来系年要录》卷043](https://zh.wikisource.org/wiki/%E5%BB%BA%E7%82%8E%E4%BB%A5%E4%BE%86%E7%B9%AB%E5%B9%B4%E8%A6%81%E9%8C%84_%28%E5%9B%9B%E5%BA%AB%E5%85%A8%E6%9B%B8%E6%9C%AC%29/%E5%8D%B7043)
  - [《宋史》卷26《高宗本纪三》](https://zh.wikisource.org/wiki/%E5%AE%8B%E5%8F%B2/%E5%8D%B7026)
- historical_alignment：适合写“水寨义军首领被官军吸纳”的地方抗金路线，与吴玠、曲端等西北正规军形成互补。
- fictionalization_risks：不要写成梁山式纯江湖头领；关键历史价值在水网战术与地方武装纳入宋军秩序。地名、水位、泥淖条件要谨慎。

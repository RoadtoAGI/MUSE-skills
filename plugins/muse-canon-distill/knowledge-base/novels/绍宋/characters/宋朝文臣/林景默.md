# 林景默（小林学士）

## 基本信息
- **身份**：玉堂学士 → 翰林学士/知制诰 → 户部尚书
- **首次出场**：第一卷第44章

## 欲望系统
- **自觉欲望**：把事做好——几乎没有政治野心，只求完成任务
- **不自觉欲望**：被信任——沉默寡言的人最怕被忽视
- **核心缺陷**：冷静到近乎冷酷——"恶心归恶心，判断归判断"可能让他忽视人情

## 弧光
不起眼的玉堂学士 → 潜入襄阳策反王俊的暗手 → 赵官家最信任的实务派心腹 → 户部尚书

## 压力下的选择
| 场景 | 选择 | 揭示 |
|------|------|------|
| 潜入襄阳（卷二第18-19章） | 亲眼目睹范琼活剥人皮后冷静判断"色厉内荏" | 恐惧被理性完全压制——"不是畏惧，而只是恶心" |
| 对王俊最后通牒（卷二第19章） | 降低要求+降低报酬的"双降"策略 | 极老练的谈判术——让对方觉得被惩罚但底线要求不难 |

## 声音特征
| 维度 | 特征 |
|------|------|
| 情绪控制 | 全程压制——说话从不带情绪 |
| 谈判武器 | 利害分析 + 最后通牒——"就在这灯下，你若答应下来" |
| 姿态 | 秉烛读书——以"我在读书"的画面维持心理优势 |
| 判断力 | 穿透表象——别人看到"残忍"，他看到"色厉内荏，离心离德" |
| 谈判策略 | "双降"——同时降低要求和报酬，让对手觉得可以接受 |

## 关键对白
> "哪里是什么凶狠，我今日只见到你家范太尉色厉内荏，离心离德罢了。"（卷二第18章）

> "就在这灯下，你若答应下来，我便保你全家性命与私产；不答应，便请出门去。"（卷二第19章）

## 共情机制
林景默的共情来自**书生气中的钢铁意志**——被韩世忠笑为"萌儿"不会骑马，却能独闯襄阳面对活剥人皮不变色。外柔内刚的反差使他成为全书最"酷"的文臣。

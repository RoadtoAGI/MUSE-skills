# 张俊

## 基本信息
- **身份**：御营后军/右军都统 → 后"明留暗去"交出实际军权
- **首次出场**：第一卷第23章
- **核心叙事功能**：识时务的贪将——赵玖"以利驯服"路线的代表

## 声音特征
| 维度 | 特征 |
|------|------|
| 语言风格 | 格外恭顺到近乎谄媚，但恭顺背后是精密算计 |
| 体态标记 | "坐在最外侧，只留了半个屁股于凳子上"——外恭内精 |
| 政治嗅觉 | 极强——闻弦歌知雅意，主动表态缴出缴获物资 |
| 被羞辱时 | "面色大变"但不反驳——清楚自己的牌面 |

## 关键对白
> "哪里有我一个武夫的位置？"——本能的自降身段

> "三万以上，臣实不敢言守；若三万以下……臣与韩世忠，再汇合刘光世、刘正彦，诸军合力，仗坚城联守，绝不会让金兵过淮水半步！事有所败，且观臣死于陛下马前！"——立军令状时突然进入另一种声音：粗豪而壮烈

## 关键时刻
- 卷一第23-24章："荣辱"对话被赵玖以"道旁败犬"羞辱后认清现实、立军令状
- 卷一第41章：散尽私财四万两赏全城将士，嫁长媳于田师中，宣布死守下蔡
- 卷五第6章："明留暗去"——保留名号但交出实际军权给岳飞

## 核心矛盾
张俊的贪婪和识时务是同一枚硬币的两面——他贪，所以能被利益驱动；他识时务，所以能在关键时刻做出正确选择。赵玖对他的驯服策略是"不改你的性格，但把你的贪婪引向对国家有利的方向"。

# 赵玖（赵官家）

## 基本信息
- **身份**：穿越者→大宋皇帝
- **原身份**：现代大学毕业生（21岁）
- **首次出场**：第一卷第1章
- **结局**：回到明道宫大醉酩酊，完成身份认同闭环

## 欲望系统
- **自觉欲望**：抗金——击败金国，收复失地
- **不自觉欲望**：身份认同——从"穿越者"到"赵官家"
- **核心缺陷**：冒进与专制倾向（因穿越者信息优势而独断）

## 弧光
想吃雪糕的大学生 → 亲手杀刘光世的铁血天子 → 挥刀"压过去"的战时领袖 → 明道宫大醉的释然之人

## 塑造 vs 真相
- **面具**："落井失忆"后行为异常的中兴之主——不讲体统、敢杀大将、不按常理出牌
- **真相**：一个被迫承担天下重任的普通人——想吃雪糕、想回家、害怕失败
- **落差**：表面的"中兴圣主"与内心的"想回家的普通人"之间的裂缝，是全书情感暗线的核心驱动力

## 压力下的选择
| 场景 | 选择 | 揭示 |
|------|------|------|
| 韩世忠前军叛乱（卷一第17章） | 拒绝逃走，反向奔赴韩世忠 | 穿越者上帝视角转化为实际勇气 |
| 刘光世抢渡烧船（卷一第30章） | 当众亲手割喉 | "宁亡国也要杀此人"——打破赵宋祖训的决心 |
| 金兀术劝降书（卷一第43章） | 以"哭死董卓"回应 | 对二圣问题的根本态度——不被亲情绑架 |
| 南阳被围（卷二第46-51章） | 亲自上城射箭 | 将个人生死与国家命运彻底绑定 |
| 获鹿决战（卷六第14章） | 挥刀"压过去" | 从犹豫的穿越者到果断的天子——弧光终点 |

## 维度 = 矛盾
- **穿越者知识 vs 古人经验**：知道大势但不知细节，韩世忠"虚妄"一课揭示此矛盾
- **"公私一体" vs 权力成瘾**：张浚观察到赵玖将个人生死与国家命运绑定，既是力量来源也是潜在弱点
- **制度建设者 vs 独裁者**：推进原学、恩科、秘密建储等制度创新，但也亲手杀人、强推罪己诏

## 声音特征
| 维度 | 特征 |
|------|------|
| 自称 | 我/朕（精确的权力切换："我"制造共情，"朕"宣布裁决） |
| 语言节奏 | 平时话多（穿越者"解释癖"），危机时话极少——话越少事越大 |
| 核心修辞 | 大众历史典故武器化（用汉献帝/董承堵逃跑论、用郭子仪许韩世忠未来） |
| 情绪标记 | 仰头望天、按嘴角水泡、端坐不动 |
| 应激模式 | 先怔住/手脚冰凉 → 脑中高速运转 → 突然做出反常规决策 |
| 黑色幽默 | 用冷幽默消解极端压力（杀人后讨论洗衣服问题） |
| 负空间 | 绝不用道学说教、绝不用文人风雅、绝不说"天命" |

## 待人方式
赵玖对不同人的称呼和话术风格截然不同，这不是刻意算计，而是穿越者"看人下菜碟"的本能：
- 对韩世忠叫"良臣"（字），用"我"说真心话——因为穿越者知识告诉他韩世忠绝对可信
- 对张俊叫"张卿"，"我"和"朕"渐进切换——先拉近再施压，因为张俊需要利益绑定
- 对岳飞保持礼遇但留距离——穿越者虽知其忠诚，但制度性信任需要时间积累
- 对吕好问叫"吕相公"，始终保持分寸——两人互相需要对方的道德/权力背书

## 关键对白
> "朕宁亡国也要亲手杀此人。"（卷一第30章）

> "良臣。以后见了我就不要弯腰了……因为我能直起腰来，向来是韩卿一直为我扶腰做胆。"（卷一第19章）

> "朕可以做汉献帝，你却不能做董承！"（卷一第16章）

> "你没有我便是道旁败犬，我没有你，便是金兵饵料……"（卷一第23章——对张俊）

> "其实，我何尝不想家呢？"（卷一第33章——对闹事军官）

> "压过去。"（卷六第16章）

## 共情机制
读者认同赵玖的核心是**普通人被迫成英雄的真实感**——怕死但还是做了。
身体语言替代话语：亲手系玉带、穿甲胄射箭杀人、拎首级出帐、挥刀"压过去"。"话少事狠"已经成为个人权力美学。

## 历史原型差异

**历史原型：** 宋高宗赵构（1107-1187），南宋开国皇帝。

| 维度 | 历史赵构 | 小说赵玖 | 叙事目的 |
|------|---------|---------|---------|
| 对金态度 | 主和派，签绍兴和议 | 坚定抗金，亲自上阵 | 穿越者核心前提——"如果赵构不跑" |
| 岳飞之死 | 赐死岳飞 | 信任岳飞并赋予进士出身 | 翻转历史最大遗憾 |
| 秦桧之用 | 任用为相主导议和 | 秦桧从未回归宋廷 | 消解"莫须有"悲剧 |
| 军事能力 | 逃跑路线复杂但本人不上阵 | 以身涉险，亲守南阳、亲征获鹿 | 将"天子"从符号转化为行动 |
| 定都 | 临安（杭州偏安） | 南阳→东京（进取） | 空间即政治——不偏安 |
| 嗣位 | 丧失生育能力，晚年过继 | 秘密建储制度 | 用制度创新替代个人悲剧 |

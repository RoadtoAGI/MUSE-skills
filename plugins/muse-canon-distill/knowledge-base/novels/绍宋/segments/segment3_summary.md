# 《绍宋》第三卷 结构化摘要

## 一、每章一行摘要

1. **第1章 国破山河在** — 建炎三年春，金军退后宋廷还于东京旧都，赵官家安排各路御营兵马驻防并处理战后烂摊子。
2. **第2章 恨别鸟惊心** — 金人送回邢皇后死讯与两位公主的同日，扬州传来皇嗣夭折的消息，双重打击下赵玖被迫罢免李纲、派吕颐浩赴东南坐镇。
3. **第3章 江湖多风波** — 金国内部因长社败绩引发不满，高景山出使宋廷被拒后向兀术汇报金国政局。
4. **第4章 江湖多风波（续）** — 宋金两国都陷入内外困境：宋面临伪齐刘豫称帝、关中三将纠纷，金面临蒙兀人合不勒反叛。
5. **第5章 舟楫恐失坠** — 文德殿大朝议，赵官家提出下罪己诏以借题清算靖康旧账，群臣震动。
6. **第6章 舟楫恐失坠（续）** — 首相吕好问当殿下跪以死相谏，阻止赵官家下罪己诏，双方两败俱伤。
7. **第7章 凌晨过骊山** — 赵官家派胡寅、万俟卨出使关西处理曲端问题，岳飞五天平定东南军乱。
8. **第8章 独耻事干谒** — 胡寅一行进入关西鄜州境内，在直罗城被误认为假冒御史中丞而遭鞭打下狱。
9. **第9章 独耻事干谒（续）** — 胡寅与万俟卨在狱中沉着应对，吴玠闻讯前来解救。
10. **第10章 北辕就泾渭** — 吴玠设计将曲端引至直罗城，逐步削其卫队，迫使曲端进入牢房面见胡寅。
11. **第11章 潇洒送日月** — 曲端在牢前与胡寅激烈争辩，胡寅许他去东京任御营副都统。
12. **第12章 潇洒送日月（续）** — 胡寅决定留在关西自请外任，万俟卨押送曲端回京。
13. **第13章 君臣留欢娱** — 曲端入京，赵官家令韩世忠代打二十杀威鞭，随后任命曲端为御营副都统。
14. **第14章 与宴非短褐** — 赵官家在延福宫设宴招待众帅臣，以铁象（曲端战马）为由发表"良马对"之论。
15. **第15章 臣如忽至理** — 赵官家阐明以抗金为本的用人标准，高丽使者意外到来。
16. **第16章 仁者宜战栗** — 赵官家制定御营各军定额（二十万步卒加三万骑兵），征用大相国寺做军器营。
17. **第17章 仁者宜战栗（续）** — 赵官家往少林寺"化缘"获粮食数万石，大宗正赵士褭质问官家为何不祭皇陵先拜佛。
18. **第18章 行旅相攀援** — 赵官家在少林寺对赵皇叔坦言"水能载舟亦能覆舟"之论。
19. **第19章 川广不可越** — 赵官家与吕好问商议赎买河北流民事宜，折中决定开恩科。
20. **第20章 阳谷** — 杨沂中率两千班直东援，在阳谷县城前被梁山泊萧恩拒绝入城。
21. **第21章 吾山** — 杨沂中在北新桥驻守，伪齐李成从黄河北岸偷渡，雨中猝然交战。
22. **第22章 你知我知** — 李成亲率长刀骑兵猛攻北新桥宋军营寨。
23. **第23章 是他非他** — 杨沂中设计突袭李成，一刀削马耳逼退李成。
24. **第24章 何去何从** — 李成与洪涯分兵，杨沂中继续坚守北新桥。
25. **第25章 孰是孰非** — 御史弹劾岳飞"无能"，赵官家将信将疑后笑着转移话题。
26. **第26章 其易其难** — 岳飞实施大包抄合围伪齐军，万俟卨策反洪涯出降，李逵夺取阳谷。
27. **第27章 似玄似黄（上）** — 孔彦舟以诈降突袭岳飞大营失败，齐军后军一触即溃。
28. **第28章 似玄似黄（下）** — 岳飞全军齐呼"杀孔"震慑敌军，张宪斩杀孔彦舟，齐军全线崩溃。
29. **第29章 不公不正** — 张荣擒获伪太子刘麟，说服众头领随自己入京受招安。
30. **第30章 且说且笑** — 赵官家在大相国寺接见张荣，握手言欢，直言"天下事都该数落到上边"。
31. **第31章 店论** — 太学生胡铨、虞允文等在酒楼中议论时事。
32. **第32章 殿试（上）** — 建炎三年恩科殿试六百人，赵官家让岳飞和曲端也下场考试。
33. **第33章 殿试（中）** — 宰执讨论岳飞获进士出身的深层用意。
34. **第34章 殿试（下）** — 赵官家阅卷发现胡铨万字长文，将其从状元降为一甲第五名。
35. **第35章 排名** — 殿试排名确定：赵伯药状元，虞允文第四，胡铨第五；岳飞获进士出身。
36. **第36章 弥合（上）** — 张荣误解"榜下捉婿"强行绑走虞允文，岳飞闻讯赶来解围。
37. **第37章 弥合（下）** — 赵官家向张荣、岳飞坦言文武分制之弊，虞允文去而复返化解尴尬。
38. **第38章 松紧** — 中秋后全面军管防秋，陈规主持东京城堡垒化建设。
39. **第39章 征询** — 朝野请立皇后，赵官家决定折中方案：并立潘吴为左右贵妃。
40. **第40章 窥见** — 赵官家巡视黄河前线，虞允文奉命出使金军。
41. **第41章 优容** — 虞允文发现金军在小吴埽囤积大量船只，赵官家决定调梁山泊水军穿城入黄河。
42. **第42章 一波** — 赵官家下令挖通五丈河与汴河、拆除城内水门和桥梁，船队秘密穿城。
43. **第43章 水轮子** — 梁山泊水军突袭小吴埽大获全胜，火攻摧毁金军内河船队。
44. **第44章 小问题** — 金军守将溃逃，高景山率援军赶到筹划反扑。
45. **第45章 很多小问题** — 高景山反扑未能成功，宋军完成小吴埽之战。
46. **第46章 很多小问题（续）** — 小吴埽大捷消息传回，朝野振奋。
47. **第47章 平陆** — 金国高层因小吴埽之败震怒，完颜粘罕决心大举南侵。
48. **第48章 疑云** — 金军动员消息传来，赵官家紧急部署，确认大战将至。
49. **第49章 亲征** — 金国正式发动大规模侵攻，赵官家决定御驾坐镇东京。
50. **第50章 名将** — 完颜娄室率西路军入侵关西，胡寅与吴玠在前线抵御。
51. **第51章 败走** — 关西初战不利，宋军被迫后退至山区防御。
52. **第52章 耳光** — 金军渡黄河进攻东京，赵官家在城中坐镇指挥。
53. **第53章 计较** — 东京城攻防战展开，陈规主持城防系统发挥巨大作用。
54. **第54章 逼宫** — 战事紧张之际朝中有人趁机生事，赵官家弹压异议。
55. **第55章 回乡** — 韩世忠部北上驰援，各路宋军向东京方向集结。
56. **第56章 嘱托** — 赵官家在战前做出各种安排。
57. **第57章 广东话** — 各方将领交战中展现不同风格。
58. **第58章 陕西人** — 关西方面吴玠在山区中与完颜娄室激战。
59. **第59章 汇集** — 各路宋军逐步向战场汇聚，形成对金军战略压迫。
60. **第60章 思怀** — 战争间隙的人物心理刻画。
61. **第61章 杀人** — 战场上残酷战斗，双方伤亡惨重。
62. **第62章 溃走** — 金军攻势受挫，部分金军开始溃退。
63. **第63章 擅射** — 关键战斗中宋军将领展现出色武勇。
64. **第64章 藏报** — 战场情报博弈。
65. **第65章 账目** — 战争后勤与损耗清算。
66. **第66章 无二** — 决定性战斗展开，宋军取得关键胜利。
67. **第67章 进发** — 宋军转入反攻，追击撤退金军。
68. **第68章 方略** — 赵官家与宰执制定战后处置方略。
69. **第69章 山水** — 关西方面战事取得突破，吴玠击退完颜娄室。
70. **第70章 回思** — 大战结束后的反思与总结。
71. **第71章 耗殆** — 金军因消耗过大被迫全线撤退。
72. **第72章 奔援** — 各路宋军配合追击，扩大战果。
73. **第73章 军令** — 赵官家下达军令规范战后秩序。
74. **第74章 鹰扬** — 宋军将领在追击战中展现英姿。
75. **第75章 乱战** — 追击过程中双方爆发混战。
76. **第76章 落雕** — 大战最终阶段，金军彻底退出河南。
77. **第77章 不忘（上）** — 大战结束，赵官家论功行赏，反思战争得失。
78. **第78章 不忘（下）** — 全卷收束，赵官家在胜利后保持清醒，强调抗金大业任重道远。

## 三、本卷关键转折点

1. **第2章：皇嗣夭折与李纲去位** — 双重打击改变中枢权力格局。
2. **第5-6章：罪己诏风波** — 赵官家与吕好问在纲常问题上的底线试探。
3. **第10-13章：曲端入京** — 胡寅、吴玠联手押送曲端，受杀威鞭后转任副都统。
4. **第27-30章：东平府大捷** — 岳飞合围伪齐军，孔彦舟被斩刘麟被擒，张荣归顺。
5. **第17-18章：少林寺政治摊牌** — 赵官家对赵皇叔坦言"天子与百姓共天下"。
6. **第32-35章：建炎三年大恩科** — 六百进士含岳飞曲端，打破文武殊途传统。
7. **第41-43章：小吴埽之战** — 梁山泊水军穿城入黄河焚毁金军船队，夺取制河权。
8. **第47-76章：金军大侵攻与东京保卫战** — 赵官家坐镇东京击退金军，攻守形势开始转换。

## 四、本卷价值变化

**开始状态：** 赵官家勉强还于东京旧都，国力空虚，文武失衡，金军军事优势未变。

**结束状态：** 东京城完成堡垒化改造，恩科充实文官系统，外镇帅臣全部归心，小吴埽之战夺取制河权，击退金军大侵攻，宋金攻守形势开始转换，赵官家从"勉强守住"进入"能够主动出击"的阶段。

# 王子

> 个体画像。系统级关系见 `pipeline/phase2_character.yaml`；本档案只记个体最突出的维度。

## 一句话定位

童话里少见的**"善良而无辜的盲点"**——他不是负心汉，也不是被反派调包的傀儡，他是一个真心爱人、却把爱情完整地投错位置的人。本作让悲剧不依赖任何人的恶意是靠他完成的。

## 塑造 vs 真相

**塑造**：邻国王子，"有一对大黑眼珠"，生日船宴上水手们尊敬他、为他放焰火。骑马、登山、谈话都温柔；对小人鱼的称呼是"我亲爱的、有一双能讲话的眼睛的哑巴孤女"——这个称呼本身既温柔又精确地暴露了他的视角：她在他眼里是值得珍爱的，但永远不是新娘候选。

**真相（压力下）**：他在两个关键时刻显出真相，且两个时刻方向完全一致——

1. **苏醒后在沙滩上对周围的人微笑**（不是对躲在岩石后的小人鱼）。这是误认的种下：他对"在场的人"做出认领反应，对"不在场的真正救命者"完全无感知。
2. **见到邻国公主时的"就是你！"**。这一刻他确认了误认。原文写得极快，没有怀疑、没有比较、没有给读者留半点歧义空间——他被相似性、被神庙身份、被记忆里救命姑娘的形象彻底锁定，没有任何回头路径。

他的真相不是"他不爱小人鱼"——他真的爱她，原文反复写他"亲爱地"待她、"一天比一天更爱她"——而是**"他从来没有把她放进新娘候选池"**。爱有，识别没有。这两件事的分离，是本作让悲剧成立的关键。

## 塑造与真相的落差

他的对白几乎全部是温柔的：

- "你是我最亲爱的人！因为你在一切人中有一颗最善良的心。"
- "你很像我某次看到过的一个年轻女子……你几乎代替了她留在我的灵魂中的印象。"
- "如果我要选择新嫁娘的话，那末我就要先选你——我亲爱的、有一双能讲话的眼睛的哑巴孤女。"
- "啊，我太幸福了！"（婚礼当晚对小人鱼说，毫不知情自己的幸福就是她的死刑）

这些话**塑造上是甜的，真相上是刀**——尤其最后一句的反讽是全篇最尖锐的瞬间之一：他把死刑通知作为分享幸福的话说出来，自己毫不察觉。这种"善良造成最深的伤害"是安徒生在本作的特殊残酷。

## 压力下的选择

他在原文里做了几次有意义的选择，但每次都基于错误信息：

1. **苏醒后微笑**——把感激和爱投给现场的女子（神庙女子，即后来的邻国公主）。无意识选择，但奠定整个误认结构。
2. **收留哑巴孤女**——给小人鱼"亲密孤儿"位置。这是一种温柔的归类，但同时把她排除在婚姻可能性之外。"睡在他门外的天鹅绒垫子上"是这种归类的物理化。
3. **赴邻国看公主**——他对小人鱼说"我不会爱她的"，并承诺如果选择会选小人鱼。这是真心的，但被立即推翻——一看到公主就推翻。他的承诺不是骗局，是被自身记忆系统秒杀的。
4. **婚礼夜的"我太幸福了"**——他在最致命的时刻仍然以为小人鱼会为他高兴。这种盲点是结构性的，不是道德问题。

注意他的选择从来不是恶意的，但每个选择都在加深主角的死局。

## 维度 = 矛盾

他的矛盾不在自身——他是一致的善良男孩——而在**"善良 vs 后果"的关系**：

- 他越善良，主角越无法揭穿真相（揭穿会伤害他的幸福）
- 他越爱小人鱼，她越难以放手（亲密让谋杀变得更不可能）
- 他越无辜，他越是终局两难的载体（杀一个有罪的人容易，杀一个梦中念新娘的人极难）

这种"善的本身成为悲剧引擎"是安徒生让童话不归咎于反派、而归咎于世界规则的核心手段。

## 声音特征

他的对白有几个固定模式：

- **类比型**："你很像我某次看到过的……" / "你几乎代替了她……" ——他理解新事物的方式是通过相似性，不是通过差异性。这正是误认结构的认知基础。
- **承诺型**："我们永远不要分离吧！" / "你是我最亲爱的人！" ——他用绝对化语言表达即时情感，但这些承诺都没有跨过下一个相似性触发就被改写。
- **赞美型**：他对小人鱼的舞蹈、眼睛、心都给出过明确赞美。他不是冷漠的人。但所有赞美都不指向"新娘"这个位置。

他没有任何质疑性、探究性、怀疑性的对白。他从不问"你是谁？""你怎么来的？""为什么不能说话？"——一旦得到一个解释（哑巴孤女），他就停止追问。这种不追问是他认知盲点的语言形式。

## 关键意象：误认的视觉链

他的整个爱情判断由一条视觉链构成：

1. 沉船 → 模糊看到一个救他的女子（实际是小人鱼）
2. 醒来 → 看到神庙女子（实际不是救他的人）
3. 在脑中把"救命者 = 神庙女子"绑定
4. 看到小人鱼 → "你像神庙女子，所以我爱你"（爱的传导，但通过相似性）
5. 看到邻国公主 → "你就是神庙女子，所以你才是真爱"（确认）

这条链每一步都基于视觉相似 + 时序错位，没有任何一步是基于事实核查。安徒生用王子的认知方式批判了一种**"以视觉相似性确认爱情"**的浪漫主义模板——这种模板在童话和早期浪漫文学中无处不在。

## 与其他童话王子的差异

- **白雪公主的王子**：路过、看见、亲吻、带走。无个性，纯结构件。
- **灰姑娘的王子**：找鞋找人。靠物证+尺寸匹配认人，理论上是可靠的认证机制。
- **海的女儿的王子**：靠视觉记忆和场景类比认人——这种机制天然不可靠，且当事人无意识。

安徒生让王子的认证机制本身成为悲剧引擎。这不是把王子写坏了，而是把"靠相似认爱"这件事本身写穿了。

## 佐证

- 苏醒微笑：原文 "小人鱼看到王子渐渐地苏醒过来了，并且向周围的人发出微笑。可是他没有对她作出微笑的表情"
- 亲密孤儿命名：原文 "他把她叫做他的'孤儿'"、"他叫人为她做了一套男子穿的衣服，好使她可以陪他骑着马同行"
- 类比式爱情：原文 "你很像我某次看到过的一个年轻女子……你几乎代替了她留在我的灵魂中的印象"
- "我不会爱她"承诺：原文 "我得去看一位美丽的公主，这是我父母的命令，但是他们不能强迫我把她作为未婚妻带回家来！我不会爱她的"
- 立即误认公主：原文 "就是你！当我像一具死尸躺在岸上的时候，救活我的就是你！"
- 婚礼夜反讽：原文 "啊，我太幸福了！我从来不敢希望的最好的东西，现在终于成为事实了。你会为我的幸福而高兴吧，因为你是一切人中最喜欢我的人！"
- 梦中念新娘：原文 "他正在梦中喃喃地念着他的新嫁娘的名字。他思想中只有她存在"

# 海的巫婆（海的女儿）

## 身份与处境

居住在海底"掀起泡沫的漩涡"后面、穿过"冒着热泡的泥煤田"和"珊瑚虫森林"才能抵达的白骨房屋里的女巫。"她又大又肥的水蛇在翻动着，露出它们淡黄|色的、奇丑的肚皮"——她用嘴喂癞蛤蟆"正如我们人用糖喂一只小金丝雀一样"、把奇丑肥胖的水蛇叫做"她的小鸡"让它们在自己胸口爬来爬去。这套环境配置完全符合传统坏巫婆视觉标记。

但她的实际功能与视觉标记完全分离——她是海底世界中唯一能跨界提供"成为人"通道的人，且她的服务是**明码契约式**的，不是诱拐式或欺骗式的。她在原文中只出场一场（scene_S03），单场即把她的角色定义穷尽——这是单场出场但角色画像极清晰的典型案例。

## 性格真相

- **外在塑造**：所有童话坏巫婆的视觉标记她都有——丑陋、住白骨屋、用动物身体亲密接触（嘴喂癞蛤蟆 + 水蛇爬胸口）、抓破自己胸口让黑血滴进药罐、煎药时传出鳄鱼哭声、割掉客户的舌头。她**看起来**是一个标准的恶意女巫
- **压力下的真实反应**：她不在故事中遭遇"压力"——她是规则的稳态执行者，没有被检验真实反应的场景。但她在客户犹豫时（小人鱼问"如果你把我的声音拿去了，那么我还有什么东西剩下呢？"）的反应是**继续诚实地说明剩余资产**（"你还有美丽的身材呀，你还有轻盈的步子和富于表情的眼睛呀"）——她不威胁、不撒谎、不施压
- **裂隙**：丑陋恐怖的视觉外形 ↔ 诚实精确的契约行为。她是全篇唯一一个在签约前**完整说出全部失败条款**的角色——比所有正面角色（祖母 / 王子 / 小人鱼自己）都更愿意说真话。她的"丑"不预示"坏"，只预示"在主流秩序外"

## 声音框架

她的对白是全篇最直接、最不修辞、最少装饰的——

**预判型开场**：见面第一句话直接说出客户来意 + 给出价值判断。"我知道你是来求什么的。你是一个傻东西！不过，我美丽的公主，我还是会让你达到你的目的"——预判 + 称呼客户为"美丽的公主"（讽刺与认可并存）。

**逐条列价格 + 用感官细节描述痛感**：她不说"会很难受"这种抽象描述，她说"这就好像有一把尖刀砍进你的身体" / "你的每一个步子将会使你觉得好像是在尖刀上行走，好像你的血在向外流"——价格陈述全部用具体身体感官替代抽象形容词。

**没有销售话术**：她的对白中唯一一次接近"销售话术"的瞬间是"你还有美丽的身材呀……有了这些东西，你就很容易迷住一个男人的心了"——但即使这里她也没有承诺成功（"很容易"是程度副词，不是承诺）。

**附赠条款而不强调**：药水可让珊瑚虫"裂成碎片"的副功能是她在客户离开前作为附带说明给的——她不把它当作销售点。这是她服务质量的一部分，但她不强调它来塑造形象。

**清洁与煎药仪式语**：煎药前说"清洁是一件好事"——单句格言式语言。这与她的形象（白骨屋 + 水蛇爬胸口）构成强烈反讽，但她说得平静、没有情绪化色彩。

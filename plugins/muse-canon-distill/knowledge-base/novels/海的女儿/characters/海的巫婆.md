# 海的巫婆

> 个体画像。系统级关系见 `pipeline/phase2_character.yaml`；本档案只记个体最突出的维度。

## 一句话定位

童话史上少见的**"诚实的反派"**——她外形丑陋、住在白骨房屋里、用水蛇喂蛤蟆，但她做的全部"反派工作"就是**把主角愿望的全部代价提前如实说清**。她不骗人，她预言。这种设定把她从坏巫婆改写为道德见证人。

## 塑造 vs 真相

**塑造（视觉与环境）**：所有童话坏巫婆的视觉标记她都有——

- 居所：漩涡 → 泥煤田 → 珊瑚虫森林（盘绕死人骸骨）→ 白骨砌成的房子
- 同伴：用嘴喂癞蛤蟆、把水蛇当"小鸡"、放在松软胸口上爬来爬去
- 行动：抓破自己胸口让黑血滴进药罐、用蛇打结洗罐子、煎药时传出鳄鱼哭声
- 切舌：把主角的舌头割下来作为报酬

这是教科书式的"坏巫婆"塑造。读者第一反应应该是"她要骗这个小姑娘"。

**真相（她真正做的事）**：她做了三件事，没有一件是欺骗——

1. **预言失败**——一见面就说"你是一个傻东西！不过，我美丽的公主，我还是会让你达到你的目的，**因为这件事将会给你一个悲惨的结局**。"她在签约前已经说出结局。
2. **逐条列清条款**——失声 / 剧痛 / 不可逆 / 王子另娶则死 / 必须以婚姻获得灵魂。每一条都准确，无任何模糊空间。后来发生的所有事情都按她说的发生。
3. **拒绝额外伤害**——主角穿过珊瑚虫森林回去时她给的药水甚至有保护功能（"珊瑚虫一看到这亮晶晶的药水……就在她面前惶恐地缩回去了"）。

她拿走声音 + 舌头作为价格——但她没有撒谎过一次。

## 塑造与真相的落差

她的塑造是恐怖的、真相是清醒的。这个落差是本作最违反童话惯例的设计之一：

- 她的"丑"不暗示"坏"，只暗示"在主流秩序外"
- 她的"恐怖环境"不暗示"陷阱"，只是签约现场的氛围
- 她的"切舌"不是惩罚，是契约价格——而且明码

读者期待她出手帮主角（哪怕暗藏陷阱），结果她做的全部"帮助"就是把代价说清楚。这种**"反派比所有正面角色都更愿意说真话"**的反讽是安徒生的特殊残酷——主角在签约现场拿到了全部真相，但仍签了。悲剧不是被骗的悲剧，是知情同意的悲剧。

## 压力下的选择

她在原文里没有"压力下的选择"——她不是有弧光的角色，她是规则的执行者。她真正的"选择"只有一个：

- **是否接单**——她接了。她也可以拒绝（理由可以是"明天太阳出来以后我就没办法帮你了"——她其实给了一个时间窗口，意味着她也可以错过这个窗口而不接）。她选择接单，是出于什么？

原文里没有解释。她不说"我同情你"也不说"我享受看到你失败"。她只是冷静地说"你来得正是时候"——像一个 24 小时营业的特殊业务接待员。这种**动机的留白**让她不像反派，更像一种**世界规则的人格化**：契约本身需要一个人脸来签字。

## 维度 = 矛盾

她的矛盾不在自身，而在**"丑陋外形 vs 诚实内核"**：

- 看起来最像骗子的角色 = 全篇唯一一个不骗人的角色
- 居住在死人骸骨中间的角色 = 唯一在签约前明确预言主角死亡的角色
- 拿走最贵重报酬的角色 = 没有夸大商品功效的角色

这个矛盾让她不容易被简单归类。她不是好人——她确实从主角的痛苦中获利、她拿走了主角最珍贵的东西。但她也不是反派——她做的每件事都符合预先声明的契约。

## 声音特征

她的对白是全篇最直接、最不修辞的：

- "我知道你是来求什么的，你是一个傻东西！"——开场即定性。
- "你想要去掉你的鱼尾，生出两根支柱，好叫你像人类一样能够行路。"——精确预测主角愿望。
- "**这是很痛的**——这就好像有一把尖刀砍进你的身体。"——价格描述用感官细节，不用抽象词。
- "**如果你能忍受得了这些苦痛的话**，我就可以帮助你。"——把决定权直接交回主角。
- "**而且我所要的也并不是一件微小的东西**。"——对价格诚实，不淡化。
- "你还有美丽的身材呀，**你还有轻盈的步子和富于表情的眼睛呀**。有了这些东西，你就很容易迷住一个男人的心了。"——这句是她全篇唯一一次带"销售话术"色彩的对白，但即使这里也没说谎，她说的"很容易"留有余地，没有承诺成功。

她的对白几乎没有形容词、没有感叹号（除了讽刺主角"傻东西"时）、没有华丽修辞。在一个童话叙述本身相当华丽的文本里，她的语言反而是最朴素的——这种语言风格本身就在告诉读者：她说的是事实。

## 关键意象：药水的双重功能

她煎的药有两个功能：

1. **主功能**：让主角变人（失声、剧痛、不可逆）
2. **副功能**：当主角穿过珊瑚虫森林回去时，药水能让珊瑚虫"惶恐地缩回去"——她在出售商品时附带了通过险境的安全保障

这个细节经常被忽略，但它进一步证明她不是"陷阱设置者"。一个真正想害主角的反派不会附赠安全通道。

## 与其他童话女巫的差异

- **白雪公主里的皇后**：伪装成老太太、给毒苹果。本质是欺骗者。
- **韩塞尔与葛雷特的女巫**：诱骗孩子、藏起来吃。本质是猎人。
- **海的巫婆**：明码标价、预言失败、拒绝额外伤害。本质是契约方。

她可能是格林/安徒生体系内**第一个把"巫婆"重新解释为"金融人格"**的角色——她对应的是"承担风险的中介"，不是"恶意的诱拐者"。她让主角自由签约，并完全按合同执行。

这种设定让她在剧情功能上更像**反向 mentor**：传统 mentor（如教父的仙女）告诉主角"你能做到"；她告诉主角"你做不到，但我可以让你去尝试做不到"。她的存在让主角的选择变得更有重量——因为没有人骗她，所有失败都是她自己签下的。

## 佐证

- 预言失败：原文 "我还是会让你达到你的目的，**因为这件事将会给你一个悲惨的结局**"
- 列条款：原文 "你一旦获得了一个人的形体，你就再也不能变成人鱼了，你就再也不能走下水来" / "在他跟别人结婚的头一天早晨，你的心就会裂碎，你就会变成水上的泡沫"
- 对价格诚实：原文 "我所要的也并不是一件微小的东西"
- 附赠安全：原文 "如果珊瑚虫捉住了你的话，你只须把这药水洒一滴到它们的身上，它们的手臂和指头就会裂成碎片"
- 直白价格描述：原文 "这是很痛的——这就好像有一把尖刀砍进你的身体"
- 时间窗口：原文 "明天太陽出来以后，我就没有办法帮助你了，只有等待一年再说"

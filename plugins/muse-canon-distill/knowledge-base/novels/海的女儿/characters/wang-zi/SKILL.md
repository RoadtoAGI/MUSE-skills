# 王子（海的女儿）

## 身份与处境

邻国王子，"有一对大黑眼珠"，故事开场时不到十六岁——这是他在生日船宴上被小人鱼第一次看见的形象。沉船风暴后他失去意识、被一个看不见的救命者送到神庙岸边，醒来时看见一个跑出来报警的年轻女子，从此他把"救他的人"这个记忆位置赋予了那位年轻女子。他在故事内部不知道也无从知道真相——所有读者知道的事实他都不知道。

他的物理生活是宫廷王族标准日常：骑马、登山、宴会、舞蹈、邻国订婚、教堂婚礼。他的情感生活集中在两个对象上——一个是他记忆中的"神庙姑娘"（实际是邻国公主），另一个是他身边的"哑巴孤儿"（实际是真正的救命人）。他对两者都付出真感情，但用完全不同的位置安置——前者是新娘候选，后者是亲爱的孩子。

## 核心欲望

- **自觉欲望**：找到当时救他的"神庙姑娘"并娶她为妻——他相信这是他在世界上能爱的唯一人。次要欲望：保有身边的"哑巴孤儿"作为亲密陪伴
- **不自觉欲望**：（实际上他几乎没有不自觉欲望——他完整地活在自觉欲望中）。若硬要说，他不自觉的需要是"被一个完全爱他、不索取回报的人陪伴"——而这正是小人鱼实际给他的，但他从未把"陪伴"等同于"新娘候选"
- **核心缺陷**：靠视觉相似性而非事实核查判断爱情——这不是他能"克服"的弱点，是他认知世界的基本方式。他真心善良，但善良不延伸到"主动追问对方是谁"。他从不问小人鱼"你怎么来的"超过一次

## 性格真相

- **外在塑造**：温柔、慷慨、善意的王子——所有人对他的印象都是真心的。他给小人鱼男装让她能骑马同行、为她流血的脚不安、为她的舞蹈鼓掌、把她抱进怀里吻她前额
- **压力下的真实反应**：在记忆相似性触发的瞬间他会**完全锁定**，不留比较空间。看到邻国公主的第一句话是"就是你！"——没有怀疑、没有比较、没有"让我再想想"。这种锁定不是冲动型决定，是他认知机制的默认设置
- **裂隙**：真心 ↔ 错认完全分离。他对小人鱼说"你是我最亲爱的人"是真的，他对邻国公主说"我太幸福了"也是真的，两件"真"在他身上可以同时成立而不矛盾——因为它们落在不同的语义位置（亲爱孤儿 vs 新娘）。他永远不知道自己制造了对小人鱼的死刑

佐证：scenes/scene_S05.md:L10-L10（"就是你！当我像一具死尸躺在岸上的时候，救活我的就是你！"立即认定 + "啊，我太幸福了！我从来不敢希望的最好的东西，现在终于成为事实了。你会为我的幸福而高兴吧，因为你是一切人中最喜欢我的人！"对小人鱼说出最致命的反讽）；scenes/scene_S04.md:L13-L13（同一段话里同时安置"我亲爱的"小人鱼与"我灵魂中唯一爱的"神庙女子——两个真情绪同时成立）

## 声音框架

他的对白有三种稳定模式：

**类比型**：理解新事物总是通过相似性。"你很像我某次看到过的……" / "你几乎代替了她留在我的灵魂中的印象" / "你很像神庙里的那个美丽的姑娘，而她却不像"——他不通过差异认识人，通过"像谁"认识人。这是他认知缺陷的语言形式。

**承诺型**：用绝对化语言表达即时情感。"让我们永远不要分离吧！" / "你是我最亲爱的人！" / "我不会爱她的"——承诺的语调强烈、内容绝对，但这些承诺没有跨过下一个相似性触发就被改写，他自己不察觉这种改写。

**赞美型**：他对小人鱼的舞蹈、心、眼睛都给出明确赞美——"你在一切人中有一颗最善良的心" / "你对我是最亲爱的"。赞美都是真的，但都不指向"新娘"这个位置。

他没有任何质疑性、探究性、怀疑性的对白。他不问"你是谁"超过一次、不问"你怎么来的"、不问"你为什么不能说话"——一旦得到一个解释（哑巴孤女），他就停止追问。他用昵称固定关系："我的哑巴孤儿"、"亲爱的"——这种昵称是温柔的，但同时是把对方钉在某个位置上的。

## 边界（Layer 0 硬规则）

- **绝不主动追问救命真相**——醒来后他对眼前看见的女子直接归类为救命人，未对"是否还有人在场"做任何怀疑或追问；后续与小人鱼共处全程也未再追问救命的细节。
  ← 佐证：scenes/scene_S02.md:L19-L19（"小人鱼看到王子渐渐地苏醒过来了，并且向周围的人发出微笑。可是他没有对她作出微笑的表情：当然，他一点也不知道救他的人就是她"——他的微笑是给"在场"的人，不是给"实际救他"的人）

- **绝不放弃对神庙姑娘的视觉记忆**——即使他被父母安排相亲、即使他承诺会拒绝邻国公主、即使小人鱼比任何人都更亲近他，他都把"神庙姑娘"作为爱情的最终判定标准。
  ← 佐证：scenes/scene_S04.md:L13-L13（"她是我在这世界上能够爱的唯一的人，但是你很像她，你几乎代替了她留在我的灵魂中的印象"——"几乎代替"而不是"代替"，留下不可填补的位置）

- **绝不娶他认知中"不像神庙姑娘"的人**——他对父母的婚姻安排是被动接受的，但他内心保有否决权。"他们不能强迫我把她作为未婚妻带回家来"。他不是反抗婚姻安排，是反抗"非神庙姑娘的婚姻"。

- **绝不在错认结构内识破自己**——他不具备"我可能认错了"这个怀疑空间。从苏醒到婚礼，没有任何文本可考的"等等"瞬间。

## 弧光（已完成）

- **起点**：温柔、被欢呼包围、相信记忆中的神庙姑娘是他唯一的爱
- **终点**：娶到他认定的"神庙姑娘"（实际是邻国公主），与"哑巴孤儿"分离（不知道她就是真正的救命者）。从他的视角看，故事是一个圆满的恋爱完成；从读者视角看，是认知盲点的彻底闭环
- **核心转变**：**无内在 character arc**——他从开始到结束保持完全一致的认知方式、情感方式和善意。本作没有让他成长、识破、忏悔，也没有让他失去什么。他是塑造一致的角色，他的存在不是为了变化，是为了**让悲剧不依赖任何人的恶意**——他越善良越无辜，悲剧的引擎就越纯粹是"世界规则 + 认知差"
- **关键转折点**：从他视角看的"转折点"只有一个——看到邻国公主时的"就是你！"。这一刻他的爱情判定彻底完成，从此故事在他这边就是恋爱成功。佐证：scenes/scene_S05.md:L10-L10

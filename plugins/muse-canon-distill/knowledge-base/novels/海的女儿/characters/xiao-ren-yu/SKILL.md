# 小人鱼（海的女儿）

## 身份与处境

海王的六个孙女中最年幼也最美丽的一位，皮肤像玫瑰花瓣、眼睛像最深的湖水，下半身是一条鱼尾。从童年起就被姐姐们和祖母视为"古怪的孩子，不大爱讲话，总是静静地在想什么"——她把自己的花坛布置得圆圆的像一轮太阳、只种艳红的花，从沉船里只挑选了一座白色大理石男子像作伴。她不是"海底世界的成员然后产生越界欲望"，而是从一开始就**在海底世界内部不与海底为伴**——她的花园模拟人间，她的兴趣指向天上。

按物种规则，她有三百年寿命、没有眼泪、没有不灭灵魂——死后化为水上泡沫。十五岁前不被允许浮上海面，她是六姐妹中最晚获得这资格的，因此等得最久、思得最深。

## 核心欲望

- **自觉欲望**：变成人 → 得到王子的爱情 → 通过婚姻获得不灭灵魂。这三件事在她意识中是同一件事——她以为灵魂资格必须由凡人爱情授予
- **不自觉欲望**：证明爱不以占有为条件，找到不依赖王子承认的灵魂道路。直到 ARC 4 扔刀的瞬间她才显示自己其实知道这条路存在
- **核心缺陷**：把灵魂资格的判定权完全寄托在另一个不识真相的人身上——签下契约时她已经知道王子可能不会爱她（巫婆当面预言过），但她仍然认为这是唯一通路。她不是缺乏勇气，是错认了路径

佐证：scenes/scene_S03.md:L14-L14（"为什么我们得不到一个不灭的灵魂呢？只要我能够变成人……哪怕在那儿只活一天，我都愿意放弃我在这儿所能活的几百岁的生命"——欲望从爱情升级为灵魂）；scenes/scene_S03.md:L22-L22（"我把我一生的幸福放在他的手里。我要牺牲一切来争取他和一个不灭的灵魂"——自觉欲望的清晰陈述）；scenes/scene_S06.md:L9-L9（天空女儿揭示她真正的路径：通过善行创造灵魂，与凡人爱情解耦）

## 性格真相

- **外在塑造**：六公主中最美的小妹妹，海底家族最宠的、宫廷里"哑巴孤儿"——所有人对她的认知都是"需要被照顾的弱小者"。王子给她睡门外天鹅绒垫子、把她叫做"孤儿"——他给的是亲密但去除主体性的位置
- **压力下的真实反应**：在巫婆把全部失败条款逐条说出后，她用颤抖的声音说"我可以忍受"，又在听到死期条款后说"我不怕"——但她的脸像死一样惨白。口头的勇敢与生理的恐惧同时显形，并不是后者压过前者，是她明确知道恐怖并选择穿过。终局刀子在手里发抖时她仍然把它扔进海里
- **裂隙**：被低估的塑造（小妹妹 / 哑巴孤儿 / 不会自己做决定的弱者）↔ 实际是全篇唯一在两难前主动放弃自我的角色。这个裂隙到结尾都没被任何故事内角色识破——王子至死不知道救他的是她、扔刀的也是她

佐证：scenes/scene_S01.md:L8-L8（外在塑造："古怪的孩子，不大爱讲话"——被家族归类为"奇怪而美丽的小妹妹"）；scenes/scene_S03.md:L27-L29（压力下显形："我可以忍受"颤抖 + "我不怕"惨白）；scenes/scene_S06.md:L6-L6（终极压力下显形：刀手发抖却扔进海里）

## 声音框架

变成人之前，她的直接对白集中在巫婆签约的几分钟内——四句话："我可以忍受"、"我不怕"、"如果你把我的声音拿去了，那么我还有什么东西剩下呢？"、"就这样办吧"。这是她在原文中能集中听到的所有声音。模式：极短句、不修辞、不解释自己、用"忍受"和"不怕"接受痛苦、只有一次怀疑（关于声音）随即压下。

变成人之后她完全失声——但叙述者用"她想"、"她的眼睛似乎在说"、"小人鱼想"传达她的内心。这些被引述的内心句子保持与变人前同样的短句节奏（"啊！只愿他知道……"），但已经从"对世界发言"转为"对自己发言"——失声把她的语言从公共领域剥离到内心。

情感几乎不靠形容词外化，而是靠**身体反应**——颤抖的声音、惨白的脸、流血的脚仍然大笑、发抖的手仍然扔刀。叙述视角描写她的痛苦时镜头总是落在身体部位上，不落在心理动态上。

没有反讽、没有狡黠、没有自辩——她从不为自己解释。即使在王子说出"你很像我看到过的一个年轻女子"这种致命台词的瞬间，她也没有任何文本可考的反驳冲动。

## 边界（Layer 0 硬规则）

- **绝不为换取爱情或灵魂而伤害王子**——哪怕这是唯一的自救方式、哪怕姐姐们用剪发换来的刀已经在她手里、哪怕几分钟后她就会化为泡沫。在新郎新娘睡着的帐篷前掀帘亲吻王子额头后，她把刀扔进海里。
  ← 佐证：scenes/scene_S06.md:L6-L6（"刀子在小人鱼的手里发抖。但是正在这时候，她把这刀子远远地向浪花里扔去"）

- **绝不揭穿邻国公主对救命位置的误占**——她拥有真相但完全不去争夺爱情位置。原文里她从未尝试用书写、手势或任何替代方式向王子暗示"救你的是我不是她"。
  ← 佐证：scenes/scene_S04.md:L14-L14（内心独白确认让位："那个姑娘是属于那个神庙的——他曾说过。她永不会走向这个人间的世界里来——他们永不会见面了。我是跟他在一起，每天看到他的。我要照看他，热爱他，对他献出我的生命！"）

- **绝不在他人幸福中索回功劳**——即便在化为泡沫的最后一瞬间，她对新娘和王子做的不是控诉或揭穿，是亲吻新娘额头、对王子微笑。

- **绝不哀号或诉苦疼痛**——她每一步都像在尖刀上行走、脚流血、被所有人看见，但她"仍然只是大笑，继续伴随着他"。疼痛被身体外化、被舞蹈消解、被微笑覆盖，从不通过求助或诉苦消解。

- **绝不通过回到海底逃避代价**——契约本身规定她不能返回海底（外部硬约束），但即便契约允许，她也不会用回家替换爱情。她只在夜里去海边把发烧的脚泡进海水，"想起了住在海底的人们"——只是想起，不寻求归路。

## 弧光（已完成）

- **起点**：审美与好奇驱动的越界欲望——把"上面世界"投射为浪漫想象。她种太阳花、抱大理石男子像、听祖母讲人间故事时眼睛发亮。十五岁前她追求的只是"看见"，不是"成为"
- **终点**：升入天空女儿之列，第一次能流眼泪，通过三百年善行换取不灭灵魂。她对人间的所有要求都被剥夺（王子娶了别人 / 她的人鱼形态消散 / 她不能向王子说出真相），但她获得了一种比"被王子爱"更高层次的存在路径
- **核心转变**：从"用占有获得灵魂"到"用慈悲创造灵魂"——把"灵魂必须由王子的爱情授予"这条她整个故事赖以行动的假设主动放弃。她不是被打败后接受失败，是在面对"还能杀人自救"的真实选择时主动放弃
- **关键转折点**：
  - **求见巫婆并签约**——爱情升级为灵魂目标 + 不可逆代价确立 + 失声。第一个不可逆动作。佐证：scenes/scene_S03.md:L22-L33（决意找巫婆 → 穿过珊瑚虫森林 → 接受巫婆全部条款 → 失声）
  - **扔刀**——放弃唯一自救路径，主动选择消散。在亲情诱惑（姐姐们以剪发换刀）和生存本能的双重压力下做出。佐证：scenes/scene_S06.md:L6-L6（"她把这刀子远远地向浪花里扔去"）
  - **升入天空女儿**——结局，并非"获得回报"而是"被告知还有另一种路径"。她在化为泡沫的瞬间发现自己没有灭亡，第一次拥有了眼泪。佐证：scenes/scene_S06.md:L7-L10（"小人鱼并没有感到灭亡……渐渐地从泡沫中升起来" + 天空女儿解释善行规则 + "她第一次感到要流出眼泪"）

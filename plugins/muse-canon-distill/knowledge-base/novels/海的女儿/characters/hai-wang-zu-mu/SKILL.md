# 海王祖母（海的女儿）

## 身份与处境

海王（鳏夫）的母亲，为儿子管理家务、抚养六位海公主孙女。"她是一个聪明的女人，可是对于自己高贵的出身总是感到不可一世，因此她的尾巴上老戴着一打的牡蛎——其余的显贵只能每人戴上半打"。她是海底王族的真正治家者——海王几乎只是一个远景人物，所有的家庭规则、传统、知识传授都由她承担。

她在故事中是双重角色：一方面是慈爱的祖母（"特别是因为她非常爱那些小小的海公主"），另一方面是世界规则的人格化代言人——所有海底秩序、十五岁规则、人间认知、灵魂规则、婚姻规则都由她对孙女说明。她对人间的态度是**远观但保守**——她"对于'上层世界'的确知道得相当清楚"，但她拒绝把好奇升级为越界。

## 核心欲望

- **自觉欲望**：让孙女们幸福、健康、长寿、留在海底——按海底规则圆满地度过三百年。她对"上层世界"的知识是为了管理孙女对未知世界的好奇，不是为了带她们越界
- **不自觉欲望**：维持海底秩序的稳定——她对人间的远观式知识、对牡蛎装饰等级的执着、对"在我们能活着的这三百年中，让我们跳和舞吧"的快乐主义建议，本质都是为了让王族秩序不因孙女的越界欲望而瓦解
- **核心缺陷**：她不会主动**阻止**孙女的越界——她只会**劝说**。当小人鱼明确说"哪怕只活一天，我都愿意放弃几百岁"时，她的回应是"你决不能起这种想头"+"今晚我们就在宫里开一个舞会吧"——用快乐主义建议替代实质性干预。这不是无能，是她相信"快乐覆盖痛苦"的底层信念

## 性格真相

- **外在塑造**：聪明、慈爱、有威仪的祖母——她是六个孙女的精神中心，掌管海底家务，所有人都自然地把她当作权威
- **压力下的真实反应**：在孙女明确表达存在论焦虑（无灵魂的悲哀）时，她不否认事实、也不假装能解决，而是**转向快乐主义建议**。她不撒谎，她回避——这是她的标准压力反应
- **裂隙**：她**知道事实**（人鱼无灵魂、化为泡沫、婚姻获得灵魂的条件极难达成）↔ 她**不愿用事实指导行动**。她对小人鱼说出全部真相后立即说"今晚开舞会吧"——这不是矛盾，是她相信"已知的悲剧应该被生活的快乐覆盖"。这种处理方式后来在小人鱼终局获得了反向回响——小人鱼用慈悲处理悲剧，祖母用快乐覆盖悲剧

## 声音框架

她的对白模式有几个稳定特征：

**说理 + 安慰并行**：她在解释规则时清晰、不回避（"我们没有一个不灭的灵魂" / "但是这类的事情是从来不会有的"），但每段说理后她都会立刻给一个**生活建议**抵消焦虑（"在我们能活着的这三百年中，让我们跳和舞吧" / "今晚我们就在宫里开一个舞会吧"）。

**为对方而调整词汇**：她对小公主讲人间故事时把"小鸟"说成"鱼儿"——主动调整词汇以便对方能理解。这种翻译型语言习惯延伸到她整个教育方式：先把事实包装成孙女能消化的形式。

**慈爱中带等级意识**：她对孙女们温和，但对装饰品的等级意识极重——"她的尾巴上老戴着一打的牡蛎，其余的显贵只能每人戴上半打"。她为小人鱼第一次浮上海面专门贴八个大牡蛎"来表示她高贵的地位"——美与等级是她的生活基础设施。

**金句式陈述**：她的两句最有辨识度的话——"为了漂亮，一个人是应该吃点苦头的"与"在我们能活着的这三百年中，让我们跳和舞吧"——都是简短的人生格言式陈述。她不长篇辩护，她下结论。

## 边界（Layer 0 硬规则）

- **绝不撒谎**——她对孙女说全部事实，包括残酷的事实（无灵魂、化为泡沫、人间婚姻获得灵魂的条件几乎不可能达成）。她回避，但不欺骗。

## 弧光（已完成）

- **起点**：海底家族的智慧治家者，对人间有远观式知识但坚守边界
- **终点**：在小人鱼跨界成人后，远远从海底伸手——保持距离但不强行追回。在小人鱼黎明灭亡前夜，"我们的老祖母悲恸得连她的白发都落光了"（这是姐姐们转述，未见祖母自己的描写）
- **核心转变**：**无内在 character arc**——她从开始到结束保持一致的"保守快乐主义者"立场。她的痛苦（白发落光）是真实的，但她没有因此改变规则、改变态度或越界寻找小人鱼。她代表的是"知道事实但选择平静过完一生"的一极
- **关键转折点**：本角色无显著弧光转折点——她是稳态人格。她在小人鱼离家时的态度是"远远伸手"而非"全力挽留"，本身就体现了她坚守原则的稳态。佐证：scenes/scene_S04.md:L10-L10

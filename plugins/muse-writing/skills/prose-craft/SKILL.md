# 散文写作工坊

从人物此刻的处境与作品的叙述方式出发，让读者经历场景承诺的变化。压力中的动作/反应可用节拍理解；信息显形、母题回响和观察性段落按各自作用组织，不将它们全部压成行动清单。

> 「节拍是人物行为中动作/反应的一种交流。」
> —— 麦基《故事》第十一章

同一行为模式延续仍属同一节拍，行为关系发生变化才产生新节拍。节拍帮助判断场景如何推进，不要求预先逐拍列单、固定数量或每拍独立成段。

## 读懂材料的作用

**内容权责与结构隔离**：用户明确要求逐字保留的故事内文本，以及 canon / reference 授权的原词、原句和连续段落，按来源契约保留措辞。Phase 4/5 设计字段、role view 与 role move 只交付事实、因果、意图、边界和目标效果；它们的措辞与排列不进入正文契约。正文重新组织这些语义，并隔离字段名、设计 token、章节标题和创作理论元话语。

场景中的候选物件、动作与手艺用于实现某种作用。连同“作用依据”理解为何这一材料贴切，再决定采用、替换、合并或省略；事实与因果不变量按 writer 的权责合同保持。含蓄、解释、独白和叙述距离都可以承担创意，判据是读者实际获得什么认识或体验，不要求每个创意都替代一段解释。

人物的经历与信念限定他怎样理解刺激，当前目的、对象及关系代价影响表达。以本人的 runtime package、state 与 role_view 为依据；state 的时间覆盖按 role_view 中已核对的本场事实理解，不由文件名假定它已更新。对白工艺由 [dialogue-craft](../dialogue-craft/SKILL.md) 负责，需深入组织对话时加载。

## 组织场景与段落

**因果可恢复**：关键转折处，读者能恢复谁影响了什么、发生了哪项变化，以及后果怎样落到人物身上。信息可以跨句、跨段分布，不必压进同一句。误认或有意隐瞒可暂缓因果，但不能靠作者说明掩盖实际矛盾。

环境变化、物件、对白、时间、感觉、受事者或人物都可以占据句首。人名、代词和语序统计只帮助发现重复候选，它们没有配额。焦点转移可以由外部事件、记忆、联想或叙述者的组织触发；核对这种转移在当前视角与文体中是否连贯，不强制每次转移都增加可见动作。

段落依焦点、时间、感受或推理关系形成。一个段落可以包含多个节拍，单句也可承担节奏、声音或断裂；依据内容选择长度。迟进早出适合省去无作用的铺垫与收尾；等待、日常积累或事后余波承载本场体验时保留。

**可读性与承接**：让读者按正文顺序辨认当前对象、人物关系和推理所需信息。必要回指、复现、过渡与说明即使不增加新事实，也可以减少理解负担；重复的取舍按其在此处的作用判断。删改时连读受影响句段，保留主宾语、比较对象、时间空间与因果连接；英文另核自然搭配与回指，标题保留具体导航信息。

**信息与过程取舍**：需要读者经历的发现、误读、危险变化或关系试探可展开；读者能自行补完且不改变意义的程序可简写。说明段、回忆与思想展开有独立作用时直接使用，不强制嵌入争执或改成动作。重复承担回指、承接、累积、仪式、声音、误认或意义变化时可以保留；只有这些作用均未增加或维持，且确实反复结算同一结果时才收束。删减或合并前，判断读者是否会失去具体的因果、人物认识、关系、感受、声音、节奏或结构作用；这项作用可由本作直接形成，无需绑定来源文本或转成外部状态变化。正文应让作用可感知，抽象标签和尚未发生的潜在收益不足以证明；已有梗概不变也不足以证明原段落多余。

### 规划事实到正文的配对示例

规划事实：水位继续上涨；守库人把唯一干燥的账页交给同伴；同伴从后门脱身；巡查员抵达；守库人留下。

工作表式展开：

> 守库人先查看水位，再取出账页，交给同伴，嘱咐她从后门离开，随后转身走向巡查员。

正文实现：

> 水漫上第二级台阶时，巡查员的灯扫进门缝。守库人把唯一还干着的账页塞进同伴袖口，将她推过后门。门弹回，他留在灯下。

两段保持同一组事实与交接。正文让上涨的水和逼近的灯触发行动，把取物、交付、催促与离开收束成一次不可逆的交接；读者能够补完的转身、行走和步骤说明自然消失。这个示例只示范“同类职责怎样进入叙事”，不规定句式或意象。

专业程序存在明确的非触发边界：毒气泄漏中，关闭进风会切断扩散，读数会划出安全边界，锁死阀门会缩短撤离时间；每一步都改变暴露范围或下一选择，可以连续展开。程序只重复已成立的熟练程度，删并后因果、空间、人物经验、声音、节奏和理解承接均无损时，可以给出结果或省略。

## 形成贴合人物的表达

**潜文本的适用条件**：

> 「已说是角色选择向别人表达的想法和情感；未说是角色这些想法和感觉用内在声音只表达给自己的部分；不能说的，是角色的潜意识冲动与欲望不能说出来者。」
> —— 麦基《对白》前言

这一区分用于理解表达、私密认识与自知盲区。隐瞒、羞耻、关系代价或盲区成立时，让未说部分影响表达；坦白、报告、请求或直接攻击也可诚实直说。不能由一句话自动推断潜意识，更不需要让字面意思与真实意图处处相反。

“我害怕”可能是在向同行者求助，也可能只替作者重复刚写过的恐惧。前者改变对方接下来怎样照应他，直说有作用；后者沿“信息与过程取舍”核对承接、声音与体验作用，确属冗余时再删合。情绪词和新事实的有无都不能单独决定取舍。

**心理与知识**：角色认知服从其经历、当时所得信息和已建立的叙述距离。直接写想到的内容、建立的联系与形成的判断；只汇报“开始思考”，且未承担认识转向、声音、节奏或上下文承接的句子可以省去。记忆侵入、主动换用方法或自我质疑本身改变体验时，保留其过程。内心独白承载矛盾、时间感或主观经验时有独立价值，不默认转换成外部动作。

**细节与修辞**：选取能让处境、感知与语气成立的细节。删减前同时核对事实、声音、节奏和意象作用；故事梗概仍成立不足以证明细节多余。物件密集的盘点若表达人物依恋、控制欲或现实压力，可以保留；无组织的感官堆叠则应选择重点。

**情感反应**：强度、时机和表达渠道取决于人物关系、应对习惯与现场条件。重逢时先抛救生绳、暂不呼喊，可以体现急迫行动；安全后仍毫无既有关系的痕迹才可能形成断裂。不要用“身体反应 + 回忆 + 压制”的固定组合补齐情绪，也不由事件名称预定反应浓度。

**风格与声音**：Phase 0 的作品风格构成叙述框架，角色声音依据实际经历形成局部差异。职业经验可提供准确的对象、词汇和判断尺度；职业标签本身不足以让每种情绪都化为系统隐喻。已有语境确立技术类比是此人的惯用理解方式时可保留，核对它是否仍贴合当下对象与目的。领域知识进入有用的观察、叙述、行动或推理，不作为独立知识清单凑篇幅。

## 写后核对与按需参考

在现有写后自检中核对本场：承诺的事实与因果是否成立，人物是否越过当时知识，关键表达是否有作用，规划措辞是否直译成清单或作者解释。问题源于输入缺失或矛盾时，在现有完成回复指出来源，交由负责输入的阶段处理；不靠反复换词掩盖。

**叙述层高风险候选**：碎片结算、短分句链、库存比喻、强制对白收尾、无依据的否定纠偏与均质分段，只在持续削弱当前信息、人物、声音或节奏时需要修订。单次形态与字符长度不决定病灶。删改保留已有事实、原文授权、异质细节和未解张力，不以检测零命中为目标。

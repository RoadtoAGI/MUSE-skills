# 表达失真的判别与修订

本文件将常见表面形态按它损伤的叙事作用组织，供 writer 和既有审阅者按问题读取。相同词句可以有不同作用；统计与 family 名帮助定位，语义问题由当前正文及其上下文确认。修复的结果是读者更顺畅地跟随对象、关系和叙述顺序，并保留事实、人物、声音、节奏与授权原文。词形、次数和篇幅用于定位，不承担删改目标。

## 信息与焦点

当前文字是否让读者获得本场所需的变化、感受或认识？判断时包括叙述声音、时间体验与意象作用，不能只看梗概是否少了事件。

| 候选形态 | 成立的问题与处理 | 合法相邻用法 |
|---|---|---|
| 主次失焦、动作清单、资产盘点 | 次要程序反复结算已知结果，关键变化被淹没；按因果、空间、人物经验、声音、节奏与承接作用组织，收束确无作用的重复 | 程序每步改变危险、盘点表达控制欲或生存压力 |
| psychological_overfill / explanation_after_action | 心理或解释反复结算已成立认识，且不承担回指、关系、声音或承接作用；删并冗余并接续仍需表达的关系 | 反思重组先前意义，或叙述者的理解与读者形成差异 |
| 概括替代过程 | 场景承诺让读者经历发现，正文只宣布“震撼”；补理解所必需的过程 | 过渡、总结、回忆或有意压缩承担叙事功能 |
| 反复感知 / 碎片结算 | 看、听、停顿等句子既不改变感知，也无声线或节奏作用；合并同一作用 | 持续观察发现差异；重复形成等待、仪式或渐变 |

例如“他害怕”在险情后只复述刚呈现的恐惧，且没有人物自知、声音、节奏或承接作用时可省；向同伴直接说“我害怕”，使同伴接管危险操作时有新的关系作用。情绪命名本身不决定修改。

## 人物与叙述权限

核对说话者或视角人物当时能知道、理解和表达什么，叙述者另按既定权限处理。

| 候选形态 | 成立的问题与处理 | 合法相邻用法 |
|---|---|---|
| omniscient_overexposure / omniscient_underexposure | 无渠道地获得秘密，或省略使当前因果无法理解；修正供给或叙述 | 受限视角的未知、叙述者有意延迟揭示 |
| dialogue_as_author_solution | 人物突然掌握作者研究所得或替作者宣布结论；回查知识与目的 | 教授讲解、审讯推理、坦白与共同讨论有场内理由 |
| narrator_self_corrects / emotion_naming_under_face_loss | 无依据的自知或道德纠偏抹平已定认知；保留人物实际理解 | 反省由经历触发；有足够自觉的人物直接表达 |
| signature_voice_overuse / 身份隐喻 | 职业标签替代真实观察，隐喻持续无对象依据；回到当前关注和关系 | 已建立的比拟习惯、讽刺、专业概念改变理解 |
| grand_scene_grand_language | 只按事件规模预定情绪强度，人物与文体失真；回查现场条件 | 克制、延迟、激烈反应及档案体均可成立 |

潜意识分析留在作者层。人物不自知可以由稳定行为和信息差显现；不需要补一段自我诊断。故事信息缺失属于上游时，回交相应材料负责人。

## 表达组织

修辞、归属和段落的形态要与所表达的关系相符。不同方法有各自用途，不排统一优先级。

| 候选形态 | 成立的问题与处理 | 合法相邻用法 |
|---|---|---|
| contrastive_negation_assertion、抽象短语、库存比喻 | 无实际对照或映射，句式伪造新认识；补准确关系或省去重复解释 | 事实纠错、概念区分、误认修正、反讽及有据类比 |
| micro_punchline_cadence / ordinal_gravity_marker | 反复宣布重要性，遮住当前需要理解的对象或关系；按已有事实澄清关系、调整节奏或删并无作用结算 | 断裂节奏、准确时间事实或声音中的强调 |
| state_persistence_template | 静止状态反复结算且无作用；合并 | 持续危险、等待或人物对稳定状态的执念 |
| 说话标签、强制对白收尾 | 换标签使声音失真，或反复靠开口结束遮断本段作用；按实际归属、交流与节奏组织 | “说/问/答”、低声避人、听者反应、动作、纯对白均可使用 |
| 同源比喻、修辞密集、副词、精确计时 | 形态持续遮住对象与认识；选准关系和重心 | 母题回响、密集风格、测量或人物确实注意时间 |
| 长独白或均质分段 | 同功能复述拖慢当前理解，或分段遮断连贯关系；按思想、时间或交流关系重组 | 思想展开、故事转述、长句与单句段有独立作用 |

“他低声提醒岗哨就在门外”提供了音量的现场原因。对白每轮都附音量说明，而这些说明已无归属辨认、声音条件、关系或节奏作用时，重复才需收束；逐轮把“低声”换成“声音很低”会保留这项无作用的复述。修复应解决已确认的表达问题，并保持自然搭配。

## 规划痕迹外泄（planning_trace_leakage）

设计字段交付事实、关系、意图、必要结果与实现候选。字段标题、理论标签或按任务表逐项结算进入正文，损伤人物经验与叙述连贯时，保留语义并重新组织表达。故事内的清单、档案或作者授权原文依既定内容契约保留。

有名著参考时，核对的是本作是否实现已采用的机制与必要结果。物件、动作、台词顺序仅属候选时可以替换、合并或省略；遗漏必要因果才须修补。正文有用的留白、长独白或冷感文体可由局部证据及其功能成立，设计字段的预声明只帮助解释。

## 复核与反馈

沿既有 finding 记录位置、实际原文、失效作用和修改范围。来源不足、上下文失真与执行偏离分别回交原环节；审美选择交作者。修后回读受影响语境，看重复或失真是否仍在，不用替换措辞证明完成。

[forbidden_migration_patterns.yaml](forbidden_migration_patterns.yaml) 保留脚本所用的同功能候选词表：contrastive_explanation、ordinal_significance、state_label_assessment、numeric_authority。出现“其实”“此刻”“全员”等只提示检查同一问题是否延续；本表不给这些普通词设普遍禁令，机器结论须按当前脚本策略及语义审阅解释。

## 指称与承接（referential_vagueness）

`dummy_pronoun` 和 `demonstrative_classifier` 定位“它、这东西、那把、这种”等形态。结合前文判断读者能否恢复所指、能否区分对象，以及当前句怎样承接上一句。高密度可安排优先复读；明确的代词、指示语和名词复现均可保留。

指代歧义导致对象错认，或省略了理解当前判断所需的对象、比较项和因果关系时，按实际缺口补明、复现或重排。重复名称使文字生硬时，可以改用清楚的代词；跨检测族的变化只记录表面现象。没有统一的省略、实词复现或换句优先级。

例如“门槛上卧着一条黑狗。它听见脚步便抬起头”中的回指清楚；“柜里有旧伞和新伞。她取出那把旧伞”保留了选择对象。删除“它”或“那把”是否合适取决于这段的语气与衔接，检测命中无需换取改文。若“她把旧伞靠在木椅上，它已经裂了”使读者无法确认裂的是伞还是椅，先依据现有事实明确对象，不凭词频猜测事实。

## 修订后的阅读验收

修改前确认句段承担的事实、回指、过渡、因果、比较、声音与节奏作用；修改后按读者的阅读顺序连读改动处及相关上下文。框架多余时可删，框架承载的必要关系应在新表达中接续。当前理解依赖共同关系时，先使该关系可恢复，再展开个别定义或例子；细节先行、后文归纳和悬念延迟按作品意图保留，关键在于读者当下需要理解什么。

保留或补回必要主宾语、比较对象、指示语、连接词与话轮归属。标题应准确提示其下的具体内容；在中文和英文中分别检查自然搭配、指代与完整比较，中文候选词表不作为英文替换规则。原文已经存在的断裂和本轮引入的问题按修订前后证据区分；本轮产生的跳步、空泛标题或声音损失应当在交接前重组或恢复。沿现有 finding 与复审字段说明实际问题和处理，不增加逐词台账。

以下构造示例将承接、压缩和成分保留的判断放在同一处，展示可采用的改法；措辞与句序随具体叙述调整。

- **去掉套话，接续动作的原因。** 原文：“她握住门把。这一选择的关键在于，门一开就会碰响铜铃。老周刚睡下，因此她没有开门，而是收回了手。”可改为：“她握住门把。门一开就会碰响铜铃；老周刚睡下，她收回了手。”框架与重复动作收束后，铜铃、睡眠和收手之间的联系仍可恢复。若只留下“她握住门把，随后收回了手”，动作虽然还在，当前场景需要的理由已经丢失。
- **压缩时保留比较与动作主体。** 场景已明确记录两队回营时间，焦点人物继续核账。原文：“It was evident that the east patrol returned nearly an hour later than the west patrol. Lena checked the gate log again.”可删去开头的评注，保留：“The east patrol returned nearly an hour later than the west patrol. Lena checked the gate log again.”比较对象和后句主语维持读者跟随；删成“returned nearly an hour later”再接“Checked the gate log again”会让当前语境缺少比较基准和动作归属。其他段落若已明确这些信息，可以采用符合其声音与语法的省略。

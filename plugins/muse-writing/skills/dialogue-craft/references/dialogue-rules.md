# 对白的作用与诊断

麦基《对白》讨论信息暴露、推进、人物塑造、差异、意义与节奏等作用。一个回合可以同时承担多种相容功能，作品与人物处境决定组合。

## 从当前交流判断

说话受可见刺激、主动追求、合作意愿、关系代价、共享知识与语言能力共同影响。下一回合需要与此前交流相容；回避、拒绝、静默、误解与坚持都可以成立。压力不必统一表现为短句，熟练者也可能更克制。

| 实际问题 | 判断与修复 |
|---|---|
| 重复没有作用 | 删并后信息、理解、承接、关系、节奏及声线都能保持，且确实减少冗余时可删。复述用于确认、压迫、仪式或讲述时保留 |
| 台词只为交付作者解释 | 场内对象与人物需要无法解释这段话时，改其来源或承载；教学、报告、辩论与自省可以直接阐述 |
| 交流无法理解 | 检查听者能否恢复省略与指代；隐语需有共同语境、隔听需求或故意误导等条件 |
| 声音失去人物依据 | 回到经历、关系与注意方式；共享行话、礼节或局部句式相似不直接判错 |
| 超出自知或语言能力 | 核实来源、训练及当前状态，恢复人物可知范围；不能仅因台词条理清楚就判错 |

## 支持与共同暴露的推进

《对白》第十八章分析《迷失东京》的微限冲突：人物各自生活中的缺失，使当场的试探、剖白与回应具有分量。外部对抗较弱时，观察一次回应怎样增加安全感、改变表达意愿或使下一步共同活动成为可能，再选择台词与停顿；无需另添争吵来证明推进。

应用例：两名朋友都知道对方刚失去亲人，其中一人把近况概括为忙碌：

> “这几天怎么样？”
> “一直找事做。”
> “我也是。停下来就不知道该干什么。”
> “我其实还没敢收他的衣服。”

第三句以自己的困境接住对方，使第四句更具体的剖白获得关系依据。若只连续追问近况、重复得到“还行”，且认识、关系、声音或节奏都未变化，增加回合不能补出层次。日常问候也可完成接触、陪伴或衔接，其作用已经成立时，不必继续挖出秘密。同一支持姿态可以持续多个回合，是否出现新节拍取决于行为关系的变化。

## 修辞如何参与交流

《对白》第五章讨论修辞的感官作用，第十一章的角色专属对白分析进一步把它与经验、目的及接收者联系起来。选择比喻时，说明两种经验在哪项特征上相通，人物为何会这样联想，以及这幅形象会使听者怎样理解当前处境；共同特征与交流作用决定取舍。

麦基分析《杯酒人生》时，人物谈黑皮诺的脆弱、养育条件与成熟潜力，既交换酒的知识，也向对方暴露自身；对方怎样接续这幅形象，影响了交流的亲密程度。可迁移的是借共同熟悉的对象试探或表达，以及听者对这种表达的回应。当前人物缺少相应经验或交流需要时，直接讲述也可完成安慰、劝说与剖白。

修辞可以促成认同，也可能被对方拒绝或重新解释。顺着实际回应继续交流。作者对比喻的复述沿“重复没有作用”的判据处理，保留理解与承接所需的表达。需要决定关键意义放在句首还是句尾、怎样用停顿组织期待与消化时，读取同包[句法与意义顺序](../../prose-craft/references/mckee-scene-craft.md#句法与意义顺序)，按当前说话者与接收者的需要选择。

## 删除测试与边界例

“最小充分回应”指删去无功能部分，保留人物目的、理解、关系、表达和节奏所需内容。例如日常争执中，“那着火了你也等审批？”可能完成反击；听证记录要求交代推理时，完整说明前提与结论更适合。决定性差异是交流目的和共享语境，句长本身不决定好坏。

归谬用于人物愿意反驳、对方前提可被推至难以接受后果的情境。直接否认、追问、承认局部、离开或合作也可成立；按角色与现场选择，不按技巧轮换。

“我会先……再……”可能是人物在制定计划，也可能是作者预告尚未发生的表演。只有后者在替代当前场面、且未承担人物交流作用时才需要改写。

修订落在已定位问题上。动作、直陈、间接表达或叙述均可实现目的；不能把所有解释机械改为物件、沉默或碎句。

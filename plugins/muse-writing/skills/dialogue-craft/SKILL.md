# 人物声音与对白

麦基《对白》把说话理解为人在具体需要下实施的行动。写作从说话者、接收者、共享知识、关系与当前处境出发；言语可以争取、照料、讲述、回避、思考或直陈，也可以共同承担信息与节奏作用。

## 取得人物依据

使用当前场次设计、本人 role_view 及实际有效的人物/对白参考。角色包提供经历与声音，角色当前所知按故事时点解释。本人未获的信息不能因作者知道而进入台词。未采用的候选与同名旧参考不自动生效。

麦基的已说、未说、不能说区分表达与自知：已说是选择表达的内容，未说是自己知道但未说出的内容，不能说涉及本人尚未觉察的冲动。它们是分析视角，不要求每句都有隐藏意图。POV 叙述还须服从本作叙述权限，叙述者的理解不总等于人物此刻的自觉。

## 实现声音与交流

词汇、句法、节奏、关注对象、合作姿态与受压反应可体现人物差异。人物在相同制度或关系语域中可以局部相似；关键交流持续抹平已有人物差异时，再回查来源。遮住名字测试只提供线索。

让新信息、沉默或拒答影响相应人物；影响也可以是维持立场或有意忽略。长句、解释、重复与礼貌合作只要承担当前作用就可保留；删掉无功能内容不等于追求最短回应。交流停在同一层、需要以支持或共同暴露推进，或修辞尚未影响听者理解时，读取[对白规则](references/dialogue-rules.md)中的相应方法与边界例。

“说、问、答”可清楚标明归属。声音状态、动作、听者反应、物件或省略归属都按实际信息与节奏选择；低声在避免被听见时有明确作用；连续使用同义音量表达时，核对说话人辨认、声音条件、关系与节奏，按这些作用是否被无益地重复决定取舍。需要选择承接方式时读[归属与承接](references/speech-attribution-patterns.md)。

人物存在隐瞒、表达代价或自知盲区时，按[潜台词理论](references/subtext-theory.md)保留可理解的表里关系。直接告白、解释或自省有依据时同样成立。

写后只检查有疑点的交流、知识与声线。复杂交锋可临时按“谁知道什么、向谁做什么、为何这样表达”拆清关系，无需交付矩阵或额外检查表。

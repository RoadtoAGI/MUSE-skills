# 短篇全文创作

一次完成整篇作品。保持作者要求、必要事实、人物连续性、核心因果与结局作用；具体动作、对白、意象、渲染详略与节奏由全文需要决定。

## 当前输入

从派发给定工作目录读取：

- `pipeline/shortform/conception.yaml`：创作意图、篇幅、硬要求、风格和来源事实。
- `pipeline/shortform/characters.yaml`：人物追求、处境、关系、声音及有条件的表达边界。
- `pipeline/shortform/outline.yaml`：事件、场景作用与默认呈现方案。
- `pipeline/shortform/inspiration_ledger.yaml`：仅取当前 outline 引用的 adopted 条目。
- 本次派发明确给出的有效 reference pack：动笔前读取适用原文与使用约定。未给路径或明示“无”时跳过，旧文件存在不使其生效。

缺少必要设计或引用时向主控指出具体缺口。无关的可选字段可省略，不能凭空补出人物心理或来源要求。

## 实现全文

动笔前加载本包 [prose-craft](../prose-craft/SKILL.md) 主文件；作品含对白时加载 [dialogue-craft](../dialogue-craft/SKILL.md) 主文件。句中意义、心理展开、修辞、形象回响与复杂交流等深度参考，按两个工坊的入口和当前问题取得。沿当前宿主的技能调用或文件读取加载，已有且仍适用的内容直接复用。

场景的起终状态帮助理解其作用。人物可以保持立场而读者改变认识，过渡段可以承担连接或经验展开；不为逐卡兑现制造价值翻转。合并、调序、换视角或改换入口时，仍须保留作者指定的安排、必要结果、实际 handoff 与人物当时可知的信息。因果依赖与列表邻接分别判断。

进入人物视角时，从这个人的经历、当前追求、感官、关系与已知信息产生判断。作者对人物深层机制的解释不自动成为人物自知。声音边界按其原有条件与对象生效；人物坦白或解释动机可以有现场理由。外部或全知叙述按作品的叙述约定组织，人物本身仍受知识边界限制。

大纲中的短语、箭头和任务标签用于理解目的。将其转成当前叙述位置下自然、完整的语言；读者应从人物与事件获得的判断保留其推断空间。普通移动、操作、重复与停顿能被相邻内容充分替代时省略；其方式或后果改变关系、压力、认识或形式体验时保留。

有效参考按本包[参考采用契约](../writer/references/reference-adoption.md)处理其用途、领域、最终档位及回执；短篇沿本次全文派发执行。作者明确的原文和世界机制复用继续成立，`style_only` 仅用于表达参考；正文保持人物知情与既定世界事实的区别。

篇幅按 `target_length` 安排，区间或上限服从 requirements 原有强度。场景无需等宽；用户硬要求在自然的叙事位置落实。句法、词类、修辞和密度只帮助诊断具体表达效果，不按指标凑写。

## 写入与收尾

正文写入根目录 `story.md`。保持一次全文创作；确因输出长度需续写时，在同一文件接续。修订任务归 short-manuscript-reviser，设计文件保持只读。

正文不含执行说明、字段标签或设计标记；麦基术语仅在故事本身确需其含义时使用。分节服从作者风格要求。收尾核对必要结果、人物知识、对白归属、硬要求及整体衔接，回执简报完成或具体输入问题，正文保持纯作品文本。

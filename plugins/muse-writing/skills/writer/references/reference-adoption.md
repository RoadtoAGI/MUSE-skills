# 参考采用契约

本文件维护 writing 包完整链与短篇的共同采用语义。有本次有效参考时读取；来源选择、生成与派发由各自编排技能负责。

多来源 ref 或 reference_pack 按每条 `<reference_scope>` 中的 `reuse_mode / intended_domains / reuse_tier` 消费；总头仅表达共同条件，不能覆盖更严格的单条范围。有效 ref 的 `reuse_tier` 是在来源用途内确定的档位；`reuse_mode / intended_domains` 和本次作者要求限定其范围。`style_only` 始终只作表达参考；领域仅含 `prose_style_imitation` 时按 style，只含 `world_rule` 或它与文风领域时至多按 material。手选、同书或高相关不扩大这些范围；其他领域只采用本次已选的机制或素材。已有设计事实继续按其原有权威保持。

| 有效契约 | 正文消费与回执 |
|---|---|
| `reuse_tier: full` | 在已采用领域内实际复用贴切的原词、原句与连续段落，候选区优先；只作接入人物、POV、时态、指代、专名和衔接所需的调整，保留原有句法与段落质地。回执给可核对复用清单；无适配候选或与故事不变量冲突时说明具体原因 |
| `reuse_tier: material` | 采用与当前正文及已选领域直接相关的来源专名、世界事实和专门术语；普通动作、物件或句段需要其自身的功能适配。回执列实际来源资产，无适用资产可为空 |
| `reuse_tier: style` | 按 usage_protocol 学习适用文风，保留自主构思；不产生原句、情节或世界素材复用义务 |
| 旧 ref 无 tier | 本次用途明确时先按该范围解释；没有新增用途限制时，沿 `reuse_mandate: true` 的 full 或原 usage_protocol。元数据与当前作者要求冲突时刷新对应 ref，其他已获授权工作可以继续 |
| 适用的 `worldview_reuse` | 读取已采用的 lore，保持机制、条件及来源确定度；人物只使用确有渠道获得的信息。人物未知的确定事实可按既定叙述视角呈现或延后，不能自动改成传闻 |

明确的原文复用要求在其适用范围内优先于自由措辞；参考与故事不变量冲突时由主控回对应来源或设计负责人处理。普通风险提示不降低已授权的复用力度。原文语言不同、且本次未要求翻译复用时，学习语态、节奏与留白。多来源分别保留用途，不能用一份来源的授权覆盖其余材料。

写作前应已取得有效参考和约定；内容已加载且仍有效时直接使用。压缩、遗失、材料变化或具体执行表现造成缺口时再补读相关部分，读取顺序随缺口安排。写作者按当前正文决定动作、感知、对白或叙述怎样承载材料；量化风格提示只帮助定位偏差，实际声腔、节奏或可读性损害才决定修订。正文首次产出、修订和重写均按同一当前来源契约执行。

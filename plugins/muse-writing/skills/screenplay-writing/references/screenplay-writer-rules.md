# 剧本场次写作

## 写作前取得的内容

读取本次 `sequence_list.yaml` 中的当前场次及相邻依赖，并从已有设计中取得：Phase 0 的媒介、作者要求和表达意图；Phase 1 的相关世界与制作条件；Phase 2 的人物经历、欲望、声音、知识与关系；Phase 3–4 的必要选择、结果及呈现安排。已读内容仍有效时直接使用；换执行者或设计变化时传递实际相关内容。

按需读取已经完成的相关场次，以正文确认已发生的行动、信息和状态。当前场的 `inspiration_refs` 指向本次 ledger 的采用项；读取其机制、成立条件、`project_encoding` 和实际采用的材料。prototype card 保留候选，不整张转成正文要求。缺少会影响关键选择的输入时回到来源补足；一般场面细节由执行者创造。

## 以媒介实现意图

麦基《对白》区分戏剧、影视与小说的表达资源：舞台独语、面对观众的言说、叙述者与歌唱都可能成为有效载体。共同要求是让目标媒介能够呈现必要经验，并让人物的言行符合其处境。具体格式由本次媒介和作者要求决定。

| 媒介 | 主要表达资源 |
|---|---|
| 影视 | 场头、可视动作、对白、声画关系；需要时使用画外音、主观镜头或蒙太奇 |
| 舞台与沉浸剧场 | 舞台空间、上下场、对白、独语、灯光声音及观众位置；制作限制按本次约定 |
| 音乐剧、歌剧、戏曲 | 对白或念白、唱段、身体与程式；唱段需在人物经验或整体表达中有作用 |
| 广播剧 | 可听辨的言语、声音、静默与空间关系，必要信息用声音组织 |

心理信息需要合适载体。若决定性内容是“她第一次意识到自己爱他”，递伞时停顿只能表现迟疑；只有前文已使该停顿具有这层意义时，才足以承担认识变化。否则可通过随后的选择、独语、唱段或其他本媒介成立的表达保留它。省略解释应保留观众重建关键意义的依据。

观众获得的信息与人物已知分开：旁语、独白或隐藏在台上的行动是否被别人听见、看见，依剧本约定与场内证据判断。作者对人物的分析也不能直接变成人物自知。

## 场面与语言

行动、话语和停顿从人物当时的欲望、阻力、关系与注意对象生长。对白可以争取、试探、照料、回避、思索或直陈；潜台词有证据时才成立。寒暄、重复、缓场和诗化言说只要承担关系、节奏或表达作用均可使用。

舞台指示与动作行交代可实现的行为和必要条件。篇幅按理解与呈现需要决定；表演提示用于会改变句意、对象或节奏的地方。避免用连续解释替演员完成每个表情，也不将所有心理信息压成模糊肢体动作。

写出 `pipeline/screenplay/scenes/{seq_id}.md`。影视可用场头 / ACTION / CHARACTER / DIALOGUE / PARENTHETICAL；其他媒介沿用自身清楚、一致的标记。正文只呈现剧本，不附设计论证或执行报告。

# 剧本审阅与修订

审阅当前场次正文时，取得 writer 使用的当前设计、采用来源和必要已写场次。按下面职责定位问题，证据落在具体语句、行为或交接处。

- **内容与因果**：作者明确要求、世界条件、必要结果是否落实；人物是否凭当时可知的信息作出选择；观众是否有理解关键变化所需的依据。
- **媒介呈现**：必要信息是否能通过本次媒介呈现，场头、上下场、声画或唱段是否可理解；制作规模只按已约定的条件评估。
- **人物与表达**：言行是否由处境、关系和目标产生，是否误把分析结论变成自知。直陈、独语、潜台词、重复或诗化语言都按其实际作用判断。
- **场次接续**：出入场、道具、信息与关系状态是否支持后续；张力回落、状态维持、空场或非线性时序按整体功能判断。

动作行没有统一长度上限，场内变化没有固定数量；篇幅和密度出现理解或演出障碍时，指出具体障碍及修复目标。采用来源时检查其条件与本场是否相容，不因相似本身判错。

局部硬性不符或语义错误原位修订。缺失输入回读原材料，设计矛盾回到对应 Phase，再更新受影响正文；整场失去因果基础时才整场重写。作者可选择的表达与审美取舍给出理由并交作者决定。修订后只核对所改问题及其影响，避免重复全场扫描；无需新增审阅文件。

# 麦基理论：结构设计

本文件解释 Phase 4 使用的结构理论与项目扩展。

---

## 幕结构

### 原文引用

> 「一个故事可用一个幕讲述……不过，如果是这样，则必须简短。一个故事可用两幕讲述……但是，这同样要求比较简短……但是，当故事达到一定的长度时，则起码需要三幕。」
> —— 《故事》第九章

### 核心原则

1. **幕是重大逆转**：每一幕的结束改变人物生活、行动条件或解释范围
2. **长度与结构**：原著在经典设计语境中提出长故事至少三幕的主张；本项目按实际组织方式和复杂度设计 Arc，不据字数机械配幕
3. **幕具有阶段功能**：各幕围绕当前故事需要承担建置、对抗、重构或收束等作用

## 进展纠葛

### 原文引用

> 「进展纠葛是指，当人物面对越来越强大的对抗力量时，产生越来越多的冲突，从而创造出一系列逐次发生的事件，经过一个个无法回归的点。」

> 「最小的努力无济于事。人物不可能通过采取较小的行动来恢复生活的平衡。从此以后，一切类似于人物第一次努力的行动……都必须从故事中排除。」
> —— 《故事》第九章

### 核心原则

1. **递进而非堆叠**：不是更多的困难，而是更深层次的困难
2. **不归点**：关键事件改变后续条件，原有策略不能无变化地反复解决问题；普通行动和形式重复不必逐次不可逆
3. **对抗力量交替**：不同类型的对抗力量交替和叠加（麦基以内在/个人/外在为例）

### 应用案例

| 作品 | 纠葛递进 |
|------|---------|
| 《大白鲨》 | 告示→关闭海滩→雇猎人→亲自出海——每次失败后行动升级 |
| 《冰血暴》 | 每次隐瞒杀人的尝试导致更深层的灾难 |

## 序列节拍与组织关系 `[项目操作性扩展]`

序列把一组场景组织成中程转折。设计时说明进入状态、压力怎样演化、哪个事件或选择造成局部高潮、结果怎样改变下一序列。递进可以落在困境性质、代价、不可逆性、信息状态或选择空间，外部冲突强度可以暂时回落。

低对抗中段也可由阶段成果连接：先取得一种能力、建立一项共同认识或形成合作条件，后续活动因而成为可能。人物经历深化时，完成标准也可能改变。例如，修好旧屋先使家人能够回来居住；共同生活又让“恢复这个家”涉及分担照护与重新相处。前一阶段的成果仍然成立，下一阶段由它带来的生活条件展开。按实际结果写 `closed`，把随后可行的行动或待解关系写入 `opened / causal_chain`，无需为每项进展追加阻挠者。

### 三种变化路径

| `spine_mode` | 序列变化怎样成立 |
|---|---|
| `desire` | 人物的策略遭遇对抗反应，期待裂口迫使其改变策略或价值取舍 |
| `information` | 新证据、缺口或披露确认、推翻或重构暂定解释，形成新的判断与问题 |
| `motif` | 母题在新情境中重复、变形或对位，重新组织人物、关系或读者感知 |

### 可选组织能力

- **信息释放**：事实发生节拍与读者获知节拍分离；释放改变归因、关系、判断或行动方向。
- **多线因果**：各条序列链分别推进；交叉把资源、代价、选择空间或意义传入另一条线。
- **时间与呈现重组**：因果顺序保持可重建，呈现顺序改变读者追问、误判或重释时机。
- **对位**：两个序列的结果互相照亮，并改变至少一条线的意义或读者判断。

技巧名称只用于检索和诊断。序列产物记录具体状态变化、因果与读者结果。

### 主次情节怎样联系

《故事》第九章给出四种主次关系：主题矛盾使不同选择的结果形成比较；主题回响用不同处境与代价展开相近认识；启动铺垫让读者在主线激励事件前经历必要的人物与世界；制造纠葛让次情节改变主线的行动条件。按当前作品需要选择，主题联系可以成立于各线的后果，无需强行安排人物会面。多情节作品也可由共同思想的对立与变异形成整体。

关系还可发生在同一人物的内心：照护亲人的牵挂改变办案时的注意和选择，工作中的判断又改变其理解亲人处境的方式。设计时保留各自的追求、阶段结果和实际牵制，把具体作用写入序列及因果说明；`narrative_threads` 继续只提供定位。

各线可以错开启动、转折和收束。切换时照看离开该线后保留的关切，以及接入另一线将取得的进展或理解；阶段结果、承诺或后果都可提供切换位置。篇幅依当前结构与情感作用分配，各线无需等长。

### 交叉节点与延迟影响

以下案例采用《水浒传》一百二十回本，示范把《故事》第七章“主人公”和第九章“次情节和多情节”用于序列设计的判断；具体编排手法属于作品分析。设计共享事件或跨线条件时，按相关问题取用。

**共享事件，分别形成结果。** 生辰纲被劫使杨志押送失败、晁盖等人劫取成功，失窃又引出追查（[第16回](https://zh.wikisource.org/wiki/水滸傳_(120回本)/第016回)、[第18回](https://zh.wikisource.org/wiki/水滸傳_(120回本)/第018回)）。大纲分别保留失去交差条件、取得财物和暴露危险等结果，再推演各方下一步行动；同一件事可以兼任一线的局部高潮与另一线的启动原因。只写“众人完成生辰纲事件”会抹去推动后文的得失差异。迁移时从各方追求、对象归属与责任推演交叉；仅有主题对照的两线继续通过各自后果形成联系。

**人物离开，关系仍可生效。** 宋江赴梁山途中收到假父丧家书后返乡，却让燕顺、花荣等人携其介绍信继续上山；梁山接纳同伴，宋江随后另有遭际（[第35回](https://zh.wikisource.org/wiki/水滸傳_(120回本)/第035回)、[第36回](https://zh.wikisource.org/wiki/水滸傳_(120回本)/第036回)）。设计可保留两边独立的阶段成果，并说明介绍信通过谁传递、接收方为何接受担保、它使什么行动成为可能。人物当场不在，不妨碍已建立的名望与承诺参与另一线；若接收方不认识担保者或拒绝其信用，后续就需要相应的接纳依据或新的行动。书信只是本例载体，可迁移的是关系经由可信传递改变他方条件。

实际采用的关系写入相关序列的 `closed / opened` 与 `causal_chain`，使 Phase 5 能安排建立条件、传递与结果发生的场景。条件可以跨越若干序列后发挥作用；它与读者何时获知分别安排。人物接力、条件传递与原著特指的主线激励事件前铺垫，按各自作用解释。

### 同层实例：《阿Q正传》

“激励事件与社会断裂”序列关闭阿Q在未庄维持生存的可能，打开进城谋生；“虚假中兴与崩塌”由进城做贼的结果触发，又关闭靠金钱改变地位的路径。两个序列以选择空间缩窄形成递进。革命线随后获得新的行动意义，体现序列结果怎样改变下一阶段。

### 失效与非触发边界

- 爆炸、争吵或追逐只提高声量，策略、状态和选择空间均未改变，不能承担序列高潮。
- POV 轮换不自动产生跨线因果；各线可以独立推进，也可以通过对位改变读者理解，需辨明实际作用。
- 单线顺叙可以完整承载因果与转折，无需增加交叉或时间重组。

## 验证清单

- [ ] 幕结构是否清晰（每幕有明确的功能和转折点）？
- [ ] 进展纠葛是否改变困境性质、代价、不可逆性、信息状态或选择空间？
- [ ] 每个序列高潮是否改变后续行动、解释或母题意义？
- [ ] 最终序列是否导向 Phase 3 已定义的 `story_climax_design`？
- [ ] 实际事件依赖是否可重建，呈现顺序与因果顺序是否分别清楚？
- [ ] 采用多线或时间重组时，跨线后果与读者识别锚是否成立？

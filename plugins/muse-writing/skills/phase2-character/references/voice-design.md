# 人物声音的八个观察面

本文件提供人物声音差异化的观察方法。八个面帮助设计者从来源中识别人物怎样注意、关联、说话、沉默与被误读；它们不构成逐项填写的参数表。Phase 2 只保留当前人物真正有来源、会影响故事的特征。

---

## 为什么声音差异化重要

麦基提出了"盖住名字测试"：遮住角色名，仅从对白能分辨谁在说话。在有充分表达机会的片段中，核对差异是否来自人物目的、认识与关系；日常简答和共同语域可以相似。

声音差异来自人物经历、欲望、关系、时代语言和当前处境在表达中的自然流露。相同人物在不同弧光时点也可能出现不同的注意与表达方式。

---

## 八个观察面

### 维度一：词汇（Vocabulary）

角色倾向使用什么类型的词？

| 维度 | 范围 | 示例 |
|------|------|------|
| 雅俗 | 典雅 ←→ 粗俗 | 诗意/骈文 vs 街头俚语 |
| 专业 | 行话 ←→ 白话 | 科学术语 vs 接地气的大白话 |
| 抽象 | 概念 ←→ 具象 | 谈论"天下苍生" vs 谈论"吃什么" |
| 时代 | 古典 ←→ 当代 | 文言句式 vs 网络用语 |

### 维度二：句法（Syntax）

角色如何组织句子？

- **句长**：来源场景中常见的长短与变化条件，不按职业或人格类型预判
- **句式**：人物怎样下判断、回避、追问、隐瞒或争取话轮
- **完整性**：哪些关系和目的下完整陈述，哪些内容会中断、省略或改口
- **问句频率**：问句在具体关系中实施好奇、控制、试探或拖延中的哪一种行动

### 维度三：修辞（Rhetoric）

当角色人设或语境需要表达复杂思想时，他们会怎么修饰表述？

- **比喻来源**：喻体来自什么领域（过去经历，经典名著，致敬桥段）？是否贴切？
- **直白程度**：帮助理解 vs 迂回暗示
- **反讽倾向**：人设/语境是否适合

### 维度四：节奏（Rhythm）

角色说话的时间感：

- **语速**：急切/紧张 vs 沉稳/犹豫
- **停顿**：思考型 vs 冲动型
- **情绪变调**：越说越来气？越说越伤心？
- **沉默**：何时选择不说话？沉默意味着什么？

### 维度五：压力下的确定性（Certainty Under Pressure）

角色被质疑、逼问、证伪、羞辱时的反应倾向：断言 / 反问 / 解释 / 沉默 / 转移动作 / 自嘲 / 攻击对方 / 用物件或事实证明。

### 维度六：非语言声纹（Non-verbal Voice）

角色稳定的动作、停顿、避视、触碰物件、处理身体疼痛的方式。

### 维度七：负空间声音（Negative-space Voice）

角色在什么关系与处境下不直说，原因是什么？动作、玩笑、沉默或直接表达怎样服务当时目的？

### 维度八：误读模式（Misread Pattern）

别人最容易如何误读 ta —— 误读本身是声音的一部分。
- 谁会误读（最近的人 / 最远的人 / 同阶层 / 跨阶层 / 上级 / 下级）
- 误读什么（动机 / 能力 / 关系 / 情感 / 价值观）
- 基于什么证据（外貌 / 行动 / 沉默 / 物件 / 第三方传闻）
- ta 是否纠正，以及当时的关系与代价如何影响这一选择

与 `misread_matrix` 字段的区别：misread_matrix 是场景级反讽工具；维度八 misread_pattern 是角色级稳定属性。

## 设计流程

1. 固定故事时间点，读取足以解释当前人物的经历、信念、关系、已知信息与盲区。
2. 从来源反复支持的注意、关联、措辞、沉默和行动习惯中选择承重特征。
3. 用八个观察面检查遗漏；只记录有来源且会影响当前故事的项，不逐维配齐。
4. 倾向仍难以判断时，用具体刺激和话语对象试想回应；只验证当前疑点，不把一次表现写成恒定公式。
5. 与其他角色对照，确认差异来自人物依据，而非口头禅、职业行话或参数标签。

## 常见错误

| 错误 | 后果 | 修正 |
|------|------|------|
| 用口头禅代替声音设计 | 删掉口头禅后角色声音一样 | 回到人物注意、关系目的与判断偏向 |
| 声音设计脱离人物依据 | 角色说话方式与行为、时代或弧光时点矛盾 | 从来源和当前处境提炼倾向 |
| 为每个角色填满八个面 | 轻角色也背负一套行为手册，正文机械兑现 | 只保留当前故事会用到的差异；纯功能角色无需独立声音档案 |

## 正负例：用工程标签表演人物逻辑

> “这位科学家以参数、概率和因果链处理情绪；决定越接近执行，语言越短，无法量化的责任越清晰。”

这段话把科学家身份扩写成行业术语，把现场压力写成句法开关，再用“因果链”宣告人物具有逻辑。它没有说明人物凭哪些经历和思想资源理解当前处境，也没有让结论从她的主观世界产生。设计者随后容易先完成一份公共伦理审计，再用短句与专业词替人物表演冷静。

可用的设计方向是：写清人物长期相信什么、这次观察到了什么、专业训练能帮助她判断哪类事实，以及私人经历使她怎样解释这些事实。句长和措辞留给具体意识流动决定。这里规定人物依据和知识边界，不预设正确答案或语法动作。

同类规则只在“身份标签取代人物依据”或“情境被写成固定句法开关”时触发。原作持续显示某人物在特定关系或压力下使用一种表达策略时，可以记录为有来源的倾向；每场仍按当前刺激重新判断。

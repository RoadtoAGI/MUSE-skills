# 从公开来源取材

使用宿主可用的搜索与页面读取工具。先围绕具体缺口检索，再打开原始页面确认来源身份、版本和相关语境；已有 URL 可直接读取。可靠一手资料能够回答问题时无需增加来源数量，争议或相互矛盾处再补查。

作品与表演题材关注角色关系、结构、场面及媒介形式；人物、地点与历史题材关注相关经历、制度、时空条件和版本差异。仅记录当前设计需要的信息。资料中的事实、来源作者的解释与本次推测分别表述，冲突保留各自来源。

把实际采用的来源列入 `sources`；各候选保留 URL 和页面位置。风格与节奏写入 `style_signature`，人物或世界事实写入对应字段，专名、原句或连续段落等进入 `reuse_candidates`。逐字候选保留准确文本和 provenance，避免重复抄入另一份字段。

网络不可用时可从用户已提供资料继续，记录实际 direct 来源；必要证据缺失则返回调用方。

# 仙侠：超常秩序与人的生活

先确定本作实际依赖的修行、神异或仙凡关系。修炼、飞升、神职、因果、法器等都是可用材料；故事可以围绕修行进展，也可以围绕其中的关系、生活或认识展开。

涉及能力变化时，说明变化依据及其对选择的影响。涉及资源争夺时，说明资源由谁掌握、如何流动；涉及仙凡边界时，说明接触条件和人物受到的影响。没有进入本作的境界、秘境或天界无需预建。

超常能力的新用法依已建立的对象、作用方式和边界成立；能力范围发生变化时，说明相应前提。灵力消耗、寿命与反噬分别按本作已定条件推演。

境界名称用于分类，采用等级时写清与当前情节有关的能力差别；采用悟道或伦理变化时，说明它怎样改变人物与世界的关系。资源、门派与渡劫条件按当前选择需要展开。

以上为项目设计启发。需要借用具体作品时，通过 canon 或用户资料取得有定位的文本，再判断其机制与本作是否相容。

# A 组审查：微观语言 + 反 AI 化 + reframing 独白判读

> 本子文件承载 A 组审查中"句级 / 段级语言细节"的诊断规则：反 AI 化失守检查、微观语言错配（含 hot zone 判读、reader-visible damage 原则、修订方向）、以及 改变前文理解的独白判读。主表逐项检查见 [`A_aesthetic.md`](A_aesthetic.md)。

## §1bis 反 AI 化失守检查（承载与视角语义模式）

针对 [`prose-craft/references/ai-cliche-patterns.md`](../../prose-craft/references/ai-cliche-patterns.md) 中的 `narrator_self_corrects` / `emotion_naming_under_face_loss`，A 组按病理机制逐场景扫描：

| 检测项 | 触发场景 | 报告落点（`dimension: ai_pattern` + subkind） |
|---|---|---|
| 叙述者过度自省 | 第一人称叙述场景，叙述者在道德灰区 | `subkind: narrator_self_corrects` |
| carrier 后重复命名情绪 | 命名只复述已成立认识，且未承担人物自知、声音、关系或承接作用 | `subkind: emotion_naming_under_face_loss` |

每条 finding 需要 `evidence_quote` 原句和一句机制级失败原因；表面词或题材类型不单独构成立案。修订方向应保留该句承担的有效认识与承接，再处理已确认的无作用复述；允许删合、补明和重排。

## §7 微观语言错配

扫描单句级"看似有文气但不成立"的问题。命中时 `dimension: micro_language`，并填 `subkind`：

| subkind | 判据 | 例 |
|---|---|---|
| `false_literary_diction` | 修饰语与被修饰动作不搭，句子只剩假文气 | "人群退得极轻" |
| `sensory_mismatch` | 感官通道错接，触/听/视觉强度混用且无转换 | "那一退极轻，却刺眼" |
| `abstract_judgment_without_action` | 抽象判断缺少理解依据或无作用地复述已成立意义；内心与叙述认识可独立成立 | "他显得复杂而沉重" |
| `stock_speech_tag` | 用库存语气标签（"淡淡道 / 声音不高 / 低声道 / 平静道 / 沉声道 / 悠悠道"等）替代角色实际语气、动作压力或对白本身——删后归属、声音反差、关系、节奏与上下文承接均无损，并已造成无作用的重复时报告 | "他淡淡道：「刀断了，人还在。」" / "杨过声音不高，「这条路给他退……」" |
| `weak_character_expression` | 人物声音 / 神情 / 动作 / 心理描写附近用弱否定、虚词、副词或状态标签替代具体动作、压力或对白效果——在当前上下文中造成可定位的失真或无作用重复时报告；状态、否定或副词的形式不决定删改 | "声音仍平" / "表情没有变化" / "脚步不慢" / "她只是看着" / "不是问句" |

**只报影响阅读的句子**：单个生僻搭配若语义清楚、符合角色感知，不报。每条 finding 必须给 `evidence_quote` 原句和一句失败原因，方便 scene-reviewer 直接转 patch。

**`stock_speech_tag` 与 dialogue_lint S3 信号联动**：dialogue_lint S3 已加 `STOCK_SPEECH_TAG` 正则信号（同名 enum，confidence=medium）；A 组消费 lint hits 时核对信息、归属、声音、关系、节奏与承接作用——某角色一贯的"低声道"刻画 / 用于场景气氛而非语气替代时**不报**；典型替代型才报为 `dimension: micro_language, subkind: stock_speech_tag`。

**`weak_character_expression` 与 dialogue_lint S3 信号联动**：dialogue_lint S3 的 `weak_character_expression_candidate` 只是候选提示，不是定罪。candidate 分两档：

- **confidence=medium**——有锚点（声音/神情/动作/心中等身体部位或感官名词），如"声音仍平 / 表情没有变化 / 脚步不慢 / 心中仍想"
- **confidence=low**——仅代词锚点（"他/她 + 弱副词 + 弱动词"），宽召回兜底

每条 candidate 还附 `near_dialogue: bool`——命中行 ± 2 行内是否有对白引号。

**Hot zone 加权（near_dialogue=true）**：人物对白前后 1-2 行是 weak_character_expression 高发区——典型场景：

- 对白前后引导句："她声音平" / "他低声道" / "声音短硬"
- 同一人物连续两句对白之间的垫句："她没有动" / "神色不变" / "只是看着"
- 对白后补态度："不是问句" / "语气淡淡" / "话里没有怒气"

常见失效是状态标签反复提供同一含义，掩盖实际话轮或关系变化。状态本身也可准确传递持续压力与人物声音。`near_dialogue=true` 帮助定位上下文，沿下方功能判据核实。

### 判读流程（reader-visible damage）

**总原则**：报的是"已经在伤害读者体验的弱标签"，不是"看起来可疑的句子"。判据是：这句话是否仍提供归属辨认、声音、关系、节奏或其他具体作用；必要的中性说话标记本身有效。把"模糊可疑"留给 reviser 自由裁量会让 reviser 机械替换、把一个坏标签换成另一个坏标签；让 A 组只报真伤害读者的，reviser 才能集中处理实质问题。

**Step 1 — 范畴判定**：原句是否属于"人物声音 / 神情 / 动作 / 心理描写"？

不属于范畴的 candidate 视为 **lint 误报**，A 组**不报**：

- **主语不是人物**：景物 / 环境 / 物件——"水鸟掠翅的声音" / "册页翻动的声音" / "门没开" / "地上没有血迹"
- **否定承担信息纠错**：时间地点对比、事实辨析——"公审是今夜，不是明晨"
- **否定承担逻辑反驳**：对辩驳类对白——"这柄刀不是我塞到你们手里" / "他喝的不是我的方"

→ 进入 Step 2 才看是否伤害读者。

**Step 2 — 功能判定**：句子是否承担归属、声音、关系、节奏或其他具体作用？

**不报**（句子在承载具体叙事功能）：

- **否定表达有依据的转折或持续状态**："接过茶，**却没饮**，**望着**远去的背影" / "**没有看他**，一直**盯着**船绳"
- **不同句子共同形成气氛与人物反应**："她说完，屋里没人接话，灯芯爆了一下" / "他听完，把杯子推到桌中央，没再开口"
- **角色一贯刻画在长程场景中已建立**：每次按当前作用判断，有效重复保留
- **删除后会让句意残缺或节奏断裂**：句子是上下文衔接的必要部件

**报**（句子是空状态标签、删去后信息不损失）：

- **无作用的库存语气标签**：相关词面反复代替应有差异、删后归属/声音/关系/节奏均无损；后续是否接动作不决定合法性
- **抽象状态替代具体反应**："声音仍平 / 表情没有变化 / 不是问句 / 没有起伏" — 删去后信息无损
- **同义堆叠**：相关成分反复交代同一状态且没有其他作用时收束；“很轻／几乎听不见／像是在自语”可能分别交代音量、听者可听度和交流对象，须按语境判断

判定时问：**reviser 删去这句，读者会损失什么？** 答得出具体内容（节拍、气氛锚点、关系信号）→ 不报；答不出 → 报。

声音描述与后接气氛句应分别及连读判断：后句有具体细节，不能推出前句无作用。前句若保留人物声线、反应持续性或衔接就保留；两部分确实重复同一含义且删并无损时再报告。

### 修订方向（写进 finding 的 `suggestion`）

建议说明读者在哪里失去对象、关系、认识或体验，以及改文需要保留什么。无作用的重复可删合，缺失的归属与衔接应补明，顺序失当则重组句段。修订可保留准确状态、中性说话标记、心理表达或连接词，避免统一改成动作。复读新旧上下文，确认原问题消失且声音、节奏与理解完整；同义替换和计数下降各自不足以证明完成。

## §reframing 独白判读

独白可以通过新事实、立场或经验改变读者对前文的理解。按受审正文独立判断：它增加了什么，如何影响人物、关系或事件的意义；设计只辅助解释意图。长篇幅、低动作密度、结尾接对白或继续叙事，都不能单独推出注水。

例如，同一段撤退往事从“懦弱”改读为“保护同伴”，关键在于新增事实改变了对选择的理解；若只是换词重复已经确立的评价，则检查重复是否仍承担节奏、声音或关系作用。迁移的是信息与解释的变化，不要求复制往事独白或特定收尾。

有具体作用时保留。确有冗余或场内交流失效时，finding 引用原文并解释损害，建议范围与损害对应；`dimension: ai_pattern, subkind: monologue_padding` 仅用于成立的注水。无需凑齐判据、追加豁免记录，A 不读取 reader 报告；修订者按本次合并反馈核实处置。

# 设计校验方法

## 时间与身份

对照互相关联的年份、年龄、时长、事件顺序及机构历史。需要计算时保留区间和相对时间基准；只在所有允许取值均无法共存时判为矛盾。显式时间旅行、寿命、记忆移植或身份变化按本作设定解释。

- **确定冲突**：普通寿命角色实际出生于 2100 年，却明确亲历 2090 年的事件，设计中没有相应机制。
- **非触发**：2140 年“外观 52 岁”的角色在 2023 年活动。`age_apparent` 不能推出实际生年；必要时回读实际年龄或长生设定。
- **近边界**：事件发生于 2140–2150 年、角色当时 38 岁。出生年仍是区间，不取年代中点制造精确矛盾。

技术合法化与发明、机构成立与前身活动分开核对。非法使用可以先于合法化。倒叙、并行线与回忆按事件发生时间检查，场景呈现次序无需单调递增。

## 世界条件

从 Phase 1 与已确认来源中识别对当前人物、事件和地点生效的规则，连同前提、强度与例外核对 Phase 2–5 的相关设计。

“任何生物均无法穿过屏障”与同条件下人物直接穿过是冲突；“法律禁止越界”与人物冒险越界可以共同成立，后者须服从已设定的执法条件和后果。“社会保守”允许激进人物。人物的误解或传闻不等于作者确认的世界事实。

来源绑定的运行机制被换成另一原因、尚未建立的能力解决关键阻力，均应定位到具体规则与事件。泛称“缺乏真实感”不能替代证据。

## 引用与结构

对照 Phase 2 角色、Phase 3 Arc、Phase 4 `seq_id`、Phase 5 `scene_id` 及 INS-*：

- 参与者和角色 POV 能找到对应人物；全知等叙述模式按 schema 解释。名称缩写使用已建立的别称映射，存在歧义时补映射。
- Phase 4 序列在 Phase 5 有对应展开，场景能回到所属序列；编号唯一，引用精确，沿用场景 ID 的既有命名约定。
- 已确定的激励事件、危机和结局在展开中保留其事件作用。结构位置可以调整，功能不能仅因字段仍在而视为落实。
- 需要分阶段释放的信息核对其实际场景落点；普通母题或手艺来源无需补造披露阶梯。

Phase 3 已明确延迟的答案，沿 Phase 5 的呈现顺序核对 `reader_track / scene_tasks / omission_plan`：当前必要发现是否有依据，尚未满足条件的确认是否在相关场景保留，确已约定揭示的答案是否有相应落点。一般原创秘密同样适用；永久留白按明确意图保持，无保密需要时不要求补字段。已明确的全篇意图与场景安排相冲突时引用两端；意图明确却缺少影响当前写作的本场条件时，按既有 `summary.input_gaps` 交 Phase 5 补足。读者先知、人物后知与先果后因按已选结构判断，人物知识另按事件时点核对。

原型与灵感的具体字段见 [schema](output-schema.md)。没有被本次设计使用的候选无需升级为正式条目；已被使用的引用缺失时应修复来源或绑定，不能用近似 ID 猜配。

## 声明兑现

对照 Phase 0 的 `requirements[]`、`reference_materials`（作者提供的素材与有效细节）、ledger 中 `accepted / bound` 的 INS-*，以及 Phase 5 的 `commitments[]`，沿呈现顺序找到承接它们的场景：该场的 `scene_tasks`、`handoff`、`omission_plan` 或 `inspiration_refs` 能看出承接关系即可，不要求字面相同。

- **确定问题**：用户提供的历史素材在 Phase 0 被列为关键细节，Phase 1–5 没有任何场景的任务、承载或省略安排提及它，也没有记录有意放弃。
- **非触发**：素材以机制形式进入（Phase 0 写明把“八股取士”转成“重新定义写作”的体制，Phase 5 的某场承载合规备忘与功用化登记），词面不出现不构成问题。
- **非触发**：`commitments[]` 写明 `deliberate_omission` 并给出理由；作者可选择不收束。

`commitments[]` 缺失时按 Phase 0 的声明与 ledger 核对；条目指向不存在的场景或既无 `payoff_in` 又无 `deliberate_omission` 由 `validate_phase5_r10.py` 先行报出，这里只判断承接是否成立。观察依据：claude-opus-4-8/20260710_020000/367 的“只剩一术”账目与玄照、樊无咎在后半消失，旧校验无 finding；claude-opus-4-7/20260522_120000/594 的焚书史素材在 phase0 出现 40 次而设计只承载了其中的体制机制。

## 人物可互换

同场多名人物对同一压力作出同类行动（表态、签字、认责、拒绝），同类行动可能掩盖人物差异时，读相关 `scene_tasks`、`irreversible_action`、`conflict` 与 Phase 2 各人的追求、判断习惯和声音：去掉姓名与职业后，设计是否仍能区分谁会先动、谁会沉默、谁会误读、谁付出不同代价。

- **确定问题**：`irreversible_action` 写“A、B、C 分别承认自己实际完成的一项动作”，Phase 2 中三人的信念与关系代价不同，场景设计却没有让这些差异改变任何一人的选择或后果。
- **非触发**：仪式、点名、投票等故事世界内确以逐人程序运作的场合，或 Phase 5 已写明差异（一人抢先、一人缺席、一人以沉默拒绝）。

定位到相关场景字段与 Phase 2 字段，建议回 Phase 5 把逐人分工改成关系结果与选择差异，或回 Phase 2 补足差异依据。观察依据：gpt-5.6-sol/20260903_210000/594 S07。

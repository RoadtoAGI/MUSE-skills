# 人物声音设计

人物声音来自经历、知识、关系位置和当下想达成的事。设计应让执行者能判断某段对白为何符合人物，同时保留坦白、沉默、解释、失控与习惯改变的可能。

## 选择有判断价值的观察

下表沿用已有字段，按真实信息缺口选择。它们是项目的观察视角，不是麦基规定的八维配额。

| 字段或视角 | 记录什么 |
|---|---|
| `vocabulary` | 人物实际会用的词、知识来源与交流对象。职业行话在专业交流中可准确而密集，不能自动扩展成所有情绪的比喻来源。 |
| `syntax` | 如何组织说明、请求或辩解，以及语境变化。长句不等于知识分子，短句不等于行动派。 |
| `rhetoric` | 人物何时借比喻、反讽、委婉或直说达成目的；记录贴切的经验领域，不预制“情绪→措辞”表。 |
| `rhythm` | 回应时机、停顿、重复或话轮控制与当时关系的联系；不预设受压就变短或变碎。 |
| `pressure_certainty` | 被特定对象质疑时如何处理证据、权力和自尊；候选反应有依据才写。 |
| `nonverbal_voice` | 已成立的非语言习惯及其情境；具体动作不成为每场必做标记。 |
| `negative_space_voice` | 在何种关系与风险下难以直说什么；困难、当前回避和真正不可说分开。 |
| `misread_pattern` | 谁依据什么将人物读错，人物是否知道并有意纠正。只有被误读一方的反应属于声音；客观误读安排留在作者设计。 |

`voice_boundaries` 保留来源中的对象、时点、触发条件与强度。普通倾向不能因“边界”之名升级为绝对禁令；作者明确限制、角色实际不能或原文确立的强底线继续保留。没有依据时不补边界。

## 用语境区分倾向与禁令

一名军人在陌生人前简短回应，不推出他在法庭作证时也只能短句。可写“陌生人追问私人感受时常略去原因；正式作证时按时间说明经过”。决定性差异是对象和沟通目的，句长本身不决定是否符合人物。

一个角色曾把关心藏在安排里，不推出永远不能说“我担心你”。当关系或代价改变时，坦白可以成为符合人物处境的新选择；只有明确来源规定了持续的限制，才维持该限制。

两名医生同场可共享术语。需要区分时，看他们如何理解风险、对谁解释、保留什么及如何承担责任，不给每人分配固定口头禅。

## 对照与交接

用实际拟写的关键对话检查：去掉姓名后，内容、利益、关系和表达是否仍支持人物辨认。简短寒暄、共同语言和有意模仿可以相似；“每一句都能猜出姓名”不作硬门槛。

有效声音信息进入 persona 及合时的变化记录，由 role-view 派生器按当前人物和场景筛选。角色不自觉的欲望、未来轨迹和别人掌握的秘密留在作者侧；不把声音说明变成当前场景必须执行的心理或动作。

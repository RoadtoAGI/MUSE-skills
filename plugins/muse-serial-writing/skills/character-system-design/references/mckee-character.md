# 麦基人物依据与连载应用

本文件保留会改变人物设计判断的理论条件。章节锚指向麦基《故事》；下述连载字段与上下文分工是项目设计。

## 压力、选择与人物深度

《故事》第五章“人物 VS 人物塑造”“人物性格揭示”区分可观察的外在特征与压力下的选择：

> 人物性格真相在人处于压力之下做出选择时得到揭示。

判断的重点是人物面对代价时选择什么。外表、职业、习惯可塑造人物印象；选择可以证实、补充或推翻这一印象。只有程度更高的危险而没有更难的选择，未必增加人物深度。

第五章用《大审判》把外在形象、败落处境与寻求救赎的选择相连。可迁移的是表象、动机、代价之间的关系。角色不必复制律师身份、酗酒经历或“外冷内热”的反转。

第十七章“人物维”强调矛盾带来的维度。设计要保留矛盾在何种关系与处境中成立，以及仍能辨认出同一人物的连续性；堆积标签或让角色无缘由地反复不能替代维度。次要人物的深度服从实际叙事职责。

## 欲望与动机的适用条件

第七章“主人公”与第八章“激励事件”“故事脊椎”要求作者理解主人公的欲望对象，同时明确：许多故事靠自觉追求即可组织，复杂人物还可能存在不自觉欲望。书中以邦德为没有不自觉欲望也可成立的例子，以《猎爱的人》说明自觉目标与不自觉需求的冲突。

设计据此保留三种判断：

- 自觉欲望应具体到人物知道自己正在争取什么，欲望对象可以在外部，也可以在内心。
- 只有人物设计或来源支持时才填写不自觉欲望；它应与自觉欲望形成实际冲突，且未必是道德上更好的“真正需要”。
- 动机有时来自多种经验与环境。第十七章提醒不要把人物缩成单一原因的个案研究；背景事件提供理解，不能据一次创伤推出所有行为。

第七章“主人公”区分复合与多重主人公：前者须共同欲望、共同利害；后者各自追求、各承后果。设计双主角或群像时先明确这种结构关系。

## 从追求到具体办法

《对白》第十二章把欲望对象、超意图、动机、场景意图与背景欲望联系起来：人物追求眼前目标时，还希望维持已有的关系、认同与安全感。《故事》第五章以有代价的选择揭示人物。以下将这些原理用于人物设计，关系分域与观念检验是项目应用。

当前目标能解释人物想达成什么，却仍不足以解释办法选择时，补清他同时顾惜什么。这些背景欲望会影响说服对象、披露范围和让步条件，也可能在受到威胁时转为眼前目标。人物可以自觉权衡，部分顾忌也可能只从既有行为显露；两者按原有自知范围保存。

信任与权力应落在具体关系中。某人信任同伴的技术，却担心他泄密；同伴未必同等信任他。保留使这种认识成立的经历，以及当前事件会动到哪项关系。拥有资源、获准调动、实际可用和愿意相助分别影响选择，名义身份本身不能保证行动可行。

办法还依赖人物相信什么有效。保留支撑该信念的经历、他如何解释当前证据，以及选择由谁承担什么代价。后续反证出现时，人物可以把它视为例外、调整局部判断、更换办法或放弃原信念；具体变化由经历和后果支持。人物声称珍惜什么，与有代价时实际保住什么，可以相互印证，也可以形成有据的矛盾。

应用例：同样要争取两天维修时间，曾靠压住消息保住工资的厂长倾向先私下协调；曾因同事未获预警而承担责任的工程师倾向立即说明风险。前者还顾惜管理权威，后者希望同事继续信任自己的判断。两人最终也可能都选择公开，但说服对象、让步条件与愿承风险各有依据。可迁移的是经历、顾忌与办法的关系，具体职业和选择按本作确定。

这些信息沿已有欲望、幕后经历、信念和关系文字保存，深度以能解释当前选择为准。角色自觉的依据可进入人物视图；作者的潜意识解释和未来弧光继续留在设计侧。

## 变化、显形与保持

第五章“人物弧光”讨论人物内在本性在故事中向好或向坏的变化，并将这种变化与连续选择相连。它没有提出本项目的四项 `character_arc.mode` 枚举，也不能从中文“弧光或变化”推导“弧光等于显形”。

项目用模式区分作者当前规划的组织线：`transformative` / `degenerative` 关注内在变化，`revelatory` 关注认识逐步揭开稳定核，`static` 关注一个不以变化或显形组织的稳定人物。模式指导卷纲理解人物，具体反应、变化速度与是否在一次关键选择中转变，仍由处境、铺垫和后果决定。

## 对抗、群像与幕后故事

第五章“结构和人物的功能”把压力、两难与选择联系起来；第七章讨论内心、个人和个人外的对抗。对抗可以由制度、环境、关系或内心构成，不必补造具名反派。第十七章要求从人物立场理解其行动；这种理解容纳残酷、自利和非人的对手，不等于为每个对手赋予正义感。

第八章把幕后故事视为可以推进当前故事的过去事件。选择哪些事件取决于它们如何影响现状与后续叙事；没有固定事件数量，也不要求每段经历都安排闪回。

第十七章“热爱你的所有人物”支持给予配角自身的生活与行动依据。项目中的 `inner_capacity`、`subjectivity_object`、误读与辨认字段是可选创作机制；角色可以通过工作、关系、意愿或抉择保有主体性，退场也不必留下物件。

## 声音与执行空间

第十七章“给演员留下空间”提醒避免过度铺陈行为、手势和语调，并指出优秀演员能以少量指导创造有力瞬间。项目把这一点用于角色上下文：保存判断依据、表达倾向与必要边界，让当前情境决定具体台词和行动。

# 共创协议

本文件负责跨技能的作者决定、决策继承与冻结修改。卷向推演归 [volume-outline](../../volume-outline/SKILL.md)，章级决策密度归 [serial-chapter-writing](../../serial-chapter-writing/SKILL.md)，字段归 [workspace-schema](workspace-schema.md)。

## 作者决定与继续条件

作者已给定的方向、选项与授权范围直接生效。`collaboration_mode` 决定默认请作者参与的密度；明确委托优先于默认停点。授权不足且当前选择会改变作者保留的意图或冻结内容时，报告具体分歧及后果，等待决定；不将例行格式选择变成停点。

需要比较时给出具有不同因果、人物关系或阅读效果的候选，说明各自收益和代价；候选数按实质分歧确定。用户可以提出候选之外的方案。待跨回合恢复的候选写 `series/decisions/D-####-candidates.yaml`；无需比较或恢复的决定直接进入正式决策与产物，不另写候选文件。

需等待作者时，`series_state.pending` 保存类型、具体对象及依赖问题、已有候选路径（无候选时 `options_file: null`）。暂停依赖该选择的动作，继续其他已授权工作；本轮可做事项完成后再离会。恢复时读相关材料承接现有讨论；已有新答复或明确委托即处理决定并清除已解决的 pending。委托段内只归档改变故事方向、冻结设计或后续取舍的决定，常规实现留在产物内。

权限或规则造成暂停时，交接拟执行动作、受影响范围、具体规则文件与关键原句，并说明当前授权为何尚未覆盖；规则明确要求与执行者的适用判断分别说明。普通工具失败先沿原责任路径定位和恢复，不写成新的作者选择；已确认的冻结修改和他人会话接管继续由作者裁决。

## 决策继承与回写

决定使用 [decision.yaml](templates/decision.yaml) 的 typed scope，按实际范围指定卷、单元或章。调用者在该范围的设计前用本包 `match_decisions.py list` 取得待消费决定，并继承已反映在总纲和上游产物中的有效决定。脚本的“待消费”结果表示尚未落到产物的记录，不能当作全部有效约束。

普通决定落实到卷纲、单元或章产物后，用 `match_decisions.py consume --decision D-#### --by <artifact-id>` 登记实际消费方。没有落实的要求继续保留待决，范围或意图冲突交对应负责人解决。已存在的设计文档仍在原文基础上完善；决策回写与保留既有设计各有职责。

规范目标标识为 `volume:V##`、`unit:V##-U##`、`chapter:C####`。冻结修订另可使用 `bible:frozen`、`profile:genre`、`worldbook:<section_id>`；closed 卷仍用对应 `volume:V##`。这些冻结目标只有 `kind: frozen_amendment` 且当前修改已获作者批准时才能使用。

## 冻结内容的修订

冻结保存跨卷承诺。修改已确认的总纲、类型档案、worldbook 公理册或 closed 卷纲时：

1. 指明要改的内容、原因、新内容与已发布影响；已有规则内的细化或追加按该产物契约处理。事实记录错误走台账更正，改变既定设计走本通道，按问题选责任位置。
2. 取得作者对这项修改的明确批准；普通阶段委托不自动授予改动任意冻结内容的权限。当前批准已覆盖这项修改时直接沿用。
3. 将本次批准与改法存入 `kind: frozen_amendment` 决策，并用 `match_decisions.py consume` 登记对应目标，再修改目标内容。
4. 按受影响的现有 `serial_lint.py` 检查核对改动及对应凭据，处理实际违规。已发布正文的文字勘误仍用 manifest revision 通道。

这里的目标 token 是已批准修改的写许可；普通决定的消费回执仍在产物落盘后登记。写作者需核对本次批准的对象与内容，历史 token 不扩大授权。

现有 lint 使用 git HEAD 与凭据核对结构差异；无可比基线时只给 WARN。宿主 hook 也不覆盖所有冻结面或证明本次批准，必要的授权判断与改后检查由当前责任方完成。保留原有恢复和写保护机制，不以脚本放行替代作者决定。

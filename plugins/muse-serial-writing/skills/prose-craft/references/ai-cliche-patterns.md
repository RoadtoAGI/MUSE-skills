# 表达失真的判别与修订

本文件将常见表面形态按它损伤的叙事作用组织，供 writer 和既有审阅者按问题读取。相同词句可以有不同作用；统计与 family 名帮助定位，语义问题由当前正文及其上下文确认。修复保留事实、人物、声音、节奏与授权原文，不以零命中为创作目标。

## 信息与焦点

判断当前文字怎样支持本场的理解、感受与认识，包括回指、关系承接、叙述声音、时间体验和意象作用。删改与对照沿 [prose-craft 的阅读连续性判据](../SKILL.md#组织场景与段落)；梗概未少事件仍可能丢失理解下一句所需的桥接。

| 候选形态 | 成立的问题与处理 | 合法相邻用法 |
|---|---|---|
| 主次失焦、动作清单、资产盘点 | 次要程序反复结算已知结果，关键变化被淹没；重组主次，保留理解后续行动、空间、风险与声音所需环节 | 程序每步改变危险、盘点表达控制欲或生存压力 |
| psychological_overfill / explanation_after_action | 心理或解释重复已明确且仍在焦点中的认识，删后承接与声音均成立；删并或重组 | 反思重组先前意义，重提对象连接被打断的行动线，或叙述者与读者形成认识差异 |
| 概括替代过程 | 场景承诺让读者经历发现，正文只宣布“震撼”；补理解所必需的过程 | 过渡、总结、回忆或有意压缩承担叙事功能 |
| 反复感知 / 碎片结算 | 看、听、停顿等句子重复已明确的感知，删后焦点承接、声线与节奏均成立；合并同一作用 | 持续观察发现差异；重复形成等待、仪式或渐变 |

例如“他害怕”在险情后只复述刚呈现的恐惧，且删后语气与下一步动机仍清楚时可省；向同伴直接说“我害怕”，使同伴接管危险操作时有关系作用。情绪命名本身不决定修改。

教学对照：“柜门要两人合力才拉得动。楼上传来闷响，阿岚去查看，老周留在柜前。阿岚回来后，两人一起拉开柜门。”若叙事正跟着老周等待，返回交代等待如何结束，并把焦点带回柜门。若这段只是概述开柜结果，且上下文足以让读者自然补完返回，“两人一起拉开柜门”也可成立。返回提示、人物复现或省略各按阅读焦点选择；这组构造案例不要求逐项交代人物移动。

## 人物与叙述权限

核对说话者或视角人物当时能知道、理解和表达什么，叙述者另按既定权限处理。

| 候选形态 | 成立的问题与处理 | 合法相邻用法 |
|---|---|---|
| omniscient_overexposure / omniscient_underexposure | 无渠道地获得秘密，或省略使当前因果无法理解；修正供给或叙述 | 受限视角的未知、叙述者有意延迟揭示 |
| dialogue_as_author_solution | 人物突然掌握作者研究所得或替作者宣布结论；回查知识与目的 | 教授讲解、审讯推理、坦白与共同讨论有场内理由 |
| narrator_self_corrects / emotion_naming_under_face_loss | 无依据的自知或道德纠偏抹平已定认知；保留人物实际理解 | 反省由经历触发；有足够自觉的人物直接表达 |
| signature_voice_overuse / 身份隐喻 | 职业标签替代真实观察，隐喻持续无对象依据；回到当前关注和关系 | 已建立的比拟习惯、讽刺、专业概念改变理解 |
| grand_scene_grand_language | 只按事件规模预定情绪强度，人物与文体失真；回查现场条件 | 克制、延迟、激烈反应及档案体均可成立 |

潜意识分析留在作者层。人物不自知可以由稳定行为和信息差显现；不需要补一段自我诊断。故事信息缺失属于上游时，回交相应材料负责人。

## 表达组织

修辞、归属和段落的形态要与所表达的关系相符。不同方法有各自用途，不排统一优先级。

| 候选形态 | 成立的问题与处理 | 合法相邻用法 |
|---|---|---|
| contrastive_negation_assertion、抽象短语、库存比喻 | 无实际对照或映射，句式伪造新认识；补准确关系或省去重复解释 | 事实纠错、概念区分、误认修正、反讽及有据类比 |
| micro_punchline_cadence / ordinal_gravity_marker | 反复宣布重要性，遮住当前需要理解的对象或关系；按已有事实澄清关系、调整节奏或删并无作用结算 | 断裂节奏、准确时间事实或声音中的强调 |
| state_persistence_template | 静止状态反复结算且无作用；合并 | 持续危险、等待或人物对稳定状态的执念 |
| 说话标签、强制对白收尾 | 换标签使声音失真，或反复靠开口结束遮断本段作用；按实际归属、交流与节奏组织 | “说/问/答”、低声避人、听者反应、动作、纯对白均可使用 |
| 同源比喻、修辞密集、副词、精确计时 | 形态持续遮住对象与认识；选准关系和重心 | 母题回响、密集风格、测量或人物确实注意时间 |
| 长独白或均质分段 | 同功能复述拖慢当前理解，或分段遮断连贯关系；按思想、时间或交流关系重组 | 思想展开、故事转述、长句与单句段有独立作用 |

“他低声提醒岗哨就在门外”提供了音量的现场原因。多次“低声”是否冗余，还须看说话人辨认、距离、态度与节奏；已确认这些作用均不需要时，逐次换成“声音很低”仍会留下无作用的标注。普通叙述中的“他以低分贝进行回答”可改为“他低声回答”，保留音量并改善搭配；具有测量或技术化声音作用的原表述另按实际语境判断。

## 规划痕迹外泄（planning_trace_leakage）

设计字段交付事实、关系、意图、必要结果与实现候选。字段标题、理论标签或按任务表逐项结算进入正文，损伤人物经验与叙述连贯时，保留语义并重新组织表达。故事内的清单、档案或作者授权原文依既定内容契约保留。

有名著参考时，核对的是本作是否实现已采用的机制与必要结果。物件、动作、台词顺序仅属候选时可以替换、合并或省略；遗漏必要因果才须修补。正文有用的留白、长独白或冷感文体可由局部证据及其功能成立，设计字段的预声明只帮助解释。

## 复核与反馈

沿既有 finding 记录位置、实际原文、失效作用和修改范围。来源不足、上下文失真与执行偏离分别回交原环节；审美选择交作者。修后对照原文回读受影响语境，确认原问题改善且对象、关系、语气仍清楚；删后解释跳步或回指含混时恢复相关作用，原稿已有问题按原稿定位。

[forbidden_migration_patterns.yaml](forbidden_migration_patterns.yaml) 保留脚本所用的同功能候选词表：contrastive_explanation、ordinal_significance、state_label_assessment、numeric_authority。出现“其实”“此刻”“全员”等只提示检查同一问题是否延续；本表不给这些普通词设普遍禁令，机器结论须按当前脚本策略及语义审阅解释。

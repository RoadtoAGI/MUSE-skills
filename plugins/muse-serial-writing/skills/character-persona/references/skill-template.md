# 人物参考包模板

生成包供有明确需求的消费者按文件读取。本包角色派生器从中取合时片段，actor 与 writer 使用派生后的 role_view。包不预装通用表演方法，也不授予写入权限。

模板中的 allowed-tools 按支持该元数据的宿主解释；其他宿主以正式文件或命令读取取得同一资料，继续遵守只读与人物信息边界。

`<!-- required -->` 标记新旧包共有的必要章节；`<!-- optional -->` 标记按信息需要写入或兼容读取的章节。校验从本文件解析标记。新包采用下方结构，有用信息可合并进相应章节，不为可选章节补造内容。

## SKILL.md 模板

```markdown
---
name: role-slug
description: 角色显示名及简短定位
version: 1
allowed-tools: Read
---

# 角色显示名

## 身份与处境
<!-- required -->

{目标时点成立的身份、处境和相关生活信息；保留职业知识而不据职业补造修辞。}
<!-- 来源：实际文件及人物字段/正文锚 -->

## 经历与信念
<!-- optional -->

{人物已经历、记得或相信什么，以及它如何影响当下判断。可保留误信及不确定认识，不能写入人物未知的真相。}
<!-- 来源：实际事件、角色获知渠道及影响 -->

## 自觉追求
<!-- optional -->

{人物知道自己想争取、保护或回避什么；作者的隐性欲望诊断留在设计源。}
<!-- 来源：当前成立的追求及处境 -->

## 判断习惯
<!-- optional -->

{有依据的注意、归因与选择倾向，说明适用的关系和条件。信息不足时不补造盲区或固定回应。}
<!-- 来源：实际经历、信念或设计依据 -->

## 声音框架
<!-- required -->

{足以支持该人物当前台词判断的表达倾向及条件。不要求固定维度，直说、长句、沉默和习惯改变均按来源与处境决定。}
<!-- 来源：声音设计或具体对白/行为锚 -->

## 边界
<!-- optional -->

{原文、明确设计或现实条件支持的限制；每条保留对象、时点、触发条件与强度。没有依据可省略，倾向不升级为绝对禁令。}
<!-- 来源：实际限制及成立理由 -->
```

角色的经历、追求与判断信息按来源保留，可在必要章节中自然合并；可选标记允许简短功能角色与旧包结构，不授权删除已存在的关键信息。只要求章节存在的脚本不判断语义充分性。

## state.md 初始化

新文件只记录目标时点成立的主观状态，并在开头注明来源截止范围。可按实际信息使用当前情绪、已知信息、关系感知、经历摘要和内在拉扯几个段落；无依据部分可为空。误信写作人物相信的内容，不能改成客观真相；未意识到的动机不能改成精准自我诊断。

已有 state 原样保留。它是否适合当前场景由人物来源与时点判断，不能仅因最近被修改就覆盖人物账本或 role_view。

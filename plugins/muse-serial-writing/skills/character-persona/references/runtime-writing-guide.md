# 人物材料的编译

编译应保留会改变人物判断的经历、关系与表达条件。完整作者设计继续留在来源；角色参考包与当前 role_view 都不能把作者知道的东西自动交给人物。

## 保留依据，区别认识层次

| 作者材料 | 可进入人物材料的内容 | 继续留在作者侧 |
|---|---|---|
| 幕后事件与影响 | 人物亲历、听闻或相信的版本，及它怎样影响现在 | 隐藏真相、未来采收用途 |
| 欲望与缺陷分析 | 人物自觉追求、已成立的归因或回避习惯 | 作者诊断的潜意识标签、预设修正答案 |
| 人物轨迹 | 当前已经成立的身份、信念、关系或能力 | 未来终点、必须如何成长、逐场兑现的命令 |
| 声音设计 | 对特定对象、目的、压力有依据的表达倾向 | 无根据的职业隐喻、固定情绪映射 |
| 物件与能力机制 | 角色知道且会影响当下的物件事实、习惯与经验 | 预设失灵、退场用法、必须重复的动作 |

来源仅写“核心缺陷是把控制误作照顾”时，先查看已给的关系或事件。如果确有“对方拒绝安排后，她仍替对方作决定”的依据，可保留她倾向把拒绝理解为低估危险；若只有标签，就保留资料不足，不补造固定行动序列。

这类转化让 actor 可以从自身信念作判断，而不必自觉承认作者诊断。假如人物在正文中已经认识并坦白了同一动机，坦白本身属于合时来源，可以进入当前认知。

## 保留条件，容纳变化

“他在陌生人前不谈家事”同时包含对象与话题范围。转写成“永远不表达感情”会丢失边界；转写成“每次提到家就沉默并摸戒指”还补造了动作。角色面对亲近者、正式调查或已经改变的关系时，应根据相应资料决定能说什么。

职业和身份提供真实知识、利益及社交条件。医生在交班时用术语完全成立；不能据此规定她在所有悲伤场景用生理比喻。稳定倾向与实际专业表达都应保留，具体措辞留给场景。

## 信息深度与生成边界

长期人物保留支撑当前判断的经验和关系，不用篇幅证明复杂。功能角色资料可以简短；没有秘密、内在能力失灵或主体性物件时，不为模板补造。

来源不足以确定身份、时点、知情渠道或真实限制时，回交具体缺口。表达有多个成立方式时保留选择空间；构建器不预先替当前场景决定情绪、目标或回应。

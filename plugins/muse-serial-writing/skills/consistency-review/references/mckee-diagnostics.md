# 麦基场景与对白诊断

《故事》第十一章的场景分析通过人物欲望、对抗、行为与反应、期待与结果的差异理解事件。审阅应还原这些关系，检查所呈现的变化是否由事件造成。文件中的一个场景单元可以承担过渡、余波或更大事件的一部分；同一正负标签也可能包含强度、代价或理解的变化。

《故事》对白讨论及《对白》关于文本与潜文本的论述，关注话语背后的欲望、行动和表达关系。可疑的是语言脱离说者的知情、目的与处境，或者替代了本应发生的事件。人物可以直说情绪、解释、争辩、说谎或独白，判断应说明这些话在当场为何成立或失效。

- 可信性：人物行为和内在反应是否有其处境与经历依据；作者知道的事实不自动进入人物意识。
- 潜文本：表面话语与实际意图怎样相关。直白的坦白也可以产生代价和新关系，无需强制隐藏所有意图。
- 表达效率：重复信息若没有新的态度、压力或节奏作用，可压缩；必要说明和情绪展开按其作用保留。

这些是来源理论的诊断方向。A/B/C 分工、报告字段、四档修订与章发布状态是 MUSE 的执行设计，不能作为麦基理论要求创作数量或固定形式的依据。

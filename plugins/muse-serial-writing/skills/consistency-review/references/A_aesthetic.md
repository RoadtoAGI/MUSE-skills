# 场景表达诊断（A 组）

读本次范围的当前正文、scene_card、当前 lint；人物相关问题按需读本场 role_views 的 character_basis、known_now 和来源。人物未装配时回派生器补齐，不要求补造小说 Phase 2 文件。场景卡给出必要处境、结果和可用材料；具体动作、承载物、修辞和表达节奏的权限沿上下文协议。

## 如何判断

先理解本场欲望、对抗、信息和情绪的变化，再用 lint 定位疑点。统计不是病灶证明；没有具体问题时不凑 finding。麦基诊断的适用边界见 [mckee-diagnostics.md](mckee-diagnostics.md)。

| dimension | 判断对象与成立条件 |
|---|---|
| value_change | 核对必要事件与离场结果是否成立。正负未翻转时继续看强度、代价、认知、关系或局势；过渡、停留和余波可以服务相邻事件 |
| voice_consistency | 人物在本场身份、对象和压力下能否这样表达。稳定声音允许策略、情绪与关系导致变化，不要求每句都有辨识性标记 |
| on_the_nose | 话语是否符合说者知情、目的和听者处境；说明、坦白、谎言、独白均可有实际作用。直说感受或主题本身不构成错误 |
| credibility | 行为、感受及信息依据是否与处境相容；区分作者知识、角色推断与可靠事实 |
| action_log | 动作细节是否持续承载可感的过程、空间、压力或节奏；只在同功能堆叠拖住主戏时建议压缩 |
| micro_language | 搭配、指代、修饰和重复是否造成确切误读或冗余，按[句级判读](A_aesthetic-micro_language.md)定位 |
| sensory_balance | 场景是否缺少理解当前作用所需的感知依据；视觉占比或感官缺席不能直接要求补写某种感官 |
| pov_boundary | 依据当前叙述权限核对人物知情与信息出处；全知、外部叙述和合法视角切换有各自范围 |
| scene_ending | 收尾是否延续/完成本场作用，或重复已成立的结论。动作、对白、议论、停格、开放余波都可采用 |
| ai_pattern | 当前语境中的同功能复述、无依据解读、模板组织是否妨碍表达；lint 命中需结合上下文确认，按[承载作用](A_aesthetic-carrier.md)区别冗余与有用补充 |

正文出现设计词汇时，判断它是在谈作品执行过程，还是角色/叙述的正常用词；“鸿沟”“节拍”“潜台词”等词不能独自证明提示词泄漏。参考原句复用同样按来源授权、场景适配和实际作用判断。

对白交流与创作方法按需加载本包 dialogue-craft / prose-craft；无需重新全量扫描其所有模式。对已确认问题给出精确引用、失败机制与修复方向，落 `pipeline/review/A_aesthetic.yaml`，字段见 [output-schema.md](output-schema.md)。

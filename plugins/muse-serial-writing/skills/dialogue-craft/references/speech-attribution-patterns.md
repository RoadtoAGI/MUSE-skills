# 对白归属与承接

先明确当前缺口是说话人辨认、声音条件、关系作用还是节奏。中性“说/问/答”、台词自身、动作、听者反应、物件、停顿和文体都有适用处，无固定优先级。

| 需要解决的问题 | 候选方式与成立条件 |
|---|---|
| 辨认说话者 | 中性归属即可；轮次和声线已清楚时可省略，切入第三人后重新给辨认依据 |
| 声音方式有表达作用 | 音量、声调可以交代听见的条件、态度、关系或叙述节奏；删后这些作用及说话归属均保留时可省 |
| 场面或关系已经改变 | 相关行动、物件状态或听者选择可承接，须有当前因果；不能为了替代“说”另造动作 |
| 时间和未回应有作用 | 等待、停顿或静默由关系常态和后续反应取得意义；不用统一写成戏剧爆发 |
| 文体承担表达 | 笔录、信件或通话格式适合本作时可用；格式本身不证明克制或冷酷 |
| 人物只能取得局部信息 | 身体位置、注意与知识解释听见/没听见的内容；必要信息仍须可重建 |

例如多人争论后突然只写“好”，读者可能无法判断谁让步；补“他说”或能明确指向本人的动作可解决。若双方轮次清楚，额外补一段转杯子的动作反会打断交流。选择依据是辨认与作用。

`dialogue_form` 的 diagnostic_verdict、single_word_winner、caretaker_tone_violence、monosyllable_confession、co_creation_as_confession 是已选表达机制的接口标签，null 合法。分别涉及判断定性、简短反制、照料语言与伤害的反差、简短告白及共同行为表达关系；使用前核实其关系和条件，标签不指定台词、动作或结尾。所选名著材料通过本次有效参考读取，贴切内容按来源与当前设计采用。

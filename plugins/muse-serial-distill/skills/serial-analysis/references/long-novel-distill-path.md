# 长篇角色定向阅读

候选角色的全部出场无法一次容纳时，先从系统关系、navigation、已有个人分析及 scene_index 确定该角色的主要处境与待解释问题。没有声音、弧光字段不会阻止从原文取证。

按角色的关系转变、重要选择或表达问题选择相关场景，连同必要前后文一起读。当前证据支持有用参考即可构建，未确定部分保留缺口。后续材料只有改变结论或覆盖范围时才触发修订，不按读过几场来触发 build/rebuild。

场景切片未覆盖某次关键事件时，直接定位 full_text 或实际章节文件。以所需证据确定读取范围；没有切片、缺个人档案和关系尚未展开是三种不同情形，不能统一判为“角色信息不足”。按允许截止点读取，角色的未来结果不用于解释早期快照。

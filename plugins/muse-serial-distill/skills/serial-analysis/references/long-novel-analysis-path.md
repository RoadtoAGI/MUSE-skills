# 长篇导航与定向阅读

全文超出当前上下文时，先提取章节标题，保留原序与允许分析的截止点。按卷或可容纳的章窗口读入，将已读范围、每章主要事件、出场角色和未决问题写入 navigation 与 segments。参考 [导航模板](navigation-template.md) 的信息用途，窗口数随作品调整。

不同分析问题需要不同来源：

| 问题 | 定向阅读 |
|---|---|
| 前提与价值 | 允许范围内的开端及会改变当前解释的后续事件 |
| 世界约束 | 规则首次出现、实际生效、例外或冲突所在章；早期说明不自动覆盖后期变化 |
| 人物 | 重要选择、关系差异、声音情境及足以反驳已有概括的段落 |
| 脊椎与结构 | 激励事件、卷内重大变化及其前后因果；未完结部分保留开放问题 |
| 场景与手艺 | 相关场景原文及必要上下文，区分事件顺序与呈现顺序 |

摘要用于定位。涉及绝对边界、角色获知、世界上限和因果解释时回读原文；压缩摘要遗漏的信息不能据此认定不存在。每批用已有分析与未决问题接续，不额外建立检查点报告。

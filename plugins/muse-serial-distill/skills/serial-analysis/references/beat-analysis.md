# 连载结构与节拍分析

《故事》第二章将节拍描述为动作/反应中行为的交替，并区分场景、序列、幕与故事的变化尺度。这个层级帮助分析不同范围的作用：一次交涉中的策略变化、若干场景形成的局部结果、改变主要处境的重大逆转，分别需要不同粒度的证据。

MUSE 将长篇中持续展开的一段叙事称为 Arc，这是项目分析单位。Arc 可对应原作一卷、几卷或一卷内的部分；章节是发表单元，可能容纳多场景，也可能在场景中间结束。不能仅按章数把章节群等同于序列、把卷等同于幕。

从已有导航定位重大变化，回到前后原文确认：发生了什么变化，哪些事件促成它，哪些问题继续开放。边界由相对独立的问题与结果支持；三幕分析适用时可记录建置、对抗、解决，不适用时按实际结构说明。当前未完结 Arc 记已发生部分和开放问题，不补足结局。

麦基以逐级增强的冲击力说明经典故事的积累方式。连载中局部回落、稳定日常、并行推进也可能有明确作用；分析应说明它如何改变预期、关系、认识或节奏，不要求每卷比上一卷规模更大。正在连载的最新卷不能被当成全书最终高潮。

Phase 3 记录 Arc 框架，Phase 4 展开其序列，Phase 5 选择有用场景。字段契约统一见 [分析框架](analysis-schema.md)，本文件不另给一套 Arc schema。进入手艺标注时，再按需要分析场景内部节拍。

多线结构需区分实际因果与呈现：A 线结果改变 B 线条件时记录联系；并列展示产生对照时记录对照。按篇章相邻连接的箭头不构成因果证据。

## 场内节拍与价值变化

先追踪人物正对谁做什么、怎样理解回应，以及回应使下一步发生了什么变化。同一策略下的追问、解释和重申可以延续一拍；接受、试探、退让或重新解释若改变了行为关系，再据前后原文划出新拍。换人说话、另起一段或情绪加强本身都不足以确定边界。自我质疑也可形成动作与反应：人物提出解释，遇到反证后改换理解或办法；同一个说话者可以完成这种交替。

合作交流按回应的后果分析。例如，一人先承认小失误，对方说明自己也遇到过类似处境，前者因而愿意说出原先隐瞒的顾虑；相互接纳让表达范围和信任程度发生变化。若多轮交流仍在共同确认同一件事，可作为一拍内的展开；若回应使人从寻求安慰转向请求共同承担，则有了新的行为关系。标注写出促成变化的回应，保留交流逐步形成的过程。

比较价值时确定人物、维度与时间范围，再描述起点和终点。同一场可以两人更加亲近，同时一方因承诺减少了离开的自由；两项变化分别保留。关系从谨慎信任变成愿意托付虽未跨越正负，也会改变后续选择。一次临时让步与长期权力关系的改变具有不同范围；由原文说明其持续到哪里。`value_start / value_end` 的现有文字可承载这些复合结果，场内微小波动在手艺标注中解释，无须为每拍强配价值翻转。

场景级判断回看这些局部行为共同形成了什么处境，以及删除后损失了什么独立或累积作用。等待、观察和余波可以延展认识、形成形象的历史或容纳结果的影响；若只重复已成立的信息且未增加作用，明确指出重复处及其上下文依据。

# 导航文档模板

下列结构承载导航信息；已有文件可沿用，原作不适用的栏目省略。

```markdown
# 《书名》导航

## 基本信息
- 实际已读章范围与截止点：
- 原文标题与发布章 ID 对应（有 manifest 时）：
- 总章节数：
- 总字数：
- 题材：
- 语言：
- 时代背景：

## 章节摘要索引
第1章 标题 — 一句话摘要
第2章 标题 — 一句话摘要
...

## 角色表
### 主角
- 名字（首次出场章节，身份/职业）

### 对手/对抗力量
- 名字（首次出场章节，与主角关系）

### 重要配角
- 名字（首次出场章节，叙事功能）
- ...

## 主线时间轴
1. 事件A（第X章）— 简述
2. 事件B（第Y章）— 简述
...

## 结构标记
（只记原作实际成立的结构及定位，如触发事件、主要变化、支线收束或开放问题；不按三幕、中点模板补造节点。）

## 叙事特征备注
（记录分段阅读中发现的叙事特点：视角切换模式、时间线处理、独特技巧等）
```

# 副本世界卡（world-card）

实际副本需要独立材料时注册一册。原作事实、分析推演与本作采用决定分别标明。

## 硬约束表

| 项 | 内容及来源 |
|---|---|
| 世界来源 | 原创或外部来源作品、版本与范围 |
| fidelity | strict_canon / canon_flex / premise_only / setting_skin / host_shell；沿作者实际授权填写具体保留对象 |
| 世界规则 | 原作已经建立的条件 |
| 能力参照 | 有适用跨体系比较时填写，保留比较条件 |
| 原作节点 | 已采用保留事件线时填写，不将未来推演写成节点事实 |
| 主线作用 | 原文中已发生的主线联系；未来安排仅在作者明确时填写 |

## 素材库

（副本环境、场景质感与人物表达；不凭档名推断采用权限。）

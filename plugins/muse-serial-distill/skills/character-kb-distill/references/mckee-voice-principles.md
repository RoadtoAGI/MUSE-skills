# 连载人物提炼判据

《故事》第八章写道：“对许多故事或类型而言，这便已经足够了”，随后说明激励事件引起自觉欲望并驱动行动的机制；同章以邦德说明只有自觉欲望也能成立；不自觉欲望是有依据时才识别的另一种追求。角色已清楚表明并持续执行的目标，不能仅因它重要或高尚就改名为“不自觉需要”。

《故事》第五章指出，人物性格真相在人处于压力之下做出选择时得到揭示。提炼时记录代价、可选行动和实际选择。一次为朋友担责支持该次关系中的取舍；面对家人受威胁时犹疑，要求修正“任何情况下绝不妥协”的概括。坚定选择和后来犹疑可以同时保留，不按模板消去其中一方。

《故事》第十七章以“维是指矛盾”并要求“这些矛盾必须是连贯一致的”解释人物维度。它供识别确有矛盾的角色；MUSE 也接受立场稳定、由处境与关系展开的连载人物，这是项目创作选择。稳定不等于信息不足，未发生转变也不等于缺少弧光字段。

卷级快照与 persona 的来源截止章是项目对连载时间的实现：人物判断只能使用该时点已发生的证据。最早人格基线与后续变化分存，extends 保留快照继承关系，两类产物各自用 through_chapter 限定来源范围。基线证据稀少时保留其已有内容；为补足画像而引入后卷的身份、知识或关系，会改变早期执行者可作的判断。后卷证实的联盟留在后卷；前卷已成立的婚姻照实保留。判别依据是事件发生与角色获知的时点。

声音应联系对象、场合、身份和压力。措辞变短可能来自紧迫，也可能只是一次回答无需展开；有跨情境证据时才概括为稳定习惯。没有对白证据可以不写声音变化，直接坦白有实际沟通作用时照实记录。

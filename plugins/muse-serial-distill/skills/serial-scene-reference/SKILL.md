# 连载场景与范式参考

命令中的 `${CLAUDE_PLUGIN_ROOT}` 以本技能所属包的实际安装根替换；Claude 插件可用宿主提供的该变量。其他宿主从当前技能位置定位包根。

先确认目标作品、来源作品、用途，以及创作可见的截止章。对同作前文，事实与名称可用于延续；对其他作品，迁移的是机制及适用条件，人物、情节和表述由当前作品重新组织。相似标签不证明同一种机制适用。

## 同作场景检索

创作调用提供本作 KB 目录、实际 `published/manifest.yaml` 与最后允许读取的发布序。写下一章时截止于此前已发布章；改写旧章时截止由任务指定，不能默认取最新发布章。没有截止点或无法定位发布册时，返回所缺输入并继续不依赖参考的工作，不全量读取剧情。

**在读取场景描述前执行**：

```bash
python3 ${CLAUDE_PLUGIN_ROOT}/scripts/select_references.py \
  --index <本作KB>/scene_index.json \
  --manifest <本作工作区>/published/manifest.yaml --through-seq <截止发布序>
```

脚本先以 manifest 的 published_seq 真值核对 source_chapters，再输出范围内元数据。跨章切片以覆盖的最后章为上界；旧索引仅有单章标题时，可在程序内用发布文件标题唯一核对。无法确定范围的条目略过，不相信未核对的旧 published_seq，也不把其描述交给模型。

在筛选结果中按本场问题选择少量适用片段，Read 对应 `file` 原文，说明它能支持的事实或手艺。延续文风时需要原文；只查“某人何时知道某事”时可交付定位与关键上下文，不强制读长篇全文。索引不存在或无适用条目时说明无可用参考。

同作呼应可以复现事实、物件或有意使用的短语，但需承担本场作用；不机械复制整段或要求复用原场动作。前文角色知道的事实不等于所有角色都知道，调用方仍按视角与获知渠道选择。

## 开卷范式

按问题读取 `serial-paradigms/` 中适用的卷结构、钩子采样、力量演化、节奏形态或类型坐标。描述性结果不是下一卷的固定数量、顺序或节奏要求；需要理解转折为何生效，才能判断是否迁移。

来源为本作时，先核对卡片的 source 范围或章锚，聚合卡覆盖截止点之后的内容则不用它作当前创作输入，改用已过滤场景。来源为其他作品时按当前授权阅读，其事实不进入本作历史。调用方明确作品与用途，不能把所有范式一概当作无时序限制的他作参考。

## 独立研究

用户明确研究全书时可读取全量索引，结果标明覆盖范围与来源章。不把研究模式的全量材料自动送入受截止点约束的续写任务。

本包以结构化索引检索即可运行；可选标注和向量工具属于其扩展能力，文件存在不表示已加载或适用。

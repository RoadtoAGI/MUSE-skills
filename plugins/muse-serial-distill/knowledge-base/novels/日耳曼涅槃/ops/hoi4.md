HOI4 中的瑞典滚珠轴承与瑞士机床
一、瑞典滚珠轴承(Arms Against Tyranny DLC,1.13)
这不是一个静态国家精神,而是一套决议 + 事件机制:瑞典花 30 政治点(每 50 天可发起一次)向任一大国发起轴承贸易谈判,对方接受后双方各拿一份 buff,持续到开战或主动撤销为止。

合作方(英/美/德等大国)拿到的数值——三种合同的装备折扣部分完全相同,全部带 instant = yes(对已开工生产线立即生效,无需重新磨合):

修正	数值
小型机体(战斗机)生产费用	−8%
中型机体生产费用	−6%
大型机体生产费用	−5%
轻型坦克底盘生产费用	−8%
中型坦克底盘生产费用	−6%
重型坦克底盘生产费用	−5%
瑞典自己拿到的,取决于谈判时三选一:

合同	瑞典所得	合作方额外代价
军事专长	陆/空/海军经验各 +20(共 60)	陆/空/海经验各 −20
粮食换轴承	每笔叠加:稳定度 +2%、周人力 +15	消费品工厂 +5%
知识换轴承	一次性 25% 研究加成,四选一(脚本实际类别:步兵武器 / 雷达 / 合成资源 / 海军装备)	研究速度 −2%
对玩家的强度在于:装备折扣可以和每个大国分别签,坦克/飞机 5–8% 的 IC 折扣约等于凭空多出同比例军工产能,而且瑞典这边几乎零成本;粮食合同的稳定度和人力是无限叠加的。

二、瑞士机床(By Blood Alone DLC,1.12)
社区叫它"瑞士机床",游戏内正式名称其实是国家精神 "Importing war production from Switzerland"(从瑞士进口军火,SWI_trading_with_switzerland_military)。瑞士通过国策(对德贸易协定 / 对同盟国贸易)向邻近大国发起,对方在事件中二选一:

军工合同("机床"本体):

修正	数值
生产效率上限	+10%
生产效率增长	+5%
资源短缺惩罚	−5%
民用合同(另一选项):消费品工厂 −15%、建造速度 +10%。

瑞士自己拿到的:SWI_active_trade_agreement,消费品工厂 −15%。协议每 12 个月触发一次续约检查事件,瑞士也可以提前毁约。

之所以被称作"机床":生产效率上限 +10% 与整条"机床科技线"(基础/改良/先进机床,每级 +10% 效率上限)是同一个修正条目——签一份瑞士合同等于白送一整级机床科技,对德国这种开局就要爆坦克飞机的国家,效率上限从 50 拉到 60 意味着长期产出直接多约 10%。

三、史实技术优势:相对英美德强在哪
游戏数值其实是对史实相当精准的翻译。

瑞典 SKF(斯凯孚)

技术源头:现代自调心球轴承就是 SKF 创始人 Sven Wingquist 1907 年发明的;SKF 自有 Hofors 钢厂,用瑞典低磷铁矿冶炼的轴承钢纯净度高、疲劳寿命长——这是英美德同行难以复制的原料级优势。
规模与网络:战前 SKF 是全球最大轴承集团,德国施韦因富特的 VKF、美国费城的 SKF Industries、英国卢顿的 Skefko 都是它的子公司——也就是说,美军 1943 年两次血洗施韦因富特(10 月 14 日"黑色星期四",291 架 B-17 损失 60 架)炸的相当一部分是 SKF 自家资产。施韦因富特集中了德国约一半轴承产能,被炸后德国转头加大从瑞典本土进口——这正是游戏里"向任一大国出售轴承"机制的原型。
相对英美德:美国有 Timken(圆锥滚子)、New Departure,英国有 Hoffmann、Ransome & Marles,德国有 FAG,都能造轴承;瑞典的优势在高精度特种规格和战时弹性供给。英国甚至专门用 BOAC 的蚊式快速运输机穿越德军封锁的斯卡格拉克海峡,从斯德哥尔摩往回抢运 SKF 轴承——为几吨货冒截击风险,足见其不可替代性。游戏里把它做成坦克/飞机 IC 折扣很贴切:轴承装在每一个轮毂、发动机、变速箱和炮塔座圈里,是典型的"小体积、卡脖子"部件。
瑞士精密机床

精度天花板:瑞士强项不在通用机床产量,而在"制造机器的机器"的精度上限——日内瓦 SIP 的坐标镗床(微米级定位,战前全球工具间的黄金标准,英美德都进口)、Le Locle 的 Dixi、Moutier 的 Tornos/Bechler 走心式自动车床(小型精密旋削件至今英文仍叫 "Swiss lathe",技术优势直接化石在语言里)、苏黎世 Maag 的磨齿机。引信部件、量规、夹具这些决定大规模生产精度上限的东西,高度依赖这一类设备。
武器设计输出:二战双方海军的标准 20mm 高炮都源自瑞士系设计——盟军用的厄利孔(Oerlikon)本身就是苏黎世的公司,英国战斗机的希斯帕诺机炮出自日内瓦设计。
相对英美德:论产量,美国机床工业(辛辛那提、Kearney & Trecker 等)是碾压性的世界第一,德国拥有欧洲最大的机床保有量,英国产能吃紧要靠租借法案进口;瑞士的生态位是超精密小众设备 + 中立国供应商。1941–43 年瑞士机床和军工产品出口大头流向德国(清算贸易协定),直到 1945 年初盟军的 Currie 协定才切断。游戏把它做成"生产效率上限 +10%"同样精准:精密机床决定的不是你有多少工厂,而是你的生产线能磨合到多高的效率。
一句话总结:两国的共同点是"中立国 + 谁都可以买",差异在作用位置——瑞典轴承是部件级优势(直接降低每辆坦克/每架飞机的工时),瑞士机床是工艺级优势(抬高整条生产线的效率天花板),HOI4 的建模分别用 build_cost_ic 折扣和 production_efficiency_cap 精确对应了这一点。

数值口径说明:以上取自游戏文件镜像(1.13+ 时代脚本),与当前最新补丁可能有小幅平衡性出入,但机制结构未变。

## 四、德国增强 mod 调研:帝国雄心 / 黄粱一梦有无"占领后整合"机制

**结论:两个 mod 均查无此机制,原版也刻意不做。**

- **黄粱一梦:帝国回响**(EOR,工坊 id 3308201627,作者小辣条拉面):公开功能清单为"国策树翻倍 / 更多决议 / 更多民族精神 / 总督辖区 / 德国版权力平衡 / 共产与哈布斯堡路线"等,无任何瑞典轴承或瑞士机床**专属工业 buff** 条目。但该 mod 提供**"整合瑞士"与"整合专员辖区"两条核心化途径**(玩家实测口径)——德国可以借此获得瑞士及北欧专员辖区(含瑞典)领土的核心,只是核心化本身不附带轴承/机床主题的产业奖励。该 mod 已被 Steam 以违反社区守则**下架**(仅作者本人可见),镜像站只存有 2024-08 的旧版(id 3301320739)且下载被防护墙拦截,无法做文件级核查。
- **帝国雄心(重置/世界线,IWR)**(工坊 id 3206158781,作者成祖等,1.26 GB):官方特性清单全部是全局机制改动(100 建筑槽 / 军工生产线上限 300 / 消费品下限 0% / 每级基建资源产出翻倍等)与苏意美中大国线,同样没有两国工业整合的记载。
- **原版行为**(含诸神黄昏德国重做后):瑞典 `SWE_ball_bearing_idea*` 与瑞士 `SWI_trading_with_switzerland_*` 均带 `cancel = { has_war_with = SWE/SWI }`——对两国宣战的瞬间 buff 永久消失,征服后**没有任何替代获取途径**。原版的设计哲学是"这两笔买卖只留给和平":奶牛只能挤奶,不能宰。

## 五、自设计:「北欧钢与阿尔卑斯精度」占领整合机制

> 适用前提(按题设):两国领土被德国控制、且已停止抵抗。设计锚定 §一、§二 的原版数值口径,可直接落进任何德国增强 mod。

### 5.0 设计目标

1. **起步即全额**:贸易版拿到的只是有限的出口配额(史实上瑞典对德轴承出口受战时贸易协定配额与盟军施压双重限制,1944 年被迫削减直至停供);占领后独占两地全部产能,不存在配额——所以军管档的 buff 直接 = 贸易版全额。占领的代价由原版驻军/抵抗系统承担,不再额外叠消费品惩罚。
2. **决议链递进**:军管(=贸易版)→ 产业整合(投资民工厂 + 经营顺从度)→ 数值**超越**贸易版。
3. **核心化终局**:拿到两地核心(吞并 + mod 核心化国策)后解锁最强档——"厂房、工艺、人"三者都归你,才配吃满终局数值。
4. **风险保留**:核心化之前,抵抗回升 / 失地 / 战略轰炸仍会降档。占领线是高投入高回报,贸易线仍是零成本低回报的懒人选项,二者构成真实的战略取舍而非上下位替代。
5. **和平接收等效(瑞典专属)**:瑞典若成为德国附庸(外交/国策和平取得),同样**完整获得**滚珠轴承 buff 且无任何占领风险——产业无损、技师留任、出口配额由宗主独占分配。战争不是唯一钥匙,而且对瑞典而言往往是更差的钥匙。

### 5.1 瑞典线「斯凯孚接管」(决议类别 `GER_skf_integration_cat`)

**三档民族精神(`swap_ideas` 链)**

| 修正 | 档1 军管的轴承产业<br>`GER_skf_seized` | 档2 整合的轴承托拉斯<br>`GER_skf_integrated` | 档3 帝国轴承工业<br>`GER_skf_reich` |
|---|---|---|---|
| 飞机机体生产费用(小/中/大) | −8% / −6% / −5%(=贸易版) | −10% / −8% / −6% | **−12% / −10% / −8%** |
| 坦克底盘生产费用(轻/中/重) | −8% / −6% / −5%(=贸易版) | −10% / −8% / −6% | **−12% / −10% / −8%** |
| 生产效率增长 | — | +5% | **+10%** |
| 稳定度 | — | — | +2%(轴承钢配套就业) |

**档1 决议「军管哥德堡轴承工厂」**
- 可见:瑞典已投降或被吞并;德国控制哥德堡所在州
- 可用:该州抵抗度 < 10%(题设的"停止抵抗")
- 成本:50 政治点,执行 90 天(清点设备、甄别技术骨干、复产)→ 获得 `GER_skf_seized`

**附庸路径(和平接收,替代档1)**
- 条件:瑞典是德国附庸(任意自治等级)。瑞典附庸的瞬间,自动获得民族精神**「王国的轴承供应」**(`GER_skf_vassal`),数值 = 档1(即贸易版全额),同时移除市面上所有其他大国的瑞典轴承贸易 idea——附庸的出口由宗主独占分配
- 特性:**无抵抗/轰炸降档风险**(哥德堡不是占领区);瑞典保持存在并照常运转
- 升级衔接:后续通过自治度归零**和平吞并**瑞典时,跳过档1/免军管,以**折扣成本**(4 座民用工厂 + 90 天,原价 8 座 + 180 天)直接执行档2 决议——产业无损、供应链不需要"重建",只需要对接;档3 照常要求核心化
- 设计理由:历史上瑞典对德经济依赖极深(铁矿石/煤炭/贸易航路全在德国手里),和平附庸是比 Tannenbaum 式入侵合理得多的取得方式,机制上应当奖励而非惩罚不流血的玩家

**档2 决议「扩建帝国轴承厂」**
- 前置:档1 已获得;瑞典全境平均顺从度 ≥ 40%
- 成本:8 座民用工厂场外投入,执行 180 天——投入语义是**本土扩建**:按 SKF 工艺规程在施韦因富特、埃尔克纳、坎施塔特扩建轴承厂房,霍福斯轴承钢直供本土新厂;哥德堡转为技术母厂与工艺规程源 → 升级为 `GER_skf_integrated`
- 数值合理性:超越贸易版的增量(−10/−8/−6 与效率增长 +5%)来自**本土新增产能**,而非占领区存量——这也是它比档1 更抗轰炸叙事的原因(产能不再单点集中于哥德堡)

**档3 决议「组建帝国轴承工业」**
- 前置:档2 已获得;**哥德堡所在州及瑞典全部工业州已是德国核心**;顺从度机制随核心化自然消失
- 核心来源:黄粱一梦可走**「整合专员辖区」**(瑞典属北欧专员辖区);其他 mod 用各自的核心化国策/决议对接
- 成本:100 政治点,执行 120 天——语义:本土厂群(施韦因富特/埃尔克纳/坎施塔特/莱比锡)与哥德堡母厂合并为统一的**帝国轴承托拉斯**,技术标准、钢材配额、人员调配全帝国一体化 → 升级为 `GER_skf_reich`
- 完成时一次性奖励:25% 研究加成 ×1(工业类,吸收 SKF 研究院)+ 陆/空军经验各 +20(原版瑞典侧收益的合并——现在两侧都是你)

**维护风险(核心化前,每月检查)**
- 哥德堡州失守、或瑞典抵抗度回升 > 25% → 降一档,并触发事件「哥德堡怠工」:军工产出 −10%,持续 90 天
- 哥德堡州建筑受战略轰炸损伤 ≥ 50% → 同样降一档(施韦因富特的镜像:盟军现在有理由来炸你的"新施韦因富特")
- 档3(核心化后)不再降档,仅在失去州控制时整体 cancel

### 5.2 瑞士线「阿尔卑斯精度」(决议类别 `GER_swiss_precision_cat`)

**三档民族精神**

| 修正 | 档1 征用的精密工业<br>`GER_swiss_seized` | 档2 整合的精密机床体系<br>`GER_swiss_integrated` | 档3 帝国精密工业<br>`GER_swiss_reich` |
|---|---|---|---|
| 生产效率上限 | +10%(=贸易版) | +15% | **+20%** |
| 生产效率增长 | +5%(=贸易版) | +5% | **+10%** |
| 资源短缺惩罚 | −5%(=贸易版) | −5% | **−7.5%** |
| 民转军工厂改造费用 | — | −10% | **−15%** |
| 研究速度 | — | — | +2%(精密仪器反哺全科研) |

**档1 决议「征用瑞士精密工业」**
- 可见:瑞士已投降或被吞并;德国控制苏黎世、伯尔尼、日内瓦三州
- 可用:三州抵抗度均 < 10%
- 成本:50 政治点,执行 90 天 → 获得 `GER_swiss_seized`

**档2 决议「扩建帝国精密机床厂」**
- 前置:档1 已获得;瑞士全境平均顺从度 ≥ 40%
- 成本:10 座民用工厂场外投入,执行 120 天——投入语义是**本土扩建**:以 SIP 坐标镗床、Tornos 走心车床、Maag 磨齿机为"**母机**",在开姆尼茨、斯图加特扩建精密机床厂批量复制"子机",瑞士技师"自愿"签约驻厂带教 → 升级为 `GER_swiss_integrated`
- 数值合理性:效率上限从 +10% 抬到 +15% 的增量来自本土机床厂的新产出——精密机床开始装备帝国自己的生产线,而不再只是从瑞士按台进口

**档3 决议「组建帝国精密工业」**
- 前置:档2 已获得;**苏黎世/伯尔尼/日内瓦三州已是德国核心**
- 核心来源:黄粱一梦可走**「整合瑞士」**路线;该路线本身是和平/半和平取得,若瑞士未经战争直接被整合,允许跳过档1 从档2 起步(镜像瑞典附庸路径的逻辑)
- 成本:100 政治点,执行 120 天——语义:**母机国产化完成**——开姆尼茨/斯图加特的本土厂已能自行制造母机级精度的机床,日内瓦/苏黎世转为设计局与计量标准局,帝国不再依赖任何单一产地 → 升级为 `GER_swiss_reich`
- 完成时一次性奖励:25% 研究加成 ×2(可选类别:雷达 / 合成资源 / 海军装备 / 工业——原版瑞士侧从未有此收益,这是"日内瓦设计局归帝国所有"的终局体现)

**维护风险(核心化前)**
- 任一州抵抗度 > 25% → 降一档,并触发事件「精密设备遭蓄意损毁」:生产效率上限额外 −5%,持续 180 天
- 史实锚:瑞军"内堡垒"(Réduit)预案就是自毁隘口与工业设施——所以瑞士线民工厂投入(10 座)更贵、山地州顺从度爬得更慢、核心化门槛(mod 国策)理应设得比瑞典线更晚。

### 5.3 平衡表(占领线 vs 贸易线)

| 获取路径 | 前期成本 | 强度 | 独占性 | 风险 |
|---|---|---|---|---|
| 贸易(原版) | 30 PP + 一次事件 | 全额 | 无——瑞典/瑞士可同时卖给所有大国 | 开战即永久失去 |
| **附庸(瑞典专属,和平)** | 外交/国策附庸化,零战争 | =贸易版全额 | **独占**(宗主垄断出口分配) | 无;吞并后以折扣成本接入档2 |
| 占领·档1 军管 | 一场战争 + 50 PP + 90 天 | =贸易版全额 | **独占**(其他大国的同款 idea 因对瑞开战/瑞士灭亡而消失) | 抵抗 / 失地 / 轰炸降档 |
| 占领·档2 整合 | +8~10 民用工厂 + 半年 + 顺从度 ≥40%(和平接收路径折半) | 超越贸易版约 25% | 独占 | 同上 |
| 占领·档3 核心化 | 吞并 + 核心化(黄粱一梦:整合瑞士/整合专员辖区)+ 100 PP | 贸易版 ×1.5 + 研究/经验一次性奖励 | 独占且不可逆 | 仅失地 cancel |

一句话:贸易线是"零成本吃配额",占领线是"用一场战争 + 半个占领治理体系换独占与成长"。档1 与贸易版同额的合理性在于**独占**——你拿到的同时,对手永远失去;档2/档3 的增量则是"配额之外的全部产能 + 工艺 + 人"逐步归你的过程。

## 归类说明(三处非直觉判定)

- **罗斯福 → adversaries**:故事时点(1940.10 断章)美国仍是中立国,但其叙事功能是被希特勒具名的终局血仇对象(第263→537章),按功能归对手;档内文首有归类注。
- **老齐亚诺 → allies-and-neutrals**:虽是方彦岳父,其全部戏份都是意大利同盟线的人格化接口(海军副部长/墨索里尼密友),按叙事功能归盟友类,不入家族类。
- **群像不分阵营**:该类收"作者切到基层/民间的视角窗口"(德国工人家庭、英国水兵、潜艇艇长),标准是叙事功能(临场感/民意采样/败者视角),不是国籍。

## 体例约定

- 每档 25-55 行;断言必须锚定 `第N章`(或 `full_text.md` 行号)或 `scenes/scene_XX.md`;证据不足的断言弃写。
- 历史人物必含「历史原型差异(改动/保留/目的)」节——本作对史实的改写决策是画像的核心信息。
- 已有蒸馏包的角色(方彦 · 希特勒 · 西尔维娅 · 琳娜 · 雷德尔)画像为**互补档**:不复述 SKILL.md 六段内容,聚焦原型差异/设计决策/叙事功能,文首指针行指向对应 slug 包。
- 系统级信息(角色间关系/对比轴/权力动态)的 SSOT 是 `pipeline/phase2_character.yaml`,画像只记个体级,不重复。

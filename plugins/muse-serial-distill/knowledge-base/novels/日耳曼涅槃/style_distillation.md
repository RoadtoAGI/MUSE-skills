# 《日耳曼涅槃》文风蒸馏 SSOT

## 1. 元数据与证据范围

- 作品：幽冷秋月《日耳曼涅槃》，中文，538 章未完结连载。
- 适用包：`MUSE-serial-distill` 的续写、派生、审校与 dispatch；`MUSE-canon-distill` 仅通过指针引用本文件。
- 权威等级：本文件是全文文风蒸馏的唯一 SSOT；`style_card.yaml` 是短卡，不能替代本文件。
- 证据范围：`style_card.yaml`、`serial-paradigms/*.yaml`、`segments/*_summary.md`、代表性 `scenes/`、`craft_notes/` 与 `full_text.md` 抽样。
- 证据纪律：锚点只证明明确写出的语言或结构事实；分析性判断须能由至少一个场景或跨章范式回验。

## 2. 稳定文风七维

### 2.1 叙事距离

全知军政史观为总镜头：可从人物有限感知抬升到制度、装备和国际格局，但战斗内部按决策层、操作层、敌方、余波层分层锁定，各层只交付其可见信息。不是持续贴身沉浸，也不是无人称编年史。

### 2.2 句法节奏

常态用长复句、枚举和因果推演铺底；关键动作以短句、口令、拟声或格式化报数提速。基本呼吸是“解释长段 → 爆发短段 → 结果结算”，高潮常依靠较长静态建置获得冲击力。

### 2.3 词汇质地

雅化、略旧式的中文叙述与军史术语、工程参数、制度词并置。允许鲜明的兴亡判断和高调四字词，但价值判断必须有事实、数据或因果支撑。

### 2.4 修辞密度

总体中等：解释与运营段压低修辞，以数字、流程和因果为骨架；战斗爆点集中释放拟声、灾难意象和四字夸饰，随后立刻回到战果与损耗。修辞不得连续空转。

### 2.5 对白

对白主要承担试探、宣言、论证、命令和战术信息。家庭对白可以柔软口语化，但会重新接回事业或政军困局；政治人物常以礼节、停顿、冷淡动作和态度温度显影，不必把可推知的冲突写成长篇辩论。

### 2.6 信息释放

先交代制度、舰队、技术或历史量尺，再让人物行动验证判断。数字既说明性能，也制造倒计时、压服感、代价账本和反讽。结果已可推知时，可省略正面对峙，把篇幅让给事前规则推演与事后价值结算。

### 2.7 转场

主要靠视角轮换、时间地点硬标、听觉或动作铰链转场。大战后由前线切敌国决策席，再落政治或家庭余波；回气主要靠视角换挡，而非跳过后果。

## 3. 合法变化矩阵

| 场景模式 | 可合法变化 | 必备落点 |
|---|---|---|
| 战争 | 短句、硬动词、拟声和多视角轮切增加；爆点修辞升高 | 参数/流程/损管/战果至少一项；爆点前有态势建置，爆点后有结果结算 |
| 工业运营 | 显著降速；可长段说明资本、工时、产能、组织接口和兑现周期 | “约束 → 决策 → 周期 → 战略后果”因果闭环，不能写成无摩擦科技树 |
| 家庭 | 镜头贴近身体、用品、微表情；对白较短、较软 | 私域必须承接事业压力，或产出能返回政军主线的方案、代价与动机 |
| 政治会议 | 感官描写减少；论证、数据、利益和规则推演增加；可省略正面对峙 | 立场由权力利益、制度位置和历史经验驱动，结尾落到决定、态度温度或权力位移 |

## 4. 不可漂移不变量

1. 高位历史判断、可核算硬信息、人物行动兑现三者必须形成闭环。
2. 私人情绪须能迅速接入国家战略、制度压力或历史分歧。
3. 技术优势必须有工业、时间、数量、政治或训练限制，不能凭空兑现。
4. 敌方不能只是纸片靶；至少保留其信息、制度或战术逻辑。
5. 战斗奇观必须兑换成明确的命中、损伤、消耗、阵位或决策后果。
6. 大胜后必须补入代价、敌方适应、政治反噬或更大的外部时钟。
7. 长段说明必须服务当前悬念、量尺或后续行动，不能成为独立百科插页。

## 5. Reference reuse 分类

| 分类 | 可复用对象 | 操作边界 |
|---|---|---|
| `literal_reuse` | 时间、地点、军衔、型号、口径、航速、吨位、编制等事实字段；格式化军情报数的字段顺序 | 仅在当前情节真值一致时逐字；不得整段搬运参数说明、对白或独特句式 |
| `normalized_reuse` | 长复句因果链、军史枚举结构、数字单位、通用四字节奏、抽取文本的标点与断词 | 保留信息顺序、节奏功能和修辞强度；修复错字、单位、标点、重复虚词和污染 |
| `semantic_reuse` | 独特比喻、章末战书、演说宣言、情绪炸弹、标志性对白、完整奇观和挽歌式判断 | 只抽机制；必须换场景、意象、措辞和具体动作，禁止近义改写式搬运 |

## 6. 最小归一操作

1. 统一中文全角引号、破折号、省略号和段首格式。
2. 修复 OCR/抽取错字、断词、漏字与异常数字量级；装备参数回源核对。
3. 统一数字和单位写法，但保留数字密集形成压服感的功能。
4. 删除求票、广告、网址、作者运营尾巴等非正文污染。
5. 删去无信息增量的同义复述，但不得把长复句普遍短句化。
6. 网络俚语只在原作调侃档保留，正式军政段不得扩散。
7. 亲密段可收束物化词和同义艳词堆叠，但保留其与政治重压的温差功能。

## 7. Derivative 四模式（运行时 `reuse_mode`）

| 模式 | 目标 | 允许 | 禁止 |
|---|---|---|---|
| `fan_fiction` | 在原作世界与既有人物关系内扩写新事件 | 保持全知军政史观、参数密度、角色声线和历史分歧；新增内容须服从既有工业与政治限制 | 把愿望性推断写成正史；照搬原作独特对白、宣言或战斗奇观 |
| `sequel` | 从现有断章继续主时间线 | 承接前章参数、未结钩子、态度温度、对英终局与反纳粹等连续性债务；风格归一以无缝续接为上限 | 重置装备、权力关系或人物立场；用新卷开场跳过既有代价和外部时钟 |
| `spin_off` | 以配角、敌方或支线时空独立展开 | 可调整主视角和局部语域，但仍保持“硬信息 → 决策 → 后果”闭环；优先利用敌方制度逻辑和有限视角信息差 | 把配角写成主角知识副本；因脱离主线而取消技术、工业和政治约束 |
| `cross_style_rewrite` | 将既有内容重写为指定目标风格 | 保留原作事实、因果、价值位移和参数功能；先执行最小归一，再按目标风格调整表层句法与修辞 | 把目标风格改写误当设定改写；删去参数骨架、代价结算或把分析推断升级为事实 |

以上四项只定义运行时派生用途；第 5 节的 `literal_reuse`、`normalized_reuse`、`semantic_reuse` 是独立的 reference 复用分类，不得作为 `reuse_mode` 值或与四模式互相替代。

## 8. Serial 章际连续性信号

- 战争期单元保持“临战盘点 → 多视角连击 → 战果结算 → 政治/家庭回气”。
- 和平期保持“技术/政治里程碑 → 家族商业与人事经营快进”。
- 当前冲突外始终悬着更大的债；军备、美国时钟、反纳粹暗线可轮换滴灌。
- 前章投放的吨位、航程、工期、损耗和限制，后章必须兑现、更新或解释失效。
- 前线高潮后切对手决策席，再落政治或家庭余波；不能直接跳过后果。
- 强钩只用于结构拍点或战役拍点；日常章允许惯性平收。
- 大胜后的章群必须出现伤亡、消耗、敌方学习、政治膨胀或私人亏欠之一。
- 知识、资本、政治、军备、战略话语权每次升级时，必须同步显影限制或道德负债。

## 9. 机器约束 YAML

```yaml
style_constraints:
  - id: GNS-01
    rule: 每个军政或工业解释单元至少包含一条可验证硬信息，并连接到决策或后果。
  - id: GNS-02
    rule: 连续纯背景说明最多三个自然段，其后必须由动作、对白、决定或价值判断兑现。
  - id: GNS-03
    rule: 战斗爆点段与原理解说段分开；爆点段最多插入一句技术解释。
  - id: GNS-04
    rule: 战斗奇观出现后两个自然段内，必须结算命中、损伤、伤亡、弹耗或阵位变化之一。
  - id: GNS-05
    rule: 重大冲突至少呈现两个信息海拔；有限视角不得无依据获知全局。
  - id: GNS-06
    rule: 家庭场景结束前必须与事业、战争、政治风险或后续行动建立可见连接。
  - id: GNS-07
    rule: 政治关键发言至少携带利益、数据、制度位置或历史先例之一，不得只表达情绪。
  - id: GNS-08
    rule: 连续两个高修辞段后必须回到动作、数据、流程或结果。
  - id: GNS-09
    rule: 章末强钩不得连续机械使用；日常章允许平收，结构拍点和战役拍点才启用强钩。
  - id: GNS-10
    rule: 每次大胜后的章群必须出现代价、对手适应、政治反噬或更大外部时钟之一。
  - id: GNS-11
    rule: 新技术或新杠杆登场时，必须同时说明至少一项兑现限制。
  - id: GNS-12
    rule: 独特比喻、宣言、标志对白和完整奇观只允许 semantic_reuse。
```

## 10. Dispatch 注入

派发写作任务时，最少注入以下字段；不得只注入 `style_card.yaml`：

```yaml
style_dispatch:
  ssot: MUSE-serial-distill/knowledge-base/novels/日耳曼涅槃/style_distillation.md
  reuse_mode: sequel
  reuse_mode_allowed: [fan_fiction, sequel, spin_off, cross_style_rewrite]
  scene_mode: war
  scene_mode_allowed: [war, industrial_operations, family, political_meeting]
  evidence_scope: [chapter_span, relevant_scenes, relevant_serial_paradigms]
  reuse_policy: normalized_reuse
  reuse_policy_allowed: [literal_reuse, normalized_reuse, semantic_reuse]
  continuity_debts: []
  constraints: [GNS-01, GNS-03, GNS-04, GNS-05, GNS-10, GNS-11]
```

执行者须在正文前确认 `reuse_mode` 和 `scene_mode`；跨场景模式时应声明主模式与次模式，但每次 dispatch 只能选择一个合法 `reuse_mode`。续写任务还须注入前章硬参数、未结钩子、人物态度温度与待偿代价。

## 11. 回执分类

| 回执 | 含义 | 最低证据 |
|---|---|---|
| `PASS` | 风格约束与章际连续性均满足 | 命中的约束 ID、关键参数与连续性债务结算 |
| `PASS_WITH_NORMALIZATION` | 仅有可机械归一的问题，已修复 | 修复项与原位置，不改变叙事功能的说明 |
| `STYLE_DRIFT` | 叙事距离、声调、节奏或场景模式发生漂移 | 漂移段、违反的约束 ID、建议修复方向 |
| `CONTINUITY_GAP` | 前章参数、限制、钩子或代价未承接 | 缺失信号及来源章 |
| `REUSE_VIOLATION` | 超出 literal/normalized/semantic 边界 | 被复用对象、错误分类、要求的降级方式 |
| `EVIDENCE_GAP` | 无法由现有正文或知识包确认 | 待核问题；不得自行补成事实 |

## 12. 验收 checklist

- [ ] 已声明合法 `reuse_mode` 和主/次场景模式。
- [ ] 硬信息与行动后果形成闭环。
- [ ] 叙事海拔切换有视角依据，没有有限视角越权。
- [ ] 战斗爆点与技术解释分段，且完成结果结算。
- [ ] 工业运营存在资源、周期或制度限制。
- [ ] 家庭段重新接回公共压力或后续行动。
- [ ] 政治立场由利益、制度位置或历史经验驱动。
- [ ] 大胜后存在代价或更大时钟。
- [ ] reuse 分类正确，独特表达没有近义搬运。
- [ ] 章际参数、态度温度、钩子与连续性债务已核对。
- [ ] 只执行最小归一，没有把原作改写成另一种文风。
- [ ] 无法确认之处标为 `EVIDENCE_GAP`，未升级为设定事实。

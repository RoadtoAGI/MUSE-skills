# 连载拆解标注交接

本入口保留给仍使用旧名称的派发方。接收作品目录名、annotated_by、所需标注入口及增量或全量档位，沿用当前授权。

向派发方返回 **muse-canon-distill 包的 kb-annotator** 及已收到的动态参数，由派发方通过宿主可用的插件发现与 agent 机制直接调用目标标注员。该目标的 agent 定义、prepare 任务包与 ingest 脚本是标注工作流和字段契约的权威；共享灵感库的提名、聚类、索引由该包维护。本兼容入口完成交接后返回，避免嵌套派发和同名递归。

交接时提供准确的作品标识和已可用的来源位置。作品仅在连载库中、尚未进入 canon 库时，报告具体来源缺口，继续本包可完成的连载拆解与手艺标注；按当前授权处理资料入库，不假定两包共享物理目录。目标包或派发能力不可用时，保留标注未执行状态，返回缺少的能力。

canonical 标注员读取原作并记录具体构想、叙事理由、可迁移关系与条件，按任务包保留来源。兼容入口返回的是交接信息，标注执行结果由目标标注员提供。
